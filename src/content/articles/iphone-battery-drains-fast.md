朝は100%なのに、昼の時点で赤い。ポケットに入れたままなのに本体が熱く、パーセントだけ落ちている。充電器に置いて 80% で長く止まるときは、手順5の「最適化されたバッテリー充電」を見ます。

パーセントがそもそも増えない、ケーブルを替えても充電表示にならないときは [充電が遅い・始まらないときの切り分け](/articles/smartphone-charging-slow/) です。この記事は、充電は入るのに持ちが短いときです。

## 症状の見分け

- 画面をつけているあいだだけ、数分で数%落ちる
- 画面は消しているのに熱く、グラフの「バックグラウンド」が伸びている
- ステータスバーの位置情報の矢印が、マップを閉じてもしばらく消えない
- 低電力モードに入ったあと、急に暗くなり、取り込むメールが遅れる
- **バッテリーの状態** の最大容量が、購入時よりはっきり低い
- 80%付近で充電が止まり、朝になっても 100% にならない（これは持ちの短さではなく、充電の止め方）

どのアプリを開いても同じペースで減るなら明るさと自動ロック。特定のアプリの時間だけ減るなら、そのアプリです。置いているあいだに減るなら、バックグラウンドか電波です。

## よくある原因

1. 明るさが最大、自動ロックが「なし」のまま
2. 位置情報が「常に」のアプリが、画面オフ後も動いている
3. Appのバックグラウンド更新と、モバイルデータでの iCloud アップロード
4. インターネット共有（テザリング）をオンにしたままにしている
5. 圏外や1本の場所で、通信の再試行が続いている
6. 最大容量が下がっていて、同じ使い方でも減りが速い
7. 直射や布団の上で熱くなり、充電が止まったり減りが速く感じたりする

## 直す前に

- 残量 20% を切っているなら、充電につないでから設定を開く
- 「バッテリー修理」「サイクル矯正」を名乗るアプリは入れない。設定の **バッテリー** 以外は見なくてよい
- 膨張、異臭、充電口の焦げは、この先の設定では扱いません。充電を止めて、Apple か正規サービスへ

> **注意:** 本体を開けてのバッテリー交換と、完全放電を何度も繰り返す調整は、この記事の手順に入れていません。低電力モードを入れても、最大容量の数字は変わりません。減りが少し緩くなるだけです。

## 手順

### 1. 24時間の内訳で、画面か裏かを分ける

1. **設定** → **バッテリー**。
2. グラフを **最後の24時間** にする。画面を使った時間帯だけ落ちているか、消している時間も落ちているかを見る。
3. 下のアプリ一覧で、上に来ている名前をタップする。**画面オン** と **バックグラウンド** のどちらが長いか出ます。
4. 過去10日間に切り替えて、毎日同じアプリが先頭なら、そのアプリから手を付けます。

システム項目は、この一覧から消せません。時間の長いアプリを終了するか、位置情報を変えるか、どちらかに進みます。

### 2. 明るさと、自動ロック

1. **設定** → **画面表示と明るさ**。スライダーを、室内で読めるところまで下げる。
2. **自動ロック** を **30秒** か **1分** にする。「なし」だと、ポケットの中でも点きっぱなしになります。
3. iPhone 14 Pro 以降で **常にオン** がある機種は、待ち受けを常時点灯していると、その分減ります。試すならオフにして半日見る。
4. コントロールセンターの明るさは、**画面表示と明るさ** のスライダーと同じ一つです。どちらから下げても、もう一方も同じ位置です。

スライダーを動かしても明るさが変わらないときは、バッテリーの手順では足りません。画面側の不具合として、販売店へ持ち込みます。

### 3. 位置情報を「使用中」に戻す

1. **設定** → **プライバシーとセキュリティ** → **位置情報サービス**。
2. バッテリー一覧で長かったアプリを開き、**常に** になっていたら **使用中** にする。マップや家族の共有など、消すと困るものだけ **常に** を残す。
3. 精度そのものが地図でずれるときは、許可を切る前に [位置情報が不正確なとき](/articles/iphone-location-inaccurate/) を見てください。許可を「なし」にすると、そのアプリの現在地は使えなくなります。
4. いちばん下の **システムサービス** を開く。**よく使う項目** は提案用なので、減りを見るあいだはオフにしてよいです。
5. **緊急電話およびSOS** や **探す** は残します。

矢印が塗りつぶしのあいだは、何かが位置を使っています。アプリを全部「使用中」に戻したあと、ホーム画面で矢印が消えるかを見ます。

### 4. バックグラウンドと、インターネット共有

1. **設定** → **一般** → **Appのバックグラウンド更新**。減りを切り分けるあいだは **Wi-Fi** だけにするか、先頭だったアプリだけ個別にオフ。
2. **設定** → **モバイル通信** → **インターネット共有**（または **設定** → **個人用ホットスポット**）。「ほかの人が接続中」なら、テザリングが減りの原因です。使っていないならオフ。
3. **設定** → 自分の名前 → **iCloud** → **写真**。大きなライブラリをモバイルデータで上げていると、熱くなり、残量も落ちます。Wi-Fi がある場所までアップロードを待つ。
4. コントロールセンターで、画面収録のボタンが赤いままになっていないか見る。録りっぱなしは、減りも熱も速いです。

### 5. 低電力モードと、最大容量

1. **設定** → **バッテリー** → **低電力モード** をオンにする。コントロールセンターの電池アイコンからでも入れます。
2. オンのあいだは、自動ロックが短くなり、バックグラウンド更新が止まり、メールの取得が遅れます。昼まで持つかを、普段の明るさで見る。
3. 同じ画面の **バッテリーの状態と充電**（表記は iOS により **バッテリーの状態**）を開く。
4. **最大容量** の数字を見る。80% 前後まで落ちていると、設定を整えても、新品のころの持ちには戻りません。
5. **最適化されたバッテリー充電** がオンだと、80% でしばらく止まることがあります。これは劣化を遅らせる動きで、残量が勝手に減っている状態とは違います。朝までに 100% へしたい日だけ、オフにして様子を見る。

充電のパーセントが飛び飛び（40% の次が突然 10%）なら、設定の範囲を超えています。最大容量の画面を撮って、サポートへ渡します。

### 6. 電波と熱で、減りが加速していないか

1. 圏外や1本の場所に長くいると、つなぎ直しだけで減ります。その場所を離れてから、もう一度グラフを見る。
2. 切り分けで機内モードにするときは、必要な電話が無い時間に30分だけにする。緊急通報が要るあいだは、機内モードを切る。
3. 減りが止まるなら、通信か位置情報です。機内モードでも止まらないなら、電波はすでに切れているので、原因は明るさか本体です。
4. 布団、直射、厚いケースのまま充電すると熱くなります。ケースを外して冷ましてから、減り方を見比べる。

## まだ直らないとき

- 最大容量が低く、**サービス** やピークパフォーマンスの低下と出る → 設定では戻りません。Apple または正規サービス。自分で開けない
- 画面オフでも特定アプリのバックグラウンドだけ長い → そのアプリを一度終了し、位置情報を「使用中」にしたあと、24時間グラフをもう一度見る
- 充電器を差してもパーセントが増えない、80%で止まったまま動かない → [充電が遅い・始まらないときの切り分け](/articles/smartphone-charging-slow/) のケーブルとポートへ。最適化充電をオフにして、それでも増えないなら本体側
- 熱い、膨らんでいる、突然電源が落ちる → 使い続けず、充電を外して持ち込む
- 会社支給で、低電力モードや位置情報が灰色 → 個人の設定では変えられません。減った時間帯と、バッテリー画面の先頭アプリを担当へ

## まとめ

バッテリー画面で、画面オンかバックグラウンドかを分ける。明るさと自動ロック、位置情報の「常に」、テザリングを戻してから、低電力モードで半日見る。最大容量がはっきり低いときは、設定を重ねても持ちは戻りません。
