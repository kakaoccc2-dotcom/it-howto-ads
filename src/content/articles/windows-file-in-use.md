削除、移動、名前の変更をするとダイアログで止まる。「別のプログラムがこのファイルを開いているため、操作を完了できません。」「フォルダーは使用中です。」「ファイルを閉じてから再試行してください。」Excel を開いた覚えが無くても出ます。プレビュー、裏に残ったアプリ、同期、エクスプローラー自身が掴んでいる、が多いです。

フォルダーを開いただけで「応答なし」になるときは、ロックより先に [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/) です。再起動のたびに同じ常駐がファイルを掴むときは [起動時に開くアプリ](/articles/windows-startup-apps/) も見てください。

## 症状の見分け

- そのファイルだけ削除できない。同じフォルダーの隣のファイルは消せる
- フォルダーごと移動しようとすると「使用中」。中のファイルを一つずつなら消せる、またはその逆
- ダイアログにアプリ名が出る。出ないまま「別のプログラム」とだけ書いてある
- 写真や動画、PDF だけが引っかかる。テキストは消せる
- USB メモリの取り外しが「使用中」で失敗する。中のファイルを消そうとしても同じ
- PC を再起動した直後だけは削除できる。数分置くとまた止まる

`C:\Windows` や `Program Files` の中は、Windows の一部です。同じ文面が出ても、この先では消しません。

## よくある原因

1. アプリの窓が最小化、または別の仮想デスクトップに残っている
2. エクスプローラーの **プレビュー ウィンドウ** や縮小表示が、画像・動画・PDF を開いたままにしている
3. フォト、映画 & テレビ、ブラウザのタブが、裏で同じファイルを持っている
4. OneDrive やバックアップが、そのファイルを書き込んでいる最中
5. アプリは落ちたのに、プロセスだけ残ってファイルを離さない
6. コマンドプロンプトやインストーラーの作業フォルダーが、消したいフォルダーそのもの

## 直す前に

- 未保存の Word や Excel が無いか、タスクバーを一度見る。このあとプロセスを終わらせると、保存前の編集は消えます
- 「強制削除」「ファイルロック解除」系の実行ファイルは入れない
- 消してよいか、コピーが要るかを先に決める。壊して消す手順は書きません

> **注意:** タスク マネージャーで **System** や見慣れない **Service Host** を終了しないでください。終了してよいのは、自分で起動したアプリだけです。システムファイルの削除、コマンドでの強制削除はしません。

## 手順

### 1. 開いている窓と、プレビューを閉じる

名前がダイアログに出ているなら、そのアプリが先です。

1. タスクバーと、時計横の **^**（隠れているインジケーター）を見る。該当アプリがあれば、右クリックで終了する。×で閉じたつもりでも、トレイに残っていることがあります。
2. `Alt` + `Tab` で裏の窓を全部見る。Excel、Acrobat、フォト、動画が残っていれば、ファイルを閉じてからアプリも終了する。
3. ブラウザで同じ PDF や動画を開いたタブがあれば閉じる。
4. エクスプローラーの **表示** を開き、**プレビュー ウィンドウ** と **詳細ウィンドウ** をオフにする。プレビューが画像を掴んだままだと、「何も開いていない」のに削除できません。
5. 消したいフォルダーの中に入った状態で、そのフォルダー自身を削除しようとすると「使用中」になります。アドレスバーで一つ上へ戻ってから、フォルダーを削除する。

アプリを閉じただけで削除できたなら、プロセスの終了までは不要です。プレビューをオフにして削除できたなら、原因はエクスプローラーのプレビューです。用が済んだらプレビューは戻して構いません。

### 2. 残っているプロセスだけを終わらせる

窓は無いのに、同じメッセージが続くとき。

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー**。
2. ダイアログに出た名前、または直前までそのファイルを開いていたアプリを探す。選んで **タスクの終了**。
3. 同じ名前が複数あるときは、そのファイルを扱いそうなものだけ終了する。判断が付かない **Service Host** は触らない。
4. エクスプローラーでプレビューを切ってもフォルダーが使用中のままなら、**Windows エクスプローラー** の **再起動** を押す。デスクトップが一度消えて戻る。戻ってから、一つ上の階層で削除をやり直す。
5. Office なら、終了後に「文書の回復」が出ていないか見る。回復の窓がファイルを持ったままになります。残すなら保存し、捨てるならその窓を閉じてから削除する。

消せたら、それで十分です。同じ文面が残るなら、同期か、名前の出ないプロセスです。

### 3. 同期とスキャンが終わるのを待つ

1. トレイの OneDrive を開く。同期中なら、終わるまで待つか、**同期の一時停止** にしてから削除する。一時停止は、その PC の同期を止めるだけで、クラウドのファイル自体は消えません。
2. セキュリティのアイコンがスキャン中なら、数十秒置いてから同じ削除をもう一度する。リアルタイム保護を恒久的にオフにはしない。止めるための未知のツールも入れない。
3. 外付け HDD のランプが点滅しているあいだは、バックアップやコピーの途中です。点滅が止まってから削除する。

待っても「使用中」のままなら、どのプロセスかを名前で見ます。

### 4. リソース モニターで、掴んでいる相手を見る

ダイアログが「別のプログラム」としか言わないときの手順です。Windows に最初から入っているツールを使います。

1. タスク マネージャーの **パフォーマンス** を開き、右上か下のほうにある **リソース モニターを開く** を押す。スタートの検索に「リソース モニター」でも出ます。
2. **CPU** タブの下までスクロールし、**関連付けられたハンドル** を開く。
3. 検索欄に、削除したいファイル名の一部を入れる。長い名前は、拡張子を除いた数文字で足ります。
4. 一覧に `Photos`、`msedge`、`EXCEL`、`OneDrive` のように、自分で閉じられる名前が出たら、その行を右クリックして **プロセスの終了**。そのあと削除をやり直す。
5. 出るのが `System` や `svchost.exe` だけのときは、終了ボタンは押さない。PC を再起動すると、ファイルを掴んだままの状態は外れることが多いです。

検索が空なら、フォルダー名でもう一度検索する。それでも空なら、プレビューを切った状態でエクスプローラーを再起動し、削除をやり直す。

### 5. 再起動の直後に消す

1. 保存できる文書を閉じて、PC を再起動する。
2. サインインしたら、クラウドや写真アプリがファイルを開く前に、そのファイルを削除してみる。ここで消せるなら、あとから起動する常駐が掴んでいます。
3. 再発するときは、タスク マネージャーの **スタートアップ アプリ** で、自分で入れたクラウド同期やランチャーをいったんオフにする。名前が分からない項目はオフにしない。起動時の整理はスタートアップの記事へ。
4. USB メモリの中だけが使用中なら、再起動後に別の USB ポートへ挿してから削除する。本体の背面か側面の直挿しにする。

> **注意:** 再起動しても外れないからといって、削除専用の常駐ソフトは入れないでください。`Windows` フォルダーのファイルが使用中なのは、正常なことが多いです。アプリを消したいときは **設定 → アプリ → インストールされているアプリ** から、名前が分かるものだけアンインストールします。

## まだ直らないとき

- ダイアログに Excel や Word と出るが、この PC では閉じてある → 共有のブックを、別の PC や別の人が開いたままです。相手に閉じてもらう
- 再起動の直後だけ消せる → スタートアップの常駐。手順5のオフを維持して様子を見る
- フォルダーの中の1ファイルだけ → そのファイルのプレビューかアプリです。フォルダーごと捨てると、関係ないファイルまで消えます
- ネットワークの共有フォルダーだけ使用中 → 相手の PC が開いたままか、相手の電源が中途半端です。パスを紙に書いてから、相手側でそのファイルを閉じてもらう
- 職場 PC でリソース モニターが開けない → 個人のツールは入れず、担当へフルパスと、ダイアログの文面を渡す

## まとめ

名前が出ているアプリを閉じ、プレビューを切り、それでも止まればリソース モニターでプロセスを見ます。`System` なら終了せず再起動です。ロック解除ツールは入れません。
