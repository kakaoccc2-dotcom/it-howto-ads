起動したら見知らぬツールバーがある。アドレス欄の検索が知らないサイトに飛ぶ。新しいタブが広告だらけ。拡張の削除と、検索エンジンの戻しで足りることがほとんどです。赤い証明書の警告は別で、[証明書の手順](/articles/browser-connection-not-private/) です。

「掃除ツール」「ハイジャック削除」は入れないでください。広告付きインストーラーと同じ経路です。

## 症状の見分け

- 拡張の一覧に、入れた覚えの無い名前がある。オフにしても、再起動で戻る
- ホームボタンや新しいタブが、いつもと違う検索サイトになる
- アドレス欄で単語検索すると、いつもの Bing / Google ではなく別ドメインへ飛ぶ
- 起動のたびに、見知らぬページが何枚も開く
- 「ブラウザは組織によって管理されています」と出る家庭用 PC
- ポップアップは出るが、拡張一覧は空（サイト側の広告で、拡張ではない）

フリーソフトのインストール途中で、チェックを外し忘れた「検索の変更」が残ることが多いです。銀行画面を真似た警告で「今すぐ修復」を押したあとに増えることもあります。

## よくある原因

1. 別アプリのインストーラーに同梱されていた拡張と、検索プロバイダー
2. 同期（同じ Google / Microsoft アカウント）が、別 PC の拡張を流し込んでいる
3. スタートアップで、ブラウザを変な URL 付きで起動している
4. Windows に残ったツールバー用ソフトが、消した拡張を書き戻す
5. 学校・職場のポリシー、またはそれに見せかけた偽の管理ソフト

## 直す前に

- 今入っている拡張の名前を控える。消してよいもの（見知らぬ検索、クーポン、PDF 変換）と、残すもの（パスワードマネージャ、広告ブロック）を分ける
- 「1クリック修復」の実行ファイルは使わない
- 銀行やメールのパスワードを、見知らぬ拡張が入っていた期間に打った覚えがあれば、公式アプリか別端末から変更する。この記事ではパスワードの抜き出し方は書きません

> **注意:** ブラウザのリセットは、開いていたタブと一部の Cookie が消えます。拡張の削除と検索エンジンの戻しで足りることが多いので、リセットは後回しです。Windows の初期化は不要です。

## 手順

### 1. 見知らぬ拡張を外す

**Chrome**

1. アドレス欄に `chrome://extensions` と入れる（**設定 → 拡張機能** でも同じ）。
2. 見覚えの無いカードの **削除** を押す。オフだけだと、次の起動でまたオンに戻ることがあります。
3. 「デベロッパーモード」がオンで、カードに「展開して読み込まれました」とある見知らぬ項目は、特に削除する。正規の店から入れた覚えが無いからです。
4. Chrome を完全に終了する（右上の … → **終了**）。タスクバーに残っていれば、そこからも閉じる。開き直して、一覧に戻っていないか見る。

**Edge**

1. アドレス欄に `edge://extensions` 。
2. 見知らぬ拡張の **削除**。 **他のストアからの拡張機能を許可する** がオンなら、切り分けのあいだオフ。
3. Edge を **… → 終了** して開き直す。

消しても再起動で戻るときは、手順4の Windows 側に、同じ名前のソフトが残っています。拡張画面だけでは終わりません。

同期を使っているなら、**Chrome の設定 → 同期と Google サービス**（Edge なら **プロファイル → 同期**）で、いったん同期をオフにしてから削除する。オンのままだと、別 PC からまた流れてきます。消したあと、必要な拡張だけを公式のウェブストアから入れ直して、同期を戻す。

### 2. 検索エンジンと、ホーム・起動ページを戻す

**Chrome**

1. **設定 → 検索エンジン → 検索エンジンの管理**。使わないものを **削除**。既定を Google または自分が使うエンジンにする。
2. **設定 → 起動時** を **新しいタブページを開く** にする。特定のページが何枚も指定されているときは、見知らぬ URL を外す。
3. **設定 → 外観** の **ホームボタンを表示する** がオンなら、その URL が自分の知っているページか見る。見知らぬ検索サイトなら、新しいタブにするか、自分で打った URL に変える。
4. **設定 → 検索エンジン** の **アドレスバーの検索エンジン** も、手順1と同じエンジンか見る。ここだけ別のエンジンのまま残ることがあります。

**Edge**

1. **設定 → プライバシー、検索、サービス → アドレス バーと検索**。検索エンジンを Bing または自分の使うものに戻す。
2. **設定 → スタート、ホーム、および新規タブ**。起動時に開くページから、見知らぬ URL を削除する。ホームも同様。
3. **新しいタブ** が広告だらけの独自ページなら、その項目を Microsoft の既定に戻す。サードパーティの「新しいタブ」拡張は、手順1で消えているはずです。

アドレス欄に単語を入れて Enter する。いつもの検索結果ならここは終わりです。見知らぬドメインなら、まだ検索エンジンが残っています。同じ名前が二重なら、両方消して使いたいものだけ入れ直す。

### 3. サイトのポップアップと、拡張を取り違えない

1. 拡張一覧が空なのに広告が出るなら、そのタブのサイト側です。そのページを閉じる。通知許可を求めてきたサイトは、鍵アイコンから通知をブロックする。
2. Chrome の **設定 → プライバシーとセキュリティ → サイトの設定 → 通知** で、見知らぬサイトを削除する。Edge も **Cookie とサイトのアクセス許可 → 通知** です。
3. 「ウイルスに感染しています。サポートに電話」は、拡張ではなく偽の警告ページです。ページを閉じる。電話はしない。ブラウザをリセットするボタンがページ内にあっても押さない。
4. タスクバーやデスクトップに、ブラウザのアイコンが増えているときは、プロパティのリンク先に見知らぬ URL が付いていないか見る。付いていれば、公式の Chrome / Edge ショートカットを作り直す。電源を入れると同じページが開きます。その場合は下のスタートアップです。

### 4. Windows に残った書き戻しソフトを外す

拡張を消しても、電源を入れるとまた入るときは、ブラウザの外にインストーラーが残っています。

1. **設定 → アプリ → インストールされているアプリ** で、ツールバー、検索、クーポン、見知らぬ「Browser Protector」系を **アンインストール**。名前が分からなければ、インストール日が症状の始まった日のものを優先する。Windows セキュリティや、普段使うソフトは消さない。
2. スタートアップにブラウザや、その検索ツールが残っていないか見る。止め方は [起動時にアプリが開く手順](/articles/windows-startup-apps/) です。
3. タスクマネージャーの **スタートアップ アプリ** に、手順1で消した名前の残りがあればオフ。
4. もう一度 `chrome://extensions`（または `edge://extensions`）を開き、消したカードが戻っていないか見る。戻らなければ、起動ページと検索も手順2をもう一度確認する。

職場や学校の PC で **組織によって管理されています** と出るのは、IT 担当のポリシーです。家庭用でこの表示が出て、身に覚えの無い管理ソフトが入っているときだけ、**設定 → アプリ** からその管理エージェントを外し、PC メーカーの案内がある場合はそちらを優先します。レジストリを手で消す手順は使いません。

### 5. それでも検索が戻るときだけ、ブラウザをリセットする

1. Chrome は **設定 → リセットとクリーンアップ → 設定を元の既定値に戻す**。内容を読んでから実行する。開いていたタブと Cookie の一部が消えます。パスワードマネージャに保存したパスワードは、Google アカウント同期が生きていれば戻ることが多いです。ローカルだけなら、先に控える。
2. Edge は **設定 → リセット設定 → 設定をリセット**。同様に確認してから実行する。
3. リセット後、手順2の検索エンジンともう一度照合する。同期をすぐオンにすると、古い拡張が戻ることがあります。必要なものだけ入れてから同期を戻す。
4. Windows セキュリティの **ウイルスと脅威の防止** でスキャンする。ブラウザのリセットの代わりにはなりませんが、一緒に入った実行ファイルが残っていないかの確認です。出所不明の「追加のクリーナー」は入れない。

> **注意:** Chrome の「コンピュータをリセット」案内や、画面いっぱいに出るサポート詐欺の電話番号は公式ではありません。Microsoft や Google の公式サイト以外から「修復ツール」を入れないでください。

## まだ直らないとき

- 拡張は空なのに起動ページだけ戻る → ショートカットの URL と [スタートアップ](/articles/windows-startup-apps/)
- 片方のブラウザだけおかしい → そのブラウザの手順1〜2。もう片方は触らなくてよい
- 家庭用なのに「組織によって管理」が残る → インストール済みアプリの管理エージェント。自分でポリシーファイルを消さない。分からなければ PC メーカーまたは購入店へ、画面の文言を渡す
- 銀行のログインがおかしい、見知らぬ拡張の期間にパスワードを打った → 公式サイトか公式アプリからパスワード変更。この記事の手順とは別に、急いでください
- 証明書の赤い画面 → 拡張ではなく [証明書の手順](/articles/browser-connection-not-private/)

## まとめ

拡張の削除と、検索エンジン・起動ページの戻しが本体です。再起動で戻るときだけ、Windows のアプリ一覧とスタートアップを見てください。
