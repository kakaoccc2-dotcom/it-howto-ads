サイトは「ダウンロードを開始しました」と出ている。Chrome 右上の矢印を開くと、ファイル名の下に **失敗しました** か **ブロックされました** だけが残る。字が違うと、直す場所も違います。赤い証明書の警告でページ自体が開かないときは [接続がプライベートではありません](/articles/browser-connection-not-private/) です。

## 症状の見分け

- アドレス欄に `chrome://downloads` と入れると、そのファイルが失敗やブロックのまま残っている
- 小さい字が「失敗しました」「失敗 - ネットワーク エラー」「ウイルスを検出したため、ブロックされました」など、ファイルごとに違う
- 「危険なダウンロードがブロックされました」「このファイルは危険な可能性があります」
- 画像の右クリック「名前を付けて画像を保存」だけ失敗する
- 同じアドレスが Edge やスマホでは保存できる
- 小さい PDF は保存できるが、zip や動画だけ失敗する

## よくある原因

1. 保存先フォルダが無い、抜いた USB、止まった OneDrive、別の PC の共有のまま
2. そのドライブの空きが、ファイルより小さい
3. Windows のフォルダー保護やセキュリティソフトが、Chrome の書き込みだけ止めている
4. 拡張機能、または会社の PC のポリシー
5. セーフ ブラウジングが、危険なファイル・安全でないダウンロードとして止めている
6. リンク先のファイルが、もうサーバーに無い

## 直す前に

- 失敗の小さい字を読む。あとで手順が分かれます
- 知らない `.exe` や、広告の「PCを修復」から来たファイルは保存しない。警告を消す設定にはしない
- レジストリや「ダウンロード修復ツール」は使わない

> **注意:** セーフ ブラウジングをオフにすると、危険なファイルの警告自体が消えます。この記事ではオフにしません。

## 手順

### 1. 一覧の文言を読む

1. 右上の下向き矢印を開く。無いときは、縦三点 → **ダウンロード**。アドレス欄の `chrome://downloads` でも同じ一覧です。
2. 問題のファイルの下の文を読む。
3. **失敗しました** 系なら、手順2へ。保存先と空きの話です。
4. **ブロック**、**危険**、**安全でない** なら、手順5へ。保存先を変えても、同じ警告が残ることが多いです。
5. **再試行** があれば一度押す。通信が切れただけなら、ここで終わります。

### 2. 保存先を、今あるフォルダにする

1. 縦三点 → **設定** → **ダウンロード**。
2. **保存先** のパスを見る。実在しないフォルダ、外した USB、`\\` で始まる共有、一時停止中の OneDrive 配下になっていないか。
3. **変更** で、エクスプローラーから開ける場所（自分の **ダウンロード** フォルダなど、C: の中）を指定する。
4. **ダウンロード前に各ファイルの保存場所を確認する** をオンにし、同じファイルをもう一度取る。保存ダイアログが出るので、短い名前でデスクトップへ置ける。元の名前が極端に長いときに、ここで避けられます。
5. OneDrive のアイコンが一時停止やエラーなら、保存先を OneDrive の外にして取り直す。同期そのものは [OneDriveが同期しない手順](/articles/windows-onedrive-not-syncing/) です。

### 3. 空きを見る

1. エクスプローラーで保存先のドライブを開き、空きがファイルのサイズより大きいか見る。バーが赤いときは入りません。
2. 片付けは [Windowsのストレージ不足](/articles/windows-storage-full/) の順です。クリーナーアプリは入れない。
3. 空きを作ったあとは、失敗したファイルの続きからではなく、サイトから取り直す。残骸が「使用中」で消せないときは [ファイルが使用中](/articles/windows-file-in-use/) です。

### 4. 拡張機能と、フォルダーの保護

ゲストでは保存できて、いつもの画面だけ失敗するときに見ます。

1. プロフィールのアイコン → **ゲスト**。同じアドレスを開き、保存できるか見る。ゲストで保存できるなら、いつものプロフィールの拡張か設定です。外し方は [拡張機能が勝手に入ったとき](/articles/browser-unwanted-extension/) 。
2. ゲストでも失敗し、Edge では保存できるなら、Chrome の保存先か、Chrome だけを止めている保護です。
3. 直前に「保護されたフォルダーへの変更をブロックされました」と出ていたら、スタートの検索に「ランサムウェアの防止」と入れる。
4. **コントロールされたフォルダー アクセス** がオフなら、ここは関係ありません。オンで、保護の履歴に Chrome が出ているときだけ、許可するアプリへ Chrome を追加する。この機能のスイッチはオフにしない。
5. 使っているセキュリティソフトの履歴に、そのダウンロードだけ残っているときは、公式の手順で検査を一時停止し、もう一度取る。取れたら一時停止を戻す。止めっぱなしにはしない。
6. VPN を切ったときだけ取れるなら、いったん切って保存する。VPN 自体が繋がらないときの手順は [VPNに接続できない](/articles/windows-vpn-cannot-connect/) です。

### 5. 「ブロックされました」「危険」と出たとき

1. アドレス欄のドメインを見る。自分で開いた市役所、銀行、学校、会社の公式か。広告のボタンから飛んだ別のドメインなら、保存しない。
2. 公式の PDF や、自分で頼んだ領収書なら、ダウンロード一覧のその項目を開く。メニューに **保持** や **保存** と出ることがあります。中身が分かっているファイルだけ使ってください。**破棄** は取らない側です。
3. 「安全でないダウンロード」は、ページは https なのに、ファイルだけ保護されていないアドレスから来ているときに出ます。同じファイルの https のリンクや、公式アプリがあるならそちらを使う。警告を消す設定にはしない。
4. パスワード付きの zip で「このファイルは危険な可能性があります」と出たら、自分で付けたパスワードのときだけ、画面の確認に進む。覚えの無い zip に、送られてきたパスワードは入れない。
5. サイトが何個もまとめて落とそうとして止められたときは、縦三点 → **設定** → **プライバシーとセキュリティ** → **サイトの設定** を開き、**自動ダウンロード** を探す。**その他の権限** や **その他のコンテンツの設定** の下にあります。開いているページなら、アドレス欄の錠 → **サイトの設定** に同じ項目が出ることがあります。
6. そのサイトだけ許可する。すべてのサイトを許可にはしない。

## まだ直らないとき

- どのブラウザでもそのファイルだけ失敗し、別サイトの PDF は保存できる → 相手のサーバーか、リンク切れです。提供元に、失敗の小さい字を伝える
- 社用 PC で保存先が灰色で変更できない → 会社のポリシーです。情シスへ、一覧の文言を渡す
- 100% まで進んだのに、開くアプリが無い → ダウンロード失敗ではなく、関連付けです。[ファイルの関連付け](/articles/windows-file-association-wrong/)
- スマホの Chrome だけ失敗する → 保存先はスマホの「ファイル」アプリ側です。この記事の Windows のフォルダとは別です

## まとめ

一覧の字が「失敗」なら、保存先と空きを見てください。「ブロック」や「危険」なら、そのファイルを自分で頼んだものかを先に決めます。警告を消す設定には進まないでください。
