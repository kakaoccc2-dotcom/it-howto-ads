カメラは開くのに画面が真っ黒。シャッター音はするのに、保存された写真も黒い。起動した瞬間に落ちることもある。Windows の会議カメラは [Windows のカメラ手順](/articles/windows-camera-not-working/) です。こちらは iPhone のカメラアプリと、Instagram や LINE の撮影画面です。

## 症状の見分け

- カメラは開くが、画面が黒いまま。切替アイコンだけ見える
- インカメラは映るが、アウトカメラだけ黒い（またはその逆）
- 写真モードは普通で、ビデオやポートレートだけ黒い
- 標準のカメラは映るが、別アプリだけ「カメラにアクセスできません」
- 撮影ボタンは押せるが、保存された画像が真っ黒、または保存に失敗する
- 落とした・強く挟んだ直後から、またはケースを替えた直後から再現する
- 緑の点が点灯しているのに映像が来ない

片方のレンズだけ黒いなら、設定より先にそのレンズの隠れとハードウェアです。どのモードでも黒いなら、許可・占有・ストレージを先に見ます。

## よくある原因

1. ケース、保護フィルム、指、レンズカバーがカメラを塞いでいる
2. 超広角・望遠・ポートレートなど、今のモードが別レンズを掴んで失敗している
3. FaceTime、Zoom、Instagram が先にカメラを使っている
4. **設定 → プライバシーとセキュリティ → カメラ** で、そのアプリがオフ
5. スクリーンタイムの制限でカメラ自体が禁止されている
6. 本体ストレージが足りず、起動や保存だけ落ちる
7. 落下や水濡れのあと、そのレンズ側が壊れている

## 直す前に

- レンズを指で強く拭かない。布があれば軽く払う程度
- 「カメラ修復」「画質アップ」を名乗るアプリは入れない
- 残したい写真があるなら、作業の前に [ストレージ不足の手順](/articles/iphone-storage-full/) で空きとバックアップを見る。初期化はこの記事では使いません

> **注意:** レンズに砂が付いたまま強くこすると、ガラスが傷つきます。水没あとや、画面が割れたまま充電できない状態での分解はしないでください。保証内なら、ここまでの画面写真を持って販売店か Apple サポートです。

## 手順

### 1. レンズが塞がっていないか、モードを戻す

1. アウトカメラ（背面の出っ張り）を見る。厚いケースの穴がずれている、シールが残っている、指がかかっている、がないか。
2. カメラアプリを開き、画面下の **写真** を選ぶ。ポートレート、シネマティック、アクションはいったん離す。
3. 画面右下（機種によっては左）のカメラ切替で、インカメラにして顔が映るか見る。映ったらアウトに戻す。
4. 0.5 / 1x / 2x などの倍率を 1x に戻す。超広角だけ黒い機種は、広角モジュール側です。
5. 画面をピンチして倍率を戻し、フラッシュはオフ。長押しで出る露出バーが極端に下がっていないか見る。真っ黒に見えるだけ、ということがあります。

インだけ映ってアウトが全部黒い、ケースを外しても同じ、なら手順2で再起動したあと、手順5の切り分けです。

### 2. ほかのアプリを閉じて、カメラを起こし直す

1. 画面下から上へスワイプして（ホームボタン機種はダブルクリック）、FaceTime、会議アプリ、Instagram、LINE の通話画面を上へ払って終了する。
2. カメラアプリも一度終了する。
3. 側面のボタンで電源オフ → 数秒 → オン。起動後、先に標準の **カメラ** だけ開く。
4. コントロールセンターのカメラショートカットではなく、ホーム画面のカメラアイコンから開く。ショートカット側だけ黒いことがあります。

緑の点が、カメラを閉じてからも点いたままなら、まだ誰かが掴んでいます。会議タブや Instagram がスイッチャーに残っていないか、もう一度上へ払ってください。

### 3. プライバシー許可と、スクリーンタイム

1. **設定** → **プライバシーとセキュリティ** → **カメラ**。一覧で、使いたいアプリがオンか見る。オフならオン。
2. 標準のカメラアプリは、この一覧に出ないことがあります。出なくても手順1で真っ黒なら、許可よりレンズかモードです。
3. 別アプリだけ「アクセスできません」と出るなら、その行をオフ→数秒→オンにしてから、アプリを開き直す。
4. **設定** → **スクリーンタイム** → **コンテンツとプライバシー制限** がオンなら、**許可されたApp**（またはプライバシー項目の **カメラ**）を開く。カメラがオフならオンに戻す。家族の制限で灰色なら、こちらでは終わりません。
5. 仕事用の構成プロファイルを入れている端末は、カメラ禁止のことがあります。**設定 → 一般 → VPNとデバイス管理** にプロファイルがあるときは、勝手に消さず管理者へ。

Safari や Instagram は、OS のカメラ許可とは別に、アプリ内でもう一度聞きます。「許可しない」を以前押していると、設定をオンにしても撮影画面は黒いままです。一度アプリを終了してから開き直してください。

### 4. ストレージと、カメラの保持設定

1. **設定** → **一般** → **iPhoneストレージ**。空きが赤い警告、または数百MBしかないときは、写真が保存できずアプリが落ちることがあります。大きな動画を移すか、使っていないアプリを削除してからカメラを開き直す。
2. **設定** → **カメラ** → **フォーマット**。切り分けでは **高効率** のままでよいです。ProRAW や最大解像度だけオンだと、空き不足で保存に失敗しやすい。
3. **設定** → **カメラ** → **保持設定**。露出調整や Live Photos、フィルタを保持していると、前回真っ暗にした露出が残ることがあります。保持をオフにして、カメラを開き、露出を中央付近に戻す。
4. 撮影はできるが保存できない、または「ストレージ残量が不足しています」と出るなら、この記事より先にストレージ側です。

空きが数GBあるのに真っ黒、なら容量ではありません。手順1と2に戻ります。

### 5. まだ黒いときの切り分け（初期化はしない）

1. 別の Apple ID の家族の iPhone で、同じケースを付けて撮影してみる。ケースを付けたときだけ黒いならケースです。
2. 純正のカメラは映るが Zoom だけ黒い → そのアプリの許可と、会議中のカメラ選択。iPhone 側のレンズ故障ではありません。
3. どのモードでも、インもアウトも黒い。再起動しても同じ。落下や液漏れの覚えがある → 設定をいじり続けない。写真のバックアップが新しいかを見てから、販売店か Apple サポートへ。画面に「カメラを使用できません」と出る機種もあります。
4. **設定 → 一般 → 転送または iPhone をリセット → すべての設定をリセット** は、Wi-Fi パスワードや壁紙も消えます。カメラが真っ黒なだけの切り分けでは使いません。

> **注意:** 「iPhone を消去」やリカバリモードからの復元は、写真が消えます。この記事の範囲外です。保証とバックアップが揃ってから、サポートの案内に従ってください。

## まだ直らないとき

- 1x は映るが 0.5 だけ黒い → 超広角モジュール。ケースの穴ずれを外してもダメなら修理
- 写真は撮れるがビデオだけ黒い → モードと保持設定。マイク権限の画面とは別です
- ロック画面のカメラショートカットだけ黒い → ホーム画面のカメラアプリで試す。ショートカットの起き直しは再起動
- 熱い・低温の警告のあと真っ黒 → 温度が戻ってから。ケースを外して少し置く
- 修理に出すとき → 標準カメラが黒いか、別アプリだけか、イン／アウトのどちらが死んでいるかをメモする。初期化済みかどうかは聞かれます

## まとめ

ケースの穴ずれと 1x の写真モードから見る。ほかのアプリを払って、許可がオフならオン。片方のレンズだけ黒いなら設定では戻りません。赤い容量警告のときは、消す前に残したい写真を移してください。
