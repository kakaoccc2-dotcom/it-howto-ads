電話は出ているのに鳴らない。バナーは来るのに音だけ無い。サイレントと着信音量、つながったままのイヤホンが多いです。未読はあるのに通知そのものが来ないなら、音より先に [iPhone の通知手順](/articles/iphone-notifications-not-working/) です。

## 症状の見分け

- 相手には「呼び出し中」なのに、こちらは無音。バイブもない
- バナーや通知センターには残るが、音もバイブも出ない
- 側面のオレンジ（または操作ボタンのベル消し）が出ている
- ステータスバーに集中モード（三日月など）がある
- Bluetooth イヤホンや車につながったまま、本体スピーカーが黙っている
- 知らない番号だけ鳴らない。登録済みは鳴る
- アラーム・タイマーは鳴る。電話とアプリ通知だけ鳴らない

アラームが鳴るならスピーカー故障ではありません。着信と通知の経路が別です。

## よくある原因

1. サイレント（リング／サイレントスイッチ、または操作ボタン）
2. **サウンドと触覚** の着信音量がゼロ。または **ボタンで変更** の取り違え
3. **集中モード**（おやすみ時間、睡眠、運転）が電話も止めている
4. イヤホン・CarPlay・補聴器に音声が逃げている
5. **知らない番号からの着信を消音**、ライブ留守番電話、転送
6. 画面注視認識で、見ていないときに音を落としている

## 直す前に

- 自分の別回線、または家族の電話から、今すぐ1本かけて再現する。履歴に残るか、鳴るか、の両方を見る
- 「着信ブースト」「マナー解除」を名乗るアプリは入れない
- 職場の構成プロファイルが入っている端末は、個人のスイッチだけでは終わらないことがある

> **注意:** **すべての設定をリセット** はこの記事では使いません。着信音量とサイレント、集中モードで足りることがほとんどです。初期化も不要です。

## 手順

### 1. サイレントと、着信音量を分ける

1. 側面にスイッチがある機種は、オレンジの点が見えていないか見る。見えているあいだは着信音も通知音も出ません。スイッチを、点が隠れる側へ倒す。
2. 操作ボタンの機種は、ボタンを長押しして **サイレントモード** になっていないか見る。コントロールセンターのベルが斜線なら、そこをタップして戻す。
3. **設定** → **サウンドと触覚**。いちばん上のスライダが着信と通知の音量です。ゼロなら上げる。メディア（動画）の音量とは別です。
4. 同じ画面の **ボタンで変更** がオンだと、音量ボタンが着信音量を動かします。オフだと、音量ボタンはメディアだけです。着信が小さいのに動画は大きい、はだいたいここです。
5. **着信音** が「なし」になっていないか見る。一時的に無音にしたままのことがあります。標準の「オープニング」などに戻して、テスト着信を1本入れる。

バイブだけ欲しいときは、サイレントをオンにしたまま **サウンドと触覚** のパターンを残します。音が欲しいのにサイレントがオン、が取り違えの定番です。

### 2. 集中モードが電話を止めているか

1. 画面右上からコントロールセンターを開き、集中モードが点灯していればオフにする。
2. **設定** → **集中モード**。 **おやすみ時間**、**睡眠**、**運転**、自分で作ったモードを開き、スケジュールが残っていないか見る。使わないモードはオフ。
3. 各モードの **人** で、電話を許可している相手を見る。誰も許可していないと、登録済みでも鳴りません。切り分けでは、いったんそのモードをオフにしてテスト着信を入れる。
4. **繰り返しかけ**（同じ人から連続）をオンにしていると、1本目だけ黙ります。家族の「1回かけて切った」は、これだと届きません。
5. ロック画面を左右に払って、集中モード用の別ロック画面に居続けていないか見る。その画面にいるあいだは、許可した相手以外は黙ります。

睡眠の就寝スケジュールや、時計のベッドタイムが夜だけ電話を止めていることもあります。昼間も無音なら、集中モードの時間指定です。通知の要約はバナーの遅れ用なので、着信音そのものより [通知の記事](/articles/iphone-notifications-not-working/) です。

### 3. Bluetooth と、車・イヤホンへの逃げ

1. 画面上部の Bluetooth アイコン、または **設定 → Bluetooth** で、つながっている機器名を見る。死んだイヤホンや、カバンの中のヘッドセットが「接続済み」のことがあります。
2. 使っていない機器は切断する。切り分けでは Bluetooth をオフにして、本体スピーカーでテスト着信を入れる。
3. 車のエンジンを切ったあとも CarPlay / Bluetooth が残っていると、着信音が車側（電源オフ）へ行きます。車から降りたら iPhone の Bluetooth 一覧で切断する。
4. **設定 → アクセシビリティ → 聴覚デバイス** に古い補聴器が残っていないか見る。残っていれば外す。
5. 有線イヤホンが途中まで刺さっていると、本体スピーカーは黙ります。根本まで抜く。

音楽は聞こえるが着信だけ無い、は手順1の着信音量です。音楽も着信も本体から出ない、は今つながっている出力先です。

### 4. 知らない番号の消音と、ライブ留守番電話

1. **設定** → **電話** → **知らない番号からの着信を消音** がオンなら、連絡先に無い番号は鳴りません。宅配や病院の電話が必要なときはオフ。迷惑対策でオンにするなら、よくかける相手を連絡先に入れる。
2. 同じ **電話** の **ライブ留守番電話**（機種と回線による）が、呼び出し音の前に画面だけ出すことがあります。切り分けではオフにして、すぐ鳴るか見る。
3. **通話の転送** がオンだと、こちらの着信音より先に別番号へ行きます。使っていない転送はオフ。
4. キャリアの「迷惑電話ブロック」アプリや、iPhone の **着信拒否** 一覧に、家族の番号が入っていないか見る。
5. **設定 → メッセージ** の通知音が「なし」なのは SMS だけです。電話の着信音は手順1の **着信音** です。取り違えない。

相手の画面がすぐ留守番電話になるなら、こちらが圏外か、転送か、相手側の問題です。こちらで呼び出し音が全く無いのに相手は長いあいだ鳴っている、ならこの手順の無音設定です。

### 5. 画面注視と、アクセシビリティの音量

1. Face ID 機種で、伏せたときや見ていないときにだけ無音になるなら **設定 → Face IDとパスコード** の **画面注視認識機能** を切り分けでオフにする。アクセシビリティ側にも同名がある機種があります。
2. **設定 → アクセシビリティ → オーディオと視覚** の **ヘッドフォン調整** がオンだと、特定のイヤホンだけで極端に小さくなることがあります。本体スピーカーの切り分けではオフ。
3. **設定 → サウンドと触覚 → ヘッドフォンの安全確認**（またはサウンド画面のヘッドフォン音量）が下がりすぎていないか見る。有線・Bluetooth の着信に効きます。本体スピーカーの着信音量とは別スライダです。
4. iPhone を再起動する。起動し直したあと、Bluetooth を切った状態でテスト着信を1本入れる。
5. 充電が極端に遅く、低電力モードばかり入るときは、着信より先にケーブルを替えて残量を戻す。低電力そのものは着信音を必ず消すわけではありませんが、集中モードと重なると気づきにくいです。

> **注意:** **設定 → 一般 → 転送または iPhone をリセット → すべての設定をリセット** は、Wi-Fi パスワード以外の設定も消えます。着信の切り分けでは使いません。

## まだ直らないとき

- バナーは来るが音だけ無い → 手順1と3。そのアプリの通知サウンドが「なし」なら [通知の記事](/articles/iphone-notifications-not-working/) の手順1
- どの音も出ない（アラームも動画も）→ スピーカー故障の疑い。別の有線イヤホンで動画が聞こえるかで分ける。聞こえるなら本体スピーカー側
- 登録済みだけ鳴る → 手順4の知らない番号の消音
- 車の中だけ鳴らない → 手順3。車側の音量つまみがゼロになっていないかも見る
- 家族の同じ回線は鳴る → 端末側です。全員鳴らないなら、キャリア障害か、家の電波

電波そのものが無い、Wi-Fi 通話だけおかしい、は音より通信です。[iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) も見てください。

## まとめ

サイレントと着信音量、集中モード、つながったままのイヤホンの3点で、無音の大半は分かれます。アラームが鳴るなら、スピーカーより設定です。
