スマホの連絡先が、パソコンの Gmail より古い。カレンダーに入れた予定が端末に出ない。Gmail が数時間前で止まる。アカウント名は表示されているのに、「同期に問題があります」「要ログイン」と出る。パスワードを変えたあと、機種を変えたあとに多いです。

ブラウザで google.com も開かないときは、同期のスイッチより先に [AndroidでWi-Fiに繋がらないとき](/articles/android-wifi-cannot-connect/) です。Play ストアのインストールだけが失敗するときは [Playストアでダウンロードできないとき](/articles/android-play-store-wont-download/) を見てください。ストアと同期は、同じログインを使うことが多いです。

## 症状の見分け

- 連絡先だけ古い。Gmail は届いている。またはメールだけ止まって、連絡先は新しい
- 設定のアカウントに、前回の同期が何日も前のまま残っている
- パソコンのブラウザでは予定が見える。スマホのカレンダーアプリには出ない
- Chrome のブックマークやパスワードだけが、ほかの端末と違う
- Google フォトのバックアップだけが止まる。連絡先は同期されている
- 画面に「仕事用」と「個人用」があり、仕事用のアカウントだけ失敗する
- 再起動の直後は同期され、半日置くとまた止まる

Google アカウントが二つあると、空のほうだけ見て「消えた」となります。メールアドレスを見比べてから同期します。

## よくある原因

1. **アカウントの同期** で、連絡先・カレンダー・Gmail のどれかがオフ
2. パスワード変更や二段階認証のあと、端末側のログインだけ切れている
3. **日付と時刻** が自動ではない。Google のログインが通らない
4. スマホの空きがほとんど無い。または Google アカウントの容量が一杯で、Gmail やフォトのバックアップが止まる
5. データセーバーやバッテリー制限が、**Google Play 開発者サービス** の通信を止めている
6. 連絡先アプリの表示が「端末のみ」になっていて、同期された連絡先が隠れたまま

## 直す前に

- パソコンか、ほかの端末のブラウザで [Google 連絡先](https://contacts.google.com) とカレンダーを開き、クラウド側にデータがあるか見る。アカウントを端末から消す前の確認です
- 「同期修復」「アカウント修復」アプリは入れない
- 仕事用プロファイルのアカウントは、自分で削除しない

> **注意:** アカウントを端末から外すと、そのアカウントで見えていたメールや連絡先が端末の一覧から消えます。クラウドに一度も上がっていない連絡先は戻りません。ブラウザで件数を見てからにしてください。端末の初期化はしません。

## 手順

### 1. 止まったアカウントと、止まった項目をオンにする

項目名はメーカーで少し違います。設定の検索が最短です。

1. **設定** の上の検索に「同期」と入れる。検索に出た画面へ進む。Pixel は **パスワードとアカウント**（**パスワード、パスキー、アカウント** のこともある）。Samsung は **アカウントとバックアップ → アカウントを管理** です。
2. **Google** を開き、メールアドレスを読む。二つあるときは、止まったほうを開く。家族のアカウントのまま、自分の連絡先を待っていることがあります。
3. **アカウントの同期** を開く。表示が **アカウントを同期** の機種もあります。連絡先、カレンダー、Gmail が並びます。同期したい項目がオフならオンにする。
4. 右上の **⋮** から **今すぐ同期** を押す。機種によっては画面内に **同期** ボタンがあります。どちらでも、押したあとに各項目の「前回の同期」が今日の時刻へ進むかを見る。
5. Gmail アプリの中だけ古いときは、Gmail のメニュー → **設定** → そのアカウント → 同期の項目もオンか見る。アカウント側がオンでも、アプリ側がオフのことがあります。

時刻が進み、連絡先や受信トレイが新しければ、スイッチがオフだっただけです。エラーの文言が残るなら手順2へ。

### 2. ログインが切れていないか

パスワードを変えた、別の国からログインした、初期化のあと入れ直していない、で起きます。

1. アカウントの画面に **要認証** や **ログイン** が出ていれば、パスワードを入れ直す。二段階認証なら、いつもの端末の通知かバックアップコードを使う。
2. 画面上から通知を下げ、「アカウントの操作が必要です」が残っていないか見る。残っていれば、その通知から入り直す。
3. Play ストアを開き、右上の丸いアイコンが目的のアカウントか確認する。違うアカウントなら、アイコンから切り替える。ストアのダウンロード自体がエラーなら、Play ストアの記事を先に進める。
4. パソコンのブラウザで、同じアドレスに入れるか試す。ブラウザでも入れないなら、先に Google のログイン回復です。同期のスイッチは、ブラウザで入れるようになってから触ります。

ここを飛ばしてアカウントを削除すると、入れ直せなくなったときに連絡先の表示まで消えます。

### 3. 日付と時刻を自動に戻す

時計が手動か、タイムゾーンだけ違うと、Google のログインが通りません。画面の時計は、だいたい合って見えてもズレていることがあります。

1. **設定** の検索に「日付」と入れる。Pixel は **システム → 日付と時刻**、Samsung は **一般管理 → 日付と時刻** です。
2. **ネットワークから提供された時刻を使用**、または **日付と時刻を自動設定** をオンにする。タイムゾーンも自動にする。
3. 戻って、手順1の **今すぐ同期** をもう一度押す。前回の同期が今の時刻になれば、時刻が原因でした。

### 4. スマホの空きと、Googleの容量

二つの容量は別です。

1. **設定 → ストレージ** を開く。残りが 1GB を切っている、バーが赤い、なら同期の書き込みが止まりやすいです。大きな動画や、使っていないアプリの本体を、設定のストレージから消す。クリーナーアプリは入れない。
2. Gmail を開き、右上のアカウント画像から **Google アカウント** へ進み、**ストレージ** のバーを見る。設定の検索に「ストレージ」と入れても、アカウント側の容量が出ることがあります。無料の個人アカウントは 15GB 前後です。Google One を足している人は、その上限までです。
3. バーが満杯なら、Gmail やフォト、ドライブのバックアップが止まります。連絡先とカレンダーは容量の影響を受けにくいです。フォトだけ止まっているなら、アカウント全体の故障と決めず、ブラウザのストレージ管理で大きい写真やメールを整理する。端末のキャッシュ削除では、クラウド側の容量は空きません。

空きを作ったあと、もう一度 **今すぐ同期** を押す。

### 5. データセーバーと、バッテリー制限

再起動の直後だけ同期され、半日で止まるときに見ます。

1. ブラウザで google.com が開くなら、Wi-Fi 自体は生きています。開かないなら Wi-Fi の記事へ戻る。
2. **設定 → ネットワークとインターネット → データセーバー** がオンなら、いったんオフにして同期を試す。オフにしたくないときは、Gmail と **Google Play 開発者サービス** を、データセーバー中も通信できる側へ入れる。
3. **設定 → アプリ → すべてのアプリを表示** で **Google Play 開発者サービス** を開く。一覧に無いときは、アプリ一覧のメニューからシステムアプリの表示をオンにする。**バッテリー** を **制限なし** にする。
4. 同じバッテリー画面を、必要なものだけ **Gmail** と **Google** アプリにも行う。極端な省電力モードがオンならオフにして、**今すぐ同期** を押す。

**制限なし** にすると、そのアプリの電池は減ります。開発者サービスだけ外して、チャットアプリまで全部外す必要はありません。

### 6. キャッシュのあと、どうしてもならアカウントを入れ直す

1. **設定 → アプリ → Google Play 開発者サービス → ストレージとキャッシュ → キャッシュを削除**。**データを削除** は押さない。
2. **Google** アプリも、同じようにキャッシュだけ削除する。
3. 端末を再起動し、**今すぐ同期** を押す。前回の同期が更新されれば、ここで終わりです。

まだ「要ログイン」のまま、ブラウザの連絡先にデータがあると確認できた人だけ、入れ直しに進みます。

1. ブラウザの連絡先の件数と、スマホの連絡先の件数をメモする。スマホのほうが明らかに多いときは、まだクラウドに上がっていない人がいます。連絡先アプリのメニューから **エクスポート**（機種によっては **設定 → インポート / エクスポート**）で、vcf を端末の中に保存してから先へ進む。件数がほぼ同じなら、エクスポートは省略してよいです。
2. **設定** のアカウント一覧で、その Google アカウントを開く。**アカウントを削除**（表示は **この端末からアカウントを削除** のこともある）を押す。
3. 削除の直後、連絡先アプリの人数が減ることがあります。クラウドに残っている分は、次の追加で戻ります。
4. **アカウントを追加 → Google** で、同じアドレスを入れ直す。同期の連絡先・カレンダー・Gmail をオンにし、**今すぐ同期** を押す。
5. 連絡先アプリで、表示対象がその Gmail になっているか見る。**端末のみ** や、別のアドレスだけに絞っていると、同期が成功しても一覧に出ません。

> **注意:** **データを削除** と **アカウントを削除** は別です。開発者サービスのデータ削除は、ログインがまとめて外れます。この記事では押しません。仕事用のアカウント削除は、会社のメールまで端末から消えます。管理者に確認してからにしてください。

Chrome のパスワードやブックマークだけが止まったときは、Android のアカウント同期とはスイッチが別です。Chrome を開き、**設定** のそのアカウントで **同期** をオンにする。

## まだ直らないとき

- 連絡先だけ古い。メールは同期される → アカウントの同期で連絡先がオフか、連絡先アプリの表示アカウントが違う
- ブラウザの Google 連絡先が空 → クラウドには、まだ上がっていません。同期を押しても人数は増えません。スマホから書き出してから先へ進む
- フォトのバックアップだけ止まる → Google フォトのバックアップ設定と、アカウントの容量。連絡先の手順を繰り返してもフォトは戻りません
- 会社の Google Workspace だけ失敗し、個人の Gmail は同期される → 端末の故障ではありません。管理者が同期を止めていることがあります
- どの項目も認証エラーで、パスワードは正しい → 日付と時刻を自動に戻し、VPN を切る。**設定 → ネットワークとインターネット → プライベート DNS** を **自動** にしてから、ログインをやり直す

## まとめ

設定の検索で「同期」を開き、止まった項目をオンにして **今すぐ同期** を押します。ダメなら時刻の自動、スマホの空きと Google の容量、ログインの入れ直しです。アカウントを端末から外す前に、ブラウザの連絡先が残っているかを見ます。
