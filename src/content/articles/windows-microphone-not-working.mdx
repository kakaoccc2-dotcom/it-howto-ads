話しているのに Zoom や Teams で「聞こえない」と言われる。録音のレベルが動かない。マイク故障より、別の入力が既定になっている、アプリの許可がオフ、ヘッドセットの物理ミュート、が多いです。

USB マイクが一覧に出ないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) です。無線イヤホンのペアリングが切れているなら、[iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) と同じく、いったん登録を外して入れ直してください（Windows 側は **設定 → Bluetooth とデバイス** でデバイスの削除）。

## 症状の見分け

- 設定の入力レベルが、話しても動かない
- レベルは動くが、ブラウザだけ / Teams だけ届かない
- 通話開始と同時に、マイクだけ内蔵に戻る
- 更新後や、新しいイヤホンのあとから無音

レベルが動くならハードは生きています。動かないなら、既定デバイス・ミュート・ドライバーを先に見ます。エコーや途切れも、設定箇所は近いです。

## よくある原因

1. **設定 → プライバシーとセキュリティ → マイク** で、OS またはそのアプリがオフ
2. 既定の入力が、使っていない内蔵マイクや「ステレオ ミキサー」になっている
3. ヘッドセット本体・インラインのミュート、キーボードのマイク キー
4. サウンドの **排他モード** で、先に開いたアプリがマイクを独占している
5. Bluetooth ヘッドセットが音楽用プロファイルのままで、通話用マイクに切り替わっていない
6. Realtek などの「オーディオエンハンスメント」や、ノイズ抑制が入力を潰している

## 直す前に

- ヘッドセットに赤いミュートランプや、スティックのスライド スイッチが無いか見る
- 今使いたい機器の名前（Realtek、USB Microphone、AirPods など）を、設定の一覧で確認できる状態にする
- 会議アプリをいったん終了する（排他モードの切り分けのため）

> **注意:** 「マイクブースター」「音声修復」系の追加ソフトは入れないでください。許可と既定デバイスを直すほうが先です。ボリュームを最大まで上げてハウリングさせるのも避けます。

## 手順

### 1. Windows のマイク許可を確認する

1. **設定** → **プライバシーとセキュリティ** → **マイク**。
2. **マイクへのアクセス** がオンか見る。オフならオンにする。
3. **マイクにアクセスできるアプリを選択** で、使っている会議アプリやブラウザがオンか見る。
4. 下のほうの **デスクトップ アプリがマイクにアクセスすることを許可する** もオンにする（Store アプリではない Zoom / Discord / ゲームで必要です）。
5. 同じ画面に **カメラ** の許可が別にあるので、ビデオ会議で映像だけ無いときは [カメラが使えない手順](/articles/windows-camera-not-working/) も見る。取り違えないでください。

組織の PC では、このスイッチ自体が灰色で触れないことがあります。その場合は IT 担当へ、マイク画面のスクリーンショットを渡します。

### 2. 既定の入力機器を選ぶ

1. **設定** → **システム** → **サウンド**。
2. **入力** で、今口に向けている機器を選ぶ。内蔵と USB が並んでいるときは、名前で区別する。
3. 選んだ機器をクリックし、**音量** を 70〜80 付近にする。0 やミュート アイコンになっていないか見る。
4. 画面の入力レベルが、声に合わせて動くか確認する。

動かないときは、同じページの **入力デバイスのテスト** や、古い画面の確認に進みます。

1. サウンド設定の関連リンクから **サウンドのコントロール パネル**（または `mmsys.cpl`）を開く。
2. **録音** タブで、使いたい機器を右クリック → **既定のデバイスにする**。使わない「ステレオ ミキサー」や切れている Bluetooth は **無効** にして、誤選択を防ぐ。
3. 対象をダブルクリック → **レベル** タブで、マイクとマイク ブーストがミュート解除されているか見る。ブーストは +10dB までを目安にし、ノイズが増えたら戻す。
4. **リッスン** タブの「このデバイスをリッスンする」は、確認用に短時間だけオンにし、ハウリングしたらすぐオフ。

### 3. 排他モードと通信時の設定を外す

特定のアプリを閉じると直る、開き直すとまた独占されるときに効きます。

1. 録音タブで対象マイクの **プロパティ** → **詳細** タブ。
2. **アプリケーションによってこのデバイスを排他的に制御できるようにする** をオフ。
3. **設定 → システム → サウンド → 詳細設定**（またはコントロール パネルの **通信** タブ）で、**通信アクティビティの発生時** を **何もしない** にする。Windows が通話を検知して入力を絞ると、「相手には小さい」になります。
4. 会議アプリを再起動し、アプリ内のスピーカー / マイク選択が、設定と同じ機器名になっているか見る。Windows 側は合っていても、Teams やブラウザが別デバイスを掴んでいることがあります。

### 4. Bluetooth と USB を切り分ける

1. Bluetooth ヘッドセットなら、一度切断し、有線または内蔵マイクで声が届くか見る。内蔵で届くなら機器側かプロファイルです。
2. 接続し直し、通話を始めてから、設定の入力名がヘッドセットの **Hands-Free** 側に変わったか確認する。音楽再生用の名前のままだと、マイクが無いことがあります。
3. USB マイクなら、モニターの USB ではなく PC 本体へ直挿しする。認識自体が不安定なら USB の記事へ戻る。
4. 外付けディスプレイの内蔵マイクが既定に奪われることがあります。[ディスプレイをつないだ直後](/articles/external-display-no-signal/) から声が届かなくなったら、入力一覧でモニター名が選ばれていないか見る。

### 5. オーディオドライバーを標準に戻す

1. デバイス マネージャー → **オーディオの入力および出力** と **サウンド、ビデオ、およびゲームのコントローラー**。
2. マイク項目に「！」があれば、右クリック → **デバイスのアンインストール** のあと再起動し、挿し直す。
3. Realtek などのユーティリティでノイズ抑制・環境キャンセルをオンにしている場合は、一時的にオフにする。声ごと消す設定になっていることがあります。
4. ドライバーは PC メーカーのオーディオ用を使う。汎用の「Realtek 最新パック」をまとめサイトから入れる必要はありません。

起動時にオーディオユーティリティが複数立ち上がっていると、既定デバイスが毎回書き換わります。不要なら [スタートアップの整理](/articles/windows-startup-apps/) で、音に関係する常駐だけ残します。

## まだ直らないとき

- 設定のレベルは動くが会議だけダメ → ブラウザならアドレス欄のマイク許可（鍵アイコン）、アプリなら再インストールより先にアプリ内のデバイス選択と、OS のデスクトップ アプリ許可を見直す
- 自分には聞こえるが相手だけ無音、かつ Bluetooth → 通話中だけ Hands-Free に切り替わり、品質が落ちることがあります。テストは有線でもう一度
- 録音はできるが音が小さすぎる → マイクと口の距離、マスク、指向性。ブーストを上げる前に、物理的な位置を変える
- どの機器でもレベルがゼロ、デバイス マネージャーに入力が無い → ドライバーまたはハードウェア。保証内なら、手順1〜2のスクリーンショットと、別のマイク（イヤホン付属のインラインでも可）での結果を添えてメーカーへ
- 職場PCでプライバシー画面が操作できない → 個人の設定では終わりません。会議ツール名と、「レベルは動く / 動かない」を担当へ伝える
