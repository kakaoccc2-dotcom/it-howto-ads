「DNS サーバーに問題があります」は、回線断とは限りません。番号（IP）では開けるのに名前だけ失敗するなら、キャッシュと DNS を見てください。

## 症状の見分け

- 特定のサイトだけ開けない。検索や動画はできる
- Chrome が `DNS_PROBE_FINISHED_NXDOMAIN` や `DNS_PROBE_FINISHED_BAD_CONFIG` を出す
- スマホのモバイルデータでは同じサイトが開ける
- `ping 8.8.8.8` は通るが、`ping example.com` は名前解決に失敗する
- アドレス欄の文面が「接続はプライベートではありません」ではない。証明書の警告は別件です

番号の ping も失敗するなら、DNS より先にケーブル・Wi-Fi・アダプターです。Wi-Fi はつながっているのにネットに出られないときは [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) が先です。有線のアイコンが切れているときは [有線LANが繋がらないとき](/articles/ethernet-not-connecting/) です。会社 VPN を切ると直る、つなぐと再現するなら [VPN が繋がらないとき](/articles/windows-vpn-cannot-connect/) です。鍵の警告（NET::ERR_CERT_）なら [接続はプライベートではありません](/articles/browser-connection-not-private/) を先に見てください。

## よくある原因

1. Windows の DNS キャッシュが古い（サイト移転や、さっきまで障害だったとき）
2. ルーターまたは ISP の DNS が一時的に応答しない
3. 「セキュア DNS」（HTTPS 経由の DNS）や、セキュリティソフトの DNS フィルタ
4. 手動で入れた DNS / プロキシが、引っ越し後やVPN後に残っている
5. アダプターが中途半端に無効、または仮想アダプター（VPN、Docker、仮想マシン）が優先されている

Android 側の「接続済み・インターネットなし」は [Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) が近いです。iPhone で同じサイトだけ開けないときも、端末の日付と Wi-Fi の入れ直しは [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) です。

## 直す前に

- スマホのモバイルデータで、同じサイトが開けるか確認する（サイト側の障害切り分け）
- 家の別端末（テレビ、他のPC）でも同じか見る
- 作業中に開いているVPNは一度切る
- PC の時計が大きくずれていると、名前は解けても次の画面で証明書エラーになります。時刻は [時計がずれるとき](/articles/windows-time-out-of-sync/) です

> **注意:** レジストリ掃除や「ネット修復ツール」のダウンロードは不要です。標準のネットワーク設定と、数行のコマンドで足りることがほとんどです。

## 手順

### 1. 本当に DNS かを切り分ける

1. 別のブラウザ（Edge と Chrome など）でも同じか見る。同じならブラウザ拡張よりOS / 回線側です。
2. アドレス欄に `https://1.1.1.1` のように、名前ではなく番号で開けるか試す。番号で開けて名前だけダメなら DNS です。
3. `Windows` キーを押し、`cmd` と入れて **コマンド プロンプト** を開く。
4. 次を実行する。

```text
ping 8.8.8.8
nslookup example.com
```

`ping 8.8.8.8` がタイムアウトなら、Wi-Fi の入れ直しやケーブル、ルーター再起動を先にします。プリンターなど別機器だけ不通なら [プリンターがオフライン](/articles/printer-offline/) を優先してください。

**ここで失敗したとき:** `nslookup` が「存在しないコマンド」なら、入力場所が PowerShell でも動きます。同じ2行を貼ってください。「サーバー: UnKnown」「タイムアウト」だけなら、今向いている DNS が返事をしていません。手順3でサーバーを変える段階です。`ping example.com` が「見つかりませんでした」で、`ping 8.8.8.8` が「損失 = 0%」なら、この記事の続きで足ります。両方タイムアウトなら、DNS の数字を変えても開きません。

### 2. DNS キャッシュを消す

コマンド プロンプトを **管理者として実行**し、次を順に打ちます。

```text
ipconfig /flushdns
ipconfig /release
ipconfig /renew
```

社内LANで `release` が禁止されていることがあります。失敗メッセージが出たら、`flushdns` だけでも効果があるので、ブラウザを開き直して確認します。

**ここで失敗したとき:** 「要求された操作には管理者特権が必要です」なら、スタートの検索で **コマンド プロンプト** を右クリックし、**管理者として実行** です。普通の窓では `flushdns` が拒否されます。`release` のあと `renew` が失敗し、IP が `169.254.` になるなら、ルーターから住所をもらえていません。DNS ではなく、Wi-Fi の再接続か、有線なら [有線LANが繋がらないとき](/articles/ethernet-not-connecting/) です。`renew` が失敗したまま放置せず、ルーターを 30秒抜いてからもう一度 `renew` してください。

### 3. DNS サーバーを一時的に変える

ISP の DNS が重いときに効きます。確認用として、Cloudflare または Google の公開 DNS に切り替えます。常用するかどうかは、あとで戻せます。

1. **設定** → **ネットワークとインターネット** → 使っている接続（Wi-Fi または Ethernet）を開く。
2. **ハードウェア プロパティ**（またはアダプターのオプション）から、**DNS サーバーの割り当て**を **手動** にする。
3. IPv4 の優先 DNS に `1.1.1.1`、代替に `1.0.0.1` を入れる（または `8.8.8.8` / `8.8.4.4`）。
4. 保存し、ブラウザを開き直す。

IPv6 の欄が空のままで保存できない機種は、IPv6 の優先に `2606:4700:4700::1111`、代替に `2606:4700:4700::1001` を入れるか、IPv6 のトグルをオフにして IPv4 だけ保存します。よくわからないときは IPv4 だけ埋めて、IPv6 は「自動」のままにしてください。

Chrome / Edge の **セキュア DNS** を使っている場合は、ブラウザ設定でいったんオフにして、OS 側の指定と二重になっていないか確認します。Chrome は **設定 → プライバシーとセキュリティ → セキュリティ → セキュア DNS を使用する** です。

**ここで失敗したとき:** 保存ボタンが灰色、または次の日に「自動」へ戻るなら、会社のポリシーか、セキュリティソフトが DNS を固定しています。数字を打ち直しても同じです。家庭用で戻るなら、入れたセキュリティソフトの「ウェブシールド」を一度切って、もう一度手動にしてください。直ったあとに自動へ戻して、また名前だけ失敗するなら、ISP の DNS が不安定です。手動のままにしてよいかは、家族の他の端末が自動のままで開けるかで判断します。

### 4. アダプターを切り直す

1. **設定** → **ネットワークとインターネット** → **詳細ネットワーク設定** → **ネットワーク アダプター オプション**。
2. 使っているアダプターを右クリックし、**無効にする** → 10秒 → **有効にする**。
3. VPN 用や仮想アダプターが何本もあるときは、使っていないものを無効にして、物理 Wi-Fi / Ethernet だけ残して試す。

名前に `vEthernet`、`VirtualBox`、`Wintun`、VPN 製品名が付いた行は、物理の Wi-Fi ではありません。無効にしても、そのソフトを次に開くと戻ることがあります。今の確認では、物理のアダプターだけ有効にしてブラウザを開き直してください。

**ここで失敗したとき:** 無効にしたあと、有効にしてもアイコンが戻らないときは、10秒足りないことがあります。もう一度無効→有効です。Wi-Fi の一覧自体が消えたなら、無効にしたのが Wi-Fi 本体です。同じ画面で有効に戻してください。戻らないときは再起動です。

### 5. プロキシが残っていないか

1. **設定** → **ネットワークとインターネット** → **プロキシ**。
2. **セットアップ スクリプトを使う** と **手動プロキシ セットアップ** がオフか確認する。
3. 会社PCで必須のプロキシなら、オフにせず IT 担当へ DNS エラー全文を渡す。

アドレス欄が `127.0.0.1` や、見知らぬポート番号のままなら、以前のフィルタソフトの残りです。家庭用でそのソフトを消したあとなら、手動プロキシをオフにしてブラウザを開き直します。

## 職場PCと、別の端末との違い

職場のアカウントで DNS の欄が灰色なら、個人の `1.1.1.1` は保存できません。エラー全文と `nslookup` の「サーバー」行を IT へ渡してください。

- 自分の PC だけ名前が失敗し、隣の席は開ける → この PC のキャッシュ、手動 DNS、プロキシ、仮想アダプターです
- 家の PC もスマホの Wi-Fi も同じサイトだけ失敗し、モバイルデータでは開ける → 家のルーターか ISP の DNS です。PC の初期化は後回しです
- 特定の社内サイトだけ失敗する → 公開 DNS に変えると、社内の名前が逆に解けなくなります。確認が終わったら自動に戻してください

## まだ直らないとき

- ルーターを 30秒電源オフ。光回線の終端装置（ONU）がある場合は、案内どおりの順番で再起動する。ONU だけ先に入れる機種と、ルーターから入れる機種があります。取扱説明の順を守ってください
- セキュリティソフトの「ウェブ保護」「DNSフィルタ」を一時停止して再現するか見る。直るなら除外設定を公式手順で入れる。停止したまま常用しない
- `nslookup` の結果に変な社内アドレスが出る、または hosts を触った記憶がある場合は、`C:\Windows\System32\drivers\etc\hosts` に自分で足した行がないか確認する（システムファイルなので、わからないときは触らない）。メモ帳で開いて、`#` 以外の見知らぬ行があれば、その行を消す前にコピーをデスクトップへ控える
- ブラウザだけ失敗し、メールアプリは届く → ブラウザのセキュア DNS か拡張機能です。シークレットウィンドウで同じサイトを開き、開けるなら拡張を疑います
- Windows のアプリ起動までおかしいときは、別件の [アプリが実行できません](/articles/windows-app-cannot-run/) も切り分けに使えます。DNS エラーと実行エラーは同時に出ても原因は別です

## まとめ

番号では通るのに名前だけ失敗するなら DNS です。キャッシュを消して、必要なら DNS を一時的に変えてみてください。直ったら、手動指定を自動に戻しても安定するか、一度見ておくとあとが楽です。
