ブラウザに「DNS サーバーに問題があります」と出ると、回線そのものが死んだように見えます。DNS は **サイト名を番号（IPアドレス）に変える電話帳** なので、電話帳だけ壊れていて、回線自体は生きていることがよくあります。一方で、本当にインターネットが切れているときも同じ画面になり得ます。

この記事では Windows 10 / 11 を中心に、他サイトや他端末で切り分けてから、キャッシュと DNS 設定を直します。

## 症状の見分け

- 特定のサイトだけ開けない（検索はできる、動画はできる、など）
- すべての https サイトで、Chrome が `DNS_PROBE_FINISHED_NXDOMAIN` や `DNS_PROBE_FINISHED_BAD_CONFIG` を出す
- スマホのモバイルデータでは同じサイトが開ける
- 会社VPNを切ると直る / つなぐと再現する
- コマンド プロンプトで `ping 8.8.8.8` は通るが、`ping example.com` は名前解決に失敗する

最後のパターンは、典型的な DNS 不調です。`ping 8.8.8.8` も失敗するなら、DNS より先にケーブル・Wi-Fi・アダプターを疑います。Wi-Fi はつながっているのにネットに出られないときは [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) が先です。

## よくある原因

1. Windows の DNS キャッシュが古い（サイト移転や、さっきまで障害だったとき）
2. ルーターまたは ISP の DNS が一時的に応答しない
3. 「セキュア DNS」（HTTPS 経由の DNS）や、セキュリティソフトの DNS フィルタ
4. 手動で入れた DNS / プロキシが、引っ越し後やVPN後に残っている
5. アダプターが中途半端に無効、または仮想アダプター（VPN、Docker、仮想マシン）が優先されている

Android 側の「接続済み・インターネットなし」は [Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) が近いです。

## 直す前に

- スマホのモバイルデータで、同じサイトが開けるか確認する（サイト側の障害切り分け）
- 家の別端末（テレビ、他のPC）でも同じか見る
- 作業中に開いているVPNは一度切る

> **注意:** レジストリ掃除や「ネット修復ツール」のダウンロードは不要です。標準のネットワーク設定と、数行のコマンドで足りることがほとんどです。

## 手順

### 1. 本当に DNS かを切り分ける

1. 別のブラウザ（Edge と Chrome など）でも同じか見る。同じならブラウザ拡張よりOS / 回線側です。
2. アドレス欄に `https://1.1.1.1` のように、名前ではなく番号で開けるか試す。番号で開けて名前だけダメなら DNS です。
3. `Windows` キーを押し、`cmd` と入れて **コマンド プロンプト** を開く。
4. 次を実行する。

```text
ping 8.8.8.8
nslookup example.com
```

`ping 8.8.8.8` がタイムアウトなら、Wi-Fi の入れ直しやケーブル、ルーター再起動を先にします。プリンターなど別機器だけ不通なら [プリンターがオフライン](/articles/printer-offline/) を優先してください。

### 2. DNS キャッシュを消す

コマンド プロンプトを **管理者として実行**し、次を順に打ちます。

```text
ipconfig /flushdns
ipconfig /release
ipconfig /renew
```

社内LANで `release` が禁止されていることがあります。失敗メッセージが出たら、`flushdns` だけでも効果があるので、ブラウザを開き直して確認します。

### 3. DNS サーバーを一時的に変える

ISP の DNS が重いときに有効です。家庭向けの確認用として、Cloudflare または Google の公開 DNS に切り替えます。常用するかどうかは、あとで戻せます。

1. **設定** → **ネットワークとインターネット** → 使っている接続（Wi-Fi または Ethernet）を開く。
2. **ハードウェア プロパティ**（またはアダプターのオプション）から、**DNS サーバーの割り当て**を **手動** にする。
3. IPv4 の優先 DNS に `1.1.1.1`、代替に `1.0.0.1` を入れる（または `8.8.8.8` / `8.8.4.4`）。
4. 保存し、ブラウザを開き直す。

Chrome / Edge の **セキュア DNS** を使っている場合は、ブラウザ設定でいったんオフにして、OS 側の指定と二重になっていないか確認します。

### 4. アダプターを切り直す

1. **設定** → **ネットワークとインターネット** → **詳細ネットワーク設定** → **ネットワーク アダプター オプション**。
2. 使っているアダプターを右クリックし、**無効にする** → 10秒 → **有効にする**。
3. VPN 用や仮想アダプターが何本もあるときは、使っていないものを無効にして、物理 Wi-Fi / Ethernet だけ残して試す。

### 5. プロキシが残っていないか

1. **設定** → **ネットワークとインターネット** → **プロキシ**。
2. **セットアップ スクリプトを使う** と **手動プロキシ セットアップ** がオフか確認する。
3. 会社PCで必須のプロキシなら、オフにせず IT 担当へ DNS エラー全文を渡す。

## まだ直らないとき

- ルーターを 30秒電源オフ。光回線の終端装置（ONU）がある場合は、案内どおりの順番で再起動する
- セキュリティソフトの「ウェブ保護」「DNSフィルタ」を一時停止して再現するか見る。直るなら除外設定を公式手順で入れる
- `nslookup` の結果に変な社内アドレスが出る、または hosts を触った記憶がある場合は、`C:\Windows\System32\drivers\etc\hosts` に自分で足した行がないか確認する（システムファイルなので、わからないときは触らない）
- Windows のアプリ起動までおかしいときは、別件の [アプリが実行できません](/articles/windows-app-cannot-run/) も切り分けに使えます

## まとめ

このメッセージは回線断とは限りません。**番号では通るが名前だけ失敗する**なら DNS です。キャッシュ削除 → DNS の手動指定 → アダプターの入れ直し、の順が安全です。直ったら、手動 DNS を自動に戻しても安定するか、一度は確認しておくとあとが楽です。
