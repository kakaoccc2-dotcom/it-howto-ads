LAN ケーブルを挿しても、タスクバーのパソコンのアイコンに×が付いたまま。「ネットワーク ケーブルが接続されていません」。設定を開くと、イーサネットの行が **無効**。Wi-Fi を切った瞬間、ページが開かなくなる。

Wi-Fi は「接続済み」なのにサイトだけ開かないときは [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) です。「DNS サーバーに問題があります」と出るなら [DNS の手順](/articles/windows-dns-server-problem/) です。ここは、ケーブルを挿しているのに Windows が有線を掴めていないときです。

## 症状の見分け

- ルーター側の口のランプが消えたまま。挿しても点かない
- ランプは点く。Windows は「ネットワーク ケーブルが接続されていません」、または **無効**
- **設定** に **イーサネット** の行が無い
- 「識別されていないネットワーク」と出て、ブラウザは開かない
- Wi-Fi をオフにすると通信が死ぬ。ケーブルは挿したつもり
- USB 変換やドックのときだけ出ない。本体の口に挿すと出る。またはその逆
- 同じ口に家族の PC を挿すと、その PC だけページが開く

ノートに LAN の口が無く、USB 変換も挿していないなら、有線はまだ始まっていません。応急は Wi-Fi です。

## よくある原因

1. ケーブルがルーターの **Internet**（WAN）側に入っている。並んでいる LAN の口ではない
2. 爪の折れたプラグで、奥まで入っていない
3. Windows でイーサネットが **無効**
4. デバイス マネージャーで、有線のアダプターが無効、または黄色い「！」
5. 前の家の固定 IP が残っていて、今のルーターの番号と違う
6. 省電力で、スリープのあとアダプターが落ちたまま
7. USB-LAN 変換やドックの接触

## 直す前に

- このページを Wi-Fi で見ているなら、その Wi-Fi のパスワードを控える。最後の **ネットワークのリセット** は、Wi-Fi のパスワードも消します
- ルーターの電源を何度も抜く前に、ケーブルの口を一つ隣へ変えてみる
- 「LAN 修復」「ネット一発復旧」の実行ファイルは入れない

> **注意:** レジストリと、配布サイトのドライバー一式は使いません。アダプターを入れ直すファイルは、PC メーカーのサポートにある型番だけです。**ネットワークのリセット** は、ケーブルと有効化が終わったあとです。

## 手順

### 1. ケーブルの先が、LAN の口か

1. 両端を一度抜き、奥まで挿し直す。爪が折れているプラグは、挿した感触があっても抜けています。
2. ルーター（ONU と一体の箱も含む）の口を見る。**Internet** や **WAN** と印字された口、色が一つだけ違う口は、壁や回線装置から来る側です。PC のケーブルは、**LAN** と書いてある並びの空いている口へ挿す。WAN に PC を挿すと、ランプが点いてもネットには出ません。
3. 挿した口のランプを見る。点灯か点滅になるか。ノートは、本体側にランプが無い機種があります。ルーター側だけでも分かります。
4. 予備のケーブルが一本あるなら入れ替える。入れ替えてランプが点くなら、最初のケーブルです。
5. 同じ口に家族の PC を挿して、その PC だけページが開くなら、ケーブルとルーターは生きています。この PC は手順2です。どの PC でもランプが死んでいるなら、口かケーブルかルーターです。設定のスイッチは、まだ押しません。

### 2. Windows で無効になっていないか

1. **設定 → ネットワークとインターネット** を開く。**イーサネット** があれば開く。状態が無効、アダプターが無い、と読めるなら次です。
2. **ネットワークの詳細設定** を開く。一覧のイーサネットが無効なら **有効にする**。
3. 有効にしたあと、**ネットワークとインターネット** の上のほうに、イーサネットが接続済みと出るか見る。
4. 詳細設定にイーサネットの行が無いときは、スタートの検索に「コントロール パネル」と入れる。**ネットワークとインターネット → ネットワークと共有センター → アダプターの設定の変更**。**イーサネット** が灰色なら右クリック → **有効にする**。
5. その画面の文が「ネットワーク ケーブルが接続されていません」なら、Windows はアダプターを認識しています。無効ではありません。手順1のランプと口に戻ります。
6. Windows 10 で **ネットワークの詳細設定** が無いときは、**設定 → ネットワークとインターネット → 状態 → アダプターのオプションを変更する** から、同じ有効化ができます。

### 3. デバイス マネージャーと、USB 変換

1. スタートボタンを右クリック → **デバイス マネージャー** → **ネットワーク アダプター**。
2. Realtek、Intel、USB の LAN、など有線らしい行を右クリックする。**デバイスを有効にする** と出るなら、それが無効です。押して、設定のイーサネットが戻るか見る。
3. 黄色い「！」の行は、右クリック → **デバイスのアンインストール**。ドライバーの削除にチェックが出ても、外したまま進める。再起動すると、Windows が標準のドライバーを入れ直します。
4. 更新の直後からだけおかしく、**プロパティ → ドライバー → ドライバーを元に戻す** が押せるなら、アンインストールより先にそれを押します。ボタンが灰色なら、戻す履歴が無いのでアンインストール側です。
5. USB 変換やモニター裏のドックなら、ハブを外して PC の USB 口へ直接挿す。挿しても行が増えない、接続音も無いときは [USB 機器が認識されない](/articles/usb-device-not-recognized/) です。本体に LAN の口が無いノートは、この変換が死ぬと有線は使えません。

### 4. 169.254 と、前の家の固定 IP

ケーブルは認識されている。ブラウザだけ開かない、識別されていない、のときです。

1. **設定 → ネットワークとインターネット → イーサネット** を開く。**IP 割り当て** の **編集** が **手動** なら、**自動 (DHCP)** に変えて保存する。前の家の `192.168.0.x` が残っていると、今のルーターと話しません。
2. 同じページの DNS も **自動 (DHCP)** に戻す。番号では開くのに名前だけ失敗する話は [DNS の手順](/articles/windows-dns-server-problem/) です。
3. **ハードウェア プロパティ** で、IPv4 が `169.254.` で始まっていたら、ルーターから番号をもらえていません。ケーブルを挿し直し、ルーターの電源をコンセントから 30 秒抜いて戻す。モデムとルーターが別の箱なら、モデムを先に入れてランプが落ち着いてからルーターです。家の Wi-Fi も同時に切れます。
4. `169.254.` が消えて `192.168.` や `10.` になり、それでもサイトが開かないなら、有線は掴めています。先は [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) です。

### 5. スリープのあとだけ死ぬとき

1. フタを閉じたあと、有線だけ戻らないノートは、省電力でアダプターが落ちていることがあります。デバイス マネージャーの有線の行を右クリック → **プロパティ** → **電源の管理**。**電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする** のチェックを外す。
2. 再起動し、一度スリープさせてから戻す。ランプと、設定の「接続済み」が残るか見る。
3. ケーブルも有効化も IP も見て、この PC だけ有線が出ないときがリセットです。**設定 → ネットワークとインターネット → ネットワークの詳細設定 → ネットワークのリセット → 今すぐリセット**。確認で **はい** を押すと、サインアウトのあと再起動します。Wi-Fi のパスワードと VPN の設定は消えます。
4. リセットのあと、自宅のファイル共有だけ見えなくなることがあります。イーサネットの **ネットワーク プロファイルの種類** がパブリックに戻っていたら、プライベートにします。資格情報の窓だけ何度も出るなら [共有フォルダーの資格情報](/articles/windows-shared-folder-credentials/) です。

## まだ直らないとき

- 別の PC を同じケーブル、同じ口に挿すと出る。この PC は有効化も再起動も済み、デバイス マネージャーに有線の行が戻らない → アダプターかドックです。分解はしません。USB 変換を一本、本体の口へ直接挿して行が増えるか見る、が修理の前の切り分けです
- どの PC でもその口だけ死んで、隣の LAN 口は生きている → ルーターのその口です。Windows の有効化では戻りません
- 家じゅう、Wi-Fi も有線もダメ → 回線側です。アダプターを何度も無効にしても戻りません。障害の案内は、スマホのモバイルデータで見ます

## まとめ

ランプが死んでいるなら、WAN ではなく LAN の口か、ケーブルです。Windows に **無効** と出ているなら、**ネットワークの詳細設定** の **有効にする** です。接続済みの表示まで出たのにサイトが開かないときは、IP の自動（DHCP）と DNS に移ります。
