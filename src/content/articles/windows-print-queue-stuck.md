テストページを押したのに、キューの先頭が「削除中」のまま3分動いていない。次のPDFも、その1件が消えるまで出てこない。本体のランプは点いていて、コピーは取れる。紙やインクより先に、Windows が抱えた印刷ジョブを見ます。

アイコンが「オフライン」だけのときは [プリンターがオフラインの手順](/articles/printer-offline/) が先です。こちらは、準備完了に見えるのにキューだけが詰まっているときです。

## 症状の見分け

- 状態が「印刷中」「削除中」「エラー」「応答を待機しています」のまま、件数が減らない
- 右クリックのキャンセルが「削除中」に変わるだけで、行が消えない
- 新しい印刷が、古いジョブのうしろで待つ
- パネルのコピーは出る。パソコンからだけ出ない
- アイコンに一時停止のマークが付いている
- ブラウザを閉じても、同じPDFがキューへ戻り続ける

1枚だけ「エラー」で、次の文書は出るなら、そのファイル側です。全部止まるなら、先頭のジョブか待ち行列です。

## よくある原因

1. 失敗したジョブが先頭に残り、次の印刷を待たせている
2. キューが「一時停止」、または「オフラインで使用する」になっている
3. 印刷スプーラーが途中で固まった
4. スプール用フォルダーに、壊れた一時ファイルが残っている
5. ブラウザやPDFアプリが、同じ文書を送り直している
6. 標準ドライバーとメーカー製が二重で、状態だけ「エラー」のまま

## 直す前に

- キューに並んでいる名前を見る。このあと取り消すと、その印刷は破棄される。Word や写真の原本は残る
- 会社の共有プリンターでは、サーバー上の他人のジョブは消さない。自分のPCに出ている行だけ触る
- 「印刷修復」という実行ファイルは入れない

> **注意:** 消えるのは未送信のジョブと一時ファイルです。ドキュメントフォルダーの原本は対象外です。レジストリの書き換えや、出所のわからない修復ツールは使わないでください。

## 手順

### 1. 先頭のジョブと、一時停止を確認する

1. **設定** → **Bluetooth とデバイス** → **プリンターとスキャナー**。Windows 10 では **設定** → **デバイス** → **プリンターとスキャナー**。
2. 普段使うプリンターを開き、**印刷キューを開く**。
3. いちばん上の状態を見る。「削除中」「印刷中」のままなら、その行が次の印刷を止めています。
4. その行を右クリックして **キャンセル**。メニューが無ければ、上部の **プリンター** → **すべてのドキュメントの取り消し**。
5. 同じ **プリンター** メニューで、次にチェックが付いていたら外す。
   - 一時停止
   - オフラインで使用する

キューが空になり、テストで1枚出ればここまでです。「削除中」のままなら、次の手順でアプリを閉じてから、スプーラーの再起動へ進みます。

### 2. 送り主のアプリを閉じる

1. 印刷したブラウザ、Acrobat、Word を終了する。タブを残すと、失敗したジョブを再送することがあります。
2. キューをもう一度開き、件数が増えていないか見る。
3. **プリンターとスキャナー** の対象プリンターから **テストページの印刷** を押す。設定画面に無いときは **プリンターのプロパティ** を開き、**テスト ページの印刷**。

テストだけ出るなら、さっきのPDFかアプリです。テストもキューで止まるなら、スプーラーです。

### 3. 印刷スプーラーを再起動する

1. タスクバーの検索に `サービス` と入れ、**サービス** を開く。
2. **印刷スプーラー** をダブルクリックする。
3. **停止** を押し、状態が「停止」になるまで待つ。
4. **開始** を押す。スタートアップの種類は **自動** のままにする。無効にはしない。
5. キューを開き直し、古い行が消えているか見る。消えていればテストを1枚。

停止のときに「これらのサービスも停止します」と出たら、名前を読んで **はい**。印刷と一緒に止まるサービスです。終わったあと、印刷スプーラーが「実行中」に戻っていることを確認します。一緒に止まったサービス（Fax など）は、印刷スプーラーを開始しても自動では戻らないので、使うならそのサービスも開始します。

### 4. 「削除中」が残るときだけ、一時ファイルを捨てる

手順3のあとでも行が残るときだけです。

1. **サービス** で **印刷スプーラー** を再び **停止** する。実行中のままでは、ファイルが消えません。
2. エクスプローラーのアドレス欄に次を貼り付けて開く。

```
C:\Windows\System32\spool\PRINTERS
```

3. 中のファイルを削除する。フォルダー自体は残す。中が空なら、この手順は不要です。
4. **印刷スプーラー** を **開始** する。
5. キューが空か確認し、テストを1枚出す。

> **注意:** 消してよいのは PRINTERS フォルダーの中身だけです。`System32` 全体や、別の spool フォルダーは触らないでください。削除に管理者の確認が出たら、そのPCの管理者で開いているかを見ます。会社PCで拒否されるときは、権限を無理に変えず、ジョブ名と時刻を担当へ渡してください。

### 5. どのプリンターへ送っているか

1. 印刷画面の名前が **Microsoft Print to PDF** や、処分した機種のままになっていないか見る。
2. **プリンターとスキャナー** に同じ機種が2行あるときは、使う1台だけ残す。Fax や PDF への仮想プリンターは残してよい。
3. USB で挿した瞬間にキューがエラーへ戻るときは、ケーブルとポートです。[USBデバイスが認識されないとき](/articles/usb-device-not-recognized/) で切り分けてから、印刷に戻ります。

名前は正しいのに状態だけ「エラー」なら、メーカー公式の、いまの Windows 向けドライバーを入れ直します。付属CDは Windows 11 では古いことが多いです。

## まだ直らないとき

- 状態が「オフライン」に変わる → [オフラインの手順](/articles/printer-offline/) へ。キューを空にしたあとの話です
- テストは出るが、特定のソフトだけ止まる → そのソフトのプリンター選択と、印刷範囲を見る
- 別のPCからは出る → このPCのスプーラーかドライバーです。本体故障ではないことが多い
- どのPCからも出ず、パネルのコピーも失敗 → 紙詰まり、インク、本体側。パネルの表示を控えてメーカーへ
- 共有プリンターで「アクセスが拒否されました」 → キュー削除では直りません。共有名と、自分のジョブの名前を担当へ

渡すときは、状態の文言（「削除中」など）、おおよその時刻、USBかWi-Fiか、テストが出たかを添えます。

## まとめ

先頭を取り消し、一時停止とオフライン指定を外す。「削除中」が残るなら、印刷スプーラーを止めてから PRINTERS の中身を消し、サービスを戻す。Word や写真の保存先はそのままです。
