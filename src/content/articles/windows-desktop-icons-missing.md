壁紙だけが残って、ショートカットもごみ箱も無い。昨日まで並んでいた書類が、今日は半分しか見えない。タスクバーとスタートは普通に押せる。表示がオフか、外したモニターの側に寄ったか、デスクトップの保存先が別の場所へ移ったか、です。ファイルが消えた、とはまだ決めません。

タスクバーやスタートまで反応しないときは、アイコンの設定より先に [スタートメニューとタスクバー](/articles/windows-start-menu-taskbar-broken/) です。フォルダーを開くと「応答なし」になるときは [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/) を見てください。

## 症状の見分け

- ごみ箱まで含めて、デスクトップが完全に空。右クリックのメニューは出る
- ごみ箱は残っている。自分で置いたショートカットや書類だけが無い
- アイコンが米粒ほど小さい。または画面の右端に名前だけが切れて並ぶ
- ノートにモニターをつないだ日のあと、ケーブルを抜いたら空になった
- エクスプローラーで「デスクトップ」を開くとファイルはある。画面の壁紙の上にだけ出てこない
- サインインのたびに「一時プロファイルでサインインしています」と出る。その日のデスクトップだけ空

右クリックができない、時計も止まった、なら手順6です。再起動してもタスクバーまで戻らないときは、[スタートメニューとタスクバー](/articles/windows-start-menu-taskbar-broken/) へ進みます。

## よくある原因

1. 右クリックの **表示** で、**デスクトップ アイコンの表示** がオフ。更新のあと、このチェックだけ外れることがある
2. ごみ箱や「PC」など、システム側のアイコンのチェックが外れている。書類はそのまま
3. `Ctrl` とホイールで、アイコンが極端に小さくなった
4. いま繋いでいない画面の位置に、アイコンが残っている
5. 保存先が OneDrive のデスクトップへ移り、サインインが切れて空に見える
6. エクスプローラーが壁紙だけ描いて、アイコンの描画が止まっている

## 直す前に

- 画面から消えても、ファイルが削除されたとは限らない。ごみ箱を空にする、クリーナーを入れる、はまだしない
- 「デスクトップ復元」「アイコン修復」系の実行ファイルは入れない
- 家族と共有の PC なら、今サインインしている名前を先に見る。アカウントが違えば、デスクトップの中身も別

> **注意:** この記事ではレジストリの配布ファイル、デスクトップの初期化、ユーザーフォルダーの削除は使いません。表示を戻しても、すでに削除したファイルは復活しません。

## 手順

### 1. 表示のチェックと、アイコンの大きさを戻す

1. デスクトップの何も無いところを右クリックする。メニューが出たら **表示** を開く。
2. **デスクトップ アイコンの表示** にチェックを入れる。すでに付いているなら、一度外して付け直す。
3. 同じ **表示** で **大アイコン** を選ぶ。**小アイコン** のまま、壁紙と名前の色が近いと、あるのに見落としやすいです。
4. デスクトップをクリックしてから、`Ctrl` を押しながらマウスホイールを上に回す。アイコンが拡大すれば、極小になっていただけです。ホイールが無いノートは、手順3の **大アイコン** で足ります。
5. **アイコンの自動整列** にもチェックを入れる。画面の外に飛ばしていたショートカットが、見える範囲へ寄ることがあります。

ごみ箱とショートカットが戻れば、ここまでです。更新の翌日にまた空になるときは、同じチェックが外れていないかもう一度見る。

### 2. ごみ箱だけ、PCのアイコンだけを戻す

書類のショートカットは見える。ごみ箱や「PC」だけが無い、というときの操作です。

1. **設定** を開き、上の検索に「デスクトップ アイコン」と入れる。
2. **テーマの設定** や **デスクトップ アイコンの設定** を開く。検索に出ないときは **設定 → 個人用設定 → テーマ** まで進み、関連項目の **デスクトップ アイコンの設定** を押す。
3. **コンピューター**（表示は **PC** のこともある）、**ごみ箱** にチェックを入れる。使わない **ネットワーク** はオフのままでよい。
4. **OK** または **適用** を押す。デスクトップにごみ箱が戻るか見る。
5. アイコンの絵だけが白い紙になっているときは、同じ窓の **通常のアイコンに戻す**。ファイルの中身は消えません。

チェックを入れても何も増えない、設定の検索が何も出さない、ときは手順6へ進む。

### 3. 外したモニターの側に残っていないか

HDMI や USB-C で画面を増やしたあと、アイコンをそっちへ寄せたままケーブルを抜くと、主画面は空に見えます。

1. `Win` + `P` を押し、**PC 画面のみ** を選ぶ。
2. デスクトップで手順1の **アイコンの自動整列** をもう一度オンにする。
3. **設定 → システム → ディスプレイ** を開く。四角が2つ以上あり、今は繋いでいない画面が残っているなら、その四角を選ぶ。**複数のディスプレイ** で切断できる項目があれば切断する。
4. **識別** を押す。今見ている画面に数字が出るか確認する。数字が出ない側にアイコンがある、という状態です。ケーブルを一度挿し直し、アイコンを主画面へドラッグしてから抜くと確実です。
5. まだ空なら、同じ画面で解像度を一段だけ変え、すぐに元へ戻す。並びが組み直されて、主画面に出てくることがあります。

タスクバー自体がもう一方の画面にいるときは、スタートメニューの記事にある複数ディスプレイの手順です。

### 4. デスクトップフォルダーと、ごみ箱の中身

画面が空でも、ファイルはフォルダーに残っていることがあります。

1. `Win` + `E` でエクスプローラーを開き、左の **デスクトップ** を押す。
2. ここに書類やショートカットがあるなら、ファイルは消えていません。手順1と3に戻る。フォルダーも空なら、移動・削除・別の保存場所です。
3. アドレスバーに `OneDrive` と出る、左に OneDrive の **デスクトップ** が別にある、ときはクラウド側を開く。トレイの雲が「サインイン」「一時停止」なら、サインインし直すか同期を再開する。再開後にアイコンが戻ることがあります。
4. スタートの検索に「ごみ箱」と入れて開く。デスクトップにごみ箱の絵が無くても、中身はここから見られます。戻したいファイルだけ右クリックで **元に戻す**。中を空にはしない。
5. スタート → アカウントのアイコンで、今の名前を確認する。別人がサインインしていれば、その人のデスクトップを見ているだけです。

OneDrive のバックアップで「デスクトップ」をオンにした直後は、ファイルが OneDrive のデスクトップへ移ります。古い `C:\Users\自分の名前\Desktop` だけ開いて空、で終わらせないでください。

### 5. 壁紙と拡大率で、あるのに見えないとき

1. **設定 → 個人用設定 → 背景** で、壁紙を一度暗い無地に変える。アイコン名が読めるようになったら、白い壁紙に白い文字が乗っていただけです。
2. **設定 → システム → ディスプレイ → 拡大/縮小** が 300% やそれ以上なら、100% か 150% に戻す。極端な拡大だと、アイコンが画面に数個しか乗らず、残りはデスクトップの外に残ります。戻したあと、手順1の自動整列をオンにする。
3. 拡大を戻したあとに文字のにじみが残っても、アイコンが戻っていればこの手順は終わりです。にじみだけ直したいときは、拡大率を家庭で使う値に戻したところで止めます。

### 6. エクスプローラーを再起動する

チェックもフォルダーも正しいのに、壁紙の上だけ空のとき。

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー**。
2. **Windows エクスプローラー** を選び **再起動**。ボタンが **タスクの終了** だけのときは終了し、**新しいタスクを実行** に `explorer.exe` と入れて開く。
3. アイコンが一度消えて、すぐ描き直される。描き直されたあとにまだ空なら、手順1の **デスクトップ アイコンの表示** がオフのままです。もう一度チェックを入れる。
4. 再起動のあとタスクバーまで戻らないときは、デスクトップの表示設定では止まりません。スタートメニューの記事へ切り替えます。

## まだ直らないとき

- フォルダーにはファイルがある。画面にだけ無い → 表示のチェック、自動整列、外したモニター。削除ではない
- フォルダーも空で、ごみ箱にも無い → 別アカウントか、OneDrive をブラウザで開いたときのデスクトップ。復元ソフトは入れない
- ショートカットの絵だけが白い紙 → リンク先のアプリや書類が無い。ほかのアイコンが普通なら、その一つだけ作り直す
- 「一時プロファイル」と出る → 再起動を一度だけ。直らなければ、`C:\Users` の中に元のユーザー名のフォルダーが残っていないか見る。中のデスクトップから、必要なファイルを USB へコピーする。ユーザーフォルダー自体は消さない
- 職場の PC で右クリックに **表示** が無い → 個人の操作では戻せないことがあります。担当へ「デスクトップ アイコンの表示が選べない」と伝える

## まとめ

ごみ箱ごと消えたときは、右クリックの **デスクトップ アイコンの表示** とアイコンの大きさが先です。書類だけ無いときは、エクスプローラーのデスクトップ、ごみ箱、OneDrive の順に中身を見る。モニターを外した直後なら、抜いた画面の側に残っています。
