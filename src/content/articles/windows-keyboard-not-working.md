キーを叩いても文字が出ない。特定のキーだけ無反応。軽く押すと無視されて、長押しだとやっと出る。サインインのパスワード欄で止まっている、という状態は、基板故障より **フィルター キー、固定キー、USB の接触、Bluetooth キーボードの電池** が多いです。文字は出るのにひらがなにならないときは、先に [日本語入力（IME）の手順](/articles/windows-ime-japanese-input/) を見てください。

## 症状の見分け

- どのキーも無反応。マウスは動く。サインイン画面のパスワードが打てない
- 画面上のキーボードでは文字が出るが、実物のキーは出ない
- 軽く叩くと無視され、少し長めに押すと出る。同じ文字の繰り返しが極端に遅い
- Shift を数回押したあとチャイムが鳴り、タスクバーに四角いアイコンが出た。次の1文字だけ大文字になる
- 英字は打てるが、数字列や矢印だけ死んでいる（またはその逆）
- ノートの内蔵はダメで、挿した USB キーボードは打てる（またはその逆）
- Bluetooth キーボードだけ死んでいて、スマホや別の PC では打てる
- 水やコーヒーをこぼした直後、または特定の1キーが沈んだまま

マウスもキーボードも完全に死んでいるときは、この先より再起動と、別の USB 機器が差さるかです。USB メモリやマウスも出ないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) です。

## よくある原因

1. **フィルター キー** がオン。右の Shift を8秒ほど押すと、音とともに入ることがある。短い入力を捨てる
2. **固定キー** がオン。Shift を5回押すと入る。修飾キーの押し方が変わる
3. USB ポート、ハブ、ケーブルの接触。差した瞬間だけ使えて、少し触ると死ぬ
4. Bluetooth キーボードの電池切れ、または別のスマホ・タブレットに繋がったまま
5. キーボードのドライバーが更新のあと止まった。デバイス マネージャーに黄色い「！」
6. こぼした液体や、キーの下のごみ。1〜数キーだけ無反応になる
7. リモートの窓やゲームが、そのアプリの中だけキーを取っている

## 直す前に

- 文書が開いているなら、マウスでそのアプリの保存ボタンを押す。再起動で未保存は消えます
- キーが全部死んでいるあいだは、検索欄に文字を打てません。スタートボタンを右クリックして **設定** や **デバイス マネージャー** を出します
- 「キーボード修復」「全キー有効化」系の実行ファイルは入れない

> **注意:** キーボードを分解してキーを外す作業、レジストリの配布、BIOS の更新はしません。液体をかぶったあとに電源を入れ続けると、被害が広がることがあります。

## 手順

### 1. スクリーン キーボードで、実物か設定かを分ける

物理キーが死んでいても、マウスだけで進めます。

1. サインイン画面で止まっているときは、画面右下の人型アイコン（アクセシビリティ）を押し、**スクリーン キーボード** をオンにする。パスワードがそこから入るか見る。
2. デスクトップにいるときは、スタートボタンを右クリック → **設定** → **アクセシビリティ** → **キーボード**。Windows 10 は **設定 → 簡単操作 → キーボード**。
3. **スクリーン キーボード** をオンにし、メモ帳を開いて画面のキーをマウスで押す。
4. 画面のキーではすぐ文字が出て、実物のキーは無反応なら、以降はキーボード側です。画面のキーでも出ないなら、手前の窓が入力を取っています。メモ帳を開いて同じキーを押す。ひらがなだけ死んでいるなら IME の記事です。

画面のキーでパスワードが入ったら、デスクトップに入ってから手順2です。画面のキーもマウスも動かないときは、電源の長押しの前に、別の USB マウスを本体背面のポートへ直接挿します。

### 2. フィルター キーと固定キーを切る

「反応が悪い」「一拍おくと出る」は、ここだけで直ることが多いです。

1. **設定 → アクセシビリティ → キーボード** を開く。
2. **フィルター キー機能** をオフにする。行を開いた先に、右 Shift の長押しで起動するショートカットがあれば、それもオフにする。オンのままだと、また8秒押しただけで戻ります。
3. **固定キー機能** もオフ。Shift を5回で起動するショートカットがあれば外す。タスクバーの四角いアイコンが消えるか見る。
4. **切り替えキー機能** は、CapsLock や NumLock で音が鳴るだけです。チャイムが残るときだけオフにします。
5. スクリーン キーボードでスタートの検索に「コントロール パネル」と入れ、開いた窓の検索欄に「キーボード」と入れる。**速度** タブの **表示までの待ち時間** が「長」の端だと、軽く叩いた文字が捨てられたように見えます。スライダーを中央へ戻す。
6. メモ帳で a を軽く一回叩き、次に長押しして連続で出るか見る。

オフにしたあと軽く叩いて出るなら、キーボードは生きています。起動のショートカットを残すと、本や袖が Shift に乗っただけでまたオンになります。

### 3. 有線と Bluetooth、内蔵を分けて試す

1. USB キーボードなら、ハブやモニター裏のポートから抜き、PC 本体の別の穴へ直接挿す。ランプが点く型は、点くか見る。
2. 差してもデバイスが増えない、Windows の接続音も無いときは、USB の記事へ。別のマウスが同じ穴で動くなら、キーボードかケーブル側です。
3. Bluetooth キーボードは、裏面の電池と電源スイッチを見る。**設定 → Bluetooth とデバイス** で名前が「接続済み」か。切れているなら一度削除し、キーボード側のペアリングボタンを押して足し直す。つながり方の詳細は [Bluetooth がつながらないとき](/articles/windows-bluetooth-cannot-connect/) です。
4. 同じキーボードが別の PC やタブレットに「接続済み」のまま残っていると、今の PC では打てません。古い側を切断してから、今の PC でつなぎ直す。
5. ノートの内蔵だけ死んで、USB を挿すと打てるなら、内蔵側です。先に手順2がオフかを見て、まだダメなら手順4へ。USB キーボードが手元にあるあいだは、それを応急に使えます。

Fn ランプが付いたあと、一部のキーだけ別の記号になるノートがあります。文字が全然出ない症状とは違います。F1 列だけ死んでいるときは、Fn ロック（Fn と Esc、または鍵アイコン）を一度押して戻します。

### 4. デバイス マネージャーで、標準のキーボードに戻す

画面のキーでは打てて、フィルター キーもオフ、差し直しても実物だけ無反応、のときです。

1. スタートボタンを右クリック → **デバイス マネージャー**。
2. **キーボード** を開く。HID キーボード、標準 PS/2 キーボードなど。黄色い「！」が無くても、今つないでいる行を対象にします。
3. その行を右クリック → **デバイスのアンインストール**。ドライバーの削除にチェックが出たら、外したまま進める。再起動後に Windows が標準のドライバーを入れ直します。
4. 再起動して、メモ帳で実物のキーを叩く。

入れ直すドライバーは、PC またはキーボードメーカーのサポートページにある、その型番のものだけにします。まとめサイトの「キーボードドライバー一式」は使いません。更新の直後からだけおかしいときは、同じ行の **プロパティ → ドライバー → ドライバーを元に戻す** を先に押します。ボタンが灰色なら、戻す履歴が無いのでアンインストール側です。更新そのものが途中で止まっているときは [Windows Update が進まないとき](/articles/windows-update-stuck/) です。

### 5. 1キーだけ、液体、アプリの中だけ

1. 特定のキーだけ沈む、甘い液体のあとベタつく、なら電源を切る。裏返して液体を出し、乾くまで電源は入れない。米に埋める、キーをこじって洗う、はしません。保証内なら型番とこぼした時刻を添えて、メーカーか購入店へ。
2. ほこり程度で、液体ではないなら、電源を入れたまま本体を少し傾け、キーのすき間を乾いた布で払う。洗剤と濡れたティッシュは使わない。
3. デスクトップやメモ帳では打てて、リモートデスクトップやゲームの中だけ無反応なら、その窓がキーを取っています。一度そのアプリを終了し、メモ帳で同じキーが出るか見る。
4. Windows キーだけ死んでいるゲーミングキーボードは、本体の Win キーロックがあります。他の文字が出るなら故障ではありません。

> **注意:** キーキャップを全部外して基板をアルコールで拭く作業は、家庭の切り分けではしません。膜やハサミ足が折れます。

## まだ直らないとき

- スクリーン キーボードは打てる。フィルター キーはオフ。別の USB キーボードも同じ PC で打てない → ポート側。背面と前面、USB-A と USB-C を変えて、USB の記事の順で見る。分解はしない
- 別の USB キーボードはこの PC で打てる。内蔵だけずっと無反応 → 内蔵のキーボード側。外付けで使い、保証内ならメーカーへ。自分でフラットケーブルを挿し直さない
- 文字は出るが「A」のまま、変換だけ無い → IME の記事。キーボード故障ではない
- 水濡れ、異臭、キーの下からサビ → 設定をいじらず電源を切ったまま、修理
- 職場 PC でアクセシビリティのスイッチが灰色 → 個人の手順では終わりません。スクリーン キーボードでログオンできるかだけ伝え、担当へ

## まとめ

軽く押して無視されるときは、先にフィルター キーをオフにします。画面のキーでは打てて実物だけダメなら、差し直しと電池、その次にデバイス マネージャーです。1キーだけ沈む、液体のあと、は修理の判断に切り替えてください。
