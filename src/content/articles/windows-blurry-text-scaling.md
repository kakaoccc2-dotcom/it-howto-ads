ノートの文字は細いのに、つないだモニターだけ印刷物みたいに滲む。Excel だけぼやけて、ブラウザはくっきり。昨日まで普通だったのに、アイコンだけ巨大になった。解像度を一段階落としたあとに、壁紙の文字までにじむこともあります。

画面が暗い、または真っ黒なだけなら [明るさと真っ黒画面](/articles/windows-brightness-black-screen/) です。チカチカするなら [画面のちらつき](/articles/windows-screen-flickering/) です。モニターに何も出ないなら [信号無し](/articles/external-display-no-signal/) です。

## 症状の見分け

- デスクトップの文字もアイコンも、全体がにじむ
- 一つのアプリだけぼやけ、ほかの窓は鮮明
- 外付けモニターに移したときだけ、異常に大きい、または小さい
- 拡大率の一覧が選べず、上にカスタムの拡大と出ている
- ブラウザの中の文字だけ極端に大きい。デスクトップのアイコンは普通の大きさ
- 1920 の画面なのに、解像度が 1366 など **（推奨）** 以外になっている
- 画面の隅に拡大の枠が残り、マウスのまわりだけ大きい

全体が虹色に割れる、線が二重、ケーブルを触ると映ったり消えたり、は倍率ではなく接続です。外付けディスプレイの記事へ戻ります。

## よくある原因

1. **ディスプレイの解像度** が **（推奨）** から外れている
2. **拡大/縮小** が推奨から外れている。モニターを替えたあと、前の倍率が残った
3. **カスタム スケーリング** に 135 のような端数が入っている。サインアウトするまで、古い倍率と混ざる
4. 高 DPI に対応していない古いアプリを、Windows が画像として引き伸ばしている
5. ブラウザや Excel 自身のズーム。Windows の倍率とは別
6. ClearType がオフ、または別のモニター用の調整のまま
7. 拡大鏡（`Windows` キーと `+`）が開きっぱなし

## 直す前に

- 滲んでいるのが内蔵液晶か、外付けか、両方か、を一つ決めてから設定を開く
- カスタム倍率を戻すときにサインアウトになります。開いている文書は保存する
- まとめサイトの「画面くっきり化」「DPI 修復」は入れない。ドライバーを足すなら、PC メーカーのサポートにある型番のものだけ

> **注意:** 解像度を推奨より下げると、文字は大きくなりますが、全体が滲みます。大きくしたいだけなら、解像度は触らず、文字のサイズか拡大/縮小の推奨値です。

## 手順

### 1. ブラウザのズームと拡大鏡を閉じる

Windows の倍率を開く前に、アプリの中だけの拡大を外します。

1. Edge や Chrome で、そのページだけ大きいなら `Ctrl` を押しながら `0`。タブのズームが 100% に戻ります。`Ctrl` と `+`、または `Ctrl` とホイールを重ねたあとに起きやすいです。
2. タスクバーに虫眼鏡が残っている、画面の隅にルーペの枠がある、なら `Windows` キーと `Esc`。拡大鏡が閉じます。
3. 閉じたあともメモ帳やデスクトップのアイコンまで滲むなら、ブラウザのズームではありません。手順2へ。

Excel の表だけ大きいときは、ウィンドウ右下のズームが 100% 以外になっていないか見ます。ここは Excel の表示倍率で、ディスプレイの拡大/縮小とは別です。

### 2. 解像度と拡大/縮小を推奨に戻す

1. デスクトップの何もないところを右クリック → **ディスプレイ設定**。同じ場所は **設定 → システム → ディスプレイ** です。
2. 上にモニターの四角が二枚あるときは、滲んでいるほうをクリックしてから下の値を変えます。選んでいない側は変わりません。
3. **ディスプレイの解像度** を、行の中に **（推奨）** と書いてある値にする。
4. **拡大縮小とレイアウト** の **拡大/縮小** も、**（推奨）** の付いたパーセントにする。100%、125%、150% のどれが推奨かは、画面のサイズで違います。
5. 一覧が灰色で、上に「カスタムの拡大/縮小率が設定されています」と出ているときは、**カスタムの拡大/縮小率をオフにしてサインアウトする** を押す。入り直したあと、もう一度 **（推奨）** を選ぶ。
6. 壁紙に文字があるならその縁、タスクバーの時計、エクスプローラーのファイル名を見る。ここがくっきりで、一つのアプリだけ残るなら手順4です。

Windows 10 も **設定 → システム → ディスプレイ** の **拡大縮小とレイアウト** です。カスタムの数字を入れたあとは、同じくサインアウトしないと一覧のパーセントに戻れません。

### 3. 文字だけ大きくする

作業領域はそのまま、文字だけ上げたいときです。

1. Windows 11 は **設定 → アクセシビリティ → テキストのサイズ**。
2. スライダーを動かし、上の見本が読めるところで **適用**。
3. Windows 10 は **設定 → 簡単操作 → ディスプレイ** の **文字を大きくする** です。
4. 見本はくっきりなのに、特定のアプリだけ滲むなら、スライダーは元に戻して手順4へ。見本まで滲むなら、手順2の解像度が推奨から外れています。

### 4. そのアプリだけ、高 DPI を上書きする

古い会計ソフトや、社内だけの専用画面に多いです。Store から入れたアプリには、このタブが無いものがあります。

1. スタートでそのアプリを右クリック → **ファイルの場所を開く**。出てきたのがショートカットなら、もう一度右クリックして、実体のアプリまで進む。
2. 種類がアプリケーションのファイルを右クリック → **プロパティ** → **互換性**。
3. **高 DPI 設定の変更** を押す。
4. **高い DPI スケールの動作を上書きします** にチェックを入れ、**拡大縮小の実行元** を **アプリケーション** にする。OK のあと、そのアプリを完全に終了して開き直す。
5. 文字はくっきりだが、アイコンが極端に小さい、ボタンが欠ける、なら同じ場所で **システム（拡張）** に変えて開き直す。まだ崩れるなら **システム**。三つとも崩れるなら、チェックを外して元に戻します。
6. **互換性** タブ自体が無いアプリは、この上書きができません。手順2の推奨倍率のまま使うか、そのアプリの中の表示設定を見ます。

### 5. ClearType と、モニターを繋いだ直後

文字の縁だけ赤や青ににじむときに効きます。

1. スタートの検索に `ClearType` と入れる。**ClearType テキストの調整** を開く。
2. **ClearType を有効にする** にチェックがある状態で次へ進む。見本が数枚出るので、毎回いちばん読めるものを選んで完了。
3. モニターが二台のときは、見本がどちらの画面に出ているか見る。滲んでいる側で選びます。
4. 繋いだ直後だけ、位置も大きさもおかしい窓があるときは、ディスプレイ設定でそのモニターの **拡大/縮小** を推奨にしたあと、一度サインアウトして入り直す。繋いだ瞬間に開いていた窓は、古い倍率のまま引き伸ばされていることがあります。

## まだ直らないとき

- 推奨に戻しても画面全体が滲む、色が分離する、ケーブルを少し動かすと悪化する → 口とケーブル。映像が途切れるなら [外付けディスプレイ](/articles/external-display-no-signal/) です。ドライバーを入れ直すなら、PC またはディスプレイのメーカーページにある型番だけ
- リモートデスクトップの窓の中だけ滲む → 接続先の拡大です。手元の PC の倍率を変えても、向こうの文字はくっきりになりません
- HDR をオンにしたあと、白が浮いて文字が読みにくい → **設定 → システム → ディスプレイ** の **HDR** を開き、**HDR を使用する** をオフにして比べる。項目が無い PC は、この切り分けは不要です
- 拡大鏡を閉じても、マウスのまわりだけ大きい → `Windows` キーと `Esc` をもう一度。Windows 11 は **設定 → アクセシビリティ → 拡大鏡**、Windows 10 は **設定 → 簡単操作 → 拡大鏡** をオフにする

## まとめ

全体が滲むなら、解像度と拡大/縮小を **（推奨）** に戻します。カスタムの数字が残っているあいだは、100% や 150% の一覧が選べません。一つのアプリだけなら、そのアプリの **高 DPI 設定の変更** です。ブラウザの中だけ巨大なら、Windows を開く前に `Ctrl` と `0` です。
