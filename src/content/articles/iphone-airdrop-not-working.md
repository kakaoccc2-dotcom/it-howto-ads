写真の共有シートに相手の顔が出ない。出てもくるくるして失敗する。相手の iPhone には何も表示されない。Android には AirDrop は無いので、Apple 同士の話です。家の Wi-Fi に繋がらないときは [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) 、イヤホンが繋がらないときは [Bluetooth の手順](/articles/iphone-bluetooth-pairing/) です。家の SSID に入れなくても、Wi-Fi 機能と Bluetooth がオンなら AirDrop は使えます。

## 症状の見分け

- 共有シートの AirDrop 欄が空、または自分の名前しか無い
- 相手の名前は出るが、タップすると「失敗しました」
- 送った側は成功に見えるが、受け側に確認バナーが出ない
- **連絡先のみ** の相手だけ見つからない。**すべての人（10分間）** にすると出る
- 数センチまで近づけると NameDrop の画面になり、共有したい写真の話ではなくなる
- 自分の Mac には届くが、家族の iPhone には届かない（またはその逆）
- コントロールセンターでは Wi-Fi が青いのに、設定アプリではオフ

受け側の画面がロックされたままだと、バナーに気づかないことがあります。双方の画面を点灯させてから探してください。

## よくある原因

1. Wi-Fi か Bluetooth の片方だけオフ。コントロールセンターの見た目と、設定アプリの実体が違う
2. 受け側が **受信しない**、または **連絡先のみ** で、送り側の Apple ID が連絡先に無い
3. 機内モード、インターネット共有（テザリング）、VPN
4. 集中モードでバナーが黙っている
5. 古いままの「すべての人」設定。最近の iOS は **すべての人（10分間）** に変わっている
6. 距離、ケース、電子レンジ横など、電波が通らない場所
7. スクリーンタイムで AirDrop が禁止されている

## 直す前に

- 送る写真やファイルを、失敗しても消えない場所（写真アプリ）から選ぶ。途中でアプリを殺さない
- 双方の iPhone を 1〜2m 以内に置く。別の部屋から探さない
- 「AirDrop強化」「ファイル瞬間転送」を名乗るアプリは不要です。標準の共有シートで足ります

> **注意:** **ネットワーク設定をリセット** は Wi-Fi パスワードも消えます。AirDrop の切り分けでは最後まで使いません。相手の端末を勝手に初期化しないでください。

## 手順

### 1. 双方で Wi-Fi と Bluetooth をオンにする

送り側と受け側、同じ操作です。

1. **設定** → **Wi-Fi** をオン。今つながるSSIDが無くてもよい。スイッチが緑なら十分です。
2. **設定** → **Bluetooth** をオン。接続中のイヤホンはそのままで大丈夫なことが多いです。切り分けでダメなときだけ、イヤホンを切る。
3. コントロールセンター左上の四角を **長押し** し、**AirDrop** を開く。受け側はここで受信の状態も変えられます。
4. 機内モードがオンならオフ。インターネット共有（テザリング）がオンならオフ。AirDrop と取り合いになります。
5. VPN やプライベートリレーを使っている人は、切り分けのあいだオフ。社用 VPN は切断だけで、構成プロファイルは消さない。

コントロールセンターの扇アイコンは「よく使うネットへの再接続」で、設定の Wi-Fi スイッチとは別物です。扇が白いだけで Wi-Fi 機能までオフになっていると、AirDrop の相手一覧は空になります。

### 2. 受け側の受信設定を、切り分けのあいだ広げる

1. 受け側で **設定** → **一般** → **AirDrop**。
2. **受信しない** になっていたら、まず **連絡先のみ** を試す。
3. それでも送り側に名前が出ないときは **すべての人（10分間）** にする。10分で自動的に戻るので、切り分け用です。知らない人からの受信も一時的に入ります。終わったら **連絡先のみ** に戻す。
4. 送り側の Apple ID メールと電話番号が、受け側の **連絡先** に入っているか見る。「連絡先のみ」は、名前が登録してあるだけでは足りず、その連絡先に今の Apple ID と同じ番号かメールが必要です。
5. 双方の名前が **設定** 一番上の自分の名前と、AirDrop に出る名前で揃っているか見る。ニックネームだけ違うと、探す側が見落とします。

iOS の版によっては、コントロールセンターからしか **すべての人（10分間）** が選べません。設定アプリと両方見てください。

### 3. 送り直す（共有シートから）

1. 受け側の画面を点灯させる。ロックしたままだと気づきにくい機種があります。
2. 送り側で写真を開き、共有ボタン → 上段の **AirDrop**。出てきた相手のアイコンを1回だけタップ。連打すると失敗しやすいです。
3. 受け側に「受け入れる」が出たら **受け入れる**。集中モードの三日月が出ているときは、コントロールセンターからオフにして、もう一度送る。
4. 「失敗しました」と出たら、双方でカメラやゲームの全画面を閉じてから、手順1の Wi-Fi / Bluetooth をオフ→10秒→オンして送り直す。
5. 2台をケースごと重ねない。金属ケースやMagSafe の厚いものだと見つかりにくいことがあります。少し離す。

画面を近づけすぎると、連絡先を交換する NameDrop が先に出ます。共有したいだけなら、10〜30cm 以上離して、共有シートの AirDrop から指名してください。

### 4. 集中モード、制限、Mac のとき

1. 受け側の **設定 → 集中モード**。おやすみ時間や睡眠がオンならオフ。ロック画面を左右に払って、集中モード用の別画面に居続けていないか見る。通知が来ないときの話は [iPhone の通知手順](/articles/iphone-notifications-not-working/) と同じです。
2. **設定 → スクリーンタイム → コンテンツとプライバシー制限** がオンなら、許可されたAppや通信関連に AirDrop が無いか見る。家族の制限で灰色なら、保護者側です。
3. 相手が Mac のときは、Mac 側で Wi-Fi と Bluetooth をオンにし、コントロールセンター（または **システム設定 → 一般 → AirDropとHandoff**）で受信を許可する。ファイアウォールの「ステルスモード」がオンだと見つからないことがあります。ステルスを切るか、同じ Apple ID のデバイス同士で試す。
4. 古い iPhone と新しい iPhone では、片方の iOS が古すぎると相手が一覧に出ません。双方を再起動してから、もう一度手順2の **すべての人（10分間）** で探す。

同じ Apple ID でサインインした自分の Mac と iPhone なら、**連絡先のみ** でも通ることが多いです。家族の別 ID だけ失敗するなら、手順2の連絡先不足です。

## まだ直らないとき

- 自分の別の Apple 機器には届く → 届かない相手側の受信設定、画面オフ、集中モード
- どの相手にも自分が出ない → 手順1。テザリングと機内モードの取りこぼしが多い
- 写真は送れるがキーノートや大きな動画だけ失敗 → 相手の空き容量。動画は一度写真アプリに保存してから、少し待って再送
- 以前は同じ2台で使えていた → 双方を再起動。iOS 更新の直後は、Wi-Fi と Bluetooth を入れ直す
- ネットワーク設定のリセットは、Wi-Fi も Bluetooth の一部も消えるので、AirDrop のためだけには使いません。ここまででダメなら Apple サポートへ、双方の iOS の版と「連絡先のみ／10分間」のどちらで失敗したかを伝える

## まとめ

設定アプリで、双方の Wi-Fi と Bluetooth をオンにする。受け側は切り分けのあいだ **すべての人（10分間）**。名前が出ないときは、連絡先に相手の Apple ID と同じ番号かメールがあるかです。テザリングがオンだと、相手一覧が空になりやすいです。
