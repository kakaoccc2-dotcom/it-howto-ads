本を読んでいる途中で画面が落ちる。室内なのに一段暗い。クイック設定を触っていないのに、朝起きたら超減光のまま。故障というより **消灯までの秒数、自動明るさ、バッテリーセーバー、エクストラディム** が多いです。Windows ノートのスリープは対象外です。そっちは [スリープと復帰](/articles/windows-sleep-wake-problems/) です。

この記事は Android 10 以降の標準の項目名を使います。Samsung や Xiaomi では、同じ中身が **ディスプレイ** や **バッテリー** の一段下にあります。充電が極端に遅く、省電力ばかり入るときは [充電の切り分け](/articles/smartphone-charging-slow/) も見てください。通知だけ来ない話は [通知が来ない・遅れるとき](/articles/android-notifications-delayed/) です。

## 症状の見分け

- 15秒〜30秒で画面が落ちる。触ると戻る
- 明るさバーは真ん中なのに、実画面だけ暗い
- ステータスバーに電池の枠、または「超減光」のアイコンが出ている
- 屋外へ出た瞬間だけ真っ黒に近く、室内に戻すと普通
- 特定のアプリ（電子書籍、地図、動画）のあいだだけすぐ落ちる
- ケースを付けたあとから、明るさが追いつかない

画面が真っ黒のまま戻らない、再起動ループ、は消灯時間ではありません。電源ボタン長押しで音量や再起動メニューが出るか先に見ます。出ないならこの先の設定では足りません。

## よくある原因

1. **画面のタイムアウト**（消灯までの時間）が 15秒、30秒になっている
2. **自動明るさ** が、暗い部屋やセンサー隠れで一段落とす
3. Android 12 以降の **エクストラディム**（超減光）がオン
4. バッテリーセーバー、またはメーカーの超省電力が輝度を落とす
5. 読書アプリやナビが、独自の「画面をつけたまま／暗くする」を持っている
6. 厚手のケース、保護フィルム、ホコリで、上部の光センサーが隠れている

## 直す前に

- 今の明るさバーの位置を覚える。戻すときの目安です
- 「明るさブースター」「画面永久点灯」を名乗るアプリは入れない
- 作業中も、充電残量が極端に低いときはケーブルをつないでおく

> **注意:** 「スリープさせない」を常時オンにすると、画面焼けと電池消費が増えます。必要なアプリ（ナビ、レシピ）だけ、そのアプリ側の設定で十分です。端末の初期化は最終手段です。

## 手順

### 1. 消灯までの時間を延ばす

1. **設定** → **ディスプレイ**（機種によっては **画面**）。
2. **画面のタイムアウト** / **スリープ** / **消灯までの時間** を開く。
3. 今が **15秒** や **30秒** なら、まず **1分** または **2分** にする。10分以上は、置き忘れで点きっ放しになりやすいです。
4. ロック画面の表示時間（Always On や、ロック画面のタイムアウト）が別項目になっている機種があります。本体画面が落ちる話と取り違えない。

ここを延ばしてもすぐ暗くなるなら、消灯ではなく明るさ側です。逆に、暗くはならないがすぐ黒画面になるなら、この項目が本丸です。

### 2. 自動明るさと、エクストラディムを切ってみる

1. **設定 → ディスプレイ** で **自動明るさ**（適応型の明るさ）をオフにする。
2. 明るさバーを指で上げ、室内で読める位置まで戻す。
3. 同じ画面かクイック設定に **エクストラディム** / **超減光** があればオフ。クイック設定を二回下げると、隠れタイルに入っていることがあります。
4. Samsung なら **ディスプレイ → 明るさを適応** のほか、**ダークモードの設定 → ダークモード時に壁紙を暗くする** も、見え方だけ変えます。点灯時間とは別です。
5. 画面上部（カメラ横）を指やケースで覆わず、10秒待つ。センサーが隠れると、自動明るさは「夜」判定します。

自動をオフにして普通に見えるなら、センサーかケースです。オフでも暗いなら、手順3の省電力です。

### 3. バッテリーセーバーを外す

1. 画面上からクイック設定を下げ、**バッテリーセーバー** / **省電力** がオンならオフにする。
2. **設定 → バッテリー** で、スケジュール（残量 20% で自動オン、など）が残っていないか見る。すぐ暗くなる時間帯と重なっていないか。
3. メーカー独自の **超省電力**、**最大省電力**、**子供モード** は、輝度を固定で落とします。切り分けのあいだオフ。
4. 充電中だけ暗い、は「充電最適化」や保護フィルムのギラつきのこともあります。ケーブルを抜き、明るさバーだけ動かして比べる。

電池が赤い日はセーバーが入りやすいです。充電が遅い本体は、先に充電記事です。熱い端末も OS が輝度を落とします。ケースを外して冷ましてから、もう一度バーを動かします。

### 4. アプリ側の上書きを外す

1. 電子書籍、ナビ、動画、懐中電灯アプリを開いているときだけ落ちるなら、そのアプリの **画面をオンに保つ** / **明るさ** を見る。
2. 逆に、そのアプリが「夜間モード」「目にやさしい」で画面全体を茶や灰色にしていることがあります。アプリ内のテーマを標準に戻す。
3. **設定 → アプリ → 特別なアプリアクセス → 他のアプリの上に重ねて表示** で、見慣れないフィルターアプリがあればオフ。画面を暗い膜で覆うタイプです。
4. ゲームの省電力、ブラウザのダークモードは、タイムアウトそのものは変えません。黒画面になるなら手順1に戻る。

画面の回転だけおかしい、明るさは普通、ならこの記事の範囲外です。センサーのアクセス権限は、回転と明るさで別です。

### 5. 再起動と、開発者向けの取りこぼし

1. 端末を再起動する。明るさデーモンが固まったあとは、これで戻ることがあります。
2. **設定** 内検索で「スリープ」と入れ、残っている短いタイムアウトがもう一つないか見る。ロック画面用と本体用が分かれている機種があります。
3. 開発者向けオプションを出したことがある人は、**充電中は画面スリープにしない** のオンオフが、期待と逆の動きをすることがあります。通常は触らなくてよい項目です。
4. それでも特定アプリだけすぐ落ちるときは、そのアプリを更新するか、キャッシュ削除（**設定 → アプリ → 対象 → ストレージ → キャッシュを削除**）。データ削除はまだしない。

> **注意:** 「画面を消さない」系の常駐アプリは、電池と画面焼けの元です。公式のディスプレイ設定で足りることがほとんどです。セーフモードの出し方はメーカーマニュアルへ。セーフモードで普通なら、あとから入れたフィルターやクリーナーを疑います。

## まだ直らないとき

- バーは最大なのに暗い → エクストラディム、ダークモード、フィルムの重ね貼り。本体の有機EL劣化は、設定では戻りません
- ポケットから出すと真っ暗 → 近接センサーか、誤って電源ボタン。ケースのフタがセンサーに当たっていないか
- 充電中だけすぐ落ちる → 充電器の電力不足で省電力が入っている。充電記事へ
- どの設定を変えても 15秒で落ちる → 管理アプリ（ファミリーリンク、会社のデバイス管理）。個人のディスプレイ設定は灰色のことがあります
- 画面が落ちたあと、電源ボタンでも戻らない → 消灯ではなくフリーズ。電源長押しで再起動。繰り返すなら販売店へ

iPhone の自動ロックは、設定名が違います。Android の手順をそのまま当てないでください。

## まとめ

新しいアプリを入れる前に、**ディスプレイ** の消灯時間、自動明るさ、エクストラディム、バッテリーセーバーを見る。触れば戻るならタイムアウト。触っても暗いなら明るさと省電力です。常時点灯アプリより、標準のディスプレイ画面の方が安全です。
