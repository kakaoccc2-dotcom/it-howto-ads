相手は送ったと言う。受信トレイの一番上には無い。通知が鳴らないだけなのか、アカウントにメール自体が無いのかで、見る場所が違います。アプリを開くと本文があるのに音だけ無いなら、iPhone は [通知が来ない手順](/articles/iphone-notifications-not-working/) 、Android は [通知が来ない・遅れる手順](/articles/android-notifications-delayed/) です。

## 症状の見分け

- ブラウザの gmail.com で検索しても、そのメールが無い
- 受信トレイには無い。迷惑メールかプロモーションを開くとある
- スマホのアプリだけ古く、パソコンのブラウザには届いている
- Gmail の画面に、容量の上限の案内が出ている
- ある相手からだけ来ない。ほかの人のメールは来る
- 別のアドレスへ転送されていて、今見ているトレイは空

## よくある原因

1. 迷惑メール、ゴミ箱、プロモーションなどのタブ
2. 右上のアカウントが、探しているアドレスと違う
3. フィルタが削除している、または受信トレイをスキップしている
4. 転送がオンで、Gmail 側にコピーを残していない
5. Google アカウントの容量上限。Gmail、ドライブ、フォトで一つの枠
6. 相手の宛先の打ち間違い、または相手の下書きのまま

## 直す前に

- スマホの赤い印ではなく、パソコンのブラウザで gmail.com を開いて確かめる。アプリの表示が遅れているだけを、未着と間違えない
- フィルタを消す前に、その行の条件を読む。仕事の仕分けをまとめて消さない
- 容量を空けるとき、メールの全削除は後です。ドライブの動画のほうが大きいことが多い

## 手順

### 1. アカウントと、トレイの外を見る

1. gmail.com を開き、右上の丸いアイコンを見る。今のアドレスが、相手に伝えたアドレスと同じか。違えば切り替える。
2. 上の検索に、相手のメールアドレスを入れる。件名が分かっていれば、それも足す。
3. 左の **迷惑メール** と **ゴミ箱** を、それぞれ開く。上の検索は、この二つを含めないことがあります。**すべてのメール** も、迷惑メールとゴミ箱は入っていません。
4. 受信トレイの上に **メイン**、**プロモーション**、**ソーシャル**、**新着** のタブがあるなら、メイン以外も開く。店やメルマガは、プロモーションに入っただけで届いています。
5. 見つかったら開いて、**迷惑メールではない** を押す。タブの仕分けを変えたいときは、歯車 → **すべての設定を表示** → **受信トレイ** → **カテゴリ**。要らないタブのチェックを外す。

### 2. フィルタとブロック

その人、その件名だけ消えるときに見ます。

1. 歯車 → **すべての設定を表示** → **フィルタとブロック中のアドレス**。
2. フィルタの行を上から見る。操作に **削除**、**受信トレイをスキップ**、**転送** とあり、条件が相手のアドレスになっていないか。
3. そのメールを巻き込んでいる行だけ **削除** する。隣の、別の用の仕分けは残す。
4. ページ下の **ブロック中のアドレス** に相手がいれば、解除する。ブロック中は、迷惑メールの一覧にも出ないことがあります。
5. 消したあと、相手に同じ宛先でもう一通送ってもらう。古いメールは、フィルタを消してもトレイには戻りません。ゴミ箱に残っていれば、そこから戻す。

### 3. 転送で外へ出ていないか

1. 同じ設定の **メール転送と POP/IMAP** を開く。
2. **転送** に、覚えのないアドレスがあり、転送が有効なら、いったん無効にする。
3. コピーを受信トレイに残す、となっていれば、転送先と Gmail の両方に来ます。残さない設定だと、今のトレイは空に見えます。残したいなら、コピーを残す側にする。
4. 手順2のフィルタにも、「転送」と書いた行がないか見る。転送先が自分の別アカウントなら、そのアカウントで gmail.com を開く。

覚えの無い転送先が入っていたら、無効にしたうえで、Google アカウントのセキュリティ（ログイン中の端末とパスワード）を見る。知らない端末が残っていたら、パスワードを変えてください。

### 4. 容量の上限で受信が止まっている

ある日を境に、どの相手からも来なくなったときです。相手にはエラーが戻っていることがあります。

1. Gmail の画面に、ストレージの上限や「受信できない」と出る案内が無いか見る。右上のアカウントから **ストレージ** を開いても、使用量が分かります。
2. 枠は Gmail と Google ドライブ、Google フォトで共通です。写真や動画のバックアップで埋まっていることが多い。メールを片っ端から消すより、ドライブの大きいファイルを先に見る。
3. 空きができたら、相手に送り直してもらう。上限で戻されたメールは、空きを作っても自動では届きません。
4. iPhone や Android 本体の空きとは別です。本体を片付けても、Google の枠は増えません。本体側の手順は [iPhoneのストレージ](/articles/iphone-storage-full/) と [Androidのストレージ](/articles/android-storage-full/) です。

### 5. ブラウザにはある。アプリだけ古い

gmail.com の検索でそのメールが見つかるなら、Gmail までは届いています。

1. 相手には、送信済みに入っているか、宛先が一字違わないか、エラーメールが戻っていないかを見てもらう。下書きのままのこともあります。
2. パソコンのブラウザにはあり、iPhone の標準「メール」アプリだけ古いときは、設定の検索に「データの取得」と入れる。**データの取得方法**（**メール → アカウント** の中）で、Gmail の行がフェッチ（15分ごと、など）なら、アプリを開くまで遅れます。すぐ読みたいなら Gmail アプリを使う。音だけ無いなら [iPhoneの通知](/articles/iphone-notifications-not-working/) です。
3. Android で、ブラウザにはありアプリの受信箱だけ古いときは [Googleアカウントの同期](/articles/android-google-account-sync/) です。
4. 会社や学校のアドレス（@gmail.com ではない Google）は、管理者が検疫で止めていることがあります。同僚も同じなら、管理者へ。自分のフィルタの画面には出てきません。

## まだ直らないとき

- 迷惑メールにも検索にも無く、容量の案内も無い → 相手の送信済みと、戻ってきたエラーの文を見せてもらう。宛先違いが多いです
- フィルタも転送も空なのに、あるメルマガだけ来ない → 配信リストから外れたままのことがあります。登録ページから、もう一度届くか試す
- 容量は空けた。再送も来ない。相手のエラーが受信拒否 → Google アカウントのヘルプへ、そのエラーの全文を送る。携帯キャリアの窓口では、Gmail の中身は分かりません
- メールがまとめて消え、転送先も知らないアドレス → 届かない原因の前に、パスワードと、回復用の電話番号を確認する

## まとめ

gmail.com の検索、迷惑メール、プロモーションに無いかを先に見てください。そこに無いときだけ、フィルタと容量と、相手の送信済みです。
