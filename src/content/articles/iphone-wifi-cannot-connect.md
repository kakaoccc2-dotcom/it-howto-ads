iPhone で自宅の Wi-Fi を選んでもくるくるして終わる、パスワードが正しいのに失敗する、「接続済み」なのに Safari だけ開けない、コントロールセンターでは扇アイコンなのに設定では別のSSID、といった状態はよくあります。一度にリセットすると、モバイルデータ以外の無線もまとめて消えるので、**忘れる → 入れ直す → プライベートアドレス → ルーター** の順にします。

この記事は iOS の標準設定名を使います。Android 側はすでに [Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) があります。家の PC はつながるのに iPhone だけダメ、がこの記事の主戦場です。家族の端末も全員ダメなら、先にルーターの電源です。

## 症状の見分け

自分の画面がどれに近いかを先に決めると、手順を飛ばせます。

- SSID（Wi-Fi名）は見えるが、タップしても「接続できません」で終わる
- 「パスワードが違います」と出る。紙に書いたパスは合っているつもり
- チェックマークは付くが、「インターネット未接続」や、Safari がすぐ失敗する
- 自宅ではダメで、外出先のモバイルデータや別のカフェの Wi-Fi は問題ない
- 家族の Android や PC は同じ Wi-Fi で問題ない（iPhone だけ）
- VPN や会社の構成プロファイルを入れたあとから、自宅でも繋がらない

コントロールセンターの扇アイコンは、**よく使うネットワークへの再接続** であって、設定アプリの一覧と同じではありません。切り分けは必ず **設定 → Wi-Fi** で見ます。

## よくある原因

1. パスワードの取り違え（2.4GHz と 5GHz で別パス、ゲスト用SSID、全角スペース）
2. 以前保存した設定が古いまま（ルーター交換、パス変更、引っ越し）
3. **プライベート Wi-Fi アドレス** が、MAC アドレス制限つきのマンション・社内回線と合わない
4. 日付と時刻がずれて、証明書やログインページ（キャプティブポータル）に失敗する
5. VPN、プライベートリレー、会社のプロファイルが、名前解決や常時接続を邪魔している
6. ルーター側の台数上限、バンドステアリング、APアイソレーション

## 直す前に

- 正しいSSID名を、ルーター本体のシールか、つながっている別端末の設定から確認する
- モバイルデータが使えるなら、作業中はそれで公式の説明を開けるようにしておく
- ルーターを抜く必要があるなら、家族のテレビや仕事用 PC が切れることを伝える

> **注意:** 「ネットワーク設定をリセット」は Wi-Fi パスワード、Bluetooth の一部、VPN も消えます。この記事では最後の手段に置いてあります。電波を強くすると名乗るアプリは、App Store でも不要です。iPhone の Wi-Fi 接続そのものは、設定アプリとルーターで足りることがほとんどです。

## 手順

### 1. 機内モードと Wi-Fi の入れ直し

1. コントロールセンターを出し、**機内モード** をオン → 10秒 → オフ。
2. **設定** → **Wi-Fi** を開き、Wi-Fi のスイッチをオフ → 10秒 → オン。
3. 目的のSSIDを選び、左側にチェックが付き、上にアンテナが出るか見る。

これで直ることは多いです。コントロールセンターの扇だけオンにして、設定側のスイッチがオフ、という食い違いもここで解消します。直らなければ次へ進みます。

### 2. このネットワークを忘れて、パスワードを打ち直す

1. **設定** → **Wi-Fi**。
2. 問題のSSIDの右の **i** を開く。
3. **このネットワークを忘れる** → **忘れる**。
4. 一覧から同じSSIDを選び、パスワードを **手入力** する。メモアプリからの貼り付けで、全角スペースや改行が混ざることがあります。
5. キーボードの地球儀で、日本語入力のまま英数字になっていないかも見る。

成功の目安は、SSIDの左にチェック、**設定 → Wi-Fi** の画面に IP アドレスが出ることです（**i** を開き、**TCP/IP** に IPv4 アドレスがあれば接続自体は成功しています）。

### 3. 「インターネット未接続」のときは DNS と VPN

接続自体は成功しているのにウェブだけダメなときです。

1. そのSSIDの **i** を開き、**DNS を構成** が **自動** か見る。以前手動にした 数字が、引っ越し後に残っていることがあります。切り分けでは **自動** に戻す。
2. **設定** → **VPNとデバイス管理**（機種によっては **一般 → VPNとデバイス管理**）で、使っていない VPN を切断する。常時接続のスイッチがあればオフ。
3. **設定 → Apple ID → iCloud → iCloudプライベートリレー**（場所は iOS の版で少し違います）を、切り分けのあいだオフにして Safari を試す。
4. 会社や学校の構成プロファイルが入っていると、自宅 Wi-Fi でもプロキシが残ることがあります。プロファイルの削除は、その組織の案内に従ってください。勝手に消すと社用メールが死にます。

家の PC で同じ回線が「繋がっているのにネットに出られない」なら、先に回線側を疑います。[Wi-Fiは繋がるがインターネットに出られない](/articles/wifi-connected-no-internet/) と、名前だけ失敗するときの [DNSサーバーに問題があります](/articles/windows-dns-server-problem/) が近いです。

### 4. プライベート Wi-Fi アドレスを切ってみる

マンション、会社、公衆無線LAN、MAC アドレス許可リストを使っている回線で効きます。Android のランダム MAC と同じ系統です。

1. 対象SSIDの **i** を開く。
2. **プライベート Wi-Fi アドレス** をオフにする。iOS の版によっては **オフ** / **固定** / **ローテーション** と出ます。切り分けでは **オフ**。
3. いったん Wi-Fi をオフ→オンし、同じSSIDに入り直す。

セキュリティのためにプライベートアドレスを戻したい場合は、直ったことを確認したあと、回線側の許可リストにそのアドレスを登録できないか管理者へ確認してください。オフのままでも自宅回線は使えます。

### 5. 日付と時刻、再起動、バンドの取り違え

1. **設定** → **一般** → **日付と時刻** で **自動設定** をオン。オフのまま昔の日付だと、ホテルやキャンパスのログインページが失敗します。
2. iPhone を再起動する（電源と音量の案内どおり、スライダでオフ→オン）。
3. それでもダメなら、ルーターの電源を抜いて 30秒待ち、本体ランプが安定してから iPhone 側で再接続する。
4. SSID が `example-2G` と `example-5G` のように分かれているときは、壁の多い部屋や古い家電連携は 2.4GHz 側を試す。プリンター連携そのものは [プリンターがオフライン](/articles/printer-offline/) です。

iPhone の無線まわりで、Wi-Fi は直ったがイヤホンだけおかしい、というときは [Bluetooth がつながらないとき](/articles/iphone-bluetooth-pairing/) も同じ「いったん忘れる」発想です。

### 6. まだダメなときのリセット（最後）

1. ほかのSSID（スマホのテザリングなど）にはつながるか見る。つながるなら iPhone の無線チップより、その自宅SSIDの保存情報かルーター側です。
2. どうしても自宅だけダメで、忘れるを繰り返しても同じなら **設定 → 一般 → 転送または iPhone をリセット → リセット → ネットワーク設定をリセット**。
3. パスコードを求められたら入力する。再起動のあと、Wi-Fi、VPN、テザリング名を入れ直す。

> **注意:** ネットワーク設定のリセットは、保存済み Wi-Fi のパスワードを全部消します。Bluetooth 機器の再ペアリングが必要になることもあります。ディスク消去や、iPhone の初期化（すべてのコンテンツと設定を消去）とは別です。初期化はこの記事では使いません。

## まだ直らないとき

- 公衆無線LANでチェックは付くが Safari が開かない → 通知の「Wi-Fiにログイン」、または Safari で利用規約ページが出ていないか見る。出ていなければ、いったんモバイルデータだけにしてから Wi-Fi を入れ直す
- 自宅のゲスト用SSIDだけ失敗する → ゲスト側の端末分離や、時間制限。メインSSIDで試す
- ほかの iPhone は同じSSIDで使える → 問題の端末の Wi-Fi アドレスが回線側でブロックされていないか、手順4のアドレスを管理者へ伝える
- モバイルデータも同時に死ぬ → Wi-Fi 記事の範囲外です。キャリアのアンテナと、機内モードの入れ直しを先に見る
- 初期化を案内されたとき → バックアップ（iCloud またはコンピュータ）が取れてから。この記事の手順6より重い手段です

## まとめ

iPhone の Wi-Fi 不調は、まず **このネットワークを忘れて手入力で入れ直す** が効きます。インターネット未接続なら DNS / VPN / プライベートリレー、特定の回線だけダメならプライベートアドレス、全員ダメならルーター、の順にすると原因の切り分けが早くなります。ネットワーク設定のリセットは、パスワードを消してよいときだけにしてください。
