アプリを開くと未読はあるのにバナーも音も無い、夜だけ遅れてまとめて来る、なら iPhone 側の通知と集中モードが多いです。Android は画面名が違うので [Android の通知手順](/articles/android-notifications-delayed/) を見てください。

## 症状の見分け

- チャットを開くと内容はあるが、ロック画面にもバナーも出なかった
- 音も振動も無い。またはロック画面には出るが、音だけ無い
- 特定のアプリ（LINE だけ、メールだけ）が来ない
- ステータスバーに集中モードのアイコン（三日月など）が出ている
- 昼間はすぐ来るのに、決まった時間帯だけ遅れてまとめて届く
- 通知センターを上から出すと履歴はある。来た瞬間には気づかなかった

アプリを開いても内容が古いままなら、通知設定より通信です。先に [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) を見てください。モバイルデータだけ死んでいるときは [iPhone のモバイルデータ](/articles/iphone-mobile-data-not-working/) です。

## よくある原因

1. そのアプリの通知がオフ、またはロック画面・バナーだけオフ
2. **集中モード**（おやすみ時間、睡眠、仕事）が、そのアプリを止めている
3. **通知の要約**（予定された要約）が、知らせを後回しにしている
4. サイレント（側面のスイッチ／操作ボタン）や、通知音量がゼロ
5. 低電力モードや、バックグラウンド App 更新がオフで、届きが遅れる

## 直す前に

- 問題のアプリを一つに決める。全部いっぺんに触ると、何が効いたかわかりません
- 「通知強化」「着信ブースト」系のアプリは入れない
- 作業中も、急ぎの連絡が必要な人には別の手段を伝えておく

> **注意:** 通知を全部オンにすると、宣伝まで鳴ります。来てほしい種類（メッセージ、通話）だけオンにしてください。iPhone の初期化はこの記事では使いません。

## 手順

### 1. そのアプリの通知をオンにする

1. **設定** → **通知**。一覧から問題のアプリを開く（または **設定** の下のほうにあるアプリ名 → **通知**）。
2. **通知を許可** がオンか見る。オフならオンにする。
3. **ロック画面**、**通知センター**、**バナー** のうち、来てほしい場所にチェックがあるか見る。バナーだけオフだと、開くまで気づきません。
4. **サウンド** と **バッジ** も、音が欲しいアプリではオン。
5. アプリ内（LINE ならトークの通知、メールならアカウントごと）にも、別スイッチがあることがあります。設定アプリがオンでも、アプリ側がミュートなら来ません。

iOS の版によっては、同じ画面に **時間指定通知** や、重要な通知だけ通す項目があります。切り分けでは、いったんそのアプリを普通の即時通知にしてください。

**ここで失敗したとき:** 一覧にそのアプリが無いときは、まだ一度も通知の許可を聞いていません。アプリを開き、許可のダイアログで **許可** を押します。過去に **許可しない** を押していると、ダイアログは二度と出ず、設定の通知一覧の下のほうに名前だけ残ります。そこをオンに戻してください。オンにしてもロック画面に出ないときは、**ロック画面** のチェックが外れています。バナーだけオン、ロック画面オフ、という組み合わせです。

LINE だけ静かなときは、このあと [LINE の通知](/articles/line-notifications-not-arriving/) でトーク単位のミュートと、パソコン版を開いたまま、を見てください。メールアプリ全体はオンなのに受信箱だけ空なら [メールが届かないとき](/articles/gmail-not-receiving/) です。

### 2. 集中モードと、通知の要約を外す

1. 画面右上からコントロールセンターを下げ、三日月や集中モードのアイコンが点灯していればオフにする。
2. **設定** → **集中モード**。 **おやすみ時間**、**睡眠**、**仕事**、自分で作ったモードを開き、スケジュールが残っていないか見る。使わないモードはオフ。
3. ロック画面を左右に払って、集中モード用の別ロック画面に居続けていないか見る。その画面にいるあいだは、許可したアプリ以外は黙ります。
4. **設定** → **通知** → **通知の要約**（予定された要約）がオンなら、問題のアプリを要約から外す。または要約自体をオフにして、すぐ来るか半日見る。

睡眠の就寝スケジュールや、時計のベッドタイムが、夜だけ通知をまとめていることもあります。昼間も遅れるなら、要約と集中モードの時間帯を先に疑ってください。

**ここで失敗したとき:** 集中モードをオフにしても、ステータスバーの三日月が残るときは、別のモード（睡眠と仕事が同時、など）がまだオンです。**設定 → 集中モード** の一覧で、色が付いているものを全部オフにしてください。要約からアプリを外したのに、翌朝またまとめて来るなら、要約の時刻がそのアプリを再度含めています。要約の中のアプリ一覧を開き、チェックが戻っていないか見ます。ロック画面を左右に払うと壁紙が変わる機種は、集中モード用の画面に居ます。普段の壁紙に戻してから、テスト通知を送ってください。

### 3. サイレントと、音量を取り違えない

1. 側面のスイッチがある機種は、オレンジが見えていないか見る。見えるあいだは着信音も通知音も出ません。
2. 操作ボタンの機種は、ボタンを長押しして **サイレントモード** になっていないか見る。コントロールセンターのベルでも切り替わります。
3. **設定** → **サウンドと触覚** で、着信音と通知音のスライダがゼロになっていないか見る。マナーだけ直しても、ここの音量がゼロだと鳴りません。
4. Face ID 機種で、見ていないのに音が消えるときは **画面注視認識機能**（**設定 → Face IDとパスコード**、またはアクセシビリティ側）を切り分けでオフにして試す。

ロック画面には出るが音だけ無い、はだいたいここです。履歴に残るのにその場で気づかない、も同じです。着信音の名前自体が鳴らないときは [着信音が鳴らないとき](/articles/iphone-ringtone-not-playing/) で、通知と着信を分けてください。

**ここで失敗したとき:** オレンジは消えている、スライダも上げている、なのにそのアプリだけ無音なら、手順1の **サウンド** がそのアプリだけオフです。全体の音量ではありません。バイブレーションだけ欲しいときは、サウンドをオンにしたまま着信音を短くするより、そのアプリのサウンドを残したほうが切り分けは早いです。オフのままだと、鳴ったかどうかわかりません。

### 4. 低電力モードと、バックグラウンド更新

1. **設定** → **バッテリー** で **低電力モード** がオンならオフにする。バッテリー残量が少ないと、勝手に入ることがあります。
2. **設定** → **一般** → **バックグラウンド App更新** をオン。問題のアプリもオンか見る。オフのままだと、アプリを開くまで届きが遅れます。
3. 充電が極端に遅い、すぐ切れて低電力ばかり入るときは、通知より先にケーブルと充電器を替えて、残量を少し戻してから同じ手順を試す。

電池を長持ちさせる設定が、届きの遅れに見えます。**低電力モード**をオフにし、そのアプリの **バックグラウンド App更新** をオンにして、半日様子を見てください。

**ここで失敗したとき:** 低電力をオフにしても、充電が 20% を下回るとまたオンになります。**設定 → バッテリー** に「自動でオン」に近い項目があれば、切り分けのあいだはオフにします。バックグラウンド更新が灰色で、Wi-Fi とモバイルデータの両方を選べないときは、低電力か、スクリーンタイムの制限です。**設定 → スクリーンタイム → コンテンツとプライバシーの制限** で変更が止められていないか見てください。パスコードが家族のものなら、自分では戻せません。

### 5. 再起動と、通信の切り分け

1. iPhone を再起動する（電源と音量の案内どおり、スライダでオフ→オン）。起動し直したあと、同じアプリの通知がすぐ出るか試す。
2. 再起動後、そのアプリから自分宛てにテスト通知を送る（別端末や、同じアカウントの別部屋からでよい）。
3. Wi-Fi だけ遅いときはモバイルデータで試す。モバイルだけ遅いときは Wi-Fi で試す。どちらでも内容が古いままなら、通知設定より回線かログインです。
4. VPN やプライベートリレーを切り分けのあいだオフにして、すぐ来るか見る。社用プロファイルの VPN は、勝手に消さず切断だけにする。

> **注意:** **設定 → 一般 → 転送または iPhone をリセット → すべての設定をリセット** は、通知以外の設定も消えます。この記事では使いません。ネットワーク設定のリセットも、Wi-Fi パスワードが消えるので通知の切り分けではやりません。

**ここで失敗したとき:** テストを送っても、送った側に「届いた」表示が無いなら、受け側の通知以前に送信が失敗しています。相手の回線を先に見てください。再起動のあと集中モードのスケジュール時刻だと、起動した瞬間にまた三日月が付きます。手順2を起動直後にもう一度オフにしてからテストします。

## 時間帯と、アプリの種類

- 夜だけまとめて来る → 睡眠の集中モードか、通知の要約の時刻です。昼間に同じアプリがすぐ来るなら、許可はオンです。スケジュールを見ます
- 昼間も、アプリを開いたときだけ未読が増える → 許可がオフか、バックグラウンド更新がオフです。要約ではありません
- LINE だけ、メールは来る → [LINE の通知](/articles/line-notifications-not-arriving/) です。iPhone 全体の集中モードなら、メールも止まります
- ロック画面には出るが、バナー（使っている最中の上部）だけ無い → 手順1の **バナー** がオフです。集中モードは関係しません

## まだ直らないとき

- 通知センターには残るが音だけ無い → 手順3。そのアプリのサウンドが「なし」になっていないかも見る
- ロック画面だけ出ない → 手順1の **ロック画面** チェック。集中モード用のロック画面に居ないかも見る
- どのアプリも来ない → 日付と時刻の自動設定（**設定 → 一般 → 日付と時刻**）、Apple ID のサインイン、機内モードの名残。時計が何時間もずれていると、通知の順序だけがおかしく見えることがあります
- 特定のアプリだけ、再インストールした直後から来ない → そのアプリに通知許可のダイアログで「許可しない」を押していないか。設定の通知一覧からオンに戻す
- 家族の同じアプリはすぐ来る → 端末側です。全員遅いなら、そのサービスの障害か、家の回線です
- バッジの数字だけ増えて、音もバナーも無い → **通知を許可** はオンで、表示場所のチェックが全部外れています。手順1のロック画面・通知センター・バナーを入れ直します
- 仕事用プロファイルのアプリだけ来ない → 個人の集中モードとは別の管理です。会社の IT へ、そのアプリ名を渡します。個人の「すべての設定をリセット」では戻りません

## まとめ

そのアプリの通知がオンか、集中モードと要約がかかっていないかを先に揃えてください。音だけ無いならサイレントと音量、内容自体が古いなら通信です。
