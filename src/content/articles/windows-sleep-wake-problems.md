ノートのフタを開けても真っ黒、キーボードを押してもファンだけ回る、数分放置しただけで勝手にスリープする、スリープしたつもりがシャットダウンになっている、といった状態は、故障というより **画面とスリープの分数、高速スタートアップ、マウスやLANが起こしている／起こせていない** ことが多いです。復帰直後だけ音やネットワークが死んでいることもあります。

この記事は Windows 10 / 11 の個人向け PC を対象にします。スリープ以前に、電源を入れてもデスクトップが出ないときは [スタートアップ修復](/articles/windows-startup-repair/) です。復帰したら画面が暗い、または真っ黒なだけなら [明るさと真っ黒画面の手順](/articles/windows-brightness-black-screen/) を先に見てください。

## 症状の見分け

- フタを開ける、電源ボタンを短く押す、キーを叩く、のいずれでも画面が戻らない。電源ランプは点灯または点滅
- 一度は戻るが、数十秒でまたスリープする
- 使っている最中に突然画面が落ちる。電源は切れていない
- 「スリープ」を選んだのに、次に開くと起動し直し（再起動やシャットダウン扱い）
- 外付けモニターだけ使っているとき、またはドッキングステーション経由のときだけ復帰できない
- マウスを少し動かしただけで夜中に起きてしまう（勝手にウェイク）

メーカーロゴも出ない、充電ランプが消えたまま、異音がある、は電源ハードウェアの話です。この記事の設定では足りません。無理に何回も強制終了を重ねないでください。

## よくある原因

1. **画面とスリープ** の分数が短すぎる。または電源接続時とバッテリーで設定が食い違う
2. スリープではなく、シャットダウンや休止状態になっている
3. 高速スタートアップのあと、中途半端な状態でフタを閉じた
4. キーボードや電源ボタンでは起きない設定のまま、マウスだけ／LANだけがウェイク担当
5. USB 機器、マウス、ネットワークアダプターが勝手にウェイクしている
6. 外付けディスプレイの入力が、復帰後に PC 側へ戻っていない

## 直す前に

- ノートなら充電器をつなぐ。バッテリー残量が極端に低いと、スリープから起きずシャットダウンすることがあります
- 外付けの USB 機器（ハブ、古い外付けHDD、ゲームパッド）は、切り分けのあいだいったん外す
- BIOS の書き換え、メーカー非公式の「電源最適化」ツールは使わない

> **注意:** 電源ボタンの長押しは強制終了です。作業中のファイルが保存されていないことがあります。復帰できないときだけ、数秒長押しして一度切り、普通に電源を入れてから設定を直してください。ディスクの初期化はしません。

## 手順

### 1. いま起きているかを、電源ランプとディスプレイで分ける

1. 電源ランプが点いているか、ファンが回っているか見る。動いているのに画面だけ黒いなら、スリープ失敗というより出力先です。`Win` + `P` を押し、**PC 画面のみ** と **複製** を一度ずつ試す。
2. 外付けモニターを使っているときは、モニター側の入力（HDMI / DisplayPort / USB-C）を、今つながっている端子に合わせる。映り方の切り分けは [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) です。
3. 内蔵画面があるノートは、外付けケーブルを外してフタを開け、本体画面だけでも戻るか見る。
4. 本当に落ちている（ランプ消、ファン停止）なら、電源ボタンを短く1回。反応がなければ、注意書きどおり長押しで一度切って入れ直す。

復帰したあと、音だけ出ない、マイクだけ死ぬ、ことがあります。その場合は OS は起きています。[音が出ない手順](/articles/windows-no-sound/) や [マイクが使えない手順](/articles/windows-microphone-not-working/) を見てください。

### 2. 画面とスリープの分数を見直す

勝手に寝る、すぐ再スリープする、の多くはここです。

1. **設定** → **システム** → **電源とバッテリー**（Windows 10 では **電源とスリープ**）。
2. **画面とスリープ** を開く。
3. **画面** と **スリープ** を、電源接続時・バッテリー時の両方見る。試しに画面は 10分以上、スリープは **なし** か 30分以上にする。
4. **電源モード** が極端な省電力なら、**バランス** に変える。
5. 変更したら、一度フタを閉じる／開ける、または **スタート → 電源 → スリープ** して、戻れるか確認する。

デスクトップで「電源とバッテリー」が短いときは、次のコントロール パネル側も同じ内容です。**コントロール パネル** → **電源オプション** → 選択中のプランの **プラン設定の変更** → **詳細な電源設定の変更**。

詳細設定では、次だけ見ます。ほかの項目は触らなくて大丈夫です。

- **スリープ** → **次の時間が経過後スリープ** が意図した分数か
- **スリープ** → **ハイブリッド スリープを許可する** が、復帰できない機種では邪魔になることがあります。試しにオフ
- **USB 設定** → **USB 選択的一時停止の設定** を、切り分けのあいだオフ

成功の目安は、設定した分数より前に勝手に落ちないこと、スリープからキーまたは電源ボタンでデスクトップに戻ることです。

### 3. フタ・電源ボタン・高速スタートアップ

1. 電源とバッテリーの画面を下へスクロールし、**カバーを閉じたときの動作** や **電源ボタンの動作** へのリンクを探す。無いときはコントロール パネルの電源オプション左の **電源ボタンの動作を選択する**。
2. **カバーを閉じたとき** を、持ち運び中は **スリープ**、常時外付けモニターだけ使うなら **何もしない** にする。シャットダウンのままだと、開いても起動し直しになります。
3. 同じ画面の上の方で **現在利用可能ではない設定を変更します** を押し、**高速スタートアップを有効にする** のチェックを外して保存する。
4. 一度シャットダウン（スリープではなく）してから電源を入れ、もう一度スリープ→復帰を試す。

高速スタートアップは起動を速くしますが、ドライバーが中途半端に残って「スリープしたつもりが起きない」ことがあります。切り分けで外して直るなら、常用をオフのままにして問題ありません。

### 4. 何が起こしているか、何が起こせるかを見る

勝手に起きる、またはキーを押しても起きない、の両方に使います。

1. デバイス マネージャーを開く。
2. **キーボード** の hid キーボード、**マウスとその他のポインティング デバイス** のマウス、**ネットワーク アダプター** の Ethernet / Wi-Fi を順に開く。
3. **電源の管理** タブがある機器だけ見る。
4. 起こしたい機器（本体のキーボード、電源ボタンに相当するもの）は **デバイスで、このコンピューターのスタンバイ状態を解除できるようにする** をオン。
5. 起こしたくない機器（USB マウスの微小な振動、有線LANの「マジックパケット」）はオフにする。夜中に勝手に起きるときは、ネットワークアダプター側をオフにするのが効きます。
6. Bluetooth マウスやイヤホンを使っているなら、アダプター側の「電力の節約で電源をオフ」も外す。手順は [Bluetooth がつながらないとき](/articles/windows-bluetooth-cannot-connect/) と同じです。

コマンドが必要なときは、管理者のコマンド プロンプトで次を実行すると、最後に PC を起こした機器名が出ます。

```text
powercfg /lastwake
```

見慣れない USB やネットワークが出るなら、その機器の電源の管理をオフにするか、切り分けで外します。

### 5. スリープ自体をやめて、原因の常駐を減らす

設定を直しても、特定のアプリを開いているときだけ寝る／起きない、ことがあります。

1. ブラウザのハードウェア アクセラレーション、動画の全画面、メーカーの「ユーティリティ」を一度終了して再現するか見る。
2. [スタートアップの整理](/articles/windows-startup-apps/) で、電源やファン、RGB、未知のメンテツールをオフにする。
3. どうしてもスリープが不安定なあいだは、手順2でスリープを **なし** にし、使わないときは自分でシャットダウンする。画面オフだけ残すと、電気は少し使いますが復帰トラブルは避けられます。
4. ディスクが常時フルで熱い PC は、省電力より先に [動作が遅いときの手順](/articles/windows-pc-running-slow/) と [ストレージ不足](/articles/windows-storage-full/) を見てください。熱保護で落ちていることがあります。

## まだ直らないとき

- フタを閉じると外部モニターも消える → カバーを閉じたときの動作を **何もしない**。映像の入力切替はディスプレイ側
- 休止状態のあとだけファイルシステムエラーが出る → 休止を使わずスリープかシャットダウンにする。ディスク検査は Windows の再起動時チェックに任せ、フォーマットはしない
- セーフモードならスリープが安定する → 通常起動のドライバーか常駐。最近入れたVPN、セキュリティ、仮想マシンを疑う
- `powercfg /energy` のレポートを深読みする必要は、家庭ではほぼありません。lastwake の機器名だけで足りることが多いです
- バッテリー膨張、充電しても数分で落ちる、本体が異常に熱い → 設定ではなくハードウェア。メーカーサポートへ型番と購入時期を渡す。BIOS 更新はこの記事では案内しません

## まとめ

スリープの不調は、新しい電源ツールを入れる前に **分数、フタと電源ボタン、高速スタートアップ、誰が起こしているか** を揃えます。画面だけ黒いなら出力先、勝手に寝るならタイマーとウェイク、起きないならキーボード側の許可と充電器です。どうしても不安定なら、当分スリープをなしにして画面オフだけにする方が、無理なリセットより安全です。
