チャットはアプリを開くと届いているのに通知だけ来ない、数十分遅れてまとめて出る、ロック画面には出るが音が無い、といった状態はアプリの障害より **通知チャネルがオフ、バッテリー最適化、集中モード、データセーバー** が多いです。Android はメーカーごとに項目名が少し違いますが、見る順番は同じです。

この記事は Android 10 以降の標準設定名を対象にします。機種独自 UI では、同じ項目が **アプリ** や **バッテリー** の一段下にあります。Wi-Fi 自体が切れていてアプリも更新されないときは、先に [Android で Wi-Fi に繋がらないとき](/articles/android-wifi-cannot-connect/) です。充電が極端に遅い・すぐ切れて省電力ばかり入るときは [充電の切り分け](/articles/smartphone-charging-slow/) も見てください。

## 症状の見分け

- アプリを開くと未読はあるが、バナーも音も来なかった
- 夜中や外出先だけ遅れて、自宅の Wi-Fi ではすぐ来る（またはその逆）
- ロック画面には出るが、音・振動だけ無い
- 特定のアプリ（チャットだけ、メールだけ）が来ない
- 「通知を一時停止」「集中モード」のアイコンが、ステータスバーに出ている
- 再起動した直後は来るが、半日置くとまた止まる

アプリを開いても内容が更新されないなら、通知設定より通信かログインです。内容はあるのに知らせだけ無いなら、この先の Android 側が主戦場です。

## よくある原因

1. そのアプリ、またはそのアプリ内のチャネル（メッセージ、その他）がオフ
2. **バッテリー使用量の最適化** が、バックグラウンド通信を止めている
3. おやすみ時間、集中モード、デジタル ウェルビーイングの「通知の一時停止」
4. データセーバーや、モバイルデータ制限で待機受信が遅れる
5. メーカー独自のスリープ中アプリ、自動起動オフ、省電力モード
6. ロック画面の通知表示が「ロック画面に表示しない」になっている

## 直す前に

- 問題のアプリ名（LINE、Gmail、社用チャットなど）を一つに決める。全部いっぺんに触ると、何が効いたかわかりません
- 公式ストア以外の「通知強化」「着信ブースト」アプリは入れない
- 作業中も、重要な通話が必要な人には別の連絡手段を伝えておく

> **注意:** バッテリー最適化を「制限なし」にすると、そのアプリの電池消費は増えます。チャットなど通知が必要なアプリだけに限定してください。端末の初期化は最終手段です。バックアップが取れてからにしてください。

## 手順

### 1. アプリの通知と、チャネルをオンにする

1. **設定** → **通知** → **アプリの通知**（機種によっては **設定 → アプリ → 対象アプリ → 通知**）。
2. 問題のアプリを開き、**通知をすべて** がオンか見る。オフならオンにする。
3. 下に並ぶチャネル（メッセージ、通話、その他、お知らせ）を個別に見る。会話だけオフ、宣伝だけオン、になっていることがあります。
4. **ロック画面に表示**、**ポップアップ**、**音** が、来てほしい種類でオンか確認する。

Android 12 以降なら、同じ通知画面に **通知履歴** があります。履歴には残っているのにその場で気づかないなら、音とバナー側です。履歴自体が空なら、アプリが送っていないか、端末が受け取っていません。

### 2. 集中モードと、おやすみ時間を外す

1. 画面上からクイック設定を下げ、**おやすみ時間** / **サイレント** / **集中モード** がオンならオフにする。
2. **設定 → 通知 → 通知の一時停止**、または **デジタル ウェルビーイングと保護者による使用制限** で、スケジュールが残っていないか見る。
3. 「ゲーム中は通知を隠す」「全画面時は通知しない」系のモードを使っているときは、対象アプリを外す。
4. 時計アプリの就寝モードが、夜だけ通知をまとめていることがあります。昼間も遅れるなら、就寝スケジュールの時間帯を確認する。

ステータスバーに三日月や、人のアイコンが出ているあいだは、アプリ側をオンにしても音は出ません。

### 3. バッテリー最適化を、そのアプリだけ外す

1. **設定** → **アプリ** → 対象アプリ → **バッテリー**（または **アプリの電池使用量**）。
2. **制限なし**（機種によっては **最適化しない**）にする。**制限** や **最適化** のままだと、画面オフから数十分で通知が遅れます。
3. **設定 → バッテリー** の **アダプティブバッテリー** や、極端な省電力をいったんオフにして、半日様子を見る。
4. Samsung なら **バッテリー → バックグラウンド使用量の制限 → スリープ中のアプリ** から、チャットアプリを外す。Xiaomi / OPPO 系なら **自動起動** とそのアプリの省電力を許可する。

電池が赤い、すぐ切れる、ときは最適化を全部外さず、充電記事でケーブルとポートを先に疑ってください。熱い端末は、OS が裏通信を止めます。ケースを外して冷ましてから、もう一度通知を試します。

### 4. データセーバーと、通信の切り分け

1. **設定 → ネットワークとインターネット → データセーバー** がオンなら、対象アプリを **データセーバー使用中に制限しない** に入れる。またはデータセーバー自体をオフにする。
2. Wi-Fi だけ遅いときは、同じアプリをモバイルデータで開き、すぐ来るか見る。Wi-Fi 側の切り分けは Wi-Fi 記事へ。
3. VPN や「電池長持ち」系の常時接続を切る。プライベート DNS をいじっている場合は、いったん **自動** に戻す。
4. 職場プロファイル（仕事用タブ）のアプリは、個人側の通知設定とは別です。仕事用のアイコン側で、同じ手順1を行う。

家族の同じアプリはすぐ来るのに自分だけ遅いなら、端末側です。全員遅いなら、そのサービスの障害か、家の回線です。

### 5. 再起動と、アプリのキャッシュ（最終手前）

1. 端末を再起動する。これで戻ることは多いです。
2. まだダメなら **設定 → アプリ → 対象アプリ → ストレージ → キャッシュを削除**。データ削除（ログインが消える）はまだしない。
3. ストアからアプリの更新があるか見る。古いままのアプリは、新しい Android の通知チャネルと食い違うことがあります。
4. それでもそのアプリだけ来ないときは、公式ストアから再インストールする。バックアップやトーク履歴が消えるアプリがあるので、各公式の案内を先に読む。

> **注意:** 「ストレージのデータを削除」はログインやダウンロードが消えます。チャットアプリでは手順を公式ヘルプで確認してからにしてください。キャッシュ削除とは別です。

## まだ直らないとき

- 通知履歴には残るが音だけ無い → サイレント、メディア音量と通知音量の取り違え、そのチャネルのサウンドが「なし」
- ロック画面だけ出ない → **設定 → 通知 → ロック画面**、または画面ロックの「ロック画面に通知を表示」
- セーフモードだと来る → あとから入れた省電力・セキュリティ・クリーナーを疑う。セーフモードの出し方はメーカーマニュアルへ
- どのアプリも来ない、履歴も空 → 日付と時刻の自動設定、Google アカウントのログイン、極端な省電力。初期化はバックアップ後
- 機種の「自動起動」項目が見つからない → 設定内検索でアプリ名を入れ、通知・バッテリー・自動起動の3語で当たる

iPhone 側の通知は、この記事の対象外です。Android と設定名が違うので、取り違えないでください。

## まとめ

通知が来ないときは、新しいアプリを入れる前に **そのアプリの通知がオンか、集中モードがオフか、バッテリーが制限なしになっているか** を揃えます。アプリを開けば内容があるなら通信は生きているので、チャネルと省電力を疑います。内容自体が古いなら、Wi-Fi とデータセーバーの順です。
