タスクバーの虫眼鏡を押しても何も出ない。`Win` キーのあとに文字を打ってもくるくるしたまま。スタートは開くのに検索だけ真っ白。スタートとタスクバーごと死んでいるときは、先に [スタートメニューとタスクバーの手順](/articles/windows-start-menu-taskbar-broken/) です。こちらは **検索だけ** がおかしいとき用です。

## 症状の見分け

- タスクバーに検索欄も虫眼鏡も無い
- アイコンはあるが、クリックしても `Win` + `S` でも反応がない
- 検索窓は開くが、いつも入っているアプリ名すら出ない
- 「検索中」のまま数分待つ。ウェブの提案だけ出て、自分のファイルはゼロ
- サインイン直後は使えるが、しばらくすると開かなくなる
- スタートのピン留めは押せる。文字検索だけ死んでいる

フォルダー窓まで「応答なし」なら検索より先に [エクスプローラーが固まるとき](/articles/windows-explorer-not-responding/) を見てください。PC 全体が極端に遅いだけなら [動作が遅いときの手順](/articles/windows-pc-running-slow/) です。

## よくある原因

1. タスクバー設定で検索が **非表示** になっている
2. **Windows エクスプローラー** か検索用プロセス（`SearchHost`）が止まっている
3. **Windows Search** サービスが停止、またはスタートアップが手動のまま
4. 検索インデックスが壊れている、またはドキュメントフォルダーが除外されている
5. 最近の更新のあと、検索ハイライトやクラウド検索だけが先に失敗している
6. 職場PCのポリシーで、検索自体が制限されている

## 直す前に

- 開いている文書は先に保存する。エクスプローラー再起動で窓が閉じることがあります
- 「検索修復.reg」「Cortana復活ツール」は入れない
- 会社の PC で設定が灰色なら、個人の手順では終わりません。画面を撮って IT 担当へ

> **注意:** インデックスの再構築はファイルを消しません。ただし終わるまで検索結果が空に近く、ディスク使用率が上がります。ノートなら電源アダプターをつないでからにしてください。レジストリ配布やディスク初期化はこの記事では使いません。

## 手順

### 1. タスクバーから検索が消えていないか

1. タスクバーの空きを右クリック → **タスクバーの設定**。スタートが死んでいて設定が開かないときは、`Ctrl` + `Shift` + `Esc` → **新しいタスクを実行** に `ms-settings:` と入れる。
2. **タスクバー項目** の **検索** を開く。
3. **検索ボックスを非表示** になっていたら、**検索アイコンのみ** か **検索ボックス** に変える。
4. アイコンか検索欄が出たら、一度クリックして窓が開くか見る。

虫眼鏡が戻るなら表示設定だけです。クリックしても無反応なら手順2へ。

### 2. エクスプローラーと検索プロセスを起こす

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー**。
2. **プロセス** から **Windows エクスプローラー** を選んで **再起動**。ボタンが「タスクの終了」しかないときは終了したあと、**新しいタスクを実行** に `explorer.exe` と入れて開く。
3. 同じ一覧に **検索** や `SearchHost` があれば選んで **タスクの終了**。次にタスクバーの検索を押すと、Windows が起き直します。
4. `Win` キーを押して、電卓など短い名前を1つ打つ。スタートの一覧に出れば、シェル側は生きています。

再起動のたびに検索が死ぬなら、スタートアップに変なランチャーが居ることがあります。[起動時アプリの整理](/articles/windows-startup-apps/) で、見慣れない「検索拡張」「スタート置換」をオフにしてください。

### 3. Windows Search サービスを動かす

検索窓は出るのに、何を打ってもゼロ件、というときに多いです。

1. `Win` + `R` → `services.msc` → Enter。
2. 一覧を下へ送り **Windows Search** を探す。名前順なら W のあたりです。
3. ダブルクリックして **スタートアップの種類** を **自動** にする。
4. **サービスの状態** が「実行中」でなければ **開始**。すでに実行中なら **停止** はせず、いったんこの窓を **OK** で閉じ、PC を再起動してからまた検索を試す。
5. 「アクセスが拒否されました」や開始ボタンが灰色なら、会社PCの制限か、管理者権限が足りていません。管理者としてサインインし直すか、担当へこの画面を渡す。

サービスが「無効」のままだと、設定アプリ側でインデックスをいじっても結果は増えません。先にここを **自動 / 実行中** にしてください。

### 4. インデックスの場所と、再構築

1. **設定** → **プライバシーとセキュリティ** → **Windows の検索**。
2. **ファイルを検索** が **クラシック** か **拡張** かを見る。ドキュメントとデスクトップだけならクラシックで足りることが多い。拡張は PC 全体なので時間も負荷も増えます。いまゼロ件なら、クラシックのまま次へ進む。
3. **除外されたフォルダー** に、普段探す場所（ドキュメント、ダウンロード）が入っていたら外す。
4. 同じ画面の **詳細なインデックスのオプション**、またはスタートに `インデックスのオプション` と入れて開く。
5. **インデックスの対象** にユーザーフォルダーがあるか見る。無いときは **変更** から `Users` 配下の自分のフォルダーにチェック。
6. 対象は合っているのにヒットしないときだけ **詳細設定** → **再構築**。確認が出たら進める。

再構築中は「インデックス作成中」と出ます。終わるまで検索は当てになりません。数十万ファイルある HDD ノートだと、完了まで何時間もかかることがあります。途中で電源を切ると、また最初からになります。

> **注意:** 再構築は削除ではありません。ただし C ドライブの空きが数GBしかないと、途中で止まります。赤い容量警告が出ているときは、先に [ストレージ不足の手順](/articles/windows-storage-full/) で空きを作ってください。

### 5. スタート検索と、クラウドの取り違え

1. `Win` キーだけ押して、スタートの検索欄に `notepad` や `メモ帳` と入れる。ストアやウェブのカードだけ出て、アプリが出ないときは、ローカルのインデックスよりスタート側です。手順2に戻る。
2. **Windows の検索** で、**クラウド コンテンツの検索**（OneDrive や Outlook の候補）を切り分けのあいだオフにする。ネット側の候補が先に失敗して、窓が空に見えることがあります。
3. サインインしている Microsoft アカウントをいったんそのままで、ローカルのファイル名（デスクトップに置いたテスト用テキストなど）だけ打ってみる。それも出ないならクラウドではなく、手順3と4です。

ブラウザのアドレス欄で PC 内を探している、という取り違えも時々あります。探す場所はタスクバーか、スタートを開いたあとの入力欄です。

## まだ直らないとき

- 検索窓は開くがファイルだけ出ない → 手順4の対象フォルダー。OneDrive の「ファイル オンデマンド」だけオンラインのファイルは、ネットが切れているとヒットしません
- アプリ名は出るが設定の項目が出ない → スタートの検索は生きています。設定アプリ側の不調は [アプリが実行できないとき](/articles/windows-app-cannot-run/) も見る
- 別のローカルユーザーで検索できる → 今のプロファイル側。常用アカウントのインデックス再構築を先に。引っ越しはファイルコピーまで（フォーマットはしない）
- 職場PCで `services.msc` の Windows Search が無効のまま灰色 → 家庭向けのオン操作では終わりません
- 再構築が何時間も 0% のまま、ディスク使用率は低い → Windows Search を実行中にしてから、もう一度詳細設定の再構築。それでもダメならメーカーサポートへ、この画面のスクリーンショットを渡す
- セーフモードだと検索できる → あとから入れたランチャーやセキュリティソフト。通常起動に戻してスタートアップを削る

## まとめ

虫眼鏡が無ければタスクバー設定、窓は出るのにゼロ件なら Windows Search とインデックスです。再構築はファイルを消しません。.reg や修復ツールは使わないでください。
