C ドライブが赤くなり、「ディスク領域が不足しています」「ファイルをコピーできません」と出ると、更新もバックアップも止まります。見た目の「空き 0バイト」でも、中身の大半は **一時ファイル、古い更新、ダウンロードフォルダー、休止状態ファイル** であることがよくあります。逆に、Windows 本体やユーザーの書類をむやみに消すと、次の起動で別のトラブルになります。

この記事では Windows 10 / 11 の標準画面だけで、消してよい順に片付けます。写真や仕事ファイルの退避が先か、一時ファイルが先かは、症状の見分けで分岐します。

## 症状の見分け

- エクスプローラーの C ドライブが赤い、または空きが数GB以下
- Windows Update や大型アプリのインストールが容量エラーで止まる
- ブラウザのダウンロードや ZIP 展開だけ失敗する
- 「ストレージ センサー」の通知が繰り返し出る
- 動画やゲームを入れた直後から、急に空きが減った

空きが数十GBあるのに特定フォルダーだけ書けないときは、権限やディスクエラーのことがあり、この記事の削除手順では直りません。

## よくある原因

1. **Windows Update の配布ファイル**と、配信の最適化のキャッシュが残っている
2. ダウンロードフォルダーに、インストーラーや ZIP が何年分も溜まっている
3. ごみ箱を空にしていない
4. 休止状態（`hiberfil.sys`）がメモリ容量と同じくらいを占めている
5. 使っていないアプリ、ゲーム、動画編集のキャッシュ
6. OneDrive やスマホバックアップが、PC 上に実体ファイルとして置かれている

更新が容量不足で止まっている途中なら、先にこの記事で空きを作ってから [Windows Update が進まないとき](/articles/windows-update-stuck/) に戻ってください。空きが少なくて操作全体が重いだけのときは [動作が遅いときの手順](/articles/windows-pc-running-slow/) も使えます。

## 直す前に

- デスクトップと **ドキュメント** に、残したいファイルがあるかざっと見る。ゴミ箱行きにする前に、外付けHDDやクラウドへコピーする
- 会社PCなら、個人の判断でユーザーフォルダーを空にしない。共有ドライブの案内を先に確認する
- クリーンアップ中に電源を切らない

> **注意:** 「Cドライブを一発で空ける」「レジストリとジャンクを削除」を名乗るアプリは使わないでください。システムファイルまで消して、起動や復元が壊れることがあります。標準のストレージ画面で十分です。

## 手順

### 1. 設定のストレージで内訳を見る

1. **設定** → **システム** → **ストレージ**。
2. しばらく待ち、**一時ファイル**、**インストールされているアプリ**、**その他** の大きい項目を確認する。
3. どの種類が多いかで、次に進む節を決める。一時ファイルが数GB以上なら手順2、アプリが大半なら手順4です。

ここを見ずにダウンロードフォルダーから消し始めると、仕事ファイルを巻き込むことがあります。

### 2. 一時ファイルから消す（いちばん安全）

1. **ストレージ** → **一時ファイル**。
2. 次は消してよいことが多いです。チェックして **ファイルの削除**。
   - Windows Update のクリーンアップ
   - 配信の最適化のファイル
   - 一時ファイル
   - サムネイル
   - ごみ箱
3. **ダウンロード** にチェックを入れる前に、中身をエクスプローラーで開いて確認する。ここはユーザーが保存したインストーラーやPDFも入ります。
4. **以前の Windows のインストール** は、大型更新のロールバック用です。更新から 10日以上経ち、問題なく使えているときだけ消します。

削除後、エクスプローラーで C ドライブを開き直して空き容量を確認します。

### 3. ディスク クリーンアップでもう一段（更新の残骸）

設定の一時ファイルで足りないときに使います。

1. スタートメニューで `クリーンアップ` と検索し、**ディスク クリーンアップ** を開く。
2. C ドライブを選び、**システム ファイルのクリーンアップ**（管理者）。
3. **Windows Update のクリーンアップ**、**配信の最適化**、使っていなければ **休止状態ファイル** を選ぶ。
4. 削除を実行し、完了まで待つ。

休止状態ファイルを消すと、蓋を閉じたあとの「バッテリー残量ゼロ近くまでメモリをディスクに書く」動作は使えなくなります。スリープだけで足りるノートなら、空き容量との交換として有効です。コマンドで切る場合は、管理者のコマンド プロンプトで `powercfg -h off` です。元に戻すときは `powercfg -h on`。

### 4. 使っていないアプリを外す

1. **設定** → **アプリ** → **インストールされているアプリ**。
2. サイズで並べ替え、何年も開いていないゲームや試用ソフトを **アンインストール**。
3. メーカーのサポートツールや GPU コントロールは、名前がわからなければ残す。起動時に余計な常駐だけ止めたい場合は、削除より [スタートアップの整理](/articles/windows-startup-apps/) のほうが安全です。

Microsoft Store のアプリは、設定の **ストレージ → インストールされているアプリ** からも外せます。デスクトップ版と Store 版が二重にあるときは、使っているほうだけ残します。

### 5. ユーザーフォルダーとクラウドの実体を見直す

1. エクスプローラーで **ダウンロード**、**ビデオ**、**ピクチャ** を開き、大きいファイルを別ディスクへ移す。
2. OneDrive を使っている場合は、エクスプローラーのファイルを右クリックし、**空き容量を増やす**（オンラインのみ）にできるか見る。PC上の実体は消えますが、クラウド側には残ります。ネットが切れる場所で必要なファイルは、先に「このデバイス上で常に保持」にしておきます。
3. スマホの写真バックアップ先が C ドライブになっていないか、メーカーアプリの保存先を確認する。

動画編集やブラウザのキャッシュが「その他」に入っていることがあります。内訳の **その他** を開き、パスが自分の作業フォルダーなら、そこだけ退避します。`C:\Windows` 配下は中身が見えても削除しないでください。

### 6. コンポーネントストアの圧縮（上級・任意）

Windows の部品置き場（WinSxS）が肥大しているときに限ります。管理者のコマンド プロンプトで次を実行します。

```text
DISM /Online /Cleanup-Image /StartComponentCleanup
```

完了まで待ってから空きを確認します。`/ResetBase` は、追加した更新をアンインストールできなくなるので、日常の掃除では使いません。

## まだ直らないとき

- 一時ファイルを消してもすぐ満杯に戻る → ごみ箱以外に、同期ツールや録画ソフトが書き続けていないか、タスクマネージャーのディスク使用量を見る
- 空きがあるのに「容量不足」と更新だけ言う → [Windows Update が進まないとき](/articles/windows-update-stuck/) の配布フォルダー入れ直しを試す。壊れたダウンロードが容量を食っていることがあります
- C が SSD で小さい（128GB クラス） → 片付けの上限に近いです。ドキュメントと写真は外付けへ移し、アプリは D ドライブへ入れ直す
- ディスクのプロパティで容量と空きが計算と合わない、異音がする → 削除を続けず、重要なデータを別媒体へコピーしてからメーカー診断へ。ハードウェア故障の切り分けです
- `chkdsk` の実行案内が出る → 指示どおり再起動時にスキャンする。エラーが出たら、その結果をサポートへ渡す

## まとめ

ストレージ不足の多くは、Windows フォルダーを削る話ではなく **一時ファイルとダウンロードと使っていないアプリ** です。設定の内訳を見てから一時ファイルを消し、ダウンロードは中身を確認して移す。休止状態と以前の Windows は、用途を理解してから外します。一括クリーナーより、標準画面のほうが元に戻しやすいです。
