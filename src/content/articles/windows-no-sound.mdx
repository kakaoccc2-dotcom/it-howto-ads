動画も会議も、自分では再生しているのに無音、3.5mm や USB のヘッドホンを挿しても内蔵スピーカーのまま、Bluetooth につないだのに切り替わらない、という状態はスピーカー故障より **既定の出力が別機器、ミュート、HDMI モニター側の音声、アプリごとの出力** が多いです。Windows は内蔵スピーカー、ヘッドホン、モニター、Bluetooth を同時に持てるので、どれかが「既定」のまま残ります。

この記事は Windows 10 / 11 の **再生（出力）** を対象にします。自分の声が相手に届かない（入力）は [マイクが使えない手順](/articles/windows-microphone-not-working/) です。USB ヘッドホン自体が一覧に出ないときは、先に [USB機器が認識されない](/articles/usb-device-not-recognized/) を見てください。

## 症状の見分け

- タスクバーのスピーカーアイコンに赤い禁止マーク、または音量は動くが無音
- ヘッドホンを挿しても、音は内蔵スピーカーやモニターから出続ける
- Bluetooth イヤホンは「接続済み」なのに、再生すると本体スピーカー
- 特定のアプリ（ブラウザだけ、ゲームだけ）が無音で、ほかは鳴る
- 外付けディスプレイをつないだ直後から、ノート本体の音が消えた
- 昨日まで使えていたのに、Windows の更新後や新しいイヤホンをつないだあとから無音

音量バーが動くのに聞こえないなら、出力先の取り違えかミュートです。バー自体が灰色・操作できないなら、ドライバーかデバイスの無効化を先に見ます。

## よくある原因

1. 既定の出力が、今使っていないモニターや切れた Bluetooth になっている
2. 本体・ヘッドホン・キーボードのミュート、または音量が 0
3. HDMI / USB-C 接続のモニターがスピーカー扱いのまま
4. **音量ミキサー** で、そのアプリだけミュートか別デバイス
5. Bluetooth が音楽用ステレオではなく、通話用の Hands-Free だけ、または接続が中途半端
6. オーディオの機能強化や空間オーディオが、その機器で失敗している

## 直す前に

- ヘッドホン本体の電源、インラインのミュート、ノートの Fn ミュートキー（スピーカーアイコン）を見る
- 今出したい機器の名前（Realtek、Headphones、HDMI、AirPods など）を、設定の一覧で確認できる状態にする
- 有線なら別の端子（ノート側面とドック、フロントとリア）を取り違えていないか見る

> **注意:** 「音質ブースター」「ドライバー一括修復」を名乗る実行ファイルは入れないでください。既定デバイスとミュートを直すほうが先です。音量を最大にしたままヘッドホンを挿すと、耳を痛めることがあります。確認中は小さめにしてください。

## 手順

### 1. 既定の出力機器を選ぶ

1. **設定** → **システム** → **サウンド**。
2. **出力** で、今音を出したい機器を選ぶ。内蔵・ヘッドホン・モニターが並んでいるときは、名前で区別する。
3. **音量** が 0 やミュートになっていないか見る。70 前後にして、テスト音が聞こえるか確認する。
4. タスクバーのスピーカーを左クリックし、同じ機器が選ばれているか見る。クイック設定側だけ古い機器のことがあります。

ヘッドホンを挿しているのに一覧に出ないときは、いったん抜き、10秒待って挿し直します。USB なら PC 本体のポートへ直挿しします。

### 2. 使わない出力を無効にして、取り違えを止める

1. サウンド設定の関連リンクから **サウンドのコントロール パネル**（または `mmsys.cpl`）を開く。
2. **再生** タブを右クリックし、**無効なデバイスの表示** と **切断されているデバイスの表示** をオン。
3. 使いたい機器を右クリック → **既定のデバイスにする**。可能なら **既定の通信デバイスにする** も同じ機器にする。
4. 使っていない HDMI、切れている Bluetooth、「デジタル出力」などは右クリック → **無効**。会議中だけモニター音声に奪われるのを防げます。

外付けディスプレイをつないだ直後から無音になったときは、モニター名が既定になっていないか見ます。映像の切り分けは [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) です。音だけ戻したいなら、出力を本体またはヘッドホンに戻し、モニター側は無効で足ります。

### 3. アプリごとの音量と排他モードを見る

特定のタブやゲームだけ無音のときです。

1. **設定** → **システム** → **サウンド** → **音量ミキサー**（または **アプリの音量とデバイスの設定**）。
2. そのアプリのスライダーがミュートでないか、出力先が全体と違う機器になっていないか見る。
3. ブラウザやゲームをいったん終了して開き直す。起動中にヘッドホンを挿すと、古い出力のまま掴むことがあります。
4. コントロール パネルの再生タブで対象機器の **プロパティ** → **詳細** タブ。**アプリケーションによってこのデバイスを排他的に制御できるようにする** をオフにする。先に開いたアプリがヘッドホンを独占しているときに有効です。

同じ画面の **通信** タブで、**通信アクティビティの発生時** を **何もしない** にすると、通話検知でスピーカーが絞られる現象を避けられます。

### 4. Bluetooth と有線で切り分ける

1. Bluetooth イヤホンなら、一度切断し、有線または内蔵スピーカーで音が出るか見る。内蔵で出るなら機器側かプロファイルです。
2. 接続し直し、再生を始めてから、設定の出力名が **ステレオ** 側になっているか確認する。Hands-Free のままだと音が小さい、または出ないことがあります。
3. ほかの端末では鳴るのに Windows だけダメなら、Windows の Bluetooth デバイスから削除し、イヤホン側もリセットして入れ直す。手順の考え方は [iPhone の Bluetooth](/articles/iphone-bluetooth-pairing/) と同じです（Windows 側は **設定 → Bluetooth とデバイス**）。
4. 3.5mm なのに検知されないノートは、コンボジャックのゴミや、Realtek のコネクタ設定（ヘッドホン / ヘッドセット）を疑います。別の有線イヤホンで当たるか見てください。

### 5. 機能強化をオフにし、ドライバーを公式に戻す

1. 再生タブで対象機器の **プロパティ** → **詳細** または **空間オーディオ**。空間サウンドや Windows Sonic を **オフ** にする。
2. **機能強化**（または **詳細**）タブで、オーディオの機能強化をオフ。機種によっては「オーディオの機能強化を無効にする」です。
3. デバイス マネージャー → **サウンド、ビデオ、およびゲームのコントローラー**。黄色の「！」があれば、右クリック → **デバイスのアンインストール** のあと再起動し、ヘッドホンを挿し直す。
4. ドライバーは PC メーカーのオーディオ用を使う。まとめサイトの「Realtek 最新パック」は不要です。

起動時にメーカーのオーディオユーティリティが複数立ち上がっていると、既定デバイスが毎回書き換わります。不要なら [スタートアップの整理](/articles/windows-startup-apps/) で、音に関係する常駐だけ残します。

## まだ直らないとき

- 設定のテスト音は鳴るが動画だけ無音 → サイトやアプリ側のミュート、別タブの専有、ブラウザのメディア自動再生。ミキサーでそのプロセスを見る
- HDMI モニターでは鳴るが本体だけダメ → 本体スピーカーまたはジャック側。保証内なら、手順1の画面と、有線／Bluetooth それぞれの結果を添えてメーカーへ
- Bluetooth だけ途切れる・遅れる → マイク記事と同様、通話開始で Hands-Free に落ちることがあります。音楽再生のテストはステレオ接続のまま
- どの機器でも無音、デバイス マネージャーにオーディオが無い → ドライバーまたはハードウェア。セーフモードで鳴るかは切り分けになります
- 更新の直後からだけ → [Windows Update が進まないとき](/articles/windows-update-stuck/) で更新を完了させるか、オーディオドライバーの **ロールバック** を試す

## まとめ

無音の多くは故障ではなく **今鳴らしたい機器が既定になっていない** ことです。設定の出力とコントロール パネルの再生タブを揃え、使わない HDMI や切れた Bluetooth は無効にする。アプリだけダメならミキサー、無線だけダメなら有線で切り分けます。機能強化と出自不明の修復ツールより、公式ドライバーのほうが元に戻しやすいです。
