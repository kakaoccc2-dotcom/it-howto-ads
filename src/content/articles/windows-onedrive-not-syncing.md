タスクバーの雲に赤い×。ファイルを保存したのに、別の PC やスマホの OneDrive に出てこない。「同期が保留されています」のまま、何時間置いてもチェックにならない。C ドライブの片付けは [ストレージ不足の手順](/articles/windows-storage-full/)、削除しようとして「使用中」と出る話は [ファイルが使用中のとき](/articles/windows-file-in-use/) です。こちらは **OneDrive の同期が止まったまま** のときの順番です。

## 症状の見分け

- 雲アイコンが赤い、または「一時停止」のマークのまま
- エクスプローラーのファイルに、雲でも緑のチェックでもなく、赤い印が付く
- アクティビティに **同期が保留されています**、**アップロードできませんでした** と出る
- サインインを求める吹き出しが、再起動のたびに戻る
- この PC では開けるが、ブラウザの onedrive.com には新しいファイルが無い
- デスクトップのアイコンが、同期をオンにした日だけ消えたように見える

最後の一つは、同期の失敗と別に、保存場所が OneDrive のデスクトップへ移ったことがあります。中身が空に見えるだけなら、先に [デスクトップのアイコンが無いとき](/articles/windows-desktop-icons-missing/) を見てください。ファイルは残っていて、雲だけ赤い、という状態がこの記事です。

## よくある原因

1. **同期の一時停止** が 2時間、8時間、24時間で残っている
2. Microsoft アカウントの OneDrive 容量が上限で、アップロードだけが止まる
3. ファイル名に使えない文字がある、またはフォルダーの階層が深すぎる
4. そのファイルを Excel や写真アプリが開いたまま
5. 個人用と職場用のアカウントを取り違えている。雲アイコンが二つある
6. OneDrive アプリが終了したまま、スタートアップでも起きていない

## 直す前に

- 赤い印の付いたファイルを、消す前に別の場所（USB メモリやデスクトップの外）へコピーする。同期のやり直しは、通常はファイルを消しません。念のためのコピーです
- **この PC のリンクを解除** は、最初の手段にしません。解除したあと、どのファイルがこの PC に残るかが分かりにくくなります
- 会社の OneDrive（組織のアカウント）で管理者が制限している項目は、個人のスイッチでは戻りません

> **注意:** OneDrive フォルダーをエクスプローラーで削除したり、`C:\Users` の中の OneDrive を丸ごと消したりしないでください。同期の失敗に見えて、実体はクラウドにしか無いファイルがあります。消すと、別の PC からも見えなくなります。

## 手順

### 1. 雲の文面を読む

色だけでは次が決まりません。クリックしたあとの一行を読みます。

1. タスクバーの ^（隠れているインジケーター）を押し、雲のアイコンを出す。白い雲と、建物マークの雲が両方あることがあります。問題のフォルダーを開いている側をクリックする。
2. 上のほうの一文を読む。
3. **一時停止中** なら、歯車 → **同期を再開**。再開すると「同期しています」に変わり、終わるまでファイル横の印が動きます。
4. **サインイン** や **アカウントの修復** なら、表示された Microsoft アカウントが、普段ブラウザで使っているものと同じか見てからサインインする。パスワードの窓がループするときは、ブラウザで onedrive.com に入れるかを先に試す。ブラウザでも入れないなら、PC の OneDrive ではなくアカウント側です。
5. **最新の状態です** なのに、探しているファイルが無い → 同期は生きています。別のフォルダー、またはもう一方のアカウントの雲を開いていないか見る。

再開のあとに緑のチェックや白い雲が増えれば、一時停止だけでした。赤が残るファイルだけ、手順3へ名前を見に行きます。

### 2. 容量が、PC 側かクラウド側かを分ける

「ストレージの上限」「空き容量が不足」は、場所が二つあります。

1. 雲の画面に、使用量のバー（たとえば 5 GB 中 5 GB）が出ていないか見る。バーが Microsoft アカウントの分なら、クラウドが満杯です。アップロードは止まり、ダウンロードは続くことがあります。
2. バーの **ストレージを管理** からブラウザが開いたら、大きいファイルや、ごみ箱（OneDrive のごみ箱は別です）を確認する。PC のごみ箱を空にしても、このバーは減りません。
3. バーは余裕があるのに、エクスプローラーで C ドライブが赤いなら、止んでいるのは「このデバイスに保持」のダウンロード側です。**設定のストレージ** で空きを作ってから、赤いファイルを右クリックして **このデバイス上に常に保持する** を押し直す。
4. クラウドが満杯で、今すぐ開けなくてよいファイルがあるなら、エクスプローラーでそのファイルを右クリックし、**空き容量を増やす**（オンラインのみ）にする。PC 上の実体は外れますが、クラウドに残っているものだけが対象です。赤い×の、まだ一度もアップロードできていないファイルには使いません。

ローカルの空きの作り方は、ストレージ不足の記事の一時ファイルとダウンロードからで十分です。OneDrive フォルダーそのものは削らないでください。

### 3. 赤いファイルの名前と、使えない文字

アクティビティセンターは、失敗したファイルの名前を出します。

1. 雲をクリックし、失敗の行を押す。エクスプローラーがそのファイルの場所で開くか、エラーの文が広がります。
2. 文面が **使用できない文字** なら、名前に `\ / : * ? " < > |` のどれかが入っています。ファイルを右クリック → **名前の変更** で、その文字を外す。保存したアプリが同じ名前で作り直すなら、アプリ側の名前も変えます。
3. **パスが長すぎます** なら、深いフォルダー（何段も入れ子）から、OneDrive の直下に近い場所へ移す。ファイル名も短くする。
4. **使用中** なら、Excel や Word、写真、ブラウザのプレビューを閉じてから、雲の画面で同期が動くまで待つ。どのアプリが掴んでいるかの見方は、ファイルが使用中の記事です。
5. 名前の末尾に、PC の名前が付いた複製（競合）ができているときは、中身を開いてどちらが残したいか決めてから、要らないほうを OneDrive のごみ箱へ入れる。両方残すなら、分かりやすい名前に変更する。

一個直るたびに、雲の一覧からその行が消えます。全部消えれば、アイコンは赤い×ではなくなります。

### 4. ファイル オンデマンドと、個人用 Vault

緑のチェックと、青い雲を取り違えているだけのことがあります。

1. エクスプローラーで OneDrive のフォルダーを開く。列に状態のアイコンが出ます。
2. 青い雲は、中身がまだこの PC に無い印です。ダブルクリックすると、ネット経由で開こうとします。ネットが切れている場所では開けません。失敗ではなく、未ダウンロードです。
3. いつも使うファイルだけ、右クリック → **このデバイス上に常に保持する**。緑の塗りつぶしチェックに変わります。フォルダーごと保持にすると、C ドライブが一気に減ります。
4. **個人用 Vault** だけ開かないときは、Vault のフォルダーを開き、ロックの解除（本人確認）を通す。Vault の外のファイルが同期しているなら、OneDrive 全体の故障ではありません。
5. 歯車 → **設定** → **同期とバックアップ** → **詳細設定** で、**ファイル オンデマンド** がオフになっていないか見る。オフだと、クラウドの全部をこの PC に置こうとして、空き不足で保留が続きます。家庭のノートはオンのままが扱いやすいです。

### 5. OneDrive を終了して、公式のリセットで起こす

一時停止ではなく、プロセスが落ちているときの手順です。ファイルは削除しません。同期の一覧を作り直します。

1. 雲の歯車 → **OneDrive を閉じる**。アイコンがタスクバーから消えることを見る。
2. スタートに `OneDrive` と入れて、アプリを起動する。「最新の状態です」または同期中に戻れば、リセットは不要です。
3. アイコンが戻らない、すぐ赤い×に戻る、というときだけ `Win` + `R` に次を入れて Enter。

```text
%localappdata%\Microsoft\OneDrive\onedrive.exe /reset
```

4. 数十秒待つ。雲が消えたままなら、もう一度 `Win` + `R` で次を実行する。

```text
%localappdata%\Microsoft\OneDrive\onedrive.exe
```

5. サインインを求められたら、手順1で確認したアカウントで入る。同期が最初から走り、大きいフォルダーだと「処理しています」が長く続きます。そのあいだに電源を切らない。

> **注意:** `/reset` は Microsoft の OneDrive に付いている起動オプションです。見慣れない「OneDrive修復」ソフトは入れないでください。リセットのあとも、リンク解除はまだ押さない。

## まだ直らないとき

- ブラウザの onedrive.com も開かない、ほかのサイトも不安定 → OneDrive の設定より回線です。PC の DNS や Wi-Fi を先に分ける
- 職場のアカウントだけ失敗、個人の 5GB は成功 → 組織側の容量か、条件付きアクセス。IT 担当へ、雲のエラー文のスクリーンショットを渡す
- 特定の拡張子だけ毎回失敗 → そのアプリが保存直後にファイルを掴んだままです。アプリを終了してから雲を見る
- リセットのあとも `onedrive.exe` が見つからない → スタートの **設定 → アプリ → インストールされているアプリ** に Microsoft OneDrive があるか見る。無いなら、Microsoft Store の OneDrive を入れ直す。出所不明のセットアップは使わない
- 同期は成功なのに、デスクトップだけ空 → フォルダーバックアップで場所が移っています。デスクトップのアイコンの記事へ

## まとめ

雲を開いた一文が「一時停止」なら再開、「上限」ならクラウドのバー、「使用できない文字」ならそのファイルの名前です。リンク解除やフォルダーごと削除の前に、赤い行の文面と `/reset` までで足りることがほとんどです。まだアップロードできていないファイルは、別のディスクにコピーしてから操作してください。
