膝の上が熱い。動画もゲームもしていないのにファンが全開。置いているだけで筐体が暑い。故障というより **通気の塞がり、CPU を食う常駐、電源モード、裏での更新** が多いです。ファンそのものを止めるソフトは使いません。熱いのにファンが無音、異臭、膨張は、この記事の設定より先に電源を切ってください。

重さそのものの話は [動作が遅いとき](/articles/windows-pc-running-slow/) です。熱とファン音が主なら、こちらです。ノートの電池だけ急減して熱くないときは [バッテリーの持ち](/articles/windows-battery-drains-fast/) 。スリープしたつもりがバッグの中で回っているときは [スリープと復帰](/articles/windows-sleep-wake-problems/) です。

## 症状の見分け

- アイドルなのにファンが数分おきに吹き上がる。本体上面が触れないほど熱い
- ブラウザのタブを増やすと、音と熱が一段上がる
- 冬の毛布の上、布団の上、膝の上だけでうるさい
- 電源につないだときだけ全開。バッテリー駆動では静か
- 起動直後の 10分だけうるさい（更新やインデックスの疑い）
- ファンは回るが、画面は普通に動く。エラーは出ない

ファンからカリカリ、金属音、煙、焦げ臭はハードウェアです。設定をいじらず電源を切り、保証期間内ならメーカーへ。バッテリーが膨らんでいるノートも同じです。無理に蓋を開けないでください。

## よくある原因

1. 吸気・排気が毛布、壁、ペットの毛で塞がっている
2. ブラウザ、ゲームランチャー、クラウド同期、セキュリティの初回スキャンが CPU を張っている
3. 電源モードが **最適なパフォーマンス** のまま、常時高回転
4. Windows Update やストアが裏で大きいファイルを取っている
5. ホコリでフィンが詰まり、回しても熱が抜けない
6. 夏場の直射、縦置きデスクトップの左右密着

## 直す前に

- 作業ファイルを保存する。熱で突然落ちることがあります
- ノートなら充電器をつないでもよいが、布団の上には置かない
- 「ファン停止」「冷却ブースター」「一秒で静音」系のアプリは入れない。温度保護を外すものがあります

> **注意:** BIOS でファン制御をオフにする、サーマルペーストを自分で塗る、ヒートシンクを外す作業はこの記事ではやりません。保証が飛び、焼け付きの原因になります。自分でやる掃除は、吹出口の外側までです。

## 手順

### 1. 置き方と、通気を空ける

1. ノートを **硬い平らな机** に置く。布団、ひざ掛け、柔らかいソファは吸気を塞ぎます。
2. 底面と奥の吹出口を見る。壁から数センチ離す。縦置きデスクトップは、左右のメッシュを本棚に密着させない。
3. 直射日光の当たる窓際から移す。夏の車内に置きっぱなしにしたあとは、冷ましてから電源オン。
4. 吹き出し口に手をかざし、風が出ているか見る。熱風が出ていればファンは回っています。無風なのに筐体だけ熱いのは、ファン停止か詰まりです。電源を切ってメーカーへ。

冷却スタンドより先に、机の上へ移す。ペットの毛が多い家は、吹出口の外側を柔らかいブラシで払う。内部へ金属棒は入れません。

### 2. タスク マネージャーで「何が熱いか」を見る

1. `Ctrl` + `Shift` + `Esc` でタスク マネージャー。
2. **プロセス** の **CPU** と **GPU** をクリックして降順。90% 付近の名前を控える。
3. 使っていないブラウザ、ゲームランチャー、メーカーの「サポート」常駐を終了してみる。ファンの音が一段落ちるか10秒待つ。
4. **アプリの履歴** や **スタートアップ アプリ** で、毎回起こしている名前を見る。整理の本体は [スタートアップの手順](/articles/windows-startup-apps/) です。
5. ディスクが 100% のまま数十分、は熱より先に遅さの記事です。CPU だけ高いなら、このまま電源モードへ。

Chrome のタブが多い、Zoom を切ったつもりが残っている、OneDrive が「処理中」のまま、が定番です。セキュリティソフトの初回フルスキャン中は、うるさいのが普通です。終わるまで電源を切らないでください。

### 3. 電源モードを一段落とす

1. **設定 → システム → 電源とバッテリー**（デスクトップは **電源**）。
2. **電源モード** を **バランス** または **最適な電源効率** にする。**最適なパフォーマンス** はファンが先に全開になります。
3. ノートは **画面とスリープ** の分数も見る。付けっぱなしの最大輝度は熱の元です。明るさは [真っ黒画面の記事](/articles/windows-brightness-black-screen/) とは別件ですが、バーを一段下げると熱は落ちます。
4. コントロール パネルの古い **電源オプション** に「高パフォーマンス」が残っていることがあります。普段使いはバランスへ。

ゲーム中だけうるさいのは、ある程度は仕様です。アイドルなのにパフォーマンス固定、がこの手順の対象です。

### 4. 裏の更新と、不要な常時負荷

1. **設定 → Windows Update** で、ダウンロード中や「再起動が必要」が残っていないか見る。止まっている更新は [Update が進まないとき](/articles/windows-update-stuck/) 。
2. Microsoft Store のダウンロード、ゲームのランチャー更新を一時停止する。
3. 仮想カメラ、マイニング、出典不明の「CPU 最適化」がプロセスにいないか。いたら終了し、スタートアップからも外す。
4. 外付け HDD の常時バックアップが、ディスクと CPU を同時に食うことがあります。手動のあいだ止めて、熱が落ちるか見る。

温度を下げるためのレジストリ、隠し電源プランの配布ファイルは使いません。標準の電源モードで足りることがほとんどです。

### 5. 外側のホコリと、再起動

1. シャットダウンする。電源ケーブルを抜き、ノートは電池が外せる古い機種だけ外す（最近の内蔵電池は触らない）。
2. 吹出口を下向きにし、**缶のエアダスター** を短い噴射で外側から吹く。液が出るまで缶を傾けない。ファンの羽根をドライバで止めて回し続ける、はしない（過回転で壊れます）。
3. 掃除機を吹出口に密着させて強く吸うのは、羽根を歪めるのでやめる。払うか、短く吹く。
4. 10分置いてから電源オン。アイドルでファンが落ち着くか見る。

内部の綿埃が塊になっている、熱いまま無風、は分解が要ります。家庭ではここまでです。メーカーサポートか、修理店へ「アイドルなのに熱い、外側は吹いた」と伝えてください。

## まだ直らないとき

- アイドルなのに CPU 100% が続く → タスク マネージャーの名前を控えて検索。Windows のシステムプロセスなら更新待ち。見慣れない exe ならスタートアップから外す
- 電源モードを落としても布団の上だけ熱い → 置き方が原因。設定では直りません
- 新品同様なのに夏だけ全開 → 部屋の温度。ノートは机＋数センチの隙間
- ファンが回らない、BIOS でも温度警告 → ハードウェア。自分でコネクタを抜かない
- 職場 PC で電源モードが灰色 → 個人では終わりません。担当へ「アイドル時の CPU 使用率と、ファンが止まらない」を渡す

温度計アプリは無くても切り分けできます。入れるなら Microsoft Store か、PC メーカーの公式ユーティリティだけです。ネット広告の「今すぐ冷却」は不要です。

## まとめ

静音アプリより、机の上、タスク マネージャーで CPU を食っている名前、電源モードの **バランス** です。熱いのに無風、異臭、膨張は設定の話ではありません。外側の埃までが家庭の範囲です。
