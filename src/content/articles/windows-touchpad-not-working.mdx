ノートのタッチパッドを撫でてもカーソルが動かない、クリックだけ効かない、逆に触っていないのにポインターがひとりで走る、といった状態は基板故障より **Fn でのオフ、設定の無効化、外付けマウス接続時のオフ、感度と手のひら誤検出** が多いです。分解やドライバーのまとめサイトは、家庭での切り分けには先に使いません。

この記事は Windows 10 / 11 ノートの内蔵タッチパッドを対象にします。USB マウス自体が一覧に出ないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) です。カーソルが動くのに全体が重いときは、先に [動作が遅いときの手順](/articles/windows-pc-running-slow/) を見てください。

## 症状の見分け

- タッチパッドを触ってもポインターがまったく動かない
- 移動はできるが、タップクリックや二本指スクロールだけ無い
- USB や Bluetooth のマウスをつないだ直後から、パッドが死んだ
- タイプ中だけカーソルが飛び、入力位置が変わる
- 触っていないのにポインターがゆっくり漂う、または端へ飛ぶ
- 昨日まで使えていたのに、Windows の更新後や水をこぼしたあとからおかしい

外付けマウスは動くのにパッドだけダメなら、設定と Fn、ドライバーです。どちらもダメなら、ポインター設定か、本体側です。水濡れ・変形・異音があるときは、この先の設定より先に電源を切り、メーカーへ相談してください。

## よくある原因

1. キーボードの **Fn + タッチパッドアイコン** で、パッドがオフになっている
2. **設定 → Bluetooth とデバイス → タッチパッド** のスイッチがオフ
3. 「マウスの接続時にタッチパッドをオフにする」がオンのまま、レシーバーが刺さっている
4. タイプ時のカーソル遅延（手のひら検出）が強すぎる、または弱すぎて誤動作する
5. マウスキー（テンキーでポインター）や、高すぎる感度で「勝手に動く」ように見える
6. Synaptics / ELAN の古いドライバー、または更新直後の不整合

## 直す前に

- 外付けマウスや、USB のレシーバーをいったん全部抜く（切り分けのため）
- キーボードに水や油が付いていないか見る。濡れているときは電源を切り、乾くまで触らない
- 出典不明の「タッチパッド修復」「ドライバーパック」は入れない

> **注意:** ノートを分解してパッドを外す作業はしないでください。保証が切れます。BIOS の更新も、この記事の範囲外です。液体をかぶったあとに電源を入れ続けると、被害が広がることがあります。

## 手順

### 1. Fn キーと、設定のタッチパッドをオンにする

1. キーボードのタッチパッドアイコン（四角に線、またはパッドの絵）を探す。`Fn` と一緒に押し、インジケーターや画面上のトーストが「オン」になるか見る。機種によっては `Fn` ロックの状態で、一発押しです。
2. **設定** → **Bluetooth とデバイス** → **タッチパッド**（Windows 10 では **設定 → デバイス → タッチパッド**）。
3. **タッチパッド** のスイッチをオンにする。グレーで触れないときは、手順4のデバイス マネージャーへ。
4. 同じ画面の **マウスが接続されているときにタッチパッドをオフにする** をオフにする。USB レシーバーを挿したままにしていると、マウスを使っていなくてもパッドが死にます。

オンにしたあと、パッドの中央をゆっくり動かして、ポインターが追従するか確認します。ここで動けば、無効化だけでした。

### 2. タップ、スクロール、手のひら検出を戻す

移動はするのにクリックできない、またはタイプ中だけ飛ぶときに有効です。

1. 同じタッチパッド画面で **タップ** を開き、**タッチパッドをタップしてクリックする** をオン。
2. **スクロールとズーム** で、二本指スクロールがオンか見る。方向が逆なだけなら、ここで入れ替えます。
3. **精度** や **感度** を **中** 付近にする。最高感度は、袖や充電ケーブルの振動で「勝手に動く」原因になります。
4. **カーソルの遅延**（タイプ時にタッチパッドをオフ）を、誤クリックが多いなら長め、タイプ中にポインターが死ぬなら短めかオフにする。

メーカー独自の Synaptics / ELAN アプリが入っているときは、Windows の画面と二重管理になります。両方でオフになっていないか見て、使っていないほうの常駐は [スタートアップの整理](/articles/windows-startup-apps/) で止めます。

### 3. マウスキーと、外付け機器で切り分ける

1. **設定 → アクセシビリティ → マウス**（Windows 10 では **簡単操作 → マウス**）。**マウスキー** がオンならオフにする。テンキーの押しっぱなしで、触っていないのにポインターが漂います。
2. Bluetooth マウスを切断し、USB レシーバーも抜く。それでもパッドが動かないか、逆に飛びが止むかを見る。
3. 家に有線マウスがあればつなぎ、ポインターだけ確保する。パッド修理までの応急です。USB が一覧に出ないときは USB の記事へ。
4. 充電中だけカーソルが飛ぶときは、充電器を別のコンセントに変える。安価なアダプターのノイズで、パッドが誤検出することがあります。

勝手に動く側の切り分けは、「手を離して30秒見て、まだ動くか」です。動くなら感度・マウスキー・充電ノイズ、止まってタイプ時だけなら手のひら検出です。

### 4. デバイス マネージャーで、標準に戻す

1. スタートボタンを右クリック → **デバイス マネージャー**。
2. **マウスとその他のポインティング デバイス** を開く。HID 準拠タッチパッド、Synaptics、ELAN、Precision などを探す。黄色い「！」が無いか見る。
3. タッチパッド項目を右クリック → **デバイスのアンインストール**。確認が出たら進める。ドライバーの削除にチェックがある画面では、メーカー公式をあとで入れるつもりが無いときだけ外す（標準で入れ直させます）。
4. 再起動する。Windows が標準の精密タッチパッドを入れ直します。設定画面にスイッチが戻るか確認する。

ドライバーを入れ直すときは、PC メーカーのサポートページから、その型番のタッチパッド／ユーティリティだけを使います。まとめサイトの「Synaptics 最新」は不要です。更新の直後からだけおかしいときは、デバイスの **プロパティ → ドライバー → ロールバック** を試します。更新そのものが止まっているなら [Windows Update が進まないとき](/articles/windows-update-stuck/) です。

### 5. 表面の汚れと、水濡れの判断

1. 電源を入れたまま、乾いた柔らかい布でパッド表面の油と粉を拭く。爪や金属、水を含ませたティッシュは使わない。
2. フィルムや厚手のカバーを貼っているときは、いったん剥がして反応を見る。
3. こぼした直後、シミ、キーの引っかかりがあるときは、設定をいじらず電源を切る。保証内なら、型番と「液体をかぶった時刻」を添えてメーカーまたは購入店へ。
4. 外付けマウスは動き、パッドだけ反応ゼロ、デバイス マネージャーにも項目が無い、ならハードウェア側です。自分でコネクタを挿し直す作業はしないでください。

## まだ直らないとき

- 設定はオンなのにまったく動かない、外付けマウスは動く → 手順1の Fn をもう一度。機種によっては BIOS にタッチパッド項目がありますが、家庭ではメーカーの案内があるときだけ触る
- タップはできるが二本指だけダメ → ジェスチャ設定。精密タッチパッドでない古いパッドは、二本指非対応のことがあります
- 勝手に動くのが止まらない、マウスキーはオフ → 感度を下げ、充電ケーブルを抜いて30秒見る。続くなら外付けマウスで使い、保証内ならメーカーへ
- どのポインターも動かない → タッチパッド以前の問題。外付けマウスでもダメなら、再起動と、スタートアップ修復の判断
- 職場 PC で設定が灰色 → 個人のスイッチでは終わりません。外付けマウスの可否を担当へ確認する

## まとめ

タッチパッドが死んだように見えるときは、新品を買う前に **Fn でオフになっていないか、設定のスイッチがオンか、マウス接続時オフが働いていないか** を揃えます。外付けマウスが動くならハード全体は生きているので、感度とドライバーを疑います。触っていないのに飛ぶときは、マウスキーと充電ノイズを先に見ます。分解と出自不明の修復ツールは不要です。
