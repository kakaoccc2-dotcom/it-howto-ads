「このアプリはお使いのPCでは実行できません」で先に進めないときの話です。システムの種類を見て、公式の正しい版を取り直してください。

## 症状の見分け

- ショートカットや `.exe` を開くと、すぐ同じダイアログ
- Store から入れたアプリが起動しない
- 大型更新のあと、昨日まで使えていたアプリが開けない
- メーカーの「Windows用」インストーラーが拒否される
- ダイアログに「0xc000007b」や「このバージョンの Windows と互換性がありません」と続く
- ダブルクリックしても何も出ず、タスクバーにも残らない（この記事の文面とは別です）

「このアプリはお使いのデバイスでは実行できません」「Windows によって PC が保護されました」など別文なら、原因が違います。文面をメモしてから進めてください。青い枠の SmartScreen（「PC が保護されました」）は、実行ファイルの入手元の警告です。この記事の互換性ダイアログとはボタンが違います。SmartScreen は **詳細情報** が出たときだけ、発行元を自分で確認して進むかどうかを決めます。発行元がわからないファイルは、詳細情報から実行しないでください。

## よくある原因

1. ARM 版 Windows に、x64 / x86 専用アプリを入れようとしている（Surface の一部、Snapdragon 搭載PCなど）
2. 32ビット専用の古いアプリを、64ビット環境の制約やポリシーで止められている
3. ベータ版・改造インストーラー・メール添付の実行ファイルで、署名や対応OSが不明
4. 破損したダウンロードや、途中で切れた ZIP を展開している
5. 会社・学校の PC で、アプリ制限（WDAC / ストア以外禁止）がかかっている

家庭向けの個人PCなら、1 と 4 がほとんどです。

## 直す前に

- エラー全文をスクリーンショットかメモに残す（「詳細」があれば開く）
- アプリ名と、入手元（公式サイト / Store / 付属DVD / 知人から）を確認する
- 有料ソフトなら、ライセンス画面やシリアルの控えがあるか見る
- 作業用に、公式サイトのダウンロードページをブラウザで開いておく
- ダウンロードが途中で止まったファイルを、そのまま実行しない。[Chrome のダウンロードが失敗するとき](/articles/chrome-download-failed/) で、ファイルが最後まで落ちているかを先に見てください

> **注意:** 検索結果の一番上にある「無料クローザー」「一発修復」系の実行ファイルは使わないでください。今回のエラーは、別の修理ツールで上書きするものではありません。

## 手順

### 1. PC のシステムの種類を確認する

1. **設定**を開く（`Windows` キー + `I`）。
2. **システム** → **バージョン情報** を開く。
3. **デバイスの仕様**の「システムの種類」を見る。

読み方の目安です。

- `64 ビット オペレーティング システム、x64 ベース プロセッサ` → 一般的な Windows PC。公式の 64ビット版を使う。
- `64 ビット オペレーティング システム、ARM ベース プロセッサ` → ARM 版 Windows。x64 アプリは動くものと動かないものがある。**ARM 対応と書いてある版**を探す。

「システムの種類」の行が見当たらないときは、同じ画面を下までスクロールしてください。Windows 11 では **デバイスの仕様** の中です。Windows 10 は **バージョン情報** の「システムの種類」です。

スマホ向けの APK や macOS 用の `.dmg` を Windows に入れて失敗している場合も、同じメッセージに近い表示になることがあります。拡張子を確認してください。エクスプローラーの **表示 → 表示 → ファイル名拡張子** がオフだと、`.exe.txt` を `.exe` と見間違えます。関連付けそのものの直し方は [ファイルが別のアプリで開くとき](/articles/windows-file-association-wrong/) です。

**ここで失敗したとき:** ダイアログが英語のまま「This app can't run on your PC」なら、意味は同じです。システムの種類が x64 なのに ARM 用のインストーラーを落とすと、この文面になります。ダウンロードページの「ARM64」「x64」「64-bit」のどれを押したか、ブラウザのダウンロード履歴で確認してください。

### 2. 公式の配布ページから取り直す

1. アプリ公式のダウンロードページを、メーカー名で検索して開く。
2. Windows 11 / 10 向け、かつ今のシステムの種類向けかを確認する。
3. 以前保存したフォルダのインストーラーは使わず、**今ダウンロードしたファイルだけ**を実行する。

ZIP の場合は、展開しきってから中の `setup.exe` を実行します。圧縮したままダブルクリックで中の exe を直接開くと、一時フォルダ側で失敗することがあります。

**ここで失敗したとき:** 取り直したファイルでも同じダイアログなら、落とした版がまだ違います。ファイルのプロパティ → **詳細** に「製品名」と「ファイルの説明」が出ます。空、または別のソフト名なら、検索結果の広告から別物を落としています。公式ドメインのページからやり直してください。ファイルサイズが公式の案内より極端に小さいときも、途中で切れています。そのファイルは削除して、もう一度最後まで落としてください。

### 3. Microsoft Store 版とデスクトップ版を取り違えていないか見る

同じ名前でも、Store 版とメーカー直配布版は別物です。

- Store に「お使いのデバイスでは利用できません」と出る → 手順1の ARM / リージョン制限を疑う
- デスクトップ版の exe だけ失敗する → 公式の別パッケージ（Store や web インストーラー）がないか確認する

両方入れる必要はありません。動いたほうを残してください。

**ここで失敗したとき:** Store のボタンが「入手」ではなく灰色の「インストール済み」なのに起動しないときは、スタートの一覧から一度アンインストールし、Store の同じページから入れ直します。デスクトップ版の exe が残っていると、スタートに同名が2つ並びます。起動しているのが古いほう、ということがあります。

### 4. 互換モードは「古い業務ソフト」のときだけ試す

今の Windows 11 向けに更新されているアプリでは、互換モードは逆効果になりがちです。最終更新が何年も前のツールに限り、次を試します。

1. 実行ファイルを右クリック → **プロパティ**。
2. **互換性**タブを開く。
3. **互換モードでこのプログラムを実行する**にチェックし、Windows 8 や Windows 7 を選ぶ。
4. **管理者としてこのプログラムを実行する**は、インストール時だけオンにし、常用は避ける。

変わらなければチェックを外して元に戻します。

**ここで失敗したとき:** **互換性** タブ自体が無いファイルは、Store アプリか、ショートカットの本体が見つかっていません。ショートカットなら右クリック → **ファイルの場所を開く** で、本当の `.exe` のプロパティを開いてください。互換モードをオンにしても同じダイアログなら、モードの問題ではありません。チェックを外して、手順1のシステムの種類へ戻ります。

### 5. 職場・学校の PC かどうかを切り分ける

サインインが「職場または学校アカウント」で、設定に **組織によって管理されています** と出る場合、個人で直せる範囲は狭いです。IT 担当へ、エラー全文と手順1のシステムの種類を渡してください。

家庭用の Microsoft アカウントなのに、特定の exe だけブロックされるときは、保護者のコンテンツフィルタや、入っているセキュリティソフトの「未知のアプリを止める」です。公式サイトから落とした同じファイルが別の家庭用PCで開くなら、このPCの制限です。

## 別のPCと比べる

同じファイルを USB メモリで別の Windows へ持っていき、そこで開くかを見ます。メールで送り直すと、また途中で壊れることがあります。USB か、公式ページからの再ダウンロードにしてください。

- 別PCでも同じダイアログ → 配布物が、そのシステムの種類に合っていません
- 別PCでは開く、このPCだけダメ → このPCの ARM / 制限 / 壊れたインストールです
- どちらのPCも x64 なのに片方だけダメ → ダウンロードの破損か、ショートカットが別のファイルを指しています

起動時に毎回このダイアログが出るなら、スタートアップに古い exe が残っています。[起動時にアプリが開くとき](/articles/windows-startup-apps/) で、その項目を無効にしてください。

## まだ直らないとき

- 同じファイルを **別の Windows PC** で開けるか試す。別PCでも同じなら配布物側の問題です。
- ARM 版でどうしても必要な x64 アプリは、メーカーの ARM 対応状況を確認する。エミュレーションで動くこともあれば、公式に非対応のこともあります。非対応と書いてあるソフトを、変換ツールで無理に動かさないでください
- 年数の経った周辺機器ユーティリティは、Windows 11 非対応のまま終了していることがあります。その場合は機器側の代替ソフトか、OSの標準機能で代用できないかを見ます
- インストールは終わるが、起動のたびに同じダイアログ → 入ったあとの別の exe（更新ツール、常駐）が非対応です。スタートアップと、インストール先フォルダーのどのファイルを開いたかをメモします
- ショートカットだけ失敗し、インストール先の exe は開く → ショートカットが古い場所を指しています。スタートからアプリ名で開き直して、新しいショートカットを作ります

関連する接続トラブルは、[プリンターがオフラインになり印刷できないとき](/articles/printer-offline/)も参照してください。ネットワーク側が怪しいときは [DNSサーバーに問題があります](/articles/windows-dns-server-problem/) です。

## まとめ

システムの種類を見て、公式の正しい版を取り直してください。互換モードは、古いソフトのときだけの最終手段です。
