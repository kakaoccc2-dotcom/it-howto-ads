アプリを開いた瞬間に「このアプリはお使いのPCでは実行できません」と出て、先に進めないことがあります。故障に見えますが、多くは **CPUの種類とアプリの対応が食い違っている**か、**配布ファイルが対象OS向けではない**だけです。

画面の名前つきで、下から見ていきます。

## 症状の見分け

次のどれかに当たると、この先の手順が使えます。

- ショートカットや `.exe` を開くと、すぐ同じダイアログが出る
- Microsoft Store から入れたアプリが起動しない
- 昨日まで使えていたアプリが、Windows の大型更新のあとに開けなくなった
- メーカーサイトから落とした「Windows用」インストーラーが拒否される

表示が「このアプリはお使いのデバイスでは実行できません」「Windows によって PC が保護されました」など別文のときは、原因が違うことが多いです。文面をメモしてから進めてください。

## よくある原因

1. **ARM 版 Windows に、x64 / x86 専用アプリを入れようとしている**（Surface の一部、Snapdragon 搭載PCなど）
2. **32ビット専用の古いアプリ**を、64ビット環境の制約やポリシーで止められている
3. **ベータ版・改造インストーラー・メール添付の実行ファイル**で、署名や対応OSが不明
4. **破損したダウンロード**や、途中で切れた ZIP を展開している
5. 会社・学校の PC で、**アプリ制限（WDAC / ストア以外禁止）**がかかっている

家庭向けの個人PCなら、1 と 4 がほとんどです。

## 直す前に

- エラー全文をスクリーンショットかメモに残す（「詳細」があれば開く）
- アプリ名と、入手元（公式サイト / Store / 付属DVD / 知人から）を確認する
- 有料ソフトなら、ライセンス画面やシリアルの控えがあるか見る
- 作業用に、公式サイトのダウンロードページをブラウザで開いておく

> **注意:** 検索結果の一番上にある「無料クローザー」「一発修復」系の実行ファイルは使わないでください。今回のエラーは、別の修理ツールで上書きするものではありません。

## 手順

### 1. PC のシステムの種類を確認する

1. **設定**を開く（`Windows` キー + `I`）。
2. **システム** → **バージョン情報** を開く。
3. **デバイスの仕様**の「システムの種類」を見る。

読み方の目安です。

- `64 ビット オペレーティング システム、x64 ベース プロセッサ` → 一般的な Windows PC。公式の 64ビット版を使う。
- `64 ビット オペレーティング システム、ARM ベース プロセッサ` → ARM 版 Windows。x64 アプリは動くものと動かないものがある。**ARM 対応と書いてある版**を探す。

スマホ向けの APK や macOS 用の `.dmg` を Windows に入れて失敗している場合も、同じメッセージに近い表示になることがあります。拡張子を確認してください。

### 2. 公式の配布ページから取り直す

1. アプリ公式のダウンロードページを、メーカー名で検索して開く。
2. Windows 11 / 10 向け、かつ今のシステムの種類向けかを確認する。
3. 以前保存したフォルダのインストーラーは使わず、**今ダウンロードしたファイルだけ**を実行する。

ZIP の場合は、展開しきってから中の `setup.exe` を実行します。圧縮したままダブルクリックで中の exe を直接開くと、一時フォルダ側で失敗することがあります。

### 3. Microsoft Store 版とデスクトップ版を取り違えていないか見る

同じ名前でも、Store 版とメーカー直配布版は別物です。

- Store に「お使いのデバイスでは利用できません」と出る → 手順1の ARM / リージョン制限を疑う
- デスクトップ版の exe だけ失敗する → 公式の別パッケージ（Store や web インストーラー）がないか確認する

両方入れる必要はありません。動いたほうを残してください。

### 4. 互換モードは「古い業務ソフト」のときだけ試す

今の Windows 11 向けに更新されているアプリでは、互換モードは逆効果になりがちです。最終更新が何年も前のツールに限り、次を試します。

1. 実行ファイルを右クリック → **プロパティ**。
2. **互換性**タブを開く。
3. **互換モードでこのプログラムを実行する**にチェックし、Windows 8 や Windows 7 を選ぶ。
4. **管理者としてこのプログラムを実行する**は、インストール時だけオンにし、常用は避ける。

変わらなければチェックを外して元に戻します。

### 5. 職場・学校の PC かどうかを切り分ける

サインインが「職場または学校アカウント」で、設定に **組織によって管理されています** と出る場合、個人で直せる範囲は狭いです。IT 担当へ、エラー全文と手順1のシステムの種類を渡してください。

## まだ直らないとき

- 同じファイルを **別の Windows PC** で開けるか試す。別PCでも同じなら配布物側の問題です。
- ARM 版でどうしても必要な x64 アプリは、メーカーの ARM 対応状況を確認する。エミュレーションで動くこともあれば、公式に非対応のこともあります。
- 年数の経った周辺機器ユーティリティは、Windows 11 非対応のまま終了していることがあります。その場合は機器側の代替ソフトか、OSの標準機能で代用できないかを見ます。

関連する接続トラブルは、[プリンターがオフラインになり印刷できないとき](/articles/printer-offline/)も参照してください。ネットワーク側が怪しいときは [DNSサーバーに問題があります](/articles/windows-dns-server-problem/) です。

## まとめ

このメッセージは「PCが壊れた」より、アプリと CPU / OS の組み合わせが合っていないことが多いです。システムの種類を見て、公式の正しい版を取り直してください。互換モードは、古いソフトのときだけの最終手段です。
