本体を横にしても縦のまま、というとき、設定は横向きにならない画面です。確認は Safari か写真でやってください。

## 症状の見分け

- どのアプリを開いても、横にしても縦のまま
- 写真や Safari は横になる。ホーム画面と設定は縦のまま
- ステータスバーに、鍵へ丸い矢印が重なったマークが出ている
- 向きのロックを消したあと、すぐ同じマークが戻る
- **拡大** の表示にしたあとから、横にならなくなった
- 一つのアプリだけ、更新のあと横にならない
- 横にすると、絵は回るが上下が逆、または半分だけ欠ける

Safari が横になれば、センサーは生きています。ホームが縦のままでも故障ではありません。

## よくある原因

1. 画面の向きのロック（縦向きのロック）がオン
2. 今開いている画面が、横向きに作られていない
3. **画面表示と明るさ** の拡大
4. 動画アプリの全画面ボタンを押す前、またはそのアプリだけの不具合
5. 向きを読むセンサーが、再起動で戻る一時停止
6. カバーの磁石や、車載ホルダーが向きを固定している

## 直す前に

- 試す画面は **Safari** か **写真**。設定、電話、多くのホーム画面は、ロックをオフにしても縦のままです
- ホームが横になるのは Plus と Max だけです。Pro（Max ではない）のホームは縦のままです。Plus や Max でも、設定は縦のままです
- センサー校正や「回転を直す」系のアプリは入れない
- iPad の Split View やステージマネージャは、この記事では扱いません。対象は iPhone です

## 手順

### 1. 鍵と矢印のアイコンを消す

1. Face ID の機種は、画面の右上から下へスワイプ。ホームボタンのある機種は、下端から上へスワイプ。コントロールセンターが開きます。
2. **鍵に、円い矢印が重なったアイコン** を探す。色が付いているあいだ、ステータスバーにも同じ鍵が出ているあいだは、縦固定です。
3. アイコンをタップして消灯させる。ステータスバーの鍵も消えるか見る。
4. Safari でページを開き、本体を横にする。アドレス欄が横に付けば、ロックが原因でした。
5. アイコンがセンターに無いときは、センターを開いたまま左上の追加（＋）から、向きのロックを入れる。**設定 → コントロールセンター** に一覧が残っている版もあります。名前は「回転ロック」「画面の向きのロック」など、版で表記が揺れます。絵が鍵と矢印のものを選ぶ。

**ここで失敗したとき:** タップしても色が消えない、すぐ点き直る、なら集中モードやアクセスガイドが向きを戻しています。手順5を先に見てください。アイコンが2つあるように見えるときは、色が付いているほうだけ消します。消灯したのに Safari が縦のままなら、ロックはもう原因ではありません。手順2へ進んで、別のアプリで横になるかを見てください。コントロールセンターが開かない機種は、画面の端からではなく、ステータスバーの電池のあたりを下へ払います。

### 2. その画面は、横になる作りか

ロックは消えた。まだ縦なら、開いているアプリを変える。

1. Safari、写真、マップで横にする。このどれかが横になれば、センサーは動いています。
2. 横にならないのが設定、電話、銀行アプリ、なら横にならない画面です。
3. ホーム画面だけ縦なら、Plus と Max 以外ではそれが普通です。Pro（Max ではない）のホームは縦のままです。Plus / Max でホームを横にしたいときは、手順1の鍵が消えているかを見る。
4. 動画は、再生画面の全画面ボタンを押すまで縦のままのものがあります。本体を回す前に、そのボタンを押す。

**ここで失敗したとき:** 写真アプリで、カメラロールの一覧は縦のまま、1枚開くと横になる、のが普通です。一覧のまま「回らない」と判断しないでください。マップはナビ中だけ横になる画面があります。経路を出す前のトップが縦でも、センサー故障とは限りません。Safari のタブ一覧（四角が重なった画面）は縦固定の版があります。ページ本体に戻してから横にしてください。

### 3. 拡大表示を標準に戻す

ロックはオフ。Safari も横にならない。表示を拡大にした覚えがあるときです。

1. **設定 → 画面表示と明るさ → 画面表示のズーム**。項目名が **表示** だけの版もあります。
2. **拡大** なら **標準** にする。画面の指示に進むと、アイコンの配置が変わり、再起動することがあります。写真やアプリは消えません。
3. 戻ったあと、Safari をもう一度横にする。
4. **設定 → アクセシビリティ → ズーム** は、三本指で画面を拡大するほうです。向きのロックとは別のスイッチです。オフにしても、横向きにはなりません。
5. 三本指の拡大を使っている人は、オフにしない。オフにすると、その操作だけ無くなります。

標準に戻すと文字は小さく感じます。向きが直ったあと、文字だけ大きくするなら **設定 → 画面表示と明るさ → テキストサイズ** です。ズームの **拡大** に戻すと、機種によってはまた横向きが止まります。

**ここで失敗したとき:** 「画面表示のズーム」が無い小さい画面の iPhone は、拡大表示を持っていません。この手順は飛ばします。標準にしたのに再起動後も Safari が縦なら、拡大が原因ではありません。鍵のアイコンが戻っていないか、手順1をもう一度見てください。標準への変更の途中で止まるときは、空き容量が極端に少ないことがあります。写真の削除まではせず、いったんキャンセルして、容量の空きを確認してからやり直します。

### 4. 一つのアプリだけ縦のまま

Safari は横になる。問題のアプリだけ縦、のときです。

1. Face ID の機種は、画面下から上へスワイプして止め、アプリの一覧を出す。ホームボタンの機種は、ホームボタンをすばやく2回押す。そのアプリを上に払って閉じ、開き直して横にする。
2. それでもそのアプリだけ縦なら、App Store に更新が残っていないか見る。更新できないときは [App Storeの手順](/articles/iphone-app-store-wont-update/) です。
3. Safari も写真も横にならないときは、本体を再起動する。Face ID の機種は、側面のボタンと音量で電源オフのスライダを出す。ホームボタンのある機種は、側面か上面の長押しで、同じスライダを出す。一度切ってから付ける。
4. 起動したら、ステータスバーに鍵が戻っていないか見る。戻っていたら手順1です。

**ここで失敗したとき:** アプリを払っても、開くとすぐ縦に戻るなら、そのアプリが横向きを用意していません。開発元の説明に「横画面に対応」と無ければ、iPhone を初期化しても横にはなりません。再起動のスライダが出ないときは、ボタンの組み合わせが機種で違います。強制再起動を何回も続けず、取扱説明の「再起動」を1回だけにしてください。

### 5. アクセスガイドの途中ではないか

画面の端が制限されて、ホームに戻れない。サイドボタンを三回押すと抜けた覚えがあるときだけ見てください。普段使っていなければ、この手順は飛ばします。

1. サイドボタンをすばやく3回押し、終了をパスコードで抜ける。
2. **設定 → アクセシビリティ → アクセスガイド**。セッションのあいだ、向きが固定されることがあります。使っていないならオフ。

**ここで失敗したとき:** 3回押しても何も出ないなら、アクセスガイドは動いていません。この手順は原因ではありません。3回押すと別のメニュー（拡大鏡、ショートカット）が出る機種は、**設定 → アクセシビリティ → ショートカット** にアクセスガイドが入っています。使っていないならチェックを外します。パスコードがわからず終了できないときは、推測で何回も入れないでください。Apple の案内に沿ってロックを解除してから戻ります。

## 機種で「横になる画面」が違う

- ホームボタンあり（SE など）: コントロールセンターは下端から上です。ホームは縦のままが普通です
- Face ID の無印・Pro: センターは右上から下です。ホームは縦のままです。Max と名前に付いていない機種は、ホームを横にしなくて正常です
- Plus / Max: ホームも横にできます。ならないときは手順1の鍵です。設定アプリは、この機種でも縦のままです
- カバーや車の磁石ホルダーを付けたまま横にしても絵が付いてこないときは、一度外して Safari だけ試します。外すと横になるなら、センサーは磁石を拾っています

落としたあと、向きだけでなく Face ID も死んでいるなら [Face ID が使えないとき](/articles/iphone-face-id-not-working/) です。カメラが真っ黒なら [カメラが真っ暗なとき](/articles/iphone-camera-black-screen/) も同じ落下のあとです。向きだけ直そうとして、両方の初期化には進まないでください。

## まだ直らないとき

- Safari は横になる。一つのアプリだけ縦 → そのアプリ側です。開発元へ、機種名と iOS の版を書く。iPhone を初期化しても戻りにくいです。版は **設定 → 一般 → 情報** の iOS のバージョンです
- 鍵のアイコンは消えている。対応しているアプリも全部縦。再起動済み → 向きのセンサーです。カバーに磁石があれば外して、もう一度だけ横にする。直らなければ Apple サポートか正規サービス。自分で分解しない
- 落としたあとから、横にしても絵が付いてこない → 修理の前にバックアップを取ります。**設定** で自分の名前を開き、**iCloud** → **iCloudバックアップ** → **今すぐバックアップを作成** です。このボタンが失敗するときの切り分けは [iCloudバックアップ](/articles/iphone-icloud-backup-failed/) です。バックアップが終わるまで、初期化や修理の予約を急がないでください
- 横にすると上下が逆のまま直らない → 一度縦に戻し、反対の横（右が下、左が下）でも同じか見る。片方の横だけ逆なら、そのアプリの表示です。どちらへ回しても逆なら、再起動のあとサポートへ「ロックはオフ、Safari も逆」と伝えます
- すべての設定をリセットや、iPhone の初期化は、この記事では使いません。サポートに「向きのロックはオフ、Safari も横にならない」と伝えて、案内されたときだけにしてください

## まとめ

鍵を消した状態で、Safari を横にします。ホームと設定が縦のままなら、その画面は横にならない作りです。
