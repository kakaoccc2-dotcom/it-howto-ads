満充電から2〜3時間で赤くなる。フタを閉じて置いただけなのに翌朝ほぼ空。充電器を外した瞬間に数%ずつ落ちる。膨張や充電ランプが点かない本体は、設定では足りません。

## 症状の見分け

- 設定のバッテリー残量が、何もしていないのに数分で数%落ちる
- ブラウザや動画のあいだだけ急減し、デスクトップに戻すと落ち着く
- 電源につないでも「充電中」にならない、またはすぐ満タン表示のまま減る
- バッテリー節約が勝手に入り、画面が暗くなる
- スリープにしたつもりが、バッグの中で熱い

使っているときだけ急減するなら明るさと常駐。置いているあいだに空になるならスリープ。どのアプリでも同じペースなら電源モードです。

## よくある原因

1. 電源モードが「最適なパフォーマンス」のまま。ファンが回り、減りも速い
2. 画面が最大輝度、または適応型の明るさが効いていない
3. ブラウザ、クラウド同期、ゲームランチャーが裏で動いている
4. バッテリー節約がオフで、バックグラウンド通信が止まらない
5. フタを閉じてもスリープせず、バッグの中で稼働している
6. Windows Update や OneDrive が裏で大きいファイルを取っている

常駐が多いときの体感は [動作が遅いときの手順](/articles/windows-pc-running-slow/) と重なります。フタを閉じても落ちない・勝手に起きるときは [スリープと復帰](/articles/windows-sleep-wake-problems/) を先に見てください。

## 直す前に

- 充電器を接続した状態で作業する。残量 20% 未満で設定をいじると、途中で落ちることがあります
- いま開いている作業ファイルを保存する
- メーカー非公式の「バッテリー再生」「サイクル矯正」ツールは入れない

> **注意:** BIOS の項目を触ったり、完全放電を繰り返したりはしないでください。家庭向けの切り分けは、設定の電源と明るさ、アプリの常駐で足ります。膨張・熱・異臭がある本体は、この先の手順より先に電源を切ってメーカーへ。

## 手順

### 1. 電源モードとバッテリー節約

1. **設定** → **システム** → **電源とバッテリー**。
2. **電源モード** を **バランス済み**（「バランス」や「バランス（推奨）」の機種もある）にする。
3. 同じ画面の **バッテリー節約機能** を開き、残量のしきい値を 20% 前後にする。今すぐ試すなら **今すぐバッテリー節約機能を使用する** をオン。
4. タスクバー右下の電池アイコンを開き、スライダーが「最高のパフォーマンス」側に寄っていないか見る。中央付近ならOK。

数分待って、残量の減りが前より緩くなれば、電源モードが原因です。変わらなければ下へ。

### 2. 明るさと画面の自動オフ

1. **設定** → **システム** → **ディスプレイ**。明るさスライダーを 40〜60% にする。
2. 同じ画面の **明るさを自動的に調整する** がオンなら、いったんオフにして体感を見る。暗い部屋で急に100%へ上げない。
3. **設定** → **システム** → **電源とバッテリー** → **画面とスリープ**。バッテリー駆動時は、画面オフを 5分、スリープを 10分前後にする。

スライダーを動かしても明るさが変わらないときは、バッテリー消耗の話ではありません。ディスプレイ側の設定を先に見てください。

### 3. どのアプリが食っているかを見る

1. **電源とバッテリー** の **バッテリー使用状況** を開く。
2. 過去 24時間（または 7日間）で、上に来ている名前を見る。
3. 使っていないゲームランチャー、チャット、クラウド同期なら終了する。スタートアップに残っているなら、設定のスタートアップからオフ。
4. ブラウザが先頭なら、タブと動画再生を減らす。残量の減りが緩くなれば、そのアプリです。

名前がわからない Microsoft の項目は、ここでアンインストールしないでください。終了して減りが止まるかだけ見ます。

### 4. バックグラウンドで動けるアプリを絞る

1. **設定** → **アプリ** → **インストールされているアプリ**。
2. 常駐しなくてよいアプリの **…** → **詳細オプション**。
3. **バックグラウンドで実行するアクセス許可** を **なし** にする（項目が無いストア以外のアプリは、手順3の終了で足りることが多い）。
4. **設定** → **Bluetooth とデバイス** で、使っていないマウス・イヤホン以外の接続を切る。Wi-Fi を使っている部屋では、モバイル用の従量制はオフのままでよい。

### 5. フタを閉じたあとに落ちていないか

1. `Windows` キーを押し、`コントロール パネル` と入力して開く。
2. **ハードウェアとサウンド** → **電源オプション** → 左の **カバーを閉じたときの動作の選択**。
3. 「バッテリー駆動」を **スリープ** にする。シャットダウンや何もしない、にはしない。
4. **変更の保存** のあと、作業を保存してフタを閉じ、1分置いて開ける。ロック画面か、すぐデスクトップに戻ればOK。

バッグに入れたあと本体が熱いときは、スリープになっていません。この項目を直したあと、翌朝まで残量を置く。

## まだ直らないとき

- 充電器を差してもパーセントが増えない → ケーブルとアダプターを、メーカー指定の出力に近いものへ替える。安価なハブ経由は外す
- 残量表示だけ飛び飛び（20%から突然3%） → 設定では直らないことがあります。メーカーサポートへ、バッテリー使用状況の画面を渡す
- 1年前は半日持ったが、今は2時間 → セルの劣化です。交換はメーカーまたは販売店。自分で分解しない
- 職場・学校アカウントで電源モードが灰色 → 個人では変えられません。IT 担当へ、減り方の時間帯とバッテリー使用状況を渡す

## まとめ

電源モードをバランス済みに戻し、明るさを下げ、バッテリー使用状況の先頭アプリを止める。フタを閉じても熱いなら、閉じたときの動作がスリープかを先に見る。
