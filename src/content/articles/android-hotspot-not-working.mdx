スマホのアンテナは立っている。ノート PC の Wi-Fi 一覧に、アクセスポイントの名前が無い。名前は出るがパスワードで弾かれる。つながったあと、PC のブラウザだけ白い。iPhone を親機にする手順は [iPhoneのインターネット共有](/articles/iphone-personal-hotspot-not-working/) です。親機の Android 自身がページを開けないときは、テザリングより先に [モバイルデータ](/articles/android-mobile-data-not-working/) です。

## 症状の見分け

- アクセスポイントのスイッチが灰色、またはオンにしてもすぐ戻る
- PC の一覧に名前が出ない。出ても「接続できません」
- 「接続済み」なのに「インターネットなし」
- スマホのブラウザは開く。乗っている PC だけ開かない
- USB でつないでも、PC に新しいネットワークが増えない
- 誰も使っていないと、数分でアクセスポイントが自分でオフになる

## よくある原因

1. 親機のモバイルデータがオフ、圏外、または容量止め
2. パスワードの打ち間違い。PC が古いパスワードを覚えている
3. 暗号化が WPA3 だけで、相手の PC が合わない
4. データセーバー、バッテリーセーバー、VPN
5. 契約にテザリングが含まれていない
6. 接続が無いと自動でオフになる設定
7. USB テザリングなのに、充電専用ケーブルを使っている

## 直す前に

- 親機の Wi-Fi を切り、ブラウザが1ページ開くか見る。開かないなら、配る通信がありません
- パスワードを無しのまま放置しない。近くの人が、自分の容量を使います
- ブログに書いてある APN を写さない。キャリアの案内にその項目があるときだけ、書いてある通りに入れる
- ルート化はしません

## 手順

### 1. 親機が単体でページを開けるか

1. 親機の Wi-Fi をオフにし、モバイルデータだけにする。
2. ブラウザでページを開く。開かない、アンテナの横が「インターネットなし」なら [モバイルデータの手順](/articles/android-mobile-data-not-working/) です。
3. 開くなら、**設定** の検索に「アクセスポイント」または「テザリング」と入れる。
4. Pixel は **設定 → ネットワークとインターネット → アクセスポイントとテザリング → Wi-Fiアクセスポイント**。Galaxy などは **接続** の下に、同じ名前があることが多いです。検索で出た項目を開く。
5. **Wi-Fiアクセスポイント** をオンにする。その画面に出ている名前とパスワードを見る。紙に写すときは、大文字と小文字まで合わせる。

画面を上から下ろし、アクセスポイントのタイルを長押しすると、同じ設定に飛ぶ機種が多いです。タイルが無い機種は、設定の検索で開きます。

家の Wi-Fi に繋いだままモバイルデータをオフにすると、相手側は「インターネットなし」になります。配っているのはモバイルデータです。家の Wi-Fi をそのまま配れる機種は一部だけです。

### 2. PCでは、パスワードを新規に入れ直す

1. PC の Wi-Fi 一覧に、手順1の名前が出るか見る。出ないなら手順3。
2. 出るなら選んでパスワードを入れる。以前繋いだことがある名前は、Windows 11 なら **設定 → ネットワークとインターネット → Wi-Fi → 既知のネットワークの管理** から削除し、一覧から入れ直す。
3. 繋がったあと、PC のブラウザでページを開く。スマホは開くのに PC だけ白いなら、スマホの VPN を切って、PC でもう一度開く。
4. 同時に繋げる台数には上限があります（案内では10台前後）。いっぱいだと拒否されます。使っていない機器の Wi-Fi を切る。

### 3. 暗号化と、自分でオフになる設定

名前が一覧に無い、またはパスワードは画面どおりなのに拒否されるときです。

1. アクセスポイントの設定に **セキュリティ** があれば開く。**WPA3** だけだと、古いノートから見えない、または接続の途中で落ちることがあります。**WPA2** と付いた項目（WPA2-Personal や WPA2 PSK）があれば、そちらにする。
2. **なし** はパスワード無しです。一覧に出るかの確認で一瞬使うとしても、ページが開けたらすぐ WPA2 に戻し、PC 側はパスワードを入れ直す。無しのまま外出先でオンにしない。
3. **アクセスポイントを自動的にオフにする** がオンだと、誰も繋いでいないと切れます。確認のあいだはオフ。使い終わったらオンに戻してよい。
4. 周波数や帯域（2.4GHz / 5GHz）の項目がある機種だけ、名前が見えない PC に対して 2.4GHz にする。項目が無ければ飛ばす。家の Wi-Fi に繋がらない話は [AndroidのWi-Fi](/articles/android-wifi-cannot-connect/) で、アクセスポイントの帯域とは別です。

### 4. スイッチが灰色、オンにしてもすぐ戻る

1. 設定の検索で **データセーバー** を開く。オンならオフにして、アクセスポイントを入れ直す。オンのままだと、テザリングが使えない機種があります。
2. バッテリーセーバーや超省電力もオフにして、もう一度オンにする。
3. 「テザリングはご利用いただけません」「加入が必要」など、契約の文が画面に出ているなら、スイッチを繰り返してもオンになりません。その文のまま、キャリアのサポートか契約ページへ。
4. その月の容量超過でモバイルデータ自体が止まっていると、アクセスポイントも止まったままです。残量はキャリアのアプリで見る。

### 5. Wi-Fiの名前が出ないときは、USBテザリング

Wi-Fi の名前がどうしても出ないときの、別の繋ぎ方です。Google の案内では、Mac は Android の USB テザリングに対応していません。

1. データ通信できるケーブルで、スマホと Windows を直結する。充電専用の線は、稲妻だけ付いてネットワークが増えません。線の見分けは [充電が遅い手順](/articles/smartphone-charging-slow/) です。
2. **アクセスポイントとテザリング** の **USBテザリング** をオンにする。ケーブルを挿す前は、項目が灰色の機種があります。
3. Windows のネットワークに、新しいイーサネットや「リモート NDIS」が増え、ブラウザが開くか見る。
4. 増えないときは、スマホの通知に出る USB の使い方（ファイル転送 / USBテザリング）を、テザリング側にする。それでも増えなければ、別のケーブルです。

## まだ直らないとき

- 家族の別のスマホからは繋げる。そのノートだけダメ → ノート側です。既知のネットワークの削除と、WPA2 への変更をやり直す
- スイッチはオン、親機のブラウザは開く、どの機器からも見えない → メーカーサポートへ。Android の版と、「Wi-Fiアクセスポイントはオンだが相手の一覧に出ない」を伝える。契約の文が出ているならキャリアです
- 家の Wi-Fi には繋がるのに、テザリング先だけダメ → 親機のモバイルデータ側です。家の回線の故障ではありません
- 初期化は、写真とアプリのバックアップが取れていて、メーカーに案内されたときだけにしてください。この確認の途中ではやりません
