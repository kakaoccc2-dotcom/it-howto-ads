「接続できませんでした」のまま、くるくるが終わる。一度「接続済み」になって、数十秒で切れる。自宅の Wi-Fi だけ失敗して、スマホのテザリングだと通ります。

対象は、自分で契約しているVPNか、会社や学校から案内された公式の接続です。検索で拾った無料サーバー一覧や、ライセンスを外す改造クライアントは使いません。案内された接続がアカウントごと停止されているときは、設定では通りません。

## 症状の見分け

- **設定** の VPN が一覧にあり、**接続** を押すと失敗する
- エラー番号が 809、691、789、800、619 のいずれか
- パスワードを入れたあとに拒否される（691 に多い）
- 接続済みになるが、社内の名前だけ開けない。普通のサイトは開く
- テザリングでは繋がり、自宅のルーター経由だけタイムアウトする
- 専用アプリ（会社配布のもの）と、Windows 標準の VPN を両方オンにしている

ブラウザで普段のサイトも開けないときは、VPN より先に回線です。[Wi-Fiは繋がっているのにインターネットなし](/articles/wifi-connected-no-internet/) を先に見てください。

## よくある原因

1. 家のネット自体が落ちている。VPN の失敗に見えているだけ
2. サーバー名、VPN の種類（IKEv2 や L2TP など）、ユーザー名のどれかが案内と違う
3. 古いパスワードが資格情報に残っている。多要素認証の番号を入れていない
4. PC の日付がずれていて、証明書の接続が拒否される
5. 自宅ルーターが、その方式（とくに古い PPTP）を通していない
6. 標準の VPN と、専用アプリが同時に動いている
7. 接続用の項目が無効のまま

## 直す前に

- 案内メールや契約画面に書いてあるサーバー名を、手元に出す。似た名前を検索結果から選ばない
- 失敗したら、エラー番号をメモしてから次を押す。パスワード違いを短時間に何度も送ると、アカウントが一時的にロックされます
- 会社PCで VPN の項目が灰色なら、個人の操作では変わりません。番号と時刻を担当へ

> **注意:** ファイアウォールを切ったままにしないでください。出所不明の「VPN修復ツール」やレジストリファイルも使わないでください。ポート開放の記事を写してルーターを広く開けない。提供元が書いている方式へ合わせます。

## 手順

### 1. 回線と、公式の接続先

1. VPN を切った状態で、ブラウザから普段のサイトが開くか見る。開かなければ回線側です。
2. 開くなら、**設定** → **ネットワークとインターネット** → **VPN**。
3. 一覧の接続名が、案内されたものか確認する。試した残骸が何個も並んでいたら、使う1件以外は **削除** する。
4. 会社が専用アプリを配っているなら、そのアプリを使う。Windows の「VPN を追加」で種類を推測して二重に作らない。

アプリの入手は、会社の案内ページか、そのメーカーの公式サイトだけにします。

### 2. 標準VPNを、案内どおり入れ直す

Windows（ビルトイン）を使う契約のときだけです。

1. **VPN** の画面で **VPN を追加**（**VPN接続を追加する**）。
2. **VPN プロバイダー** は **Windows (ビルトイン)**。
3. **接続名** は自分が分かる名前。**サーバー名またはアドレス** は案内の文字列を貼る。
4. **VPN の種類** は案内どおり。IKEv2、SSTP、L2TP/IPsec など。分からないときだけ **自動** にし、失敗したら案内の種類へ変える。
5. **サインイン情報の種類** も案内どおり。ユーザー名とパスワードなら、その欄に入れる。
6. L2TP で事前共有キーを求められたら、案内に書いてあるキーだけ入れる。
7. 保存して **接続**。失敗したら、画面のエラー番号を残す。

エラー 809 は届いていないときで、自宅だけならルーターか方式です。

### 3. 古いパスワードを捨てて、入れ直す

エラー 691、または「ユーザー名かパスワードが違う」に見えるときです。

1. タスクバーの検索に `資格情報マネージャー` と入れ、**資格情報マネージャー** を開く。
2. **Windows 資格情報** を見る。VPN の接続名や、サーバー名に似た項目があれば **削除**。
3. **設定** の VPN から、もう一度 **接続** し、パスワードを手で入れる。ブラウザに保存された古い方を選ばない。
4. 認証アプリや SMS の番号を求める契約なら、その入力が終わるまで次の接続を押さない。

まだ 691 なら、パスワードの期限切れか、ロックです。提供元か担当へ。ここから先のサービス再起動では通りません。

### 4. 日付と時刻を合わせる

証明書を使う接続は、PC の時計がずれると拒否されます。

1. **設定** → **時刻および言語** → **日付と時刻**。
2. **時刻を自動的に設定する** をオン。タイムゾーンが **(UTC+09:00) 大阪、札幌、東京** になっているか見る。
3. **追加の設定**（画面によっては **関連設定**）の **日付と時刻を同期する** で **今すぐ同期** を押す。最終同期の日時が更新されれば、時計は合っています。
4. 年や日付が明らかに違うときは、自動をいったんオフにして日付を直し、またオンにします。VPN の再接続はそのあとです。

直したあと、手順2の接続をもう一度だけ試します。

### 5. サービスと、WANミニポート

1. 検索に `サービス` と入れ、**サービス** を開く。
2. **リモート アクセス接続マネージャー** を右クリックして **再起動**。止まっていたら **開始**。スタートアップは **自動** のまま。
3. IKEv2 を使っているなら、**IKE and AuthIP IPsec キーイング モジュール** が「実行中」かも見る。止まっていたら **開始**。
4. 検索に `ncpa.cpl` と入れて **ネットワーク接続** を開く。
5. **WAN ミニポート (IKEv2)** や、案内の種類に合うミニポートが無効なら、右クリックで **有効にする**。項目の削除はしない。

有効にしたあと、VPN を一度切断し、接続し直します。

### 6. 自宅のルーターだけ失敗するとき

1. スマホのテザリングにPCを繋ぎ、同じ VPN を1回だけ試す。テザリングで通るなら、アカウントより自宅ルーター側です。
2. ルーターの管理画面に **VPNパススルー** や **IPsecパススルー** があればオン。項目の名前は機種で違います。無い機種に、ブログのポート番号を足さない。
3. 専用アプリ側に「プロトコル」や「接続方式」の選択肢があるなら、提供元が書いているものへ合わせる。
4. テザリングでも同じ番号で失敗するなら、ルーターではなくアカウントかサーバー側です。

## まだ直らないとき

- 接続済みなのに、社内の名前だけ開けない → トンネルはできていて、名前の解決で止まっています。[「DNSサーバーに問題があります」](/articles/windows-dns-server-problem/) の切り分けに進み、VPN を繋いだ状態で見ます
- エラー 789 → L2TP の事前共有キーと、VPN の種類が案内と一致しているかだけ見直す
- エラー 809 がどの回線でも出る → サーバー名の打ち間違い、または提供元側の停止。パススルーを何度も触らない
- セキュリティソフトに VPN を止める項目がある → そのソフトの画面で VPN を許可する。Windows のファイアウォール自体はオフにしない
- 回線も資格情報も時刻も見たあとでも失敗するときだけ、**設定** → **ネットワークとインターネット** → **詳細なネットワーク設定** → **ネットワークのリセット**。リセットのあと、VPN は手順2から作り直す
- このリセットで、保存した Wi-Fi のパスワードは消えます
- 担当へ渡すときは、エラー番号、VPN の種類、テザリングでは通るか、時刻は合っているか、をセットにする

> **注意:** ネットワークのリセットは、Wi-Fi のパスワードと、一部のアダプター設定を消します。実行する前に、スマホのテザリングか、有線で戻せるかを確認してください。

## まとめ

普段のサイトが開くかを見てから、案内のサーバー名と種類で接続し直す。691 は古いパスワード、時計のずれは証明書、自宅だけ 809 ならルーターか方式の不一致です。ファイアウォールは切らず、エラー番号を残して提供元へ渡します。
