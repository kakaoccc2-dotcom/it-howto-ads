画面の下を押しても鍵が開かない。電源ボタンの横を触っているのに無反応。登録の円が最後の一回りで止まる。「指紋を追加」が灰色のまま。センサーの位置は機種で違います。画面の下にアニメが出るもの、背面の丸い窓、電源ボタンそのものがセンサー、の三通りがあります。メニュー名もメーカーで違います。設定の上の検索に「指紋」と入れると、今の端末の項目に着地します。

iPhone の顔認証は [Face ID が使えないとき](/articles/iphone-face-id-not-working/) です。

## 症状の見分け

- ロック画面で、登録したはずの指を当てても PIN を求められる
- 何回か失敗したあと、しばらく指紋が出ず、PIN だけになる
- 登録の円やパーセントが途中で戻り、「もう一度」が続く
- 指紋の項目が無い、または灰色
- 画面のロックは指紋で開く。銀行アプリや店の決済だけ拒否する
- フィルムを貼り替えた週、画面を交換したあとから、失敗が増えた
- 冬の朝だけ落ちる。手を洗った直後だけ落ちる

カメラのレンズを長押ししても、そこがセンサーでなければ開きません。

## よくある原因

1. センサーと違う場所を押している
2. 乾いた指、水滴、ハンドクリーム、厚いフィルム、ケースの縁
3. 画面ロック（PIN、パターン、パスワード）が無く、指紋の登録が始まらない
4. 失敗が続いて、一時的に指紋が止まり、予備のロックだけになっている
5. 登録した指と、今当てている指が違う
6. 画面の交換や水濡れのあと、センサーが応答しない
7. 会社の管理端末で、指紋が禁止されている

## 直す前に

- PIN、パターン、パスワードのどれかは分かる状態で始める。指紋を消したあと、次に開くのはその予備だけです
- 予備のロックを忘れているときは、この先の登録画面に入れません。端末の消去は書きません
- 「指紋修復」「センサー較正」を名乗るアプリは入れない

> **注意:** 画面を割ってセンサーを剥がす、アルコールを画面に直接かける、基板を拭く、はしません。フィルムを剥がすかどうかは、登録がフィルムの上で終わるかで判断します。

## 手順

### 1. センサーの位置に、登録した指を乗せる

1. ロック画面で指をゆっくり動かし、指紋のアニメや振動が出る場所を探す。画面内の機種は、ディスプレイの下のほうであることが多いです。背面の丸、側面の電源ボタン、の機種もあります。
2. 登録したのと同じ指の腹を、その場所に一度乗せる。こすると、画面内のセンサーは失敗しやすいです。Pixel の画面内は、ロックが開くまで少し押し続ける、と Google が案内しています。
3. 指がカサカサのときは、乾いたまま連打しない。少し湿った状態でもう一度乗せる。水滴が付いたまま、クリームを塗った直後は、逆に落ちます。布で指を拭いてからにします。
4. 画面内なら、センサーの上のホコリとフィルムの気泡を、乾いた柔らかい布で払う。背面センサーをケースの縁が半分隠しているなら、ケースを外してもう一度。
5. 屋外の直射日光で、画面内だけ失敗するときは、影に入れて押し直す。

開いたなら、登録を消す前に一日様子を見ます。フィルムを新しくした週だけ失敗が増えているなら、手順4で、そのフィルムを貼ったまま登録し直します。

### 2. 設定の検索から、指紋の画面を開く

1. 設定アプリの上の検索に「指紋」と入れる。
2. **指紋**、**指紋認証**、**指紋によるロック解除** のどれかが出たら、それを開く。PIN などを聞かれたら入れる。
3. 検索が空のときの例です。最近の Pixel は **設定 → セキュリティとプライバシー → デバイスのロック解除 → 顔認証と指紋認証 → 指紋認証**。途中の名前が一つでも違ったら、検索で出たほうを開きます。
4. 画面ロックが未設定だと、指紋の前に PIN、パターン、パスワードの作成へ飛びます。作らないと、指の登録は始まりません。
5. 項目が灰色で、「管理者が無効にしています」と出る仕事用の端末は、個人の操作ではオンに戻りません。端末を管理している部署へ。

### 3. 失敗が続いたあとの、PIN だけの状態

1. 何回か外したあとは、指紋を出さず PIN やパターンを入れる。入れた直後に画面を一度消し、ロック画面でもう一度同じ指を乗せる。
2. それでも PIN しか聞かないなら、手順2の指紋の画面を開く。登録済みの指が残っているか見る。ゼロ件なら、消えているか、最初の登録が完了していません。手順4です。
3. 電源ボタンがセンサーの機種で、画面が消えているときだけ無反応なら、指紋の設定に常時の解除スイッチが無いか見る。Pixel Fold の名前は **いつでもタップしてロック解除** です。オフだと、画面が点いているあいだはタップ、消えているあいだは押し込み、と分かれます。その行が無い機種は、指の削除へ進みます。

### 4. その指を消して、角度を変えて登録する

1. 指紋の画面で、失敗する指の削除を押す。全部消す必要はありません。残っている別の指でロックが開くなら、センサーは生きています。
2. **指紋を追加** を押す。円やパーセントの指示のあいだ、腹、少し左、少し右、先端、を順番に乗せる。同じ一点だけを何度も当てると、登録は終わっても、持ち方を変えただけで落ちます。
3. フィルムを貼ったまま使うなら、貼った状態で登録する。貼る前の指紋は、フィルムの厚さのぶんずれます。厚いガラスで、何本やっても円が終わらないときは、フィルムを外して同じ指が登録できるか見る。外した状態なら終わるのに、貼ると止まるなら、フィルム側です。
4. 登録できる本数には上限があります。Pixel の画面内は 4 本まで、という案内です。機種で違います。**指紋を追加** が押せないなら、使っていない指を消してから足します。
5. 完了の表示が出たら、設定を閉じて電源ボタンで画面を消す。ロック画面で、今の指だけで開くか見る。設定の中のテストが通っただけでは、ロック解除の確認になりません。

### 5. ロックは開くのに、アプリだけ拒否する

銀行、証券、店の決済だけ「一致しません」と出るときです。端末のロックは別です。

1. そのアプリを完全に終了し、指紋を求める画面でもう一度乗せる。アプリが独自に生体認証を持っているものは、アプリの設定で一度オフにして、オンに戻すと、端末の指紋を読み直します。
2. 手順4で端末の指紋を消して作り直したあとは、アプリ側の生体認証もオフにして、オンに戻します。アプリが、消す前の指紋を覚えたままのことがあります。
3. ロック解除は毎回成功し、そのアプリだけ再登録しても拒否するなら、アプリの更新か、そのアプリの案内です。センサー故障とは限りません。

## まだ直らないとき

- 画面を交換したあと、水に落としたあと、登録の円が最初の一回も進まない → 設定では戻りません。メーカーの修理です。パネルは開けません
- 別の指を上限まで登録しても、ロック画面だけ全部失敗する。PIN は通る。ケースもフィルムも外した → センサー側です。修理の判断に切り替えます
- 予備の PIN もパターンも忘れた → 指紋の削除も再登録もできません。端末を消去する手順は書きません

## まとめ

アニメが出る場所に、登録したのと同じ指の腹を一度乗せます。項目が見つからないときは、設定の検索に「指紋」です。登録は終わるのにロックで落ちるなら、その指を消して、普段のフィルムを貼った角度で入れ直します。円が最初から動かない、修理のあとだけ、はセンサーの故障側です。
