認証エラーや「保存済み」のままくるくるするときは、保存済みを消して打ち直すところから見てください。iPhone 側は [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) です。

## 症状の見分け

- SSID は見えるが、タップしてもくるくるして失敗
- 「認証に問題があります」「パスワードが正しくありません」
- 「接続済み」なのに「インターネットなし」
- 自分の端末だけ / 家族も全滅
- 一覧に目的の名前が無く、隣の家のSSIDだけが並ぶ
- 一度つながったあと、画面を消すと切れて、起こすたびに「保存済み」に戻る

家族も全滅なら、先にルーターの電源を入れ直してください。自分の端末だけなら、この先の Android 側です。iPhone だけ使える、Android だけダメ、ならパスワードより周波数や MAC のことが多いです。

## よくある原因

1. パスワードの取り違え（2.4GHz と 5GHz で別パス、ゲスト用SSID）
2. 以前保存した設定が古いまま（ルーターを交換した、パスを変えた）
3. ランダムMACアドレスが、MACアドレス制限つきの社内・マンション回線と合わない
4. 端末の日付が大幅にずれて、証明書やキャプティブポータルに失敗する
5. プライベートDNS、VPN、省電力が名前解決や常時接続を邪魔している

## 直す前に

- 正しいSSID名を、ルーター本体のシールか、つながっている別端末の設定から確認する
- モバイルデータが使えるなら、作業中はそれで公式手順を開けるようにしておく。モバイル側が死んでいるときは [モバイルデータが使えないとき](/articles/android-mobile-data-not-working/) です
- ルーターを抜く必要があるなら、家族のテレビや仕事用PCが切断されることを伝える

> **注意:** 「Wi-Fiブースター」や「信号増強」を名乗るアプリは入れないでください。Android の Wi-Fi 接続そのものは、設定アプリとルーターで足りることがほとんどです。

## 手順

### 1. 機内モードと Wi-Fi の入れ直し

1. 画面上からバーを下げ、**機内モード**をオン → 10秒待つ → オフ。
2. **Wi-Fi** をオフ → 10秒 → オン。
3. 目的のSSIDを選び、接続されるか見る。

これでつながることがあります。まだなら下へ。

**ここで失敗したとき:** 機内モードをオフにしてもアンテナが戻らない、Wi-Fi のタイルが灰色、ならクイック設定ではなく **設定** 側でスイッチを見ます。機内モードの行に「Wi-Fi はオンのまま」と出る機種があります。その状態だと、機内モードを切ったつもりでも無線が寝たままです。タイルを長押しして設定の Wi-Fi 画面へ入り、スイッチがオンか確認してください。

### 2. 保存済みネットワークを削除して、パスワードを打ち直す

1. **設定** → **ネットワークとインターネット** → **インターネット**（または **Wi-Fi**）。
2. 問題のSSIDの横の歯車を開く。
3. **削除**（機種によっては **忘却**）。
4. 一覧から同じSSIDを選び、パスワードを**手入力**する（メモアプリからの貼り付けで全角スペースが混ざることがあります）。

キーボードの地球儀アイコンで、日本語入力のまま英数字になっていないかも見てください。

**ここで失敗したとき:** 歯車が無く、名前をタップしても「接続」しか出ない機種は、保存済み一覧が別画面です。**保存済みネットワーク** や **管理** を探して、そこから削除します。削除したのに一覧へすぐ戻るときは、削除が終わっていません。機内モードを一度オンにしてから、もう一度削除してください。パスワードを打つ画面で「パスワードが正しくありません」が即出るなら、見ているSSIDがゲスト側か、5GHz 側の別名です。シールの名前と、1文字ずつ照合してください。

### 3. 「インターネットなし」のときは DHCP とプライベートDNS

つながったのにウェブだけダメ、というときです。

1. そのSSIDの設定で **詳細設定** を開き、**IP設定**が **DHCP** になっているか確認する。手動IPを以前いじっていると、引っ越し後に取り残されます。
2. **設定** → **ネットワークとインターネット** → **プライベートDNS** をいったん **自動** に戻す。
3. VPNアプリを使っている場合は切断し、常時接続VPNもオフにする。

ステータスに「接続済み / インターネット接続なし」と出て、IP が `169.254.` で始まっているなら、ルーターから住所をもらえていません。パスワードは通っています。DHCP に戻して、ルーターを 30秒抜いてください。

同じ回線を PC でも使っているなら、[Wi-Fiは繋がるがインターネットに出られない](/articles/wifi-connected-no-internet/) で家全体か PC だけかを分けてください。ケーブルのアイコンが切れているときは [有線LANが繋がらないとき](/articles/ethernet-not-connecting/) です。名前だけ失敗するなら [DNSサーバーに問題があります](/articles/windows-dns-server-problem/) が近いです。

**ここで失敗したとき:** プライベートDNSの欄が「オフ」しか無く「自動」が無い機種は、オフのままで構いません。ホスト名の入力欄に誰かが文字を入れているなら、それを消してオフに戻します。VPN のスイッチが設定に残っているのにアプリを消したあとは、その行が「常にオン」のまま失敗し続けます。行をタップして切断し、残っていればそのVPN設定を削除してください。

### 4. MACアドレスのランダム化を切ってみる

マンションや会社の Wi-Fi、公衆無線LAN、MACアドレス許可リストを使っている回線で効きます。

1. 対象SSIDの詳細を開く。
2. **プライバシー** または **MACアドレスの種類** を探す。
3. **ランダム化MAC** から **デバイスのMAC**（電話のMAC）に変える。
4. いったん切断し、再接続する。

セキュリティのためにランダム化を戻したい場合は、直ったことを確認したあと、回線側の許可リストにランダムMACを登録できないか管理者へ聞いてください。

**ここで失敗したとき:** 「MACアドレスの種類」が灰色、または項目が無い機種は、その回線ではランダム化を切る画面が別です。SSIDの詳細ではなく、Wi-Fi の詳細設定の「プライバシー」にあることがあります。変えた直後に「接続済み」のままインターネットなしなら、許可リスト側がまだ古いMACです。管理者に、今の画面に出ているMAC（ランダムではないほう）を伝えてください。自分でルーターの管理画面を開く家庭用なら、許可リストを空にするか、そのMACを追加します。管理画面のURLがわからないときは、シールの「設定ページ」を見て、知らないツールは入れないでください。

### 5. 日付と時刻、再起動

1. **設定** → **日付と時刻** で **日付と時刻を自動設定** をオン。
2. 端末を再起動する。
3. それでもダメなら、ルーターの電源を抜いて 30秒待ち、本体ランプが安定してからAndroid側で再接続する。

年が 2020 のまま、など大きくずれていると、ホテルや会社のログインページ（キャプティブポータル）だけ失敗します。SSIDにはつながっているのに、ブラウザが白い、という見え方です。通知の「ネットワークにログイン」をタップするか、ブラウザで `http://neverssl.com` のように暗号化なしのページを一度開いて、規約画面が出るか見てください。

### 6. 2.4GHz と 5GHz を取り違えていないか

SSID が `example-2G` と `example-5G` のように分かれていることがあります。壁が多い部屋や、古い家電（プリンターなど）と連携したいときは 2.4GHz 側を使います。プリンター連携そのものは [プリンターがオフライン](/articles/printer-offline/) を見てください。

一覧に 5GHz だけ出て 2.4GHz が無い部屋は、端末が 5GHz に寄っています。壁の向こうで切れるなら、2.4GHz の名前を選んで保存し直してください。両方同じパスワード、とは限りません。

## メーカーで画面名が違うとき

中身は同じでも、入口の名前が違います。見つからないときは次の系統を探してください。

- Pixel など素の Android: **設定 → ネットワークとインターネット → インターネット**
- Galaxy: **設定 → 接続 → Wi-Fi**。歯車はネットワーク名の右です
- Xperia: **設定 → ネットワークとインターネット → Wi-Fi**
- Xiaomi など: **設定 → Wi-Fi**、または **接続と共有**。削除は「ネットワークを削除」や「消去」

どの系統でも、やることは「保存済みを消す」「DHCP」「MAC」「日付」の4つです。項目名が英語のまま（Forget / Privacy / MAC address type）でも、同じ順番で足ります。

## 別の端末と比べる

- 家族のスマホは同じSSIDでブラウザまで開ける。自分の Android だけ「インターネットなし」→ ルーターより、この端末の保存済み・MAC・VPNです
- iPhone は開けるが Android だけ認証エラー → パスワードの打ち間違いより、Android が別SSID（ゲストや 5GHz）を掴んでいることが多いです
- どのスマホもダメで、PC の有線もダメ → 回線かルーターです。Android の初期化は後回しにしてください
- 自宅だけダメで、カフェの Wi-Fi は使える → 自宅ルーターのSSIDかパスワード、または 2.4 / 5 の分離です

## まだ直らないとき

- **セーフモード**で起動して Wi-Fi が使えるなら、あとから入れたVPN・セキュリティアプリ・省電力アプリを疑う。電源ボタン長押しのメニューに「セーフモードで再起動」が出る機種と、電源を切ったあと音量下を押し続ける機種があります。出ない機種は、メーカーの「セーフモード」案内に従ってください。普段の再起動で戻ります
- 他のAndroid端末が同じSSIDで使えるなら、問題の端末のWi-Fi MACが回線側でブロックされていないか確認する
- 公衆無線LANでブラウザが開かないときは、通知の「Wi-Fiにログイン」や、ブラウザでゲートウェイページ（利用規約）が出ていないか見る。日付がずれていると、このページだけ証明書エラーになります
- 会社の Wi-Fi で「認証に問題があります」が続く → 個人のパスワードではなく、社員証や証明書の期限です。IT へ、SSID名とエラー文を渡す。端末の初期化では通りません
- 画面オフのたびに切れる → そのSSIDの詳細で **従量制** や省電力の「Wi-Fi をスリープ中も維持」がオフになっていないか見る。機種によっては **詳細設定 → Wi-Fi のスリープ** です
- 端末初期化は最終手段です。バックアップが取れてからにしてください

## まとめ

保存済みを消して、パスワードを手で打ち直してください。自分の端末だけならスマホ側、家族も全滅ならルーターです。
