文字や画像をコピーしたつもりなのに貼れない、`Win` + `V` を押しても履歴が出ない、さっきコピーした内容が消えている、といった状態はクリップボード故障というより **履歴がオフ、別アプリが上書き、管理者画面との行き来、同期の取り違え** が多いです。Windows のクリップボードは、メモ帳・ブラウザ・Office・リモートデスクトップで扱いが少しずつ違います。

この記事は Windows 10 / 11 の標準クリップボードを対象にします。PC 全体が重いせいでコピー直後に固まるときは、先に [動作が遅いときの手順](/articles/windows-pc-running-slow/) です。特定のストアアプリだけ操作不能なら [このアプリは実行できません](/articles/windows-app-cannot-run/) も見てください。

## 症状の見分け

- `Ctrl` + `C` のあと `Ctrl` + `V` しても、前の内容のまま、または何も貼れない
- `Win` + `V` で「クリップボードの履歴を有効にする」と出る、または真っ白
- メモ帳には貼れるが、ブラウザや Excel だけ失敗する（またはその逆）
- 通常のウィンドウから、管理者として開いたアプリへ貼れない
- 昨日まで履歴が出ていたのに、サインアウトや更新のあとから空
- 別の Microsoft アカウントの PC に、意図せず同じ履歴が届く

どのアプリでも失敗するなら OS 側、1つのアプリだけならそのアプリの書式や権限です。履歴パネル自体が開かないときは、設定のオン／オフを先に見ます。

## よくある原因

1. **設定 → システム → クリップボード** で履歴がオフ、または一度も有効にしていない
2. コピーのあと別アプリが空や別の内容で上書きしている（自動保存、翻訳、切り取りツール）
3. 管理者権限のウィンドウと、通常権限のウィンドウのあいだでは貼り付けできない
4. クリップボード履歴の上限（だいたい25件）を超えて、古い項目が落ちた
5. 「デバイス間でコピー」がオンで、別 PC の内容に入れ替わる、または Microsoft アカウント未サインイン
6. リモートデスクトップや仮想マシン側のクリップボード共有がオフ

## 直す前に

- パスワードやキャッシュカード番号を履歴に残したまま、共有 PC で作業しない
- いまコピーしたい文字列を、いったんメモ帳に手入力できる状態にしておく（切り分け用）
- 出典不明の「クリップボード修復」「コピー強化」ツールは入れない

> **注意:** クリップボード履歴には、先ほどコピーしたパスワードや個人情報が残ります。共有パソコンでは **クリップボード データをクリア** し、履歴そのものをオフにしてください。クラウド同期をオンにすると、同じ Microsoft アカウントの別端末にも送られます。

## 手順

### 1. 履歴をオンにして、Win+V で中身を見る

1. **設定** → **システム** → **クリップボード**。
2. **クリップボードの履歴** をオンにする。Windows 10 では **クリップボード履歴** のスイッチです。
3. メモ帳を開き、短い単語を選んで `Ctrl` + `C`。
4. `Win` + `V` を押し、今コピーした単語が一番上に出るか見る。

ここで出るなら、コピー自体は成功しています。貼れないアプリ側の書式か、上書きです。履歴スイッチが灰色で触れない職場 PC は、個人の設定では終わりません。IT 担当へこの画面を渡します。

ピン留めしたい項目は、履歴パネルのピンアイコンで残せます。再起動しても残るのはピン留めしたものだけです。

### 2. 上書きと、アプリごとの貼り付けを切り分ける

1. コピーした直後に、翻訳・切り取り・チャットの常駐が動いていないか見る。通知領域に見慣れないアイコンがあれば、いったん終了する。
2. 同じ内容を **メモ帳** に貼れるか試す。メモ帳で成功し Excel だけ失敗なら、セルの編集モード（`F2`）や、保護されたシートです。
3. ブラウザの入力欄だけ失敗するときは、拡張機能の「コピー監視」やパスワード管理を一時オフにする。
4. 画像だけ貼れないときは、コピー元が「ファイル」なのか「画像データ」なのかを分ける。エクスプローラーでファイルをコピーした場合、ペイントには貼れず、フォルダーへ貼る操作になります。

常駐が毎回クリップボードを掴むときは、[スタートアップの整理](/articles/windows-startup-apps/) で、使っていないクリップボードツールだけオフにします。標準の `Win` + `V` で足りることがほとんどです。

### 3. 管理者画面と、リモート先を取り違えない

1. 貼り付け先のタイトルバーに「管理者」と付いていないか見る。付いているアプリへ、通常のブラウザから貼ることはできません。
2. 管理者側で使いたい文字列は、そのアプリの中で開いたメモ帳（同じく管理者）へいったん置き、そこからコピーする。または両方を通常権限で開き直す。
3. リモートデスクトップで向こうの PC に貼れないときは、ローカルの **リモート デスクトップ接続** → **表示** → **ローカル リソース** で、クリップボードにチェックが付いているか見る。
4. 会社の仮想デスクトップは、セキュリティポリシーでコピー自体が禁止されていることがあります。その場合は家庭向けの設定では直りません。

UAC の許可ダイアログが出た直後も、クリップボードが空に見えることがあります。ダイアログを閉じてから、もう一度コピーし直してください。

### 4. クラウド同期と、履歴のクリア

1. クリップボード設定の **デバイス間でコピー**（機種によっては **他のデバイスとの同期**）を確認する。1台だけで使っているならオフで十分です。
2. オンにするなら、**設定 → アカウント** で、意図した Microsoft アカウントにサインインしているか見る。家族のアカウントが残っていると、別の履歴が混ざります。
3. 変な項目ばかり出る、貼ると別の文になる、ときは **クリップボード データをクリア** を押す。ピン留めも消えます。
4. クリアしたあと、メモ帳で1語コピーし、`Win` + `V` にそれだけが出るか確認する。

同期を使う場合も、パスワードや個人番号は履歴に残さない、ピン留めしない、が安全です。

### 5. エクスプローラーの再起動と、入力の取り違え

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー** を開く。
2. **プロセス** から **Windows エクスプローラー** を選び、**再起動** する。デスクトップが一度消えて戻ります。そのあと手順1をもう一度。
3. 日本語入力の変換中に `Ctrl` + `C` しても、未確定の文字はコピーされません。確定（`Enter`）してからコピーする。
4. 全角スペースや、見た目だけ同じ別文字が混ざると、「コピーしたのに検索でヒットしない」ことがあります。メモ帳に貼って、余分な空白を消してから使います。

エクスプローラーの再起動で直ることがあります。それでも全部のアプリで空なら、サインアウトして入り直すか、PC を再起動します。ディスクが赤いときは、先に [ストレージ不足](/articles/windows-storage-full/) を片付けてから再試行してください。

## まだ直らないとき

- 履歴は出るが、特定の Office だけ書式が崩れる → 貼り付けの「テキストのみ」または「貼り付けのオプション」。OS の履歴設定では直りません
- ゲームや全画面アプリのあとだけコピー不能 → そのアプリを完全に終了してから、もう一度 `Win` + `V`
- どのアプリでも貼れず、履歴も空のまま → 手順5のあと、別のユーザーでサインインして再現するか見る。再現しなければ、今のプロファイル側です
- 職場 PC でスイッチが灰色 → 個人のクリップボード設定は使えません。禁止ポリシーの有無を担当へ確認する
- コピーのたびに見知らぬウィンドウや広告が出る → 標準機能ではありません。スタートアップから見慣れない常駐を外し、ブラウザの拡張も見直す

## まとめ

コピーできないときは、新しいツールを入れる前に **履歴がオンか、`Win` + `V` に今の内容が出るか、貼り付け先が管理者画面ではないか** を揃えます。1つのアプリだけ失敗するなら書式と拡張機能、全部ダメならエクスプローラーの再起動です。履歴には個人情報が残るので、共有 PC ではクリアとオフを忘れないでください。
