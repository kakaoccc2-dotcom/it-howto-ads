半角／全角キーを押しても「A」のまま、タスクバーの「あ」が反応しない、変換（スペース）しても候補が出ない、ブラウザだけ日本語が打てない、といった状態は、キーボード故障より **IME がオフ、言語パックの取りこぼし、アプリ側が英語固定、言語バーが隠れている** ことが多いです。昨日まで普通で、更新のあとに突然ローマ字のまま、という相談もよくあります。

この記事は Windows 10 / 11 の **Microsoft IME**（標準の日本語入力）を対象にします。Google 日本語入力など別 IME を入れている場合も、切り分けの最初は標準に戻す方が安全です。コピーはできるが貼れないだけのときは入力ではなく [クリップボード履歴の手順](/articles/windows-clipboard-history/) です。特定のストアアプリだけ入力欄が死んでいるときは [アプリが実行できないとき](/articles/windows-app-cannot-run/) も見てください。

## 症状の見分け

- タスクバー右下の入力インジケーターが **A** のまま。`半角/全角` や `Win` + `Space` を押しても **あ** にならない
- **あ** なのに、ひらがなが出ず英字のまま。またはカタカナだけ、全角英数だけ
- 変換候補が出ない。スペースを押すと空白が入るだけ
- メモ帳では打てるが、ブラウザや Excel、ゲームのチャットだけ打てない（またはその逆）
- インジケーター自体が消えて、今ひらがななのか分からない
- サインイン画面では日本語が使えるが、デスクトップに入ると使えない

どのアプリでもダメなら OS の IME、1つのアプリだけならそのアプリの言語とフォーカスです。キーそのものが全部無反応なら、日本語入力よりキーボード接続です。ワイヤレスなら [Bluetooth がつながらないとき](/articles/windows-bluetooth-cannot-connect/) も疑います。

## よくある原因

1. 入力モードが **直接入力（A）** のまま。キーの取り違えや、言語が英語だけになっている
2. **日本語** 言語パックまたは Microsoft IME が、更新のあと無効／未インストール
3. 以前のバージョンの Microsoft IME と、新しい IME の食い違い
4. アプリが英語 UI 固定、または管理者画面と通常画面で IME がつながっていない
5. かな入力とローマ字入力の取り違え（「A」を押すと「ち」など）
6. 言語バーや入力インジケーターがオフで、状態が見えないだけ

## 直す前に

- 外付けキーボードを使っているなら、一度抜いて内蔵（または別の有線）で試す。Bluetooth の電池切れと取り違えない
- パスワードや暗証番号を打つ前に、今 **A** か **あ** かを必ず見る。日本語のまま暗証を入れると失敗します
- 出典不明の「IME 修復」「辞書クリーナー」や、レジストリ配布は入れない。標準の言語設定で戻ることがほとんどです

> **注意:** 言語パックの削除や「Windows の機能」のオフは、日本語そのものが消えることがあります。この記事では、日本語を消さずに IME を入れ直す手順にしています。職場 PC で言語スイッチが灰色なら、個人では終わりません。

## 手順

### 1. 今のモードを、タスクバーで確かめる

1. タスクバーの右下、時計の左あたりを見る。 **あ**（ひらがな）または **A**（直接入力／英数）が出ているはずです。
2. そこをクリックし、**ひらがな** を選ぶ。またはキーボードの `半角/全角`（`英数` と書いてある機種もある）を1回押す。
3. それでも切り替わらないときは `Win` + `Space` で、一覧に **日本語** と **英語** が出るか見る。日本語を選ぶ。
4. メモ帳を開き、「aiueo」と打ってひらがなになるか確認する。なってからスペースで変換できるかも見る。

ここで切替わるなら、IME は生きています。切れやすいアプリの話は手順4です。インジケーターが無いときは、**設定 → 時刻と言語 → 入力** → **キーボードの詳細設定** で **使用可能な場合にデスクトップ言語バーを使用する** と、タスクバーの入力インジケーター（**設定 → 個人用設定 → タスクバー → システム アイコン** 付近）をオンにします。Windows 11 では **タスクバー隅のオーバーフロー** に隠れていることもあります。

### 2. 日本語と Microsoft IME が入っているか

1. **設定** → **時刻と言語** → **言語と地域**。
2. **優先する言語** に **日本語** があるか見る。無ければ **言語の追加** から日本語を入れ、言語機能のダウンロードが終わるまで待つ。
3. 日本語の **三点メニュー** → **言語のオプション**。
4. **キーボード** に **Microsoft IME** があるか確認する。無ければ **キーボードの追加** から入れる。英語（米国）のキーボードだけ残っていて IME が無い、がよくある取りこぼしです。
5. 同じ画面で、使っていない変なキーボード（手書き、適当な言語）が大量にあるときは、Microsoft IME と普段使う配列以外を削除する。`Win` + `Space` の順番が安定します。

言語のダウンロード中は、飛行機モードをオフにし、[インターネットなし](/articles/wifi-connected-no-internet/) になっていないかも見てください。パックが途中で止まると、切替だけ死ぬことがあります。

### 3. IME の設定を標準に戻す

1. **設定** → **時刻と言語** → **入力** → **キーボードの詳細設定**。または言語のオプションから **Microsoft IME** の **キーボード オプション**。
2. **全般** で、入力方式が **ローマ字入力** か **かな入力** か、自分の打ち方と一致しているか見る。ローマ字派なのにかな入力だと、キーと文字がまったく合いません。
3. 同じ全般の下の方、**以前のバージョンの Microsoft IME を使う** を探す。新しい IME で突然変換できないときは、いったんオンにして再起動する。逆に、オンのあとから切替が死ぬときはオフに戻す。
4. **キーとタッチのカスタマイズ** で、`半角/全角` が無効になっていないか見る。ゲーム用にキーを奪っているツールがあれば、切り分けのあいだ終了する。
5. 予測変換やクラウド候補が邪魔なだけ、というときは全般の予測を弱めても、打てない症状自体は直りません。打てないときは予測より手順2です。

成功の目安は、メモ帳で「今日」と変換できることです。辞書の学習を消す必要は、この段階ではありません。

### 4. アプリごと、管理者画面ごとに切り分ける

1. メモ帳で成功し、ブラウザだけ失敗するときは、アドレスバーや拡張の「英語固定」、パスワードマネージャの自動入力を疑う。プライベートウィンドウで同じ欄を試す。
2. Excel で英数のままなときは、セルが数値書式でも日本語は打てます。IME が **A** になっていないかを先に見る。`Alt` + \`（機種による）や、数式バーをクリックし直す。
3. タイトルバーに **管理者** と付いたアプリへ、通常権限のまま日本語を送ると、切替だけ無視されることがあります。そのアプリをいったん閉じ、同じ権限で開き直す。クリップボードも同じ制限があります。
4. ストアアプリやゲームの全画面では、IME の候補ウィンドウが画面外に出ることがあります。ウィンドウモードに戻してから変換する。
5. リモートデスクトップ先で打てないときは、ローカルの IME ではなく先の Windows の言語です。先の画面で手順1をやり直す。

常駐のキーフック（翻訳、スクリーンショット、マクロ）が半角／全角を奪っているときは、[スタートアップの整理](/articles/windows-startup-apps/) で見慣れない入力ツールだけオフにします。

### 5. IME プロセスの入れ直しと、新しいユーザー

1. `Ctrl` + `Shift` + `Esc` でタスク マネージャーを開く。
2. **プロセス** から **Microsoft IME** や **CTF ローダー**（`ctfmon.exe`、**テキスト入力** と出ることもある）を探し、**タスクの終了** する。エクスプローラーはまだ終了しない。
3. タスクバーの「あ／A」が戻るか見る。戻らなければサインアウトして入り直す。
4. それでも全アプリでダメなら、家族のアカウントまたは新しいローカルユーザーでサインインし、メモ帳で日本語が打てるか見る。こちらで成功するなら、今のプロファイルの IME 設定です。言語のオプションから Microsoft IME を一度削除→追加し、再起動する。

> **注意:** IME を削除しても、日本語の表示言語まで消さないでください。**言語と地域** の Windows の表示言語は **日本語** のままにします。表示言語を英語だけにすると、設定画面の名前が変わり、戻しにくくなります。

スタートやタスクバー自体が死んで IME のアイコンも消えるときは、入力よりシェルです。[スタートメニューとタスクバーの手順](/articles/windows-start-menu-taskbar-broken/) を先にどうぞ。

## まだ直らないとき

- キーを押すと「ち」「し」など別の文字 → かな入力になっている。手順3でローマ字入力に戻す。JIS 配列と US 配列の取り違えでも起きます。言語のオプションのキーボードを **Microsoft IME** の日本語配列にする
- 変換候補は出るが、確定すると文字化け → アプリ側のフォントや、古いソフトの文字コード。IME の入れ直しでは直りません
- サインイン画面だけ日本語不可 → その画面左下の言語アイコン。PIN を日本語配列で登録した記憶があるなら、英語配列で試す
- 職場 PC で言語の追加が灰色 → 個人の IME 設定は使えません。担当へ「Microsoft IME が無い／切り替わらない」と渡す
- 新しいユーザーでも打てない → 言語パックの再ダウンロード、Windows Update。修復ツールは不要です。更新が止まるときは [Update が進まないとき](/articles/windows-update-stuck/)

## まとめ

日本語が打てないときは、新しい IME を足す前に **今が「あ」か「A」か、言語に Microsoft IME があるか、ローマ字とかな入力が自分の打ち方か** を揃えます。全部のアプリでダメなら言語パック、一つのアプリだけならその画面の権限と全画面です。辞書クリーナーやレジストリより、標準の言語オプションの方が安全です。
