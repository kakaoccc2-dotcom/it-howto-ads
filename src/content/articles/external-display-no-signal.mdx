モニターは「信号なし」、内蔵だけ映る、なら入力番号と Win+P を先に見てください。USB ハブ自体が認識されないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) です。

## 症状の見分け

- 電源は入るが「信号なし」「ケーブルを確認」
- 内蔵は普通、外付けだけ出ない。複製はできるが拡張だと片方黒い
- USB-C ハブは充電するのに映像だけ無い
- 更新の直後から 2枚目が消えた

テレビの入力が HDMI 2 なのにケーブルが HDMI 1、ノートの USB-C が充電専用、は先に多い見落としです。

## よくある原因

1. モニター / テレビの入力が、今挿している端子と違う
2. Windows の投影が **PC 画面のみ** になっている（`Win` + `P`）
3. ケーブル・変換コネクタの不良、または HDMI と DisplayPort の変換方向が合っていない
4. USB-C ポートが **DisplayPort Alt Mode** 非対応（充電とデータだけで映像が出ない）
5. GPU ドライバーの失敗、または更新直後のロールバック不足。デスクトップではオンボードとグラボの端子取り違えもあります

更新そのものが途中で止まってドライバーだけ中途半端なときは、[Windows Update が進まないとき](/articles/windows-update-stuck/) もあわせて見てください。

## 直す前に

- モニターの電源ランプ（緑 / 橙 / 点滅）と、リモコンや本体の **入力切替** の位置を確認する
- 可能なら、別の HDMI ケーブルか、別の機器（ゲーム機や別PC）でそのモニターが映るかを見る
- 変換アダプター（USB-C → HDMI、HDMI → VGA など）を使っているときは、アダプター名を控える。片方向しか通らない製品があります

> **注意:** 「モニター修復」「GPU最適化」を名乗る実行ファイルは不要です。入力切替と Windows の検出、公式ドライバーで足りることがほとんどです。

## 手順

### 1. モニター側の入力とケーブルを先に確定する

1. ケーブルを両端とも抜き、奥まで挿し直す。モニター側の端子番号（HDMI 1 / HDMI 2 / DP）を目で見る。
2. モニターのメニューまたはリモコンで、**その番号の入力** に切り替える。自動検索のままだと、別端子を見続けて「信号なし」になることがあります。
3. 可能なら、テレビやモニターを別の機器につなぎ、ケーブルとモニターが生きているか確認する。
4. 4K / 高リフレッシュのときは、ケーブルが HDMI 1.4 のままだと映らないことがあります。箱や印字で HDMI 2.0 以上、DisplayPort なら 1.2 以上を目安にします。

別機器では映るのに PC だけダメなら、この先は Windows / GPU 側です。

### 2. Windows の投影モードを切り替える

1. `Windows` キー + `P` を押す。
2. **複製** または **拡張** を選ぶ（**PC 画面のみ** だと外付けは出ません。内蔵を消して外付けだけ使いたいときは **セカンド スクリーンのみ**）。
3. 10秒待ち、モニターを見る。
4. まだなら **設定** → **システム** → **ディスプレイ** を開き、下のほうの **検出** を押す。

複数のディスプレイ欄に 2 が出たら、**識別** で番号を確認し、配置を実際の机の左右に合わせます。1 枚のまま検出されないときは手順3へ。

### 3. USB-C / ハブの「映像が出る口」かを切り分ける

USB-C は、充電できる＝映像も出る、ではありません。

1. ノートのマニュアルで、雷マークやディスプレイのアイコンが付いた USB-C を使う。片側の口だけ映像対応の機種があります。
2. ハブ経由なら、PC 本体の HDMI / USB-C へモニターを直結して試す。直結で映ればハブ側（ファームウェアや給電）です。
3. ハブの HDMI が 4K60 非対応で真っ黒、ということもあります。いったん 1080p のモニターや、設定のディスプレイで解像度を下げて確認します。

ハブに挿した USB メモリまで消えるなら、映像より先に USB 認識の問題です。

### 4. ディスプレイ アダプターを入れ直す

1. スタートを右クリック → **デバイス マネージャー** → **ディスプレイ アダプター**。
2. Intel / AMD / NVIDIA の項目を右クリック → **デバイスを無効にする** → 10秒 → **デバイスを有効にする**。
3. 改善しなければ、同じ項目の **デバイスのアンインストール**（ドライバー ソフトウェアも削除する、にチェックできる場合は入れる）。再起動後、Windows が基本ドライバーを入れ直します。
4. PC メーカーまたは GPU メーカーの公式から、今の Windows 向けドライバーを入れる。NVIDIA と Intel が両方あるノートは、外部モニターを **NVIDIA の端子** に挿しているか確認する。デスクトップの増設グラボでは、マザーボード背面の HDMI ではなく **グラボ本体の端子** を使います。

ドライバー更新の直後から映らなくなったときは、デバイス マネージャーのアダプター → **プロパティ → ドライバー → ロールバック** が使えることがあります。

### 5. 解像度・リフレッシュレートがモニターの範囲を超えていないか

信号はあるのに「範囲外 / Out of Range」と出るときです。

1. 内蔵画面が見える状態で **設定 → システム → ディスプレイ**。
2. 外付けを選び、**ディスプレイの解像度** を 1920×1080 など低めにする。
3. **詳細ディスプレイ** でリフレッシュ レートを 60Hz にする。
4. HDR をオンにしている場合はいったんオフにする。対応していない HDMI 機器で黒画面になることがあります。

クローン（複製）で内蔵が 1366×768、外付けが 4K だと、低いほうに引っ張られて失敗することがあります。そのときは **拡張** に変えてから、外付けだけ解像度を上げます。

## まだ直らないとき

- BIOS / メーカーロゴは外付けに出るが、Windows のサインイン以降だけ黒い → OS の投影モードか GPU ドライバーです。セーフモードで外付けが出るか見る
- ゲーム中や動画の全画面だけ消える → ドライバーの省電力、または HDMI CEC。公式の新しいドライバーと、モニターの自動電源オフを確認する
- USB-C で充電も映像も不安定 → ケーブルが 20Gbps / 映像対応かを見る。充電専用の短いケーブルでは足りません
- 会社のドッキングステーション → メーカー指定のドライバとファームウェアが必要なことがあります。汎用ハブの手順では終わらないので、型番を IT 担当へ渡す
- どの入力・どのケーブルでも、別の機器からも信号なし → モニター側の故障や内部基板の可能性があります。保証と、ここまでの切り分け（別機器では映る / 映らない）を添えてサポートへ
