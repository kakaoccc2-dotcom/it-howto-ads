昨日まで普通だった PC が、サインインからデスクトップが出るまで何分もかかる、クリックしてからウィンドウが開く、ファンだけ回り続ける、といった状態は故障より先に **常駐アプリ、ディスク使用率 100%、空き容量不足、裏での更新** が多いです。一度に「最適化ツール」を入れると、何が効いたかわからず、次の不具合の原因にもなります。

この記事は Windows 10 / 11 の個人向け PC を対象にします。起動そのものが修復画面で止まるときは、先に [スタートアップ修復](/articles/windows-startup-repair/) です。

## 症状の見分け

- サインイン後、マウスは動くがアイコンがなかなか出ない
- タスク マネージャーで **ディスク** か **CPU** がしばらく 90〜100% のまま
- 特定のアプリ（ブラウザ、セキュリティソフト）を開いたときだけ固まる
- Windows Update や大型ゲームのインストール中から遅くなった
- 朝は軽いが、数時間使うと熱くなって遅くなる（冷却の疑い）
- クリックから反応まで数秒あるが、エラーメッセージは出ない

ディスクが常時 100% なら、スタートアップを減らすだけでは足りないことがあります。CPU だけ高いなら、特定アプリかスキャンの切り分けです。メモリ使用率が搭載量のほぼ上限なら、タブと常駐を先に見ます。

## よくある原因

1. 起動時に走るアプリが多すぎる（チャット、ゲームランチャー、メーカーツール）
2. C ドライブの空きが数GB以下で、仮想メモリや更新が追いつかない
3. Windows Update や Store が裏でダウンロードしている
4. ブラウザのタブ・拡張機能、または検索インデックスの再構築
5. セキュリティソフトの初回フルスキャン、または実害のある不要ソフト
6. HDD 本体の寿命（異音、待ち時間が年単位で悪化）や、ホコリによる熱暴走

空きが赤いときは、遅さの手順より先に [ストレージ不足の片付け](/articles/windows-storage-full/) を進めてください。常駐だけが怪しいときは [スタートアップの整理](/articles/windows-startup-apps/) が本丸です。

## 直す前に

- 作業中に電源を切らない。ノートなら充電器をつなぐ
- 残したいアプリ（セキュリティ、バックアップ、GPU コントロール）の名前をメモする
- 「メモリ解放」「レジストリ最適化」「1クリック高速化」系は入れない

> **注意:** 検索上位のクリーナーや、出典不明の「軽量化パッチ」は使わないでください。標準のタスク マネージャーと設定で足りることがほとんどです。BIOS の更新や、メモリの載せ替えは、この記事の範囲外です。

## 手順

### 1. タスク マネージャーで「何が忙しいか」を見る

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー** を開く。
2. **プロセス** で、CPU・メモリ・ディスク・ネットワークの列をクリックし、使用率の高い順に並べる。
3. 数分待って、一時的なピークか、張り付いたままかを見る。
4. 名前がわかる不要なアプリ（終わらせてよいブラウザやゲーム）なら **タスクの終了**。名前がわからない項目や、`Windows プロセス` は終了しない。

読み方の目安です。

- **ディスク 100%** が続く → 手順2の空き容量と、HDD かどうか。更新の裏ダウンロードも疑う
- **CPU** が高いまま → そのプロセス名をメモし、該当アプリを終了して軽くなるか見る
- **メモリ** が 90% 超 → タブと常駐。搭載が 4GB クラスなら、ソフトの整理が先です
- **ネットワーク** が高い → Update やクラウド同期。回線そのものの切り分けは [Wi-Fiは繋がるがインターネットに出られない](/articles/wifi-connected-no-internet/) へ

### 2. 空き容量と更新の裏仕事を止める

1. エクスプローラーで C ドライブを開き、空きが **10GB 以上**あるか見る。赤い、または数GBならストレージ記事の一時ファイル削除を先に行う。
2. **設定** → **Windows Update** で、ダウンロード中や「再起動が必要」が出ていないか見る。進まないときは [Windows Update が進まないとき](/articles/windows-update-stuck/) です。
3. 従量制ではない自宅回線なら、更新を無理に止めなくてよいです。ただし **今すぐ作業したい** ときは、更新の一時停止を短時間だけ使い、作業後に解除します。
4. OneDrive や写真バックアップが「同期中」でディスクを占有しているときは、完了まで待つか、同期を一時停止する。

### 3. スタートアップを必要最小にする

1. タスク マネージャーの **スタートアップ アプリ**、または **設定 → アプリ → スタートアップ**。
2. 影響が大きいものから、使っていないランチャーやツールをオフ。
3. セキュリティソフトと、画面表示に必要な GPU ユーティリティは残す。

オフにしたあと **再起動**し、サインインから操作できるまでの体感を比べます。手順の詳細と、残してよい名前の目安はスタートアップ記事に任せます。

### 4. ブラウザと、Windows セキュリティの確認

1. ブラウザの拡張機能を一時的にすべてオフにし、タブを減らして重さが変わるか見る。変わるなら拡張が原因です。
2. **設定** → **プライバシーとセキュリティ** → **Windows セキュリティ** → **ウイルスと脅威の防止**。
3. **クイック スキャン** を1回実行する。初回のフルスキャンはディスクを占有するので、作業が一段落してからにする。
4. 最近入れた「無料コーデック」「PDF変換」「プレーヤー」で、スタートアップやツールバーが増えていないか、**アプリ → インストールされているアプリ** で確認する。不要ならアンインストール。

アプリが開けず互換性エラーになる場合は、遅さではなく実行側の問題です。[このアプリは実行できません](/articles/windows-app-cannot-run/) を先に見てください。

### 5. 電源プランと、熱の簡易確認

1. **設定** → **システム** → **電源**（Windows 11）またはコントロール パネルの **電源オプション**。
2. ノートで「省電力」だけ極端に遅いときは、**バランス** またはメーカーの標準プランに戻す。
3. 本体底面の吸気口にホコリが厚く乗っていないか見る。ブロワーで外側から吹く程度なら家庭でもできます。内部の分解清掃は、保証とネジ位置がわかるとき以外はメーカーへ。
4. 夏場や布団の上で使うノートは、熱でクロックが落ちます。平らな硬い面に置いて、もう一度体感を見る。

ファンが常時全開で、タスク マネージャー上は何も忙しくないときは、センサーやホコリのことがあります。異音（カチカチ、スクラッチ）がある HDD は、軽量化より **データの退避** を優先してください。

## まだ直らないとき

- 再起動直後だけ重い → スタートアップと、検索インデックスの再構築。数時間で落ち着くことがあります。半日以上 ディスク 100% が続くなら、セキュリティスキャンの完了待ちか、HDD の寿命を疑う
- セーフモードだと軽い → あとから入れた常駐が原因です。スタートアップをさらに減らし、最近のアプリを外す
- 設定やエクスプローラーまで固まり、修復画面や自動修復に入る → [スタートアップ修復](/articles/windows-startup-repair/) へ切り替え、この記事の常駐整理は後回し
- 搭載メモリが 4GB、ストレージが HDD のまま何年も使っている → ソフトの整理には上限があります。データのバックアップを取ったうえで、SSD 化やメモリ増設はメーカー案内または販売店の作業が安全です。自分で分解したことがない場合は無理に開けない
- 職場・学校アカウントで「組織によって管理されています」 → 個人の電源プランやスタートアップがロックされていることがあります。IT 担当へ、タスク マネージャーのスクリーンショットを渡す

## まとめ

急に重くなった Windows は、本体故障より **何が CPU / ディスクを占有しているか** を見るのが先です。タスク マネージャーで張り付きを確認し、空き容量と更新、スタートアップ、ブラウザと標準のセキュリティスキャンの順にします。クリーナーは不要です。異音や修復ループに入ったら、この記事の軽量化よりデータの退避と修復手順へ切り替えてください。
