エクスプローラーで `\\パソコン名` や家庭用 NAS を開くと **ネットワーク資格情報の入力** が出て、合っているつもりでも繰り返される、「ユーザー名またはパスワードが正しくありません」「アクセスが拒否されました」になる、という状態は、回線が切れたときとは別の切り分けです。多いのは **PIN をパスワードだと思っている、古い資格情報の記憶、ネットワークがパブリック、NAS 側のユーザーと Windows のログイン名が違う** です。

この記事は Windows 10 / 11 と、自宅の NAS や別の Windows PC の共有フォルダを対象にします。自分の機器へ、自分が使うアカウントで入る手順です。他人の共有へ無断で入る話ではありません。ブラウザ全体が開けないときは、先に [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) や [DNS の手順](/articles/windows-dns-server-problem/) です。

## 症状の見分け

- `\\名前` や `\\192.168.x.x` を開くと、毎回資格情報のダイアログが出る
- 入力してもすぐ同じ画面に戻る。エラーは「正しくありません」または何も出ない
- 同じ LAN のスマホのメーカーアプリからは NAS が見えるが、Windows だけ入れない
- 昨日まで入れていたのに、パスワードを変えた・Windows を更新したあとから失敗する
- 「ネットワークパスが見つかりません」「指定されたネットワーク名は利用できません」
- フォルダは見えるが、中を開くと「アクセスが拒否されました」

名前解決だけ失敗（パスが見つからない）と、認証失敗（資格情報が繰り返される）は別です。前者は名前かアドレス、後者はユーザーとパスワードと記憶です。

## よくある原因

1. Windows Hello の **PIN や顔** を、共有のパスワードだと思って入れている
2. 資格情報マネージャーに、古いユーザー名／パスワードが残っている
3. Wi-Fi のネットワーク プロファイルが **パブリック** で、共有が制限されている
4. NAS に作ったユーザーと、Windows の表示名（Microsoft アカウントの名前）が一致していない
5. パスワードなしのゲスト共有を、最近の Windows が拒否している
6. PC と NAS が別の Wi-Fi（ゲスト SSID）に乗っている、またはホスト名が通らない

## 直す前に

- 入ろうとしているのが **自分の NAS / 自分の PC** か確認する。勤務先のファイルサーバーは、IT 担当の案内が優先です
- NAS の管理画面で、共有用に作った **ユーザー名** を控える。Windows のサインイン名と違うことが普通です
- Microsoft アカウントの PC では、共有に使うのは **アカウントのパスワード** です。サインインの PIN では入れません。パスワードを忘れた場合は、Microsoft の公式アカウントページでリセットします。PIN のリセットではありません

> **注意:** 「共有フォルダ解除ツール」、出自不明の SMB 修復、古い **SMB 1.0** を進んでオンにする手順は使わないでください。家庭向けには、ユーザーとパスワードを揃える、記憶を消す、ネットワークをプライベートにする、で足りることがほとんどです。ゲスト（パスワードなし）共有を Windows 側で無理に通す設定も、この記事では扱いません。NAS にユーザーを作ってください。

## 手順

### 1. 入れるアドレスと、使うユーザー名を確定する

1. エクスプローラーのアドレスバーに、名前ではなく **IP アドレス** を入れて試す。例: `\\192.168.1.5`。ルーターの機器一覧や NAS の画面で番号を確認します。名前だけ失敗して番号で出るなら、DNS やホスト名の問題です。
2. 資格情報の **ユーザー名** は、次のどれかです。表示名（「太郎」）では入れません。
   - NAS: NAS に作ったユーザー（例: `homeuser`）
   - 相手が Windows のローカルアカウント: `パソコン名\ユーザー名`
   - 相手が Microsoft アカウント: その **メールアドレス**
3. **パスワード** は、そのユーザーのパスワードです。Windows の PIN、スマホのロック番号、NAS の管理画面の別アカウントと取り違えない。
4. 「資格情報を記憶する」は、成功したときだけオンにします。失敗した状態で記憶すると、手順2が必要になります。

同じ部屋のスマホから NAS アプリで入れるなら、機器と LAN は生きています。Windows 側のユーザー指定を疑います。

### 2. 古いネットワーク資格情報を消す

失敗したユーザー名が残っていると、ダイアログに何を入れても古いほうが使われます。

1. スタートメニューで `資格情報マネージャー` と検索して開く。
2. **Windows 資格情報** を開く。
3. 対象の PC 名、NAS 名、`192.168.` で始まる項目を選び、**削除**。汎用資格情報に同じ先があればそれも削除。
4. PC を再起動し、エクスプローラーから `\\IPアドレス` を開き直す。今回は記憶せず、正しいユーザーとパスワードだけ入れる。

コマンドで接続を切る場合は、コマンド プロンプトで `net use * /delete` です。自分で割り当てたネットワークドライブも外れるので、必要なドライブはあとから入れ直します。

### 3. ネットワークをプライベートにし、探索を許可する

1. **設定** → **ネットワークとインターネット** → 使っている **Wi-Fi** または **イーサネット**。
2. 接続中のネットワークを開き、**ネットワーク プロファイルの種類** を **プライベート** にする。パブリックのままだと、家庭内共有が見えない・入れないことがあります。
3. **設定** → **ネットワークとインターネット** → **詳細ネットワーク設定** → **共有の詳細設定**。
4. **プライベート** で、ネットワーク探索とファイルとプリンターの共有をオン。**パブリック** 側は無理にオンにしない（カフェの Wi-Fi 向けです）。
5. パスワード保護共有は、家庭ではオンのままで構いません。オフにして誰でも入れる状態にはしないでください。代わりに NAS / PC 側へユーザーを作ります。

ゲスト Wi-Fi（「Guest」など端末同士が隔離される SSID）に PC だけ乗っていると、NAS の番号すら見えません。家の通常 SSID に切り替えます。プリンターだけ見える／見えない話は [プリンターがオフライン](/articles/printer-offline/) に近い切り分けです。

### 4. 共有する側（Windows PC）のフォルダ許可

自分の別 PC を共有しているときです。NAS だけ使う人は手順5へ。

1. 共有する側で、**設定 → アカウント** のサインイン名（ローカルならそのユーザー名）を確認する。
2. フォルダを右クリック → **プロパティ** → **共有**。**共有する** 相手に、今入力しているユーザーが入っているか見る。使う人を追加する。
3. 同じプロパティの **セキュリティ** タブでも、そのユーザーに読み取り（必要なら変更）があるか見る。共有タブだけ許可してセキュリティ側が拒否、が「アクセスが拒否されました」の定番です。
4. **Windows セキュリティ** → **ファイアウォールとネットワーク保護** で、プライベートネットワークのファイアウォールが有効か見る。メーカー製セキュリティソフトがファイル共有を止めているときは、ソフト側で LAN を許可します。ファイアウォール自体を常時オフにはしないでください。

### 5. NAS 側は「ユーザー付き」で合わせる

バッファローや I-O DATA などの家庭用 NAS で多いパターンです。

1. ブラウザで NAS の管理画面を開き（本体シールのアドレスや、メーカーの検出アプリ）、共有フォルダ用の **ユーザーとパスワード** を作る。管理者アカウントと、普段の共有ユーザーを分けると事故が減ります。
2. そのユーザーに、入れたいフォルダの読み取り（必要なら書き込み）を付ける。
3. Windows の資格情報には、手順1のユーザー名と、ここで設定したパスワードだけを入れる。Windows の Microsoft アカウントのメールでは、NAS は知りません。
4. ファームウェア更新の案内が NAS にあるときは、メーカー手順で更新する。とても古い機種が古い通信方式しか話せない場合は、Windows 側で危険な互換をオンにするより、メーカーの案内か機種の見直しです。

ネットワークドライブとして残したいときは、エクスプローラーの **このPC** → **ネットワークドライブの割り当て** で、フォルダに `\\IPアドレス\共有名`、ユーザーは NAS のユーザーを指定します。成功してから「サインイン時に再接続」をオンにします。

## まだ直らないとき

- 番号では入れるが名前だけダメ → ルーターの名前解決か DNS。インターネット全体がおかしいなら DNS / インターネットなしの記事へ。LAN 内だけなら、普段は IP かネットワークドライブで足りることが多いです
- スマホのアプリでは入れるが Windows だけダイアログが繰り返す → 資格情報の削除と、NAS ユーザー名の取り違えを再確認。大文字小文字、全角、前後の空白
- 更新直後からだけ失敗する → 記憶の削除を先に。それでもダメなら NAS のファームウェアと、Windows Update の完了（[更新が進まないとき](/articles/windows-update-stuck/)）
- 会社の共有や VPN 越し → 家庭向けのプライベート設定では終わりません。PIN ではなく会社アカウントか、担当から渡されたユーザーを使う
- どの PC からもパスが見つからない → NAS の電源、LAN ケーブル、ルーターの機器一覧。無線が不安定なら有線で NAS とルーターを直結して切り分ける

## まとめ

資格情報が繰り返されるときは、回線より先に **PIN ではなくその共有のパスワード、資格情報マネージャーの古い記憶、プライベート プロファイル、NAS に作ったユーザー** を揃えます。パスワードなしのゲストや SMB 1.0 を無理に通すより、ユーザーを1つ作るほうが安全です。名前で見つからないときだけ、IP アドレスで切り分けてください。
