Wi-Fi を切るとブラウザが白い。アンテナは立っているのに「インターネットなし」。4G / 5G の表示自体が出ない。Wi-Fi の認証エラーや保存済みSSIDの話は、この記事では扱いません。

## 症状の見分け

- 画面上のアンテナは見えるが、すぐ横に「インターネットなし」
- Wi-Fi オフだとアプリが更新されず、オンに戻すと動く
- モバイルデータのスイッチを入れても、すぐオフに戻る
- 通話はできるが、回線交換だけ生きている（SMS は届く）
- 自宅ではダメ、外出先では使える（またはその逆）
- デュアルSIMで、使いたい回線のほうだけ死んでいる
- アンテナも「4G」も出ない。バツ印、または電波の枠だけ

家族のスマホが同じ場所で使えるなら、端末かSIMです。誰の端末もダメなら、その場所の電波か、契約の通信障害です。iPhone の同じ症状は [iPhone のモバイルデータ](/articles/iphone-mobile-data-not-working/) で、画面名が違います。

## よくある原因

1. 機内モードがオン、またはクイック設定のモバイルデータがオフ
2. データセーバーや、そのアプリだけのモバイルデータ制限
3. APN（接続名）が空、または以前いじった手動設定が残っている
4. SIM の接触不良。差し直しで戻ることがある
5. VPN、プライベートDNS、日付のずれで、名前解決だけ失敗している
6. 契約の容量超過、またはeSIM / 物理SIMの切り替えミス

Wi-Fi につないでも同じ「インターネットなし」なら、先に [Android で Wi-Fi に繋がらないとき](/articles/android-wifi-cannot-connect/) です。チャットの中身は更新されているのに知らせだけ遅いときは [通知が来ない・遅れるとき](/articles/android-notifications-delayed/) へ。Gmail だけ来ないときは [メールが届かないとき](/articles/gmail-not-receiving/) です。

## 直す前に

- 今つながっている Wi-Fi の名前を控える。あとで戻す用です
- キャリアの障害情報を、別の端末か PC で一度見る
- 「APN自動設定」「通信制限解除」を名乗るアプリは入れない

> **注意:** root 化、キャリアの非公開APNをネットからコピーして上書き、改造系の「電波改善」はしないでください。APNは見るだけ、またはキャリア公式の案内どおり戻すところまでです。SIM 交換や初期化は、バックアップが取れてからの最終手段です。

## 手順

### 1. 機内モードとモバイルデータを入れ直す

1. 画面上からバーを下げ、**機内モード** をオン → 10秒待つ → オフ。
2. 同じバーの **モバイルデータ**（機種によっては **データ通信**）をオフ → 5秒 → オン。
3. Wi-Fi をオフにして、ブラウザで検索できるか見る。トップページが出ればOK。

まだ「インターネットなし」なら、設定アプリ側を見ます。

**ここで失敗したとき:** モバイルデータのタイルが無く、機内モードしか無い機種は、バーをさらに下へ広げるか、編集（鉛筆）からタイルを追加します。タイルが灰色のまま動かないときは、クイック設定ではなく手順2の SIM 画面です。機内モードをオフにしても飛行機アイコンが残るなら、オフが完了していません。もう一度タップして、アイコンが消えてからデータをオンにしてください。

### 2. SIM とデータ通信の画面

1. **設定** → **ネットワークとインターネット** → **SIM**（表記が **モバイルネットワーク** の機種もある）。
2. 使っている回線を開き、**モバイルデータ** がオンか確認する。オフならオン。
3. **ローミング** は国内利用なら触らなくてよい。海外にいないのにオンでも、それ自体は切断の主因になりにくい。
4. デュアルSIMなら、**データ通信に使用するSIM** が、契約どおりのほうになっているか見る。通話用とデータ用が入れ替わっていることがあります。

スイッチが灰色で動かせないときは、保護者による使用制限か、会社端末の管理です。無理にオンにしないでください。

**ここで失敗したとき:** SIM の行が「なし」「無効」なら、トレイの挿し忘れか、eSIM がオフです。物理SIMの機種は手順5の差し直しへ。eSIM は同じ画面の **eSIM を使用** や **SIM をオン** を見てください。オフならオンにします。デュアルで、アンテナは出るのにブラウザだけ死ぬときは、データ用の SIM が通話専用のほうになっています。**データ通信に使用するSIM** を、契約でデータを付けた番号へ切り替えて、Wi-Fi をオフのままブラウザを開き直します。

### 3. データセーバーと、アプリ単位の制限

1. **設定** → **ネットワークとインターネット** → **データセーバー**。オンならオフにする。
2. 同じ系統の画面に **アプリのデータ使用量** がある機種では、使いたいアプリの **モバイルデータの使用** が許可か見る。
3. メーカー独自の「通信制限」「省電力」一覧で、ブラウザやマップが止められていないか見る。

これでブラウザだけ戻るなら、OS全体ではなくそのアプリの制限です。

**ここで失敗したとき:** データセーバーをオフにしても、ステータスの「インターネットなし」が消えないなら、セーバーは原因ではありません。手順4へ進んでください。特定のアプリだけぐるぐるで、ブラウザは開けるなら、そのアプリの **モバイルデータ** と **バックグラウンドデータ** がオフです。アプリ情報（設定のアプリ一覧からその名前）で両方オンにします。

### 4. APN は「見る」ところまで

1. **設定** → **ネットワークとインターネット** → **SIM** → 対象回線 → **アクセスポイント名**（APN）。
2. 一覧に、契約キャリアの名前が1つ以上あるか見る。空、または「未設定」だけなら、キャリア公式サイトの「APN設定」ページを別回線で開く。
3. すでにキャリア名のAPNが選ばれている（左の丸が付いている）なら、値を手で書き換えない。選ばれていないときだけ、公式の項目をタップして選択する。
4. 以前自分で追加した行があり、名前が覚えのないときは、その行を選ばない。公式の行へ戻す。

数値をブログから写す必要はありません。選ぶ・公式の初期値に戻す、までです。

**ここで失敗したとき:** APN のメニュー自体が無い、灰色、ならその回線はキャリア側で自動です。手入力の画面を探すのはやめてください。一覧が空なのにメニューはあるときは、Wi-Fi を一度オンにしてキャリアの設定を受信できないか、公式の案内に「APN をリセット」があればそれだけ実行します。見知らぬブログの数字を足して、空の一覧を埋めないでください。公式の行を選んだ直後に「インターネットなし」のままなら、選択は届いています。次は SIM の接触か契約です。

### 5. VPN・DNS・日付、SIMの軽い確認

1. **設定** → **ネットワークとインターネット** → **VPN**。接続中なら切断。常時接続VPNもオフ。
2. **プライベートDNS** を **自動** に戻す。
3. **設定** → **日付と時刻** で **日付と時刻を自動設定** をオン。
4. ここまででダメなら、電源を切ってから SIM トレイを開け、金属面を触らずに一度抜いて差し直す。eSIM だけの機種では、この手順は飛ばす。
5. 電源を入れ、Wi-Fi オフのままブラウザを開く。

家の Wi-Fi では使えるのにモバイルだけダメ、なら手順4のAPNまでで足りることが多いです。外出先でも同じなら、契約とSIM側を疑います。

**ここで失敗したとき:** SIM を差し直したあと「SIM がありません」と出るなら、向きか、トレイの表裏です。金属面を触ったまま擦らないでください。説明書の絵と同じ向きでもう一度入れ、それでも「ありません」なら、そのSIMを別の対応端末で一度見ます。別端末でも無いなら SIM、別端末では使えるならこのスマホです。eSIM だけの機種でトレイをこじ開けないでください。

## メーカーで入口の名前が違うとき

- Pixel: **設定 → ネットワークとインターネット → SIM**
- Galaxy: **設定 → 接続 → SIM マネージャー**。データ通信は **モバイルネットワーク** の中に分かれている機種があります
- Xperia: **設定 → ネットワークとインターネット → モバイル ネットワーク**
- Xiaomi など: **設定 → SIMカードとモバイルネットワーク**。データセーバーは **セキュリティ** 側にある機種もあります

どの名前でも、見るのは「データがオンか」「データ用の SIM はどちらか」「APN は公式の行か」の3つです。

## 別の端末と比べる

- 隣のスマホは同じ場所でブラウザが開く。自分の Android だけ「インターネットなし」→ 電波の場所ではなく、この端末の SIM・APN・データスイッチです
- 自分の iPhone に同じ物理SIMを入れると使える → Android 側の APN か、データ用 SIM の選択です。値の手作りはせず、公式の行を選び直します
- どの端末も、Wi-Fi を切るとダメ → 契約の停止か、その場所の障害です。端末の初期化は後回しです
- 通話はどの端末でもできるが、データだけ全滅 → 容量超過か、データ通信の停止です。キャリアのマイページを、Wi-Fi が生きている別端末で開いてください

アカウントの同期だけ失敗して、ブラウザは開けるなら [Google アカウントの同期](/articles/android-google-account-sync/) です。アンテナの話ではありません。

## まだ直らないとき

- 通話もSMSもダメ → 電波かSIM障害です。別の場所へ移動して、もう一度アンテナを見る。地下やビル内だけバツなら、APN をいじっても戻りません
- 設定に「モバイルデータは契約で無効」に近い文言 → キャリアのマイページで容量と、データ通信の停止がないか確認する
- セーフモードにすると使える → あとから入れたVPN・セキュリティ・省電力アプリを外す。セーフモードの入り方は機種で違います。電源メニューに出ないときは、メーカーの案内の操作だけ使ってください
- 同じSIMを別のAndroidに入れると使える（物理SIMの場合） → 元の端末側。初期化はバックアップ後
- 公式APNを選んでもすぐ「インターネットなし」 → キャリアのサポートへ、画面のAPN名と「インターネットなし」のスクリーンショットを渡す。ネット上の未確認APNは使わない
- 5G の表示だけ無く、4G にするとブラウザが開く機種 → **優先ネットワークの種類** を 4G / LTE にして様子を見る。項目が無い機種は、そのままにします。無理に帯域を固定するアプリは入れません
- Wi-Fi をオンに戻した瞬間だけモバイルが死ぬ → その Wi-Fi が「接続済み・インターネットなし」のまま優先されています。Wi-Fi をオフにするか、[Wi-Fi の手順](/articles/android-wifi-cannot-connect/) でそのSSIDを削除します

## まとめ

機内モードとモバイルデータを入れ直し、データセーバーを切る。APNは公式の行が選ばれているかだけ見る。値の手入力や改造アプリは不要です。
