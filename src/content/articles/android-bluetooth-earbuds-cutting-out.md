音楽がプツプツ切れる。ケースから出すと左だけ鳴る。充電不足と古い登録が多いです。一覧に出てこない、ペアリング画面から先に進めない、は途切れより接続です。iPhone なら [iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) です。

## 症状の見分け

- 再生は続くが、1〜2秒無音が何度も入る。動画の口の動きとずれる
- 左だけ、または右だけ聞こえる。バランスが端に寄っていることもある
- 歩き始めると切れる。机の上では安定する
- 2台同時接続（スマホと PC）にしているときだけ片耳、または途切れる
- ケースから出した直後は両方鳴るが、数分で片方が落ちる
- 同じイヤホンを別のスマホでは普通に使える

完全に無音で、通知音もメディアも出ないなら、Bluetooth より端末の音量と出力先です。途中で途切れる話とは分けてください。

## よくある原因

1. イヤホンまたはケースの充電不足。接点の汚れで片耳だけ起きない
2. マルチポイントで、片方が PC や古い端末に取られている
3. バッテリー最適化が、音楽アプリやイヤホン用アプリを止めている
4. LDAC など高ビットレートが、壁や距離に負けている
5. 2.4GHz の Wi-Fi、USB 3、電子レンジと同じ場所での干渉
6. 片方のファームウェア不整合。ケースに入れてリセットする前の、古いペアリング情報

## 直す前に

- ケースとイヤホンを、ランプが満充電になるまで置く。赤いランプのまま試さない
- イヤホン付属アプリの「ブースター」「接続強化」は、切り分けのあいだ入れない（すでに入っている分は残してよい）
- 出典不明の「Bluetooth 修復」APK は入れない

> **注意:** イヤホンの初期化（ケースのボタン長押し）は、つながっているすべての機器とのペアリングが消えます。スマホ側の登録削除とセットでやってください。片方だけ消すと、また片耳や途切れに戻りやすいです。

## 手順

### 1. 充電、装着、片耳の物理を先に見る

1. 両方のイヤホンをケースに戻し、蓋を閉じる。ケース側もケーブルで充電する。15分以上置いてから出す。
2. ケースの接点（金メッキのピン）と、イヤホン側の接点を、乾いた布で軽く拭く。片方だけ充電できないと、その耳だけ途中で落ちます。
3. 左右を逆の耳に入れてみる。同じ側の「端末から見て左」だけ聞こえないなら、バランス設定です。耳を変えても同じ個体（L 印のほう）だけ黙るなら、その個体の充電か故障です。
4. **設定** → **ユーザー補助**（機種により **アクセシビリティ**）→ **聴覚** または **オーディオ調整** の **左右のバランス** が中央か見る。端に寄っていると、片耳だけ小さくなります。
5. 片方だけケースに残したまま使っていないか見る。片耳モード対応機でも、通話用マイクが片側固定の機種があります。両方出して、ランプが両方点くか見る。

水洗い、アルコールの浸け置きはしないでください。接点の水分は、むしろ片耳落ちの原因になります。

### 2. 古い登録を消して、1台だけでつなぎ直す

1. イヤホンをケースに入れる。
2. Android の **設定** → **接続済みのデバイス**（機種により **接続** → **Bluetooth**）。対象のイヤホンをタップし、**削除** / **登録解除**。
3. PC や iPad、古いスマホにも覚えがあるなら、そちらでも削除する。マルチポイント対応機は、削除しない端末が片方のチャンネルを掴んだまま、ということがあります。
4. イヤホンをペアリングモードにする（機種の取説どおり。ケースを開けてボタン長押し、ランプが点滅、が多い）。
5. Android の一覧から選び直す。つながったら、**ほかの機器はBluetoothオフ** にして、3分以上音楽を流す。

Windows と同時に使うのが目的でも、切り分けのあいだはスマホ1台だけにしてください。PC 側の不安定さは [Windows の Bluetooth 手順](/articles/windows-bluetooth-cannot-connect/) です。

成功の目安は、ポケットに入れて部屋を歩いても、左右とも途切れないことです。机の上だけ安定、は手順4の距離と干渉です。

### 3. 省電力が通信を切っていないか

1. **設定** → **バッテリー** で、超省電力 / バッテリーセーバーをオフにする。オンのままだと、画面オフのあと Bluetooth が細くなります。
2. 同じバッテリー画面の **バッテリー使用量** または **アプリのバッテリー使用量** から、音楽アプリとイヤホンメーカーのアプリを開き、**制限なし**（機種により **最適化しない**）にする。
3. Pixel 系なら **設定 → アプリ → 対象アプリ → バッテリー → 制限なし**。Samsung なら **設定 → アプリ → 対象 → バッテリー → バックグラウンドでの使用を許可** と、自動最適化の対象から外す。
4. **設定 → 位置情報** がオフだと、一部機種で Bluetooth スキャンが弱くなります。切り分けではオンにして、安定するか見る。安定したら、常用するかどうかは自分で決めてよいです。
5. 開発者向けオプションを触った覚えがあるなら、**Bluetoothオーディオコーデック** が LDAC 固定になっていないか見る。未使用なら、開発者向けオプションは閉じたまま、手順4のアプリ側品質設定だけ見てください。

ゲームモードや「ネットワークを最適化」系のメーカーユーティリティが、Bluetooth を後回しにすることがあります。切り分けのあいだはその機能をオフにします。

### 4. 音質設定と、2.4GHz の干渉

1. イヤホン付属アプリの音質が **高音質 / LDAC / LHDC** なら、いったん **標準** または AAC / SBC 相当へ下げる。高音質は途切れやすいです。安定してから戻すかどうかを決める。
2. 空間オーディオ、ドルビーアトモス、ゲームの低遅延モードをオフにして、同じ曲を3分流す。低遅延は途切れとセットになる機種があります。
3. スマホをズボンの右ポケット、体の反対側の耳、という組み合わせは、人体で電波が遮られます。手に持つか、同じ側のポケットで試す。
4. 自宅 Wi-Fi が 2.4GHz だけのとき、電子レンジの使用中だけ途切れるなら干渉です。5GHz の SSID があるルーターなら、スマホを 5GHz 側へ移す。Wi-Fi そのものが切れる話は [Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) です。
5. USB 充電しながら聞くと途切れるデスクトップ周りは、USB 3 ポートの干渉があります。充電ケーブルを外して、同じ位置で再現するか見る。

壁の向こうのスマホ、カバンの奥、金属製の机の下、はどれも途切れやすいです。先に2メートル以内、見通しで安定するかを見る。

### 5. イヤホン側のリセット

手順2のあとも片耳、または数分で落ちるときだけやります。

1. 公式の取説で **リセット**（初期化）の手順を開く。ケースに両方入れてボタン 10〜15秒、がよくある型です。ランプが指定の色に変わるまで待つ。
2. Android 側の登録が残っていれば、もう一度削除する。
3. リセット後にペアリングし直し、付属アプリがあればファームウェア更新を公式手順どおり入れる。更新中はケースの蓋を閉じない、充電する、など案内どおり。
4. 更新後も同じ個体（L または R）だけ落ちる、充電ランプが片方だけ付かない、は故障側です。保証期間内なら、試した内容（削除、リセット、片耳入れ替え）を添えてメーカーへ。

リセットしても両方すぐ切れる、別のイヤホン（有線でも可）は安定、ならスマホ側の Bluetooth です。機内モードをオン→10秒→オフのあと、Bluetooth だけオンにして再試行します。端末の初期化はこの記事では使いません。

## まだ直らないとき

- 机の上は安定、歩くと切れる → 手順4。ポケットの位置と、高音質コーデック
- 通話だけ片耳 → 機種の仕様（マイク側だけ使う）か、電話アプリの音量。音楽で両方鳴るなら故障ではないことが多い
- 特定アプリ（動画だけ）途切れる → そのアプリのバッテリー制限。手順3
- 家ではダメ、外のモバイルデータでは安定 → 家の 2.4GHz 干渉。Wi-Fi を 5GHz へ
- どの Bluetooth 機器も途切れる → 端末側。保証内なら、別のイヤホンで再現した記録を添えてメーカーへ

## まとめ

満充電と、1台だけのつなぎ直しで分かることが多いです。片耳は接点とバランス、途切れは高音質と干渉です。
