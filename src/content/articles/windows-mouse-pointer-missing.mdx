USB マウスを動かしてもカーソルが凍ったまま。画面上からポインターが消えた。動くがクリックだけ効かない。ノートのタッチパッドは生きている、またはその逆。基板故障より **レシーバーの差し直し、Bluetooth の電池、マウスキー、タブレットモード、ポインターの表示** が多いです。

内蔵タッチパッドだけの不具合は [タッチパッドの手順](/articles/windows-touchpad-not-working/) です。デバイス一覧にマウスが出ないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) 、ペアリング自体が失敗するときは [Bluetooth がつながらないとき](/articles/windows-bluetooth-cannot-connect/) を先にどうぞ。画面全体が重いだけなら [動作が遅いとき](/articles/windows-pc-running-slow/) です。

## 症状の見分け

- マウスを動かしてもポインターが完全に止まる。キーボードの `Tab` や `Win` は効く
- ポインター自体が見えない。動かすと端に一瞬出る、または出ない
- 移動はできるが、左クリック／右クリックが無い。ホイールだけ死ぬ
- USB 有線は動くが、無線だけダメ（またはその逆）
- サインイン画面では動くが、デスクトップに入ると消える
- ゲームや全画面のブラウザだけ、ポインターが消えたまま戻らない

BIOS やメーカーロゴの画面では動くが Windows だけダメ、なら OS 側です。どの画面でもダメ、ランプも点かない、なら電池・ケーブル・本体 USB です。水濡れや変形があるマウスは、この先の設定より先に電源を切り、廃棄またはメーカーへ。

## よくある原因

1. 無線マウスの電池切れ、レシーバーの接触、USB ポートの給電不足
2. Bluetooth マウスが接続切れ、または別の PC に繋がったまま
3. **マウスキー**（テンキーでポインター）や、ポインターを「表示しない」系の設定
4. タブレットモード、ペン優先で、マウスポインターを隠している
5. 全画面アプリがカーソルをつかみっぱなし
6. タッチパッドは生きていて、外付けマウスのドライバーだけ落ちている

## 直す前に

- 有線マウスが1本でもあれば、切り分け用に確保する。ノートならタッチパッドでも可
- 無線のレシーバーをハブ経由で挿しているなら、いったん全部抜く
- 出典不明の「マウス修復」「ドライバーパック」は入れない

> **注意:** デバイス マネージャーでマウスをアンインストールしても、多くの場合は再起動で標準ドライバーが戻ります。チップセットごと消す、不明な exe を管理者で実行する、はしないでください。

## 手順

### 1. 電池・差し直し・別ポート

1. 無線マウスなら電源スイッチをオフ→オン。電池または充電残量を見る。ランプが点かないなら電池が先です。
2. USB レシーバーを抜き、**本体背面または側面の USB 端子へ直挿し**する。机の前のハブ、モニターの USB、キーボード通しは使わない。
3. 別の USB ポートへ移す。USB 2.0 と 3.0（青い端子）の両方を試す。
4. 有線マウスなら、別のケーブルまたは別のマウスを同じポートへ。こちらが動くなら、元のマウス側です。
5. ノートはタッチパッドでポインターが出るか確認する。パッドが出て外付けだけダメなら、外付けの接続です。パッドも外付けもダメなら手順3です。

レシーバーが USB レシーバーなのに Bluetooth 設定をいじっても直りません。底面に USB ドングルが収納されている機種があります。抜け落ちていないか見てください。

### 2. Bluetooth マウスの切り直し

1. **設定 → Bluetooth とデバイス** で Bluetooth がオンか見る。
2. 問題のマウスが **接続済み** か、**ペアリング済み** のまま切れているか。切れていれば選択して **デバイスの削除** → マウス側をペアリングモード → **デバイスの追加**。
3. 同じマウスを会社の PC やタブレットにも登録していると、近いほうへ吸い寄せられます。使わない機材の Bluetooth を切る。
4. 2.4GHz のレシーバー付きなのに Bluetooth 一覧にも出ているマウスは、同時接続の取り違えが起きます。今使っている方式（USB ドングルか Bluetooth か）を一つに決める。

ペアリング画面に出てこないときは、Bluetooth 記事へ。ここは「一覧にはあるが動かない」用です。

### 3. ポインター表示と、マウスキー

1. `Win` キーが使えるなら **設定 → Bluetooth とデバイス → マウス**。
2. **ポインター速度** が左端（遅すぎ）や右端（飛びすぎ）になっていないか。中央付近に戻す。
3. **関連設定** の **その他のマウス設定**、またはコントロール パネルの **マウス** → **ポインター オプション**。**ポインターの軌跡を表示する** は好み。**入力中にポインターを非表示にする** がオンだと、タイプ直後に消えたように見えます。いったんオフ。
4. **ポインター** タブで、配色が背景と同化するテーマになっていないか。白い画面に白ポインター、がよくあります。Windows 標準に戻す。
5. **設定** 内検索で **マウスキー**。**テンキーでマウスを操作する** がオンならオフにする。オンのままだと、外付けマウスと取り合い、または NumLock の状態でポインターが勝手に漂います。

キーボードだけ使える状態なら、`Win` + `Ctrl` + `Enter` でマウスキーのオンオフが切り替わることがあります。誤って入っていたら、同じキーをもう一度押す。

### 4. 全画面と、固まったアプリ

1. `Alt` + `Tab` でほかのウィンドウに切り替え、ポインターが戻るか見る。ゲームや動画の全画面が、カーソルを掴んだままのことがあります。
2. `Alt` + `F4` でその全画面を閉じる。閉じられないときは `Ctrl` + `Shift` + `Esc` でタスク マネージャー → そのアプリを **タスクの終了**。
3. エクスプローラーごと固まり、ポインターも動かない（砂時計のまま）なら [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/) です。マウス故障と取り違えやすいです。
4. タブレットモードや、ペンを近づけるとポインターを隠す設定の機種があります。ペンを離し、**設定 → Bluetooth とデバイス → ペンと Windows Ink** 付近を見る。

スタートメニューやタスクバー自体が消えているときは、マウスよりシェルです。[スタートメニューとタスクバー](/articles/windows-start-menu-taskbar-broken/) を先に。

### 5. デバイス マネージャーと、新しいユーザー

1. `Win` + `X` → **デバイス マネージャー**。キーボードが死んでいるときは、タッチパッドの右クリック相当でスタートボタン長押し。
2. **マウスとその他のポインティング デバイス** を開く。警告アイコンがあればダブルクリックし、コードを控える。**ドライバーの更新** は Windows の自動検索まで。まとめサイトの zip は使わない。
3. 該当マウスを右クリック → **デバイスのアンインストール**（ドライバーの削除にチェックは入れない）→ 再起動。標準ドライバーで戻ることが多いです。
4. まだダメなら、家族のアカウントか新しいローカルユーザーでサインインし、同じマウスが動くか見る。こちらで成功するなら、今のプロファイルの設定です。

USB 全部が「認識されません」なら、マウス記事ではなく USB 記事です。電力不足のハブは、本体直挿しで切り分けてください。

## まだ直らないとき

- サインイン画面だけ動く → デスクトップ側の全画面アプリ、またはそのユーザーのマウス設定。別ユーザーで試す
- ポインターは動くがクリックが無い → マウス本体のスイッチ寿命。別マウスで即切り分け。設定では戻りません
- ノートのパッドも外付けもダメ、画面タッチは効く → ポインター非表示、マウスキー、タブレット扱い。手順3
- デバイス マネージャーにマウスが無い → USB / Bluetooth 側。それぞれの記事へ
- 職場 PC でドライバー更新が灰色 → 個人では終わりません。担当へ「ポインターが消える／コード」を渡す

レーザーマウスは、ガラスや高光沢の机で飛びます。布や紙を一枚敷いてから、故障と決めないでください。

## まとめ

修復ツールより、別ポート直挿し、電池、**入力中にポインターを非表示にする**、マウスキーです。タッチパッドが生きていれば外付け側。どちらもダメなら表示設定かシェルです。ドライバーは標準に戻すところまで。
