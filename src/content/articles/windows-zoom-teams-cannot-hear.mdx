会議には入れているのに相手の声だけ無音、自分の声は届いている、YouTube は普通に鳴る、といった状態はスピーカー故障より **会議アプリの出力先、音量ミキサー、相手側のミュート、Bluetooth の通話プロファイル** が多いです。Windows 全体が無音なときと、会議だけ聞こえないときでは、見る場所が違います。

この記事は Windows 10 / 11 の Zoom と Microsoft Teams を対象にします。動画も通知音も出ないときは、先に [音が出ない手順](/articles/windows-no-sound/) です。自分の声が相手に届かない（入力）は [マイクが使えない手順](/articles/windows-microphone-not-working/) です。映像だけ黒いときは [カメラの手順](/articles/windows-camera-not-working/) を見てください。

## 症状の見分け

- YouTube やシステム音は鳴るが、Zoom / Teams だけ無音
- 会議ウィンドウのスピーカーアイコンや、相手のミュート表示が付いたまま
- 自分のスピーカーはヘッドセットなのに、会議だけモニターや本体から（またはその逆で無音）
- Bluetooth イヤホンは音楽では鳴るが、会議を始めた瞬間に聞こえない
- ブラウザ版では聞こえるがアプリ版だけダメ（またはその逆）
- 特定の相手だけ無音で、ほかの参加者は聞こえる

システム音まで無いなら、この記事より先に出力全体の記事です。会議だけなら、アプリ内のデバイスとミキサーを先に見ます。一人だけ無音なら、相手のマイクか、その人のミュートです。

## よくある原因

1. Zoom / Teams のスピーカーが「なし」、切れた Bluetooth、使っていない HDMI モニターになっている
2. Windows の **音量ミキサー** で、その会議アプリだけミュートか極端に小さい
3. 相手がミュート、または自分が「コンピューターオーディオに参加」していない（Zoom）
4. Bluetooth が会議開始で Hands-Free に切り替わり、再生側が空になる
5. 通信時に Windows がほかの音を絞り、会議側の出力も一緒に落ちる
6. 回線が細く、映像は残るが音声パケットだけ落ちる

## 直す前に

- 相手に「そちらでミュートになっていないか」をチャットかメールで確認する。自分だけでは直せないことがあります
- ヘッドホン本体の電源、インラインのアイコン、ノートの Fn ミュートを見る
- 確認中は音量を小さめにする。いきなり最大にすると、直った瞬間に耳を痛めることがあります

> **注意:** 「会議音声ブースター」「Zoom 修復」を名乗る実行ファイルは入れないでください。アプリのスピーカー選択と、Windows のミキサーで足りることがほとんどです。相手の同意なく通話を録音する機能は、この記事の範囲外です。

## 手順

### 1. 会議アプリ内のスピーカーを選び直す

**Zoom のとき**

1. 会議中の **音声**（または **^** のスピーカー）→ **オーディオ設定**。
2. **スピーカー** で、今耳に当てている機器を選ぶ。「同じものを選択」や切れたデバイス名のままになっていないか見る。
3. **スピーカーのテスト** を押し、テスト音が聞こえるか確認する。
4. テスト音も無いときは、いったん **コンピューターオーディオから退出** し、すぐに **コンピューターオーディオに参加** する。電話発信（通話）と PC 音声を取り違えていることがあります。

**Teams のとき**

1. 会議中の三点メニュー → **デバイス設定**（または **設定 → デバイス**）。
2. **スピーカー** で今使いたい機器を選ぶ。マイクとスピーカーが別々の名前になっていることがあります。
3. 同じ画面のスピーカー プレビュー、または会議に入り直して、相手のレベルメーターが動くか見る。
4. 新しい Teams とクラシックが両方入っているときは、実際に起動しているほうの設定だけが効きます。アイコンを取り違えないでください。

アプリ内の選択が Windows の既定と違うと、「普段は鳴るのに会議だけ無音」になります。揃えたら、会議を抜けて入り直します。

### 2. Windows のミキサーと、通信時の音量を見る

1. **設定** → **システム** → **サウンド** → **音量ミキサー**（または **アプリの音量とデバイスの設定**）。
2. Zoom または Microsoft Teams のスライダーがミュートでないか、出力先が全体と違う機器になっていないか見る。
3. 会議アプリを完全に終了（通知領域のアイコンも含む）してから開き直す。起動中にヘッドホンを挿すと、古い出力のまま掴みます。
4. コントロール パネルのサウンド → **通信** タブで、**通信アクティビティの発生時** を **何もしない** にする。Windows が通話を検知して音を絞ると、相手の声も小さく、または無音に聞こえます。

出力デバイスそのものの無効化や HDMI の取り違えは、[音が出ない手順](/articles/windows-no-sound/) の再生タブと同じです。こちらは「会議プロセスだけ」を先に疑います。

### 3. 相手側と、自分側のミュート表示を分ける

1. 参加者一覧で、相手のマイクアイコンに斜線が無いか見る。付いているなら、相手に解除してもらうしかありません。
2. 自分のスピーカー（出力）アイコンと、マイク（入力）アイコンを取り違えない。マイクをオンにしても、相手の声は戻りません。
3. Zoom で「電話で参加」と PC 音声が二重になっていると、片方だけ無音に見えます。どちらか一方に揃える。
4. ウェビナーや、主催者が「参加者の音声をミュート」している配信は、聞く側の設定では直りません。

自分の声が届かない話はマイク記事へ戻ります。この手順は、相手の声（再生）だけを見ています。

### 4. Bluetooth と有線で切り分ける

1. Bluetooth イヤホンを切断し、本体スピーカーまたは有線ヘッドホンで会議に入り直す。有線で聞こえるなら、機器かプロファイルです。
2. 無線に戻すときは、接続し直してから会議を始め、設定の出力名が **ステレオ** 側か見る。Hands-Free だけだと、音楽用の再生が出ないことがあります。
3. USB ヘッドセットは PC 本体へ直挿しする。モニターの USB や未給電ハブは、マイクは生きてスピーカーだけ落ちることがあります。認識自体が不安定なら [USB機器が認識されない](/articles/usb-device-not-recognized/) です。
4. 外付けディスプレイをつないだ直後から会議だけ無音になったときは、アプリのスピーカーがモニター名になっていないか見る。

### 5. ブラウザ版と回線で切り分ける

1. 同じ会議をブラウザ（Edge または Chrome）で開き、アドレス欄のスピーカー／音の許可を確認する。アプリ版だけダメなら、アプリの再インストールより先に手順1のデバイス選択です。
2. ブラウザ版だけダメなら、拡張機能を一時オフにするか、別ブラウザで当たる。
3. 声が途切れる、遅れる、映像は残る、ときは Wi-Fi 側です。カメラをオフにして音声だけ残るか見る。家全体が怪しいときは [Wi-Fiは繋がるがインターネットに出られない](/articles/wifi-connected-no-internet/) です。
4. VPN や仮想 LAN を会議中だけ切ると戻ることがあります。セキュリティ上切れない職場回線は、担当へ「音声だけ欠ける」と伝えてください。

起動時にメーカーのオーディオユーティリティが既定を書き換えると、会議のたびに出力が戻ります。不要なら [スタートアップの整理](/articles/windows-startup-apps/) で、音に関係する常駐だけ残します。

## まだ直らないとき

- テスト音は鳴るが相手だけ無音 → 相手のミュート、相手のマイク故障、主催者側のミュート。自分の PC だけでは終わりません
- 自分には聞こえるが家族の同じ会議では聞こえない → その端末の出力。この記事の手順1を、聞こえない側で行う
- Bluetooth だけ会議開始と同時に無音 → Hands-Free への切り替え。有線か、ドングル付き USB ヘッドセットで切り分ける
- どの出力でも会議だけ無音、ミキサーにもアプリが無い → アプリを完全終了して入り直す。それでもダメなら、アプリの修復（設定 → アプリ）は公式ストア／公式サイトの手順だけで行う
- 職場 PC でデバイス設定が灰色 → 個人の設定では終わりません。会議ツール名と、「YouTube は鳴る / 鳴らない」を担当へ伝える

## まとめ

会議で相手の声だけ無いときは、スピーカーを買い替える前に **アプリ内の出力が今の機器か、ミキサーでそのアプリがミュートでないか、相手がミュートでないか** を揃えます。YouTube が鳴るならハードは生きているので、Zoom / Teams の選択と Bluetooth のプロファイルを疑います。全体が無音なら、この記事ではなく出力全体の手順です。
