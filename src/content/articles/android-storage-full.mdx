カメラを押すと「空き容量が不足しています」。Play ストアの更新も、途中で容量エラーに戻る。写真、チャットの動画、ダウンロード、アプリのキャッシュが溜まっていることが多いです。システムのフォルダーは触らず、設定の内訳を見てから大きいものだけ移すか消します。

空きを作ったあともストアだけ「保留中」なら [Google Play でダウンロードできないとき](/articles/android-play-store-wont-download/) です。パソコンへ退避したあと、PC側の C ドライブが赤いときは [Windows のストレージ不足](/articles/windows-storage-full/) を見てください。

## 症状の見分け

- カメラやスクリーンショットが、保存直前に失敗する
- Play ストアの更新が、空き容量の表示で途中から戻る
- 通知にストレージ不足が出る。設定のバーがほぼ埋まっている
- 写真を消したのに、空きが数百MBしか増えない
- 特定のアプリだけ数GBある。ほかは小さい
- 本体の空きは残っているのに、SDカード側だけ赤い（またはその逆）

数GB空いているのに、そのアプリだけ保存できないときは、容量一括ではなく、そのアプリの中のキャッシュや権限です。

## よくある原因

1. カメラの動画、スクリーンショット、画面録画が写真に溜まっている
2. LINE などのトーク画像が、ギャラリーにもう一組保存されている
3. アプリのキャッシュと、途中で止まった更新ファイル
4. ダウンロードフォルダーの APK、ZIP、ブラウザが保存した動画
5. ゴミ箱に入れただけで、空きに戻っていない
6. 使っていないゲームや、一度試した大型アプリ
7. microSD の空きと、本体ストレージを取り違えている

## 直す前に

- 残したい写真と動画が、クラウドに上がり切っているか見る。上がる前に本体から消すと、そのコピーは戻りません
- 銀行、認証、会社の業務アプリは、容量が大きくても消さない。再登録が必要になります
- 出自不明の「クリーナー」「メモリ解放」は入れない。標準の **設定 → ストレージ** で足ります

> **注意:** アプリの **ストレージを消去**（古い画面では **データを削除**）は、キャッシュ削除と別です。ログインと、そのアプリの中だけにあるファイルが消えます。SDカードのフォーマットも、容量不足の最初の手段にはしないでください。カード内の写真は消えます。

## 手順

### 1. 本体とSDカードの、どちらが埋まりかを見る

1. **設定** → **ストレージ**。Galaxy では **設定** → **バッテリーとデバイスケア**（または **デバイスケア**）→ **ストレージ**。読み込みに少し待つことがあります。
2. バーの下で、**写真**（画像・動画）、**アプリ**、**システム**、**その他** のどれが大きいか見る。
3. SDカードが別行で出ている機種は、本体とカードを混ぜない。カメラの保存先がカードなら、カード側の空きだけ先に見ます。
4. 写真が過半なら手順2、特定アプリが数GBなら手順3、ダウンロードやファイルなら手順4です。

システムは Android が使う領域で、設定から中身は消せません。写真とキャッシュを減らしたあと、再起動すると少し縮むことがあります。

### 2. 写真と動画を移してから消す

1. カメラや **フォト** で、長い動画と画面録画を選ぶ。残すものは、USB でパソコンへコピーするか、クラウドのアップロードが終わるまで待つ。
2. **Google フォト** を使っているなら **ライブラリ** → **空き容量を増やす**。バックアップ済み、と出ているものだけが対象です。枚数の確認画面を読んでから実行する。「バックアップを待機中」の写真は、ここから消さない。
3. 消したあとは **ライブラリ** → **ゴミ箱** を開く。残したいものが無ければ空にする。空にするまで、空きはほとんど戻りません。Google フォトのゴミ箱は、数十日残ります。
4. Samsung のギャラリーを使っている場合も、アプリ内のゴミ箱を別に空にします。フォトとギャラリーの両方に同じ動画があるときは、片方を消しても、もう片方は残ります。

Wi-Fi が細い部屋で原本を上げるときは、充電につないだままにする。途中で切れると、本体にもクラウドにも中途半端なファイルが残ることがあります。

### 3. キャッシュだけ消す。アプリのデータは残す

1. **設定** → **アプリ** → **すべてのアプリを表示**（機種により **アプリを管理**）。サイズ順に並びます。ストレージ画面の **アプリ** から入っても同じ一覧です。
2. 大きいアプリを開き、**ストレージとキャッシュ**。
3. **キャッシュを削除** だけ押す。トーク履歴やログインは、通常ここにはありません。
4. **ストレージを消去** は、そのアプリを入れ直した直後に近い状態に戻します。LINE ならトークのローカルデータ、ゲームならセーブが消えることがあるので、説明を読んでからにします。

LINE のキャッシュだけなら、LINE の **設定**（歯車）→ **トーク** → **データの削除** → **キャッシュデータを削除**。隣にあるトーク履歴の削除とは別のボタンです。画面の説明が「キャッシュ」であることを確認してから押します。

ギャラリーへ写真を自動保存していると、トークとカメラロールで二重になります。自動保存をオフにしても、すでにギャラリーへ出た分は残るので、手順2で動画だけ整理します。

### 4. ダウンロードと、ファイルのゴミ箱

1. 標準の **ファイル** アプリを開く。メーカー名のファイルアプリでも構いません。
2. **ダウンロード** をサイズ順にし、古い APK、ZIP、ブラウザが落とした動画を、残すか見てから削除する。
3. **ゴミ箱** があれば中を見て、問題なければ空にする。
4. 内部ストレージの **動画** や **ダウンロード** に、メッセージから保存したファイルが残っていないか見る。

Galaxy のストレージにある **クリーンアップ** や **ジャンクファイル** は、キャッシュの提案までにします。アプリのデータをまとめて捨てる項目には進みません。

### 5. 使っていないアプリを外す

1. 同じアプリ一覧で、何ヶ月も開いていないゲームや試用アプリを開く。
2. **アンインストール**（**削除**）。ホーム画面のアイコンを隠しただけでは、本体に残ります。
3. **使用していないアプリ** や休止の項目がある機種は、対象を休止にできます。アイコンが残っても、更新や権限が止まって空きが少し戻ることがあります。認証アプリは休止にしない。
4. 削除のあと **設定 → ストレージ** に戻り、空きが増えたか見る。増えないときは、手順2のゴミ箱が残っています。

Play ストアの更新だけまだ失敗するときは、空きが数GBできてからストア側の手順へ戻ります。

## まだ直らないとき

- 写真を消してもバーがすぐ戻る → フォトとギャラリーのゴミ箱、またはバックアップ待ちの再ダウンロード。Wi-Fi で同期が終わったあと、もう一度サイズを見る
- **その他** だけ異常に大きい → 再起動を1回。ファイルアプリで大きいファイルを探す。クリーナーアプリで「その他」を分解する、ということはしない
- SDカードだけ「破損」と出る → パソコンで読めるなら先にコピーする。フォーマットはコピーのあと。読めないカードを容量不足の手順で直そうとしない
- 熱い、充電が落ちる、再起動を繰り返す → 容量の話ではなく本体側です。片付けを急がず、販売店へ
- 仕事用プロファイル（仕事用タブ）のアプリは、個人側のストレージとは別枠のことがあります。仕事用のアイコン側で同じ一覧を見る

## まとめ

ストレージ画面で、写真・アプリ・ダウンロードのどれが大きいかを先に決める。キャッシュ、バックアップ済みの写真、ゴミ箱を空にすると空きが戻ります。アプリの中身の消去と、SDカードのフォーマットは、何が消えるかを読んでからにします。
