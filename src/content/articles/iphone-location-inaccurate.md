マップの青い点が、今いる交差点から一区画ずれている。ナビの矢印が後ろを向く。天気アプリだけ「位置情報を取得できません」。屋内と、車のホルダーに付けたときだけひどい。先に見るのは、そのアプリの **正確な位置情報**、Wi-Fi と Bluetooth、磁石、時刻です。

Wi-Fi 自体に繋がらないときは [iPhoneでWi-Fiに繋がらないとき](/articles/iphone-wifi-cannot-connect/) 、モバイルデータが使えないときは [モバイルデータが使えないとき](/articles/iphone-mobile-data-not-working/) です。青い点は出るのにページが開かない、はそちらの記事です。

## 症状の見分け

- 標準の **マップ** の青い点が、数百メートルずれている。歩くと少しずつ寄ってくる
- 点の位置は建物に合っている。向いている方向の矢印だけが違う
- マップは正しい。一個のアプリだけ、別の町や「取得できません」になる
- 屋上や広い駐車場では合う。店内、地下、窓の無い部屋だけ大きくずれる
- VPN を入れたあと、ブラウザの天気や動画の地域が別の都市になった。マップの青い点は動いていない
- 落としたあと、カメラの横がへこんだあとから、点がまったく出ない

パスコードが分からないと、あとのリセットはできません。写真やアプリを消す操作には進みません。

## よくある原因

1. そのアプリの位置情報が **しない**、または **正確な位置情報** がオフ。おおまかな範囲だけがアプリに渡っている
2. Wi-Fi と Bluetooth がオフで、屋内の手がかりが無い。機内モードのまま補助も切れている
3. **日付と時刻** が手動で、実際の日時とずれている
4. 磁石付きの車載ホルダー、スマホリング、スピーカーの上が、コンパスだけをずらしている
5. VPN や構成プロファイルが、サイト側の「地域」を別の都市にしている。マップの青い点とは別
6. **コンパスの調整** がオフ、または強い磁石のあとで方位が戻っていない

## 直す前に

- 位置を書き換えるアプリ、偽の GPS、出所の無いプロファイルは入れない
- **緊急電話およびSOS** の位置情報はオフにしない
- 手順6で、位置情報の許可が一度クリアされます。写真やアプリは残ります。どのアプリに位置を許していたか、ざっと思い出せると再開が早いです

> **注意:** **すべての設定をリセット** と **すべてのコンテンツと設定を消去** は、この記事では使いません。点がずれるだけで iPhone を消去しないでください。

## 手順

### 1. 標準のマップと、困っているアプリを比べる

1. 窓のそば、または空が見える場所に出る。**マップ** を開き、現在地の矢印を押す。青い点が出るまで、歩き出さずに数十秒待つ。
2. 点が今いる建物に近いなら、iPhone の位置は取れています。ずれるのはアプリ側の許可です。手順2でそのアプリだけを見る。
3. マップの点も大きくずれる、点がずっと出ないなら、手順3へ。
4. 点は建物に合っていて、矢印の向きだけ違うときは手順5へ。

大きいモールの中は、階の地図がずれて見えるだけ、ということもあります。外へ出て点が合うなら、端末の故障ではありません。

### 2. 位置情報サービスと、正確な位置情報

1. **設定 → プライバシーとセキュリティ → 位置情報サービス** を開く。一番上のスイッチがオフならオンにする。オフのあいだは、どのアプリも現在地を取れません。
2. 一覧から、ずれているアプリを開く。**このアプリの使用中** にする。家族の居場所やナビのように、画面を閉じていても必要なものだけ **常に**。**しない** のままだと、そのアプリは現在地を取れません。
3. 同じ画面の **正確な位置情報** をオンにする。オフだと、おおまかな範囲だけがアプリに渡り、地図の上では大きくずれます。
4. **次回または共有時に確認** のままだと、聞くたびに止まって「取得できない」に見えることがあります。いつも使うナビや天気は **このアプリの使用中** にしておく。
5. 一覧の **マップ** も開く。マップ自体がずれるなら、マップの **正確な位置情報** もオンにする。

設定を変えたら、そのアプリを一度閉じる。画面下から上にスワイプして止め、開き直して現在地を押す。設定のスイッチだけでは、点の位置は変わりません。

### 3. Wi-Fi、Bluetooth、機内モード

店の中では、衛星より近くの Wi-Fi と Bluetooth のほうが頼りになります。両方オフだと、点が建物ひとつ分ずれます。

1. コントロールセンターで機内モードをオフにする。機内モードでも衛星の電波は受信できますが、補助が切れるので点が出るまで時間がかかり、屋内は粗くなります。
2. **設定 → Wi-Fi** をオンにする。知っているネットワークに繋がなくてよいです。スキャンできる状態にする。自宅の Wi-Fi に繋がるなら繋ぐ。最初の一点が早くなります。繋がらないときの手順は Wi-Fi の記事です。
3. **設定 → Bluetooth** をオンにする。イヤホンを接続する必要はありません。
4. 屋外でデータも Wi-Fi も無いと、最初の点が安定するまで数分かかることがあります。電波そのものが「圏外」のときはモバイルデータの記事へ。
5. **設定 → プライバシーとセキュリティ → 位置情報サービス → システムサービス** を開く。**ネットワークとワイヤレス** と **コンパスの調整** がオフならオンにする。

> **注意:** システムサービスのスイッチをまとめてオフにすると、屋内の点がさらに粗くなります。記録系の項目を一つ消すときも、ほかは触らない。**緊急電話およびSOS** はオフにしません。

オンに戻したあと、屋外でマップの現在地をもう一度押す。点が建物に近づけば、補助が足りていなかった状態です。

### 4. 日付と時刻、VPN

1. **設定 → 一般 → 日付と時刻** を開く。**自動設定** をオンにする。手動の日付が未来や過去だと、位置が合わないことがあります。
2. オンにしたらマップに戻り、現在地を押し直す。
3. VPN アプリを切る。マップの青い点は、VPN の出口の都市では決まりません。切っても点が動かないなら、VPN は点のずれの原因ではありません。ブラウザの天気や動画の「地域」だけが別の都市なら、見ているのは VPN の出口です。そのアプリの VPN を切って開き直す。
4. **設定 → 一般 → VPNとデバイス管理** に、自分で入れた覚えの無い構成プロファイルがあれば、仕事用かどうか確認する。仕事用は自分で消さず、管理者に聞く。個人で入れた位置用のプロファイルなら削除し、iPhone を再起動する。

### 5. コンパスを、8の字で合わせる

向きだけが違う、ナビの進行方向が逆、というとき。

1. 磁石の付いた車載ホルダー、スマホリング、分厚い磁気ケースを外す。スピーカーやノート PC の上に置いたまま、方位は見ない。
2. **コンパス** アプリを開く。数字が落ち着くまで、腕を伸ばして空中で8の字に数回動かす。コンパスが入っていないときは、マップで現在地を押したあと、同じように8の字に動かす。
3. 手順3の **コンパスの調整** がオンかも、もう一度見る。
4. ケースを戻した瞬間に矢印がまた狂うなら、そのケースかホルダーです。青い点の位置まで数百メートル飛ぶときは、手順2の **正確な位置情報** を見ます。

金属の机の上だけでおかしい、という再現なら、iPhone の故障ではありません。場所を変えてからもう一度現在地を押す。

### 6. 再起動と、位置情報とプライバシーのリセット

マップの点が、屋外でも建物ひとつ分以上ずれたままのときだけ進みます。

1. 音量ボタンのどちらかとサイドボタンを、電源オフのスライダが出るまで長押しする。オフにして数十秒置き、サイドボタンで起動する。屋外でマップの現在地を押す。
2. まだずれるなら **設定 → 一般 → 転送またはiPhoneをリセット → リセット** を開く。
3. **位置情報とプライバシーをリセット** を選ぶ。パスコードを入れる。写真、アプリ、LINE のトークはこの操作では消えません。位置情報の許可が一度クリアされます。
4. マップを開くと、位置情報の使用を聞き直されます。許可し、**正確な位置情報** をオンに戻す。天気やナビも、次に開いたときに **このアプリの使用中** へ戻す。

リセットの直後は、点が安定するまで屋外で数十秒待ちます。すぐ歩き出すと、古いおおまかな位置のままに見えます。

> **注意:** 同じ画面にある **すべてのコンテンツと設定を消去** は押しません。位置の許可をやり直す項目と、名前が似ています。

## まだ直らないとき

- マップは合う。一個のアプリだけ違う → そのアプリの **正確な位置情報** と、アプリの中の現在地ボタン。再インストールはログインが消えるものがあるので、各公式の説明を先に読む
- 店内だけずれる → Wi-Fi をオンにしたまま使う。衛星だけでは、天井の下の点は粗くなります
- 車の中だけ矢印が逆 → ホルダーの磁石です。ダッシュボードの別の位置に移して、もう一度8の字に動かす
- 落下や画面修理のあとから、点がまったく出ない → 同じリセットを繰り返さない。パスコードでロックを解除して使い、Apple か購入店へ
- 子供の iPhone で位置情報のスイッチがグレー → **設定 → スクリーンタイム → コンテンツとプライバシーの制限** を見る。保護者のパスコードが要ります

## まとめ

先に標準のマップを開きます。アプリだけずれているなら **正確な位置情報**。マップの点もずれているなら、Wi-Fi と Bluetooth をオンにして屋外で待ちます。矢印の向きだけなら、磁石を外して8の字です。
