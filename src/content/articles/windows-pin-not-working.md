サインイン画面で番号を入れても「正しくありません」と戻る。更新のあと「問題が発生したため、PIN を使用できません」と出て、入力欄が消える。パスワードは覚えているのに、鍵の絵がどこにも無い。PIN は Microsoft アカウントのパスワードとは別で、その PC にだけ登録した短い番号です。直す場所は、サインイン画面と **設定** の **PIN (Windows Hello)** だけです。

数字が一つも打てないときは [キーボードが反応しないとき](/articles/windows-keyboard-not-working/) です。メーカーのロゴから先に進まないときは [スタートアップ修復](/articles/windows-startup-repair/) です。

## 症状の見分け

- PIN を入れると「PIN が正しくありません」。続けて外すと、待つように言われる
- 「問題が発生したため、PIN を使用できません。クリックして PIN をもう一度設定してください」
- 入力欄の下に **PIN を忘れた場合** が出ている
- ノートの数字は入る。右側のテンキーだけ反応が無い
- **サインイン オプション** を開いても、パスワードの鍵アイコンが無い
- 別のユーザーは入れる。自分の PIN だけ死んでいる
- 学校や会社のアカウントで、スイッチが灰色、または組織の管理と出る

デスクトップには入れている。ロックからの復帰だけ PIN が拒否される、も同じ画面です。BitLocker の回復キーを求める青い画面は、PIN の入力欄ではありません。

## よくある原因

1. NumLock が消えていて、テンキーが矢印になっている
2. Windows Update のあと、Windows Hello の PIN だけ外れた
3. **PIN を忘れた場合** の途中でネットが切れている。Microsoft アカウントの確認には回線が要る
4. **セキュリティ向上のため、このデバイスでは Microsoft アカウント用に Windows Hello サインインのみを許可する（推奨）** がオンで、パスワードの絵が隠れている
5. ローカル アカウント。この種類には、サインイン画面の **PIN を忘れた場合** が出ない
6. 職場や学校のポリシーで、PIN の作り直しが止められている
7. 短時間に外しすぎて、PIN だけ一時的にロックされた

## 直す前に

- Microsoft アカウントなら、メールアドレスとパスワードを別のスマホで思い出せるか見る。PIN の再設定は、パスワードの代わりにはならない
- サインイン画面の右下に、ネットワークの扇がある。切れていると、再設定のコードが通りません
- 「PIN 解除」「ログインバイパス」と書いた USB や実行ファイルは使わない

> **注意:** レジストリの書き換え、システムフォルダーの削除、コマンドでパスワードを空にする操作は使いません。初期化も案内しません。公式の画面に出る再設定で止まったら、そこで終わりです。

## 手順

### 1. テンキーと、画面の数字を分ける

桁は合っているのに拒否されるとき、右側のテンキーが矢印になっていることがあります。

1. ノート上段の数字と、右側のテンキーを取り違えていないか見る。NumLock のランプが消えていると、8 は上矢印です。ランプが付くキー（NumLock、または Fn と NumLock）を一度押して、もう一度 PIN を入れる。
2. サインイン画面の右下、人型のアイコン（アクセシビリティ）から **スクリーン キーボード** を出し、そこの数字で PIN を入れる。
3. 画面の数字では通って、実物のキーだけダメなら、キーボード側です。PIN は生きています。
4. 何回も外したあとに待ち時間が出たら、表示のとおり置く。連打すると待ちが伸びます。

通ってデスクトップまで出たら、手順4だけ残します。番号を変える必要が無ければ、そこで終えて構いません。

### 2. パスワードの絵に切り替える

PIN の欄は出ている。パスワードは覚えている。そのときは PIN 欄から離れます。

1. PIN 欄の下にある **サインイン オプション** を押す。
2. 鍵の絵が出ていれば、それを押す。入れるのは Microsoft アカウントのパスワードで、PIN ではありません。
3. 絵が PIN しか無いときは、Hello だけを許可する設定がオンです。この画面からパスワードは出せません。手順3へ。
4. パスワードで入れたら、手順4で PIN を作り直します。

パスワードの入力欄で文字がひらがなになるときは、右下の入力モードを英数にします。半角と全角を間違えると、正しいパスワードでも拒否されます。

### 3. 「PIN を忘れた場合」で作り直す

Microsoft アカウント向けの、サインイン画面上の再設定です。ローカル アカウントには、このリンクが出ません。

1. 右下のネットワークがつながっているか見る。切れていたら、知っている Wi-Fi を選ぶ。文字が打てないときは、手順1のスクリーン キーボードです。
2. PIN 欄の下の **PIN を忘れた場合** を押す。「クリックして PIN をもう一度設定してください」と出ているなら、その文を押します。
3. Microsoft アカウントのパスワードを聞かれたら入れる。次に、メール、SMS、認証アプリのどれかでコードが来ます。コードは、この PC 以外のスマホで受け取ります。
4. 通ると、新しい PIN を二回入れます。デスクトップまで出れば、再設定は終わりです。
5. リンクが無く、ローカル アカウントだと分かるときは、パスワードで入る側です。サインイン画面に **パスワードを忘れた場合** があり、アカウント作成時のセキュリティの質問に答えられるなら、そこまでが公式の範囲です。質問もパスワードも無いローカル アカウントは、この先の手順では入れません。

Microsoft アカウントのパスワードも忘れたときは、**サインイン オプション** に **Web サインイン** が出る PC なら、そこから **パスワードを忘れた場合** に進めます。出ないときは、別のスマホや PC のブラウザで、Microsoft アカウントのパスワードリセットを開きます。この PC の中のファイルを書き換えて入る方法は使いません。

コードが来ないときは、迷惑メール、電話番号の桁、画面内の別の確認方法、をその場で切り替えます。届かないまま先へ進む操作はありません。

### 4. 入れたあとに、設定から PIN を登録し直す

すでにデスクトップにいるときです。

1. スタートボタンを右クリック → **設定** → **アカウント** → **サインイン オプション**。
2. **PIN (Windows Hello)** を開く。Windows 10 では **Windows Hello ピン** と出ることがあります。
3. 今の PIN が分かっていて番号だけ変えたいなら **PIN の変更**。古い PIN を聞かれます。
4. 今の PIN が分からない、更新のあと使えなくなった、なら **PIN を忘れた場合**。本人確認のあと、新しい PIN を作ります。
5. **PIN の削除** が灰色のときは、同じページの **追加の設定** まで下り、**セキュリティ向上のため、このデバイスでは Microsoft アカウント用に Windows Hello サインインのみを許可する（推奨）** をオフにする。ページを開き直し、削除が押せるか見る。削除したあとは **PIN のセットアップ**（または追加）から登録し、必要なら先のスイッチをオンに戻します。オフのまま、パスワードでも入れる状態を残しても構いません。
6. 顔認証や指紋も一緒に死んだときは、PIN を作り直したあと、同じ **サインイン オプション** で登録し直します。PIN が無いと、そちらの登録は始まりません。

### 5. 職場の PC と、更新の直後

1. アカウントが学校や会社のメールで、スイッチが灰色、「組織によって管理」と出るなら、個人用の再設定では戻りません。画面の文をそのまま担当に渡します。
2. 大型更新の再起動の直後だけ PIN が死に、パスワードでは入れる、というときは手順4で足ります。更新そのものが途中で止まっているときは [Windows Update が進まないとき](/articles/windows-update-stuck/) です。
3. 起動の途中で回復キーを求める青い画面が出たら、PIN の再設定ではありません。キーは、別の端末で Microsoft アカウントのデバイス一覧から見ます。桁を推測して試す作業はしません。

## まだ直らないとき

- パスワードでは入れる。PIN の再登録だけ毎回「問題が発生しました」で終わる → ネットをつないで手順4をもう一度。それでも同じなら、PC メーカーのサポートです。レジストリは触りません
- Microsoft アカウントのパスワードも、確認用のメールもスマホも手元に無い → 別端末の公式の回復だけです。この PC を書き換えて入る手順は案内しません
- ローカル アカウントで、パスワードもセキュリティの質問も無い → 購入店かメーカー。データを消す初期化は、ここでは書きません
- スクリーン キーボードも実物のキーも死んでいる → [キーボードが反応しないとき](/articles/windows-keyboard-not-working/)

## まとめ

PIN の欄があるなら、テンキーの NumLock とスクリーン キーボードを先に見ます。パスワードの絵があるなら、それで入ってから **設定** の **PIN (Windows Hello)** で作り直します。絵が無いときは、ネットをつないで **PIN を忘れた場合** です。PIN もパスワードも分からないアカウントを、この画面の外から開ける手順はありません。
