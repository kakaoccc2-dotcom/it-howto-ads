`Ctrl` + `Shift` + `Esc` を押しても何も出ない。`Ctrl` + `Alt` + `Del` から選んでも真っ白、または開いた瞬間に **応答なし**。フォルダーが固まる話は [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/)、スタートごと死んでいる話は [スタートメニューとタスクバー](/articles/windows-start-menu-taskbar-broken/) です。こちらは **タスク マネージャー自体** が出ない、固まるとき用です。

## 症状の見分け

- `Ctrl` + `Shift` + `Esc` を押しても、窓も音も無い
- `Ctrl` + `Alt` + `Del` の青い画面で **タスク マネージャー** を押すと、デスクトップに戻ったあと何も無い
- 窓は出るが、プロセス一覧が空のまま、タイトルに **応答なし**
- 「タスク マネージャーは管理者によって無効にされています」とだけ出る
- タスクバーにアイコンが一瞬出て、すぐ消える

Windows 11 のタスクバーを右クリックしても、**タスク マネージャー** の行は出ません。メニューが **タスクバーの設定** だけなら、それが普通です。開き方は `Ctrl` + `Shift` + `Esc` か `Win` + `X` です。

窓が開いて CPU の数字が動くなら、ここで終わりです。出ない、真っ白、応答なし、のときだけ先へ進みます。

## よくある原因

1. 窓が外したモニターや、画面の外に残っている。タスクバーのアイコンだけ点いている
2. 前に開いた `taskmgr.exe` が固まったまま残り、新しい窓を出せない
3. エクスプローラーが止まっていて、スタートや `Win` + `X` からも開けない
4. 会社のポリシー、または入れた「最適化」ツールがタスク マネージャーを止めている
5. セキュリティソフトが `taskmgr.exe` を隔離した
6. 今のユーザーだけ壊れていて、別のアカウントでは開く

## 直す前に

- 保存していない文書は、まだ開けるアプリから先に保存する。このあとサインアウトや再起動をします
- 「タスクマネージャー復活.reg」「taskmgr修復ツール」は入れない。中身を自分で確認できない配布ファイルです
- 会社の PC で「管理者によって無効」と出るなら、個人の操作では戻せないことが多いです

> **注意:** プロセスを終了するときは、自分で起動したアプリの名前だけにします。`System` や見慣れない `Service Host` は終了しないでください。レジストリの配布ファイルで無効化を外す操作は、この記事では使いません。

## 手順

### 1. ショートカット以外の開き方を順に試す

キーボードの組み合わせだけ死んでいることがあります。窓が出た時点で、次の番号には進まないでください。

1. `Ctrl` + `Alt` + `Del` を押し、青い画面の **タスク マネージャー** を押す。デスクトップに戻ってから数秒待つ。
2. それでも無いときは `Win` + `X`。メニューの下のほうに **タスク マネージャー** があれば押す。
3. `Win` + `R` を押し、`taskmgr` と入れて Enter。
4. スタートが生きているなら、スタートに `タスク マネージャー` と入れる。アプリのアイコンが出たら Enter。

成功すると、左に **プロセス** **パフォーマンス** **スタートアップ アプリ** と並んだ窓が出ます。CPU の％が動いていれば、開くことには成功しています。

`Win` + `R` の「ファイル名を指定して実行」自体が出ないときは、タスク マネージャー単体よりシェル側です。先にスタートとタスクバーの記事で、エクスプローラーの再起動まで進めてから、もう一度 `taskmgr` を試してください。

### 2. 開いているのに見えないとき

タスクバーにタスク マネージャーのアイコンが残っているのに、画面のどこにも窓が無い、というパターンです。

1. `Alt` + `Tab` で、タスク マネージャーの縮小画面が出るか見る。出たらそれを選ぶ。
2. タスクバーのそのアイコンを、Shift を押しながら右クリックする。**移動** があれば押す。マウスは動かさず、キーボードの矢印を一回押してからマウスを動かす。画面の端から窓が付いてきます。
3. 外付けモニターを外したあとなら、`Win` + `Shift` + `←` または `→` を数回押す。別画面に残った窓が、今の画面へ戻ります。
4. アイコンを右クリックして **ウィンドウを閉じる** が出るなら、一度閉じてから手順1の `Win` + `R` → `taskmgr` で開き直す。

縮小画面にもタスクバーにも何も無いなら、開いているつもりは外れています。次へ進みます。

### 3. 「応答なし」の窓を一度終わらせる

窓は出るが、CPU やメモリの数字が止まったまま、というときの手順です。

1. タイトルに **応答なし** と出ているなら、十秒だけ待つ。ディスクが忙しい直後は、描画が遅れるだけです。
2. 戻らないときは `Win` + `R` に次を入れて Enter。

```text
taskkill /f /im taskmgr.exe
```

3. 「成功: プロセス "taskmgr.exe" は強制終了されました」と出たら、もう一度 `Win` + `R` → `taskmgr`。
4. 「プロセスが見つかりませんでした」なら、固まった窓はもう残っていません。開き直しでも出ないなら手順4へ。
5. 開き直した **プロセス** に、見慣れない名前が CPU を占有していたら、そのアプリを選んで **タスクの終了**。`System` は終了しない。

`taskkill` は、固まったタスク マネージャー自身を落とすだけです。書類や Windows の設定は消えません。

### 4. 「管理者によって無効」と出たとき

この文面のときは、ショートカットを変えても同じダイアログに戻ります。

1. 画面の文をそのまま読む。「管理者によって無効にされています」なら、Windows が起動を拒否しています。
2. 職場・学校のアカウントで、設定のどこかに **組織によって管理されています** と出るなら、家庭向けのオン操作では戻りません。このダイアログの写真を IT 担当へ渡す。
3. 自分の PC で、最近「高速化」「軽量化」「タスクマネージャーを隠す」系のアプリを入れた覚えがあるなら、**設定 → アプリ → インストールされているアプリ** から、その名前をアンインストールする。再起動してから `taskmgr` を試す。
4. 覚えが無いのに家庭の PC でこの文面だけ出るときは、.reg を検索して入れない。別のローカルユーザーでサインインし、そちらで `Ctrl` + `Shift` + `Esc` が開くかを見る。開くなら今のユーザー側の制限、開かないなら入れたセキュリティや最適化ソフトです。

プロセスの名前だけ見たいなら、タスク マネージャーの代わりにリソース モニターが使えます。`Win` + `R` → `resmon` → Enter。**CPU** タブの一覧に、動いているプログラム名が出ます。ここまで「管理者によって無効」になることは少ないです。

### 5. 再起動と、セキュリティの履歴

1. 保存してから PC を再起動する。サインイン直後に `Ctrl` + `Shift` + `Esc` を押す。
2. 起動直後だけ開いて、数分でまた出なくなるときは、あとから入れた常駐です。**設定 → アプリ → スタートアップ** で、見慣れない「最適化」「ゲームブースター」をオフにする。名前が分からない項目はオフにしない。
3. **Windows セキュリティ** → **ウイルスと脅威の防止** → **保護の履歴** を開く。`taskmgr.exe` や **タスク マネージャー** が隔離されていないか見る。自分で入れた覚えの無い修復ツールと一緒に隔離されているなら、そのツールは戻さず、タスク マネージャーだけ **復元** できるか見る。復元ボタンが無い、または場所が `C:\Windows\System32\taskmgr.exe` 以外なら、ネットから同名ファイルを拾って上書きしない。
4. 別のローカルユーザーを足して試す。設定が開けるなら **アカウント → 他のユーザー → アカウントの追加**。Microsoft アカウントは後回しで、ローカルアカウントでサインインし、同じショートカットを押す。

そちらでは開くなら、Windows 全体ではなく今のプロファイルです。常用アカウントのファイルは `C:\Users\<今の名前>` に残っています。ディスクの初期化はしません。

> **注意:** `System32` の `taskmgr.exe` を削除したり、ダウンロードした同名ファイルで置き換えたりしないでください。無いように見えても、隔離からの復元か、Windows の修復に任せます。

## まだ直らないとき

- フォルダーもスタートも死んでいて、`taskmgr` も `resmon` も出ない → タスク マネージャー単体の話ではありません。スタートとタスクバーの手順のあと、必要ならスタートアップ修復へ
- 青い `Ctrl` + `Alt` + `Del` の画面自体が出ない → キーボードか、画面が完全に固まっています。電源ボタンの長押しで切り、もう一度入れる。毎回すぐ固まるなら、メーカーサポート
- 職場 PC で無効のダイアログだけ → 担当へ。家庭向けのオン手順は通りません
- 別ユーザーでも開かない、保護の履歴にも無い → メーカーサポートか、回復画面の **システムの復元**（復元ポイントがあるとき）。ディスク消去のリセットは、バックアップのあとだけ
- 開くが数字がずっと 100% → 開くことには成功しています。占有しているプロセス名を、その一覧で見てください

## まとめ

出ないときは `Win` + `R` の `taskmgr`、見えないときは別モニターと **移動**、応答なしなら `taskkill` でその窓だけ落として開き直します。「管理者によって無効」は .reg では触らず、会社なら担当、家庭なら入れた最適化ソフトと別ユーザーで分けてください。
