ケーブルを挿しても電池マークが増えない、一晩つないでも数パーセントしか増えない、触るとコネクタが熱い、といった状態はバッテリー交換より先に **充電専用ではないケーブル、ホコリの詰まったポート、PCのUSB端子、機種側の充電制御** で分かることが多いです。一方で、本体が膨らんでいる、液体をかぶった、は自分で無理に続けない判断が先です。

この記事は iPhone（Lightning または USB-C）と、USB-C の Android を対象にします。PC に挿してもデバイスとして出ないときの Windows 側は [USB機器が認識されない](/articles/usb-device-not-recognized/) です。ワイヤレス充電の位置ずれは、有線と切り分ける材料として使います。

## 症状の見分け

- 挿しても通知が出ない、電池アイコンに稲妻が付かない
- 「充電中」と出るが、パーセントが減る、または極端に遅い
- 「このアクセサリは使用できません」「水分が検出されました」と出る
- 特定のケーブルや、特定のコンセントだけ失敗する
- PC の USB につないだときだけ遅い（壁コンセントでは普通）
- 無線充電はできるが、有線だけダメ（またはその逆）
- 充電中に本体が異常に熱い、ケーブルの根本が熱い

無線だけ成功ならポートかケーブル、有線だけ成功ならコイル位置かケース厚です。どの組み合わせでもダメなら、本体側（端子の破損、充電IC、バッテリー）を疑います。

## よくある原因

1. ケーブルが断線しかけ、または **充電はできても通信しない／電力が細い** 安価ケーブル
2. ポートにホコリや糸くずが入り、端子が奥まで当たっていない
3. 5W 相当の古いアダプターや、PC の USB 2.0 ポートで「充電はしているが遅い」
4. iPhone の最適化されたバッテリー充電、Android の充電最適化・保護
5. ケースやホコリで無線充電の位置がずれている
6. 水分検出（iPhone）、ケーブル認証エラー、バッテリー劣化の警告

Bluetooth イヤホンのケースが充電できない話は、スマホ本体とは別です。[iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) でペアリング側を見つつ、ケースは付属ケーブルで単体充電できるか切り分けてください。

## 直す前に

- 純正またはこれまで問題なく使えていたケーブルと、別の充電器を1本でも確保する
- 作業は乾いた机で。ポートに金属ピンや安全ピン、金属の爪楊枝は使わない
- 膨らみ・変形・異臭があるバッテリーは、充電を繰り返さない。電源を切り、販売店またはメーカーへ

> **注意:** 「バッテリーキャリブレーションで完全放電」「急速充電ブースターアプリ」、分解して端子をいじる作業はしないでください。水分が出たあとに米に埋める必要はありません。乾かしてから公式の案内を見てください。ポートを強くこすると端子が折れます。

## 手順

### 1. ケーブル・充電器・差し込み口を入れ替える

1. 今のケーブルを抜き、**別のケーブル** で壁コンセントのアダプターにつなぐ。PC やハブ経由は使わない。
2. アダプターも別のものにする。USB-A の古い5Wと、USB-C の PD（Power Delivery）対応では、対応機種なら速さが変わります。
3. 同じケーブルとアダプターで、**別のスマホ** が普通に充電できるか見る（できるなら、問題は今の端末側）。
4. 逆に、今のスマホが **別のケーブル** で普通に充電できるなら、元のケーブルかアダプターです。

iPhone 15 以降は USB-C、それ以前の多くのモデルは Lightning です。変換アダプターを何段も重ねると失敗しやすいので、端子が一致する一本にします。Android も USB-C 同士のケーブルで、ディスプレイ用の太いケーブルが充電に弱いことがあります。データ通信できるケーブルでも、急速充電の規格（PD、PPS など）は充電器側との組み合わせです。

PC の USB 端子は、充電専用としては遅いのが普通です。「充電中（低速）」に近い表示なら、故障ではなく給電能力の問題です。切り分けが終わったら壁コンセントへ戻してください。

### 2. ポートのホコリを安全に取る

充電プラグが斜めにしか入らない、少し動かすと充電が切れたり入ったりするときに有効です。

1. 電源を切るか、少なくともケーブルを抜く。
2. 明るい場所でポートの中を見る。糸くずや砂が奥に溜まっていることが多いです。
3. **木製またはプラスチックの爪楊枝、柔らかいブラシ** で、端子をこすらずゴミをかき出す。缶スプレーのエアを使う場合は、液が吹き出さない距離で短く。
4. 金属ピン、安全ピン、細いドライバーは使わない。ショートと端子折れの原因になります。
5. 乾いてから、奥までまっすぐ挿し、充電表示を見る。

iPhone で「液体が検出された」と出るときは、無理に乾かそうと熱風を当てず、ポートを下向きにして時間を置き、ケーブルを変えて再試行します。繰り返し警告が出るなら、正規サービスへ。

### 3. 再起動と、充電の最適化を一時的に見る

1. スマホを再起動してから、同じ壁コンセントでもう一度つなぐ。
2. **iPhone:** **設定 → バッテリー → 充電の最適化**（またはバッテリー充電）。最適化がオンでも通常は充電できますが、80% 付近で止まるのは仕様です。満充電したいときだけ、案内に従って一時的にオフにする。
3. **Android:** **設定 → バッテリー** で、充電の最適化・保護、またはメーカーの「バッテリー保護」が 80〜90% で止めていないか見る。遅いのではなく、上限で止まっていることがあります。
4. 省電力モードや、ゲームの高負荷中は充電が増えにくいです。画面をオフにして 20分置き、パーセントが動くか見る。

アプリの「電池修理」「キャリブレーション」は入れないでください。標準のバッテリー画面の情報だけで十分です。

### 4. 無線充電と、別ポートで本体側かを分ける

1. ワイヤレス充電器があるなら、ケースを外して中央に載せ、有線なしでパーセントが増えるか見る。増えるなら、バッテリーと充電ICの一部は生きています。有線だけダメならポートかケーブルに戻る。
2. 無線もなく、有線もすべてのケーブルでダメなら、ポートの物理破損や本体故障の可能性が上がります。
3. USB-C の Android で、イヤホンや USB メモリは認識するのに充電だけ弱いときは、給電対応のケーブルと、充電器のワット数を先に疑う。PC に接続したときの認識そのものは USB 記事へ。

機種によっては、純正に近い認証ケーブル以外で「このアクセサリは使用できません」と出ます。別の認証済みケーブルで消えれば、ケーブル側です。消えなければ、ポート汚れか本体です。

### 5. 熱と、これ以上充電しない判断

1. 充電中に本体背面が熱すぎて持てない、ケーブルの根本が変形する → その組み合わせを使わない。別のケーブルとアダプターに切り替える。
2. バッテリーが膨らんで画面との間に隙間がある、ケースが閉じない → 充電を止め、電源を切る。膨張は発火のリスクがあります。自分で剥がさない。
3. 水没直後は電源を入れず、ポートを下向きに置き、メーカーの案内または修理窓口へ。

## まだ直らないとき

- どのケーブルでも稲妻が付かない、無線も不可 → 正規の修理。保証と水濡れの有無を伝える。自分でバッテリーを通販交換するのは、膨張や認証の面で家庭向けではありません
- 特定の急速充電器だけ失敗する → 機種がその規格（PPS など）に対応していないことがあります。付属またはメーカー推奨ワットのアダプターに戻す
- 車のシガーソケットだけ失敗する → 車側の出力不足や、振動で接触不良。家庭の壁コンセントで問題なければスマホ側は生きています
- 充電はできるが電池の減りが極端に速い → バッテリー劣化の目安です。iPhone は **設定 → バッテリー → バッテリーの状態**、Android はメーカーの診断。充電ケーブルの切り分けとは別問題です
- Windows に USB でつないでも充電も認識もしない → スマホ側手順のあと、PC 側は USB 記事。ケーブルが充電専用だと、充電はできてもデータは出ません
