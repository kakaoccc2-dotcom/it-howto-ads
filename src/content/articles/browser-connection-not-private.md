「接続がプライベートではありません」「この接続ではプライバシーが保護されません」は、回線が切れたときとは別です。時計がずれているか、今の Wi-Fi が割り込んでいることが多いので、警告を押して進む前にそこを見てください。

## 症状の見分け

- Chrome や Edge が赤い三角や錠の斜線で止まり、`NET::ERR_CERT_DATE_INVALID` や `NET::ERR_CERT_AUTHORITY_INVALID` と出る
- 自宅では普通なのに、カフェ・ホテル・駅の Wi-Fi だけ出る
- 家族のスマホのモバイルデータでは、同じサイトが普通に開く
- どの https サイトも同じ警告になる（時計や回線側の疑いが強い）
- 小さな店のサイトや、自作の機器設定画面（ルーター管理ページ）だけ出る

名前解決で止まる「DNSサーバーに問題があります」は、この画面とは別です。先に [DNS の手順](/articles/windows-dns-server-problem/) です。Wi-Fi はつながっているのに何も開けないときは [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) が先です。

## よくある原因

1. PC やスマホの **日付と時刻** がずれていて、証明書の有効期間と食い違う
2. 公衆無線LANのログイン前や、ホテルの割り込みページを https で開いてしまっている
3. セキュリティソフトの「HTTPS スキャン」が、途中で証明書を差し替えている
4. サイト側の証明書切れ、または名前の取り違え（似た別ドメイン）
5. 本当に危ない改ざんや、偽の無料 Wi-Fi（ログインや銀行では特に）

## 直す前に

- 開こうとしていたのが **銀行、カード、役所、メール、店のログイン** なら、警告を閉じて、別の回線（スマホのモバイルデータ）で開き直す。進むボタンは押さない
- スマホのモバイルデータで、同じアドレスが警告なしで開くか見る
- 「証明書無視ツール」「SSL 解除パック」は入れない

> **注意:** 「詳細設定 → 〇〇へ移動する（安全ではありません）」は、家のルーター設定画面など、自分が何を開いているか分かっているとき以外は使いません。銀行やログインでは押さないでください。警告を消す拡張機能も不要です。

## 手順

### 1. 日付と時刻を自動にする

電池切れのあとや、長期間スリープした PC で日付がずれます。

1. Windows 11 なら **設定** → **時刻および言語** → **日付と時刻**。Windows 10 も同じ名前です。
2. **時刻を自動的に設定する** と **タイムゾーンを自動的に設定する** をオン。オフのまま昔の日付だと、ほとんどの https が日付エラーになります。
3. オンなのに年が違うときは、いったんオフ→正しい日付を手で入れて→またオン。
4. ブラウザを完全に閉じて開き直し、同じサイトを試す。エラー文に `ERR_CERT_DATE_INVALID` とあれば、ここが本命です。

iPhone で同じ警告なら **設定 → 一般 → 日付と時刻** の自動設定をオン。Android は **設定 → 日付と時刻**（機種により **システム** の下）です。

### 2. どのサイトか、どの回線かを分ける

1. アドレス欄のドメインをよく見る。銀行なのに見慣れない英語や、1文字違う名前なら、警告どおり閉じて公式アプリか、自分で打ち直した公式 URL だけ使う。
2. 同じ PC で、普段使っている別の https（検索やこのサイト）も警告になるか見る。全部ダメなら時計か回線。一サイトだけなら、そのサイト側か、名前の取り違えです。
3. スマホを **モバイルデータ** にして、同じアドレスを開く。モバイルだけ普通なら、今の Wi-Fi 側です。
4. カフェやホテルなら、ブラウザで `http://neverssl.com` や、通知の「Wi-Fi にログイン」を先に開く。利用規約に同意する前の割り込みが、証明書エラーに見えることがあります。

家中の端末が同じサイトだけダメなら、サイト側の証明書切れです。自分では直せないので、公式の別連絡手段を待つか、モバイルデータで公式アプリを使います。

### 3. 別ブラウザ、ゲスト、別のネットワーク

1. Edge で出るなら Chrome、その逆も試す。片方だけなら、そのブラウザの拡張や、セキュア DNS の食い違いです。
2. Edge なら **新しい InPrivate ウィンドウ**、Chrome なら **シークレット**。拡張を切った状態で同じです。
3. 自宅 Wi-Fi をいったん忘れ、スマホのテザリングで開く。テザリングで消えるなら、家のルーターか、その SSID の保存設定です。
4. 会社 VPN を切ると消える／つなぐと再現するなら、VPN 側の検査です。家庭向けの設定では終わらないので、担当へエラー全文を渡します。

片方のブラウザだけ、かつ銀行以外のサイトなら、拡張を全部オフにして再現するか見てください。直るなら、証明書を書き換える系の拡張が残っています。

### 4. セキュリティソフトの HTTPS 検査（家庭向け）

1. 使っているセキュリティソフトに **HTTPS スキャン**、**SSL 検査**、**ウェブ保護** があれば、公式の案内どおり **一時停止** して同じサイトを開く。
2. 一時停止で消えるなら、ソフトをアンインストールせず、公式の「除外」または「HTTPS 検査をオフ」を使う。止めっぱなしにはしない。
3. Windows 標準の **Windows セキュリティ** だけ、という人は、ここをいじる必要はほとんどありません。

一時停止しても銀行で警告が残るなら、ソフトではなく、そのサイトか回線です。進むボタンは、それでも押さないでください。

### 5. 時計を直したあとも、同じサイトだけ残るとき

日付を直した直後だけ、以前の失敗をブラウザが覚えていることがあります。

1. そのタブを閉じ、ブラウザを完全終了して開き直す。古い警告のまま残っているだけなら、ここで消えます。
2. まだ同じドメインだけダメで、**モバイルデータでは警告なし**のときに限る。開いているのが自分のテストサイトや、自分で入れた機器の画面など、中身が分かっているときだけ次へ進む。
3. Chrome のアドレス欄に、HSTS（このサイトは https だと以前覚えた記録）の削除画面 `chrome://net-internals/#hsts` を入れる。**Delete domain security policies** にそのドメインだけを入れて削除する。Edge は `edge://net-internals/#hsts`。
4. 銀行、カード、メール、店のログインでは、この削除をしない。別回線で公式アプリか、電話連絡にしてください。

HSTS の削除は「警告を無視して進む」ではありません。時計や回線を直したあと、古い記録だけを消す操作です。ドメインを間違えると別のサイトの記録も消えるので、入力は一度見直してください。

## まだ直らないとき

- `ERR_CERT_DATE_INVALID` が残る → 手順1のあとに再起動。BIOS の時計はいじらず、Windows の日付が合っているかをもう一度見る
- 公衆 Wi-Fi だけ → ログインページを先に出す。どうしても必要なログインは、その場の Wi-Fi ではせずモバイルデータへ切り替える
- 自宅のルーター管理画面（`192.168.0.1` など）だけ → 名前の証明書が無い機器では、この警告が出ます
- その画面へ進むか → お気に入りや自分で打った番号から開いていて、家のルーターだと分かっているときだけ。インターネット上の銀行では、この判断は使わない
- 番号では開くが名前だけおかしい → [DNS の手順](/articles/windows-dns-server-problem/)
- 職場や学校のネットワーク → 個人の例外追加が禁止されていることがあります。IT 担当へ、エラーコードとアドレス欄のスクリーンショットを渡す

## まとめ

日付が合っているか、今つながっている回線かを先に見てください。銀行やログインの警告は、進むより別の回線で開き直すほうが安全です。
