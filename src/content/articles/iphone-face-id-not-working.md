ロック画面で顔を向けても鍵が開かない。何回か失敗したあと、パスコードだけ聞かれる。「Face IDを利用できません」と出て、セットアップの円が終わらない。ホームボタンで指紋を使う機種（Touch ID）は対象外です。カメラアプリの映像が真っ黒なときは [カメラが真っ暗なときの手順](/articles/iphone-camera-black-screen/) です。顔認証のセンサーは、インカメラとは別です。

## 症状の見分け

- 顔を向けてもロックが解除されない。パスコードを入れると中には入れる
- 暗い部屋、寝転がったとき、サングラスやマスクのときだけ失敗する
- 画面を正面から見ていないと失敗し、目を合わせると開く
- Apple Pay や App Store の認証だけ失敗し、ロック解除は通る（またはその逆）
- セットアップで顔をゆっくり回しても、「Face IDを利用できません」で止まる
- 落としたあと、画面を交換したあとから、急に項目自体が使えなくなった
- 朝と夜で通り方が違う。メガネや髪型を変えた週から失敗が増えた

パスコードも覚えていないときは、この記事の作業に入れません。Face ID のリセットにもパスコードが要ります。端末の消去はここでは行いません。

## よくある原因

1. 画面上部（ノッチや Dynamic Island のまわり）の汚れ、保護フィルムの気泡、厚いケースの縁がセンサーを覆っている
2. **iPhoneのロックを解除** など、用途ごとのスイッチがオフ
3. **画面注視が必要な機能** がオンで、サングラスや視線がずれると拒否される
4. マスク、メガネ、ひげ、髪型の変化で、登録した顔と差が出ている
5. iOS の一時的な不具合。再起動で戻ることがある
6. 落下や画面修理のあと、顔認証のセンサーが無効になっている

## 直す前に

- パスコードは分かる状態で始める。作業の途中で Face ID をリセットすると、登録し直すまでロック解除はパスコードだけになります
- 「Face ID 修復」や、プロファイルを入れる顔認証アプリは入れない
- 画面が割れて液が見える、水に落とした直後なら、拭く前に電源を切る。濡れたまま充電しない

> **注意:** この記事では「iPhoneを消去」、リカバリモードからの復元、脱獄は使いません。Face ID のリセットは端末の中身を消しませんが、パスコードを忘れると別問題になります。

## 手順

### 1. 画面上部を隠しているものを外す

1. 本体を顔の高さに持ち、明るい室内で、ロック画面を正面から見る。布団の中、逆光、カメラ側に指がかかった状態は失敗しやすいです。
2. ノッチ、または Dynamic Island のまわりを、乾いた柔らかい布で軽く拭く。ティッシュを強くこする、液体を直接かける、はしない。
3. 保護フィルムの端が上部にかぶさっている、気泡がセンサーの前にある、ならフィルムを剥がしてからもう一度顔を向ける。
4. ケースを外す。縁が厚いハードケースは、上部のセンサーだけを覆っていることがあります。外した状態でロックが開けば、ケースかフィルムです。
5. インカメラ（画面側）が真っ黒かどうかは、カメラアプリで切り替えると分かります。顔認証のセンサーはインカメラとは別ですが、落としたあとに両方使えなくなることはあります。映像が黒いだけならカメラの記事です。

正面、ケースなし、でパスコードなしに開いたなら、登録を消す前に様子を見ます。

### 2. ロック解除と、使う場面のスイッチを見る

1. **設定 → Face IDとパスコード** を開き、パスコードを入れる。
2. **iPhoneのロックを解除** がオフならオン。ロックだけ失敗しているのに、店の決済は通る、というときはここがオフです。
3. 失敗しているのが支払いなら **Apple Pay**、アプリのインストールや購入なら **iTunes StoreとApp Store**、パスワード欄なら **パスワードの自動入力** を見る。全部をオンにする必要はありません。今失敗している用途だけオンです。
4. マスクで失敗するなら、同じ画面の **マスクを着用したFace ID** を見る。出るのは対応機種だけです。項目が無い iPhone は、マスク中の顔認証に対応していません。パスコードで解除します。
5. **もう一つの容姿を設定** で、メガネをかけた顔、または今の髪型を追加する。登録は一つ余分に持てます。かけたり外したりするメガネで失敗が分かれているときは、両方の状態を残す方が、リセットより先です。

スイッチをオンにしたあと、一度サイドボタンで画面を消し、ロック画面でもう一度顔を向けます。設定アプリの中だけでは、ロック解除の成否は分かりません。

### 3. 注視を切って、見ているのに拒否されるかを分ける

サングラス、色の薄い目、画面を少し斜めから見る、で失敗が偏るときに有効です。

1. **設定 → アクセシビリティ → Face IDと注視** を開く。
2. **画面注視が必要な機能** をオフにして、ロック画面で顔を向ける。オフにすると、画面を見ていなくても解除されます。開いたなら、目線やサングラスで拒否されていました。スイッチは、サングラスを使うあいだだけオフにします。オフにしても開かないなら、オンに戻して手順4へ。
3. 隣にある **画面注視認識機能** は、見ているあいだ画面が消えにくい、通知の中身を出す、という側です。ロックが開かない原因とは別です。ここをオフにしても、認識そのものは戻りません。

注視をオフにしても、正面から見て失敗するなら、登録側かセンサー側です。手順4へ。

### 4. 再起動して、パスコードのあとに顔を向けたままにする

1. 音量ボタンのどちらかとサイドボタンを、電源オフのスライダが出るまで長押しする。オフにして、数十秒置く。サイドボタンで起動する。
2. ロック画面で顔を向ける。失敗したら、画面を見たままパスコードを入れる。失敗の直後にパスコードで開けると、そのときの顔を追加で覚えることがあります。顔をそらしてからパスコードだけ入れると、この追加は起きません。
3. それでも当日中に何度も失敗するなら、手順5で登録を作り直す。
4. **設定 → 一般 → ソフトウェアアップデート** に更新が残っていて、Face ID の不具合がその版で続いているなら、空きを見てから入れる。空きが足りず更新できないときは [ストレージ不足の手順](/articles/iphone-storage-full/) です。

通常のオフでは戻らず、画面は付くが Face ID の項目だけおかしいときは、強制再起動を一度だけします。音量を上げるボタンを押してすぐ離し、音量を下げるボタンを押してすぐ離し、サイドボタンを Apple ロゴが出るまで押し続けます。中のデータは消えません。ロゴが出る前に指を離すと、ただ再起動が途中で止まります。

### 5. Face IDをリセットして、セットアップをやり直す

登録を消します。写真やアプリは残ります。終わるまでロックはパスコードです。

1. **設定 → Face IDとパスコード → Face IDをリセット**。
2. **Face IDをセットアップ** を押す。円の中で顔をゆっくり回す。マスクとサングラスは外す。画面は顔の高さ、部屋は明るくする。
3. メガネを常用するなら、案内に **メガネをかけた状態** が出たら、それに従ってもう一周する。出なければ、セットアップ後に **もう一つの容姿を設定** でメガネありを追加する。
4. 完了したらサイドボタンで画面を消し、ロックが顔で開くか見る。Apple Pay を使う人は、店の前ではなく、設定のスイッチがオンに戻っているかを先に見る。

セットアップを始めた瞬間に「Face IDを利用できません」、円がまったく進まない、落下や画面交換のあとからそうなった、なら同じリセットを繰り返さない。パスコードでロックを解除して使い、Apple サポートか購入店へ。センサー側のときは、設定のやり直しでは戻りません。

> **注意:** **すべての設定をリセット** や **iPhoneを消去** は、壁紙や Wi-Fi パスワード、中身に影響します。顔が通らないだけの切り分けでは押しません。

## まだ直らないとき

- メガネを外したときだけ通る → もう一つの容姿に、かけた状態を追加する。リセットはまだ先でよい
- マスクのときだけ失敗し、マスクの項目が設定に無い → その機種は非対応です。マスクを外すか、パスコードを使う
- 修理に出したあと、落として画面の端が浮いたあとから「利用できません」 → ハードウェアです。保証と、修理店が Face ID の動作確認をしたかを聞く
- パスコードを忘れた → Face ID の記事では戻せません。消去になる手順は、Apple の案内に任せる
- 仕事用の構成プロファイルで Face ID が禁止 → **設定 → 一般 → VPNとデバイス管理** にプロファイルがあります。自分で消さず、管理者にロック解除の可否を確認する

## まとめ

ケースとフィルムを外し、正面の明るい場所で、**iPhoneのロックを解除** がオンかを見ます。視線やサングラスで偏るなら注視を一度オフ。それでもダメなときだけ Face ID をリセットして登録し直してください。セットアップの時点で「利用できません」と出る端末は、繰り返し消さず修理の判断です。
