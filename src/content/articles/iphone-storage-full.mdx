「iPhoneのストレージ残量が不足しています」、写真が撮れない、アプリが更新できない、という状態は、本体故障より **写真と動画、使っていないアプリ、LINE やメッセージの添付、最近削除した項目が残っている** ことが多いです。PC の C ドライブ掃除と同じで、システムを削るより、内訳を見てから大きいものを移す／消すほうが安全です。Windows 側の片付けは [ストレージ不足の手順](/articles/windows-storage-full/) です。

この記事は iPhone（最近の iOS）の標準画面を対象にします。「容量不足」系のクリーナーアプリは使いません。iCloud の有料枠を急いで買う前に、本体の内訳を見てください。

## 症状の見分け

- 設定の先頭やカメラに、ストレージ不足の警告が出る
- 写真が撮れない、または撮影直後に保存できない
- App Store の更新・ダウンロードが容量エラーで止まる
- iOS の更新が「空き容量が足りません」で止まる
- ストレージの内訳で **写真** か **アプリ** が極端に大きい
- ファイルを消したつもりなのに、空きがほとんど増えない（最近削除が残っている）

空きが数GBあるのに特定アプリだけ保存できないときは、そのアプリのキャッシュや権限のことがあり、この記事の一括削除では足りないことがあります。

## よくある原因

1. 4K 動画や連写、スクリーンショットが **写真** に溜まっている
2. 使っていないゲームや、一度入れた大型アプリが残っている
3. **最近削除した項目** が 30日間残って、空きに戻っていない
4. LINE のトーク画像・動画、メッセージの添付がアプリ容量を食っている
5. iCloud 写真が「オリジナルをこの iPhone に残す」になっていて、フルサイズが本体にある
6. 使っていない App の「取り除く」ではなく、キャッシュ付きのまま残っている

## 直す前に

- 残したい写真・動画があるか、アルバムをざっと見る。消す前に iCloud か PC か外付けへコピーする
- iCloud 写真をオンにしている場合、本体からフルサイズを外しても、クラウド側に残るか（最適化）を先に理解する。ネットが無い場所で必要な写真は、先にダウンロードしておく
- 会社支給の iPhone なら、業務アプリを個人の判断で消さない

> **注意:** 「iPhone クリーナー」「メモリ解放」を名乗る出自不明のアプリは入れないでください。写真へのアクセスを広く求め、消したつもりが別の場所に残る、または個人情報を渡すことがあります。標準の **設定 → 一般 → iPhoneストレージ** で十分です。初期化はこの記事の対象外です。

## 手順

### 1. 内訳を見て、何が大きいか決める

1. **設定** → **一般** → **iPhoneストレージ**。読み込みに数十秒かかることがあります。
2. 上のグラフで **写真**、**アプリ**、**システムデータ**、**iOS** の割合を見る。
3. 一覧はサイズ順です。写真が過半なら手順2、特定アプリが数GBなら手順4、メッセージや LINE なら手順5です。

システムデータは iOS が一時ファイルに使う領域で、直接は消せません。写真とアプリを減らすと、あとから縮むことがあります。ここを「システム削除アプリ」で触らないでください。

### 2. 写真と動画を先に移す／最適化する

1. **写真** アプリで、明らかに大きいもの（長時間の 4K、スクリーン録画）を選び、残すなら PC や外付けへ書き出す。AirDrop や USB-C のストレージ、Mac の Finder / Windows の写真アプリが使えます。
2. **設定** → 自分の名前 → **iCloud** → **写真**。すでに iCloud 写真を使っているなら **iPhoneのストレージを最適化** にする。オリジナルは iCloud に残り、本体は縮小版になります。Wi-Fi でのアップロードが終わるまで、電源と空きを確保してください。
3. iCloud を使わない場合は、移し終えた写真だけをアルバムから削除する。削除しただけでは空きに戻らないので、次の手順3が必要です。
4. 重複やスクリーンショットが多いときは、写真アプリのユーティリティ（機種・iOS により「重複項目」）で、残すほうを確認してからまとめて消します。

カメラが保存に失敗しているときだけ、一時的に不要な動画を消して空きを数GB作り、そのあとで整理しても間に合います。充電が不安定なケーブルで PC へ移すときは、途中で切れないよう [充電の切り分け](/articles/smartphone-charging-slow/) も見てください。

### 3. 「最近削除した項目」を空にする

1. **写真** → **アルバム** → **最近削除した項目**（または削除済み）。
2. 残したいものが混ざっていないか見る。問題なければ **削除**（すべて削除）。
3. **設定 → 一般 → iPhoneストレージ** に戻り、写真のサイズが減ったか確認する。

ここを空にしないと、削除した動画が最大 30日分、容量を食ったままです。

### 4. 使っていないアプリを取り除く／削除する

1. 同じ **iPhoneストレージ** の一覧で、何ヶ月も開いていないゲームや試用アプリを選ぶ。
2. **Appを取り除く** は、アイコンは残り、本体のデータは消えて再ダウンロードが必要です。書類をアプリ内にだけ置いているものは、取り除く前に書き出します。
3. 完全に不要なら **Appを削除**。ホーム画面からアイコンを消しただけでは、オフロードされず残ることがあります。必ずストレージ画面か、長押し → 削除で確認します。
4. 設定の **App Store**（または App の設定）に **使用していないAppを取り除く** があれば、容量が逼迫したとき用にオンにできます。自動で消えて困るアプリは、先にオフにしておきます。

銀行・認証アプリは、削除すると再登録が必要です。容量が大きくても、安易に消さないでください。

### 5. LINE・メッセージ・Safari の中身を減らす

1. **iPhoneストレージ** で **LINE** が大きいときは、LINE 内の **トーク** → 対象トーク → 変更 → **アルバム・動画** から大きいファイルを消す。キャッシュ削除の項目がある版では、トーク履歴が消えないか説明を読んでから実行します。
2. **メッセージ** が大きいときは、設定の **メッセージ** で古い会話の添付を見直す。必要なら **メッセージを自動的に削除**（30日 / 1年）を、今後の分だけ検討する。既存の添付は会話を開いて消します。
3. Safari は **設定 → Safari → 履歴とWebサイトデータを削除** でキャッシュを捨てられます。保存したパスワードまでは消えませんが、開いていたタブの状態は消えます。
4. **ファイル** アプリの **このiPhone内** に、古い ZIP や動画が無いか見る。メールの添付を「ファイルに保存」したままのことが多いです。

Bluetooth イヤホンの容量はこの記事の対象外です。接続の不調は [iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) です。

## まだ直らないとき

- 写真を消してもグラフがすぐ戻る → 最近削除が残っている、または iCloud 写真がフルサイズを再ダウンロードしている。「最適化」になっているか、Wi-Fi で同期が終わったかを見る
- システムデータだけが異常に大きい → 再起動を一度試す。数日使って縮まなければ、iOS の再インストールやサポートへ。自分でフォルダを削る手段はありません
- iOS の更新だけ容量不足 → 不要アプリを取り除き、写真を最適化してから、更新を Wi-Fi と十分な充電でやり直す。パソコン経由の更新が使える場合は、本体空きが少なくても通ることがあります
- クリーナーアプリを入れてからおかしくなった → そのアプリを削除し、写真の許可を見直す。写真ライブラリの「非表示」に入っていないか、最近削除も見る
- 本体が熱い・充電もおかしい・膨らんでいる → 容量の話ではなくハードウェアです。片付けを急がず、販売店や Apple のサポートへ

## まとめ

iPhone の容量不足の多くは、システムを削る話ではなく **写真と最近削除、使っていないアプリ、トークの添付** です。ストレージ画面の内訳を見てから、残したい写真を移して最適化し、最近削除を空にする。クリーナーより標準画面のほうが、何が消えたかわかります。
