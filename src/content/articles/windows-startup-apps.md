電源を入れたら、使っていないアプリが次々と開く。見る場所は設定、タスクマネージャー、スタートアップフォルダーの3つです。名前がわからない項目は消さないでください。

## 症状の見分け

- サインイン後、ブラウザやチャットが自分で開く
- 右下に、何年も使っていないソフトの常駐が増える
- 特定のアプリだけ、入れ直すたびにまた開く
- パスワードを入れた直後だけ、更新ツールや「セットアップを完了」の窓が前面に出る
- 自分のアカウントでは開くが、家族の別アカウントでは開かない

自分のアカウントだけなら、そのユーザーのスタートアップです。どのアカウントでも同じ窓なら、全ユーザー向けのフォルダーか、会社のポリシーを疑います。

## よくある原因

1. アプリ内の「Windows にログオンしたときに起動」がオン
2. **設定 → アプリ → スタートアップ** のトグルがオン
3. `shell:startup` フォルダーにショートカットが置いてある
4. タスク スケジューラに、ログオン時のタスクが残っている（メーカーのサポートツールでよくある）
5. ブラウザが「前回のウィンドウを開く」になっていて、スタートアップとは別原因

ネットワークが上がる前に常駐ソフトが名前解決して失敗し、あとからエラーになることもあります。起動そのものより通信が怪しいときは [DNS の手順](/articles/windows-dns-server-problem/) も見てください。

## 直す前に

- 残したいアプリ（セキュリティ、バックアップ、GPU コントロール）の名前を紙に書く
- 仕事用のチャットやメールを起動時に出したいなら、それだけはオンのままにする
- 会社PCなら、強制スタートアップはグループポリシーのことがあります。個人の設定だけでは消えません

> **注意:** 「スタートアップクリーナー」「1クリック最適化」系は、一緒に別の常駐まで消して元に戻せなくなることがあります。標準画面だけで十分です。

## 手順

### 1. 設定のスタートアップを見る（いちばん多い）

1. **設定** → **アプリ** → **スタートアップ**。
2. 一覧の「影響」が大きいものから、不要なアプリのトグルをオフ。
3. 名前がわからないものは検索せず、いったん残す。オフにして起動が壊れたら、同じ画面でオンに戻せます。

Windows 11 では、アプリ側の設定とこの一覧が連動するものと、しないものがあります。オフにしてもまた開くなら手順2へ。

**ここで失敗したとき:** 「スタートアップ」の項目自体が無い、または一覧が空でくるくるだけ、なら版が古い Windows 10 のことがあります。そのときは手順2のタスク マネージャーが本体です。「影響: 測定していません」のままなら、一度普通に再起動してから同じ画面を開き直します。トグルをオフにしても次のサインインでオンに戻る項目は、アプリ本体の「ログイン時に起動」が上書きしています。アプリを開いて、そのスイッチを先に切ってください。

### 2. タスクマネージャーからも確認する

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー** を開く。
2. **スタートアップ アプリ** を開く。
3. 不要な項目を選んで **無効にする**。

ここには、設定アプリより細かいメーカーツールが出ることがあります。`Update Helper` のような名前は、親アプリ（Adobe、ゲームランチャーなど）の一部です。親を使っているなら無効にしても、また有効化されることがあります。その場合は親アプリの環境設定で「起動時に実行」を探します。

**ここで失敗したとき:** タスク マネージャー自体が開かないときは [タスク マネージャーが開かないとき](/articles/windows-task-manager-wont-open/) です。タブ名は Windows 11 だと **スタートアップ アプリ**、Windows 10 だと **スタートアップ** です。片方だけ見て「無い」と決めないでください。右クリックの **無効にする** が灰色なら、その項目は別の管理者か会社のポリシーです。家庭用で灰色なら、そのアプリを一度終了してから同じ行をもう一度選んでください。

### 3. スタートアップフォルダーを空にする

古いソフトがショートカットを置く場所です。

1. `Windows` キー + `R` でファイル名を指定して実行を開く。
2. `shell:startup` と入力して Enter。
3. 不要なショートカットを削除する（アプリ本体は消えません。起動時の呼び出しだけ消えます）。
4. 全ユーザー向けに入っている場合は、同じダイアログで `shell:common startup` も見る。こちらは管理者権限が必要なことがあります。

**ここで失敗したとき:** フォルダーが開かない、または「アクセスが拒否されました」なら、入力が全角になっていないか、`shell:common startup` を管理者なしで開いていないかを見ます。個人用は `shell:startup` だけで足ります。中が空なのにアプリが開くなら、原因はフォルダーではありません。手順1に戻ってください。ショートカットを消したあとも同じ窓が出るなら、設定かスケジューラ側です。

### 4. ブラウザが「前回のタブを全部開いている」だけではないか

スタートアップ一覧にブラウザがなくても、前回クラッシュ扱いでウィンドウが復元することがあります。

- Chrome / Edge: 設定の起動時オプションを **新しいタブページを開く** にする
- 復元ダイアログが出たら、不要なら閉じる

Edge なら **設定 → スタート、ホーム、新規タブ** の「Microsoft Edge の起動時」です。Chrome は **設定 → 起動時**。ここが「前回開いていたページを開く」だと、スタートアップを全部オフにしても窓は出ます。

アプリが起動すらせず互換性エラーになる場合は、スタートアップ以前の問題です。[実行できませんエラー](/articles/windows-app-cannot-run/) を先にどうぞ。

## サインイン直後に画面が埋まるとき

ブラウザとチャットが重なって、トグルを押せないときだけセーフモードを使います。BIOS の項目は触りません。

1. **設定** → **システム** → **回復**。
2. **PC の起動をカスタマイズする** の **今すぐ再起動**。
3. 青い画面で **トラブルシューティング** → **詳細オプション** → **スタートアップ設定** → **再起動**。
4. 再起動後の番号一覧で **4**（セーフモード）。キーボードが無反応なら **F4**。
5. セーフモードでは多くの常駐が止まります。手順1で不要なトグルをオフにしてから、普通に再起動する。

**ここで失敗したとき:** 「スタートアップ設定」が青い画面に無い、回復環境に入れない、というときは同じ操作を繰り返さないでください。家庭用ならメーカーの起動案内、職場PCなら IT 担当です。電源ボタンの長押しを何度も続けると、開いている文書が壊れます。作業は先に保存してください。

セーフモードでも同じアプリが開くなら、スタートアップではなく「前回のウィンドウを復元」です。手順4を見てください。

## 職場PCと、Windows 10 / 11 の違い

職場または学校アカウントで、トグルが灰色、またはオフにしても翌朝オン、ならグループポリシーです。個人の手順では消えません。項目名と「無効にできない」画面を、IT 担当へ渡してください。

Windows 11 の設定アプリの一覧と、Windows 10 のタスク マネージャーの「スタートアップ」は、載る項目が完全には同じではありません。片方だけオフにして「まだ開く」ときは、もう片方にも同じ名前が無いか見てください。

OneDrive やメーカーの更新ツールがサインインのたびに窓を出すときは、スタートアップを切るより、そのアプリの中の「起動時に開く」を切ったほうが再発しません。同期そのものが止まった話は [OneDrive が同期しないとき](/articles/windows-onedrive-not-syncing/)、更新の％が動かない話は [Windows Update が進まない手順](/articles/windows-update-stuck/) です。

## まだ直らないとき

- **タスク スケジューラ**（タスクの作成結果を確認する画面）で、ログオン時・スタートアップ時のタスク名に見知らぬ発行者がないか見る。わからないタスクは無効にせず、名前を検索してからにする。状態が「準備完了」でトリガーが「ログオン時」なら、その行が朝の窓の正体です
- スタートアップに無いのにウィンドウが出る → そのアプリの「ログイン時に開く」をアプリ内で探す（OneDrive、チャット、クリップボードツールに多い）
- サインイン直後だけ重い → スタートアップを減らしつつ、タスク マネージャーの使用率は [動作が遅いときの手順](/articles/windows-pc-running-slow/) で見ます。エクスプローラーだけ固まるなら [応答なしの手順](/articles/windows-explorer-not-responding/) です。ディスクが HDD なら、常駐をゼロにしても起動そのものは遅く残ります
- 周辺機器のユーティリティ（プリンター、マウス）が原因で起動が長いときは、[プリンターのオフライン手順](/articles/printer-offline/) の入れ直しと同じく、公式ドライバー1本に揃える
- 新しいユーザーでサインインすると開かない → 今のユーザーのスタートアップだけが汚れています。手順1〜3をそのユーザーでやり直したあと、普段のアカウントへ戻る
- 無効にした翌日から同じ名前が「有効」に戻る → アプリの更新か、会社の管理です。更新ならアプリ内設定、管理なら IT
- スタートアップは空なのに、右下の矢印に常駐が増える → サインイン時ではなく、アプリを一度開いたあとの常駐です。終了してもすぐ戻るか見てください

## まとめ

設定のスタートアップから見て、わからない項目は消さないでください。ブラウザの「前回のウィンドウを開く」だけ、ということもあります。
