写真を開いたら見知らぬ画像ビューア。PDFがメモになる。`.docx` なのにワードパッド。アプリが起動エラーで落ちる場合は、開き方ではなく実行側です。

## 症状の見分け

- 同じ種類のファイルをどれも、意図しないアプリで開く
- アイコンが変わった（白い用紙、見知らぬロゴ）
- 右クリック → **プログラムから開く** に、使いたいアプリが無い
- Store や新規インストールのあとから、全部そのアプリ経由になる
- 「このファイルを開く方法を選んでください」が毎回出る
- メールの添付やダウンロードだけ失敗し、元フォルダーの同種ファイルは普通
- アイコンは正しいのに、開くと「このアプリでは開けません」と中身を拒否される

同じ拡張子が全部おかしい → 既定のアプリ。1個だけ → そのファイルの破損か、名前の末尾。デスクトップのアイコンだけ消えて、ファイルは開けるなら [デスクトップのアイコンが無いとき](/articles/windows-desktop-icons-missing/) です。

## よくある原因

1. 新しいアプリの初回起動で、「既定にする」を押してしまった
2. **設定 → アプリ → 既定のアプリ** が、拡張子単位で入れ替わっている
3. 拡張子が実際と違う（`report.pdf.txt` のように二重）
4. 使いたいアプリが入っていない、または一度壊れている
5. 会社PCで、既定アプリがポリシー固定されている
6. ブラウザが PDF や写真を、自分の中で開く設定に変わっている

アプリが「実行できません」で止まるときは、関連付けより先に [このアプリは実行できません](/articles/windows-app-cannot-run/) です。フォルダーを開いた瞬間に固まるなら [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/) を見てください。

## 直す前に

- 直したい拡張子を1つに決める（例: `.jpg`、`.pdf`、`.xlsx`）。全部いっぺんに変えると、何が効いたかわかりません
- 使いたいアプリの正式名を、スタートメニューで一度開いて確認する
- 「関連付け修復」「拡張子一括復元」の実行ファイルは使わない

> **注意:** レジストリエディターで `HKEY_CLASSES_ROOT` を手で書き換えないでください。設定の既定のアプリと、右クリックの「常に使う」で足ります。出典不明の `.reg` は、別の種類まで巻き込みます。

## 手順

### 1. 右クリックから、その種類だけ付け直す

1. 問題のファイルを1つ選ぶ。拡張子が見えないときは、エクスプローラーの **表示** → **表示** → **ファイル名拡張子** をオン。
2. 右クリック → **プログラムから開く** → **別のアプリを選択**（Windows 10 は **別のプログラムを選択**）。
3. 使いたいアプリを選び、**常に使う**（または「常にこのアプリを使って .xxx ファイルを開く」）にチェックして **OK**。
4. 同じ種類の別ファイルをダブルクリックする。意図したアプリが前面に出ればOK。

一覧に無いときは **その他のアプリ** や **PCで別のアプリを探す** から、インストール先の `.exe` を指定します。アンインストール済みの名前が残っているだけなら、選ばないでください。

**ここで失敗したとき:** 「常に使う」のチェックが無く、今回だけ開く、なら次のダブルクリックで元に戻ります。チェックを入れてから OK です。一覧に使いたいアプリが無く、`.exe` を指定しても「このファイルを開く方法として使えない」と出るなら、そのアプリはその拡張子に対応していません。別の公式アプリを選びます。右クリックの項目が英語のまま、または見知らぬソフトの名前だけなら、最近入れたビューアがメニューを奪っています。手順2の既定で、その拡張子だけ戻してください。

### 2. 設定の「既定のアプリ」で拡張子を固定する

1. **設定** → **アプリ** → **既定のアプリ**。
2. 上の検索に `pdf` や `jpg` など、拡張子を入れる（先頭のドットは無くてよい機種が多い）。
3. 今の既定をタップし、使いたいアプリを選ぶ。
4. アプリ名から探すなら、同じ画面でアプリを開き、種類ごとの既定を1つずつ変える。

「リセット」は全種類がメーカー初期値に戻ります。PDFだけ直したいときに押さないでください。全部が崩壊しているときだけ、画面下部の **リセット** を使い、そのあとよく使う種類を手順2で入れ直します。

Windows 10 の同じ画面は、拡張子の検索が弱く、**ファイルの種類ごとに既定のアプリを選ぶ** の一覧から `.pdf` を探します。Windows 11 は上の検索ボックスが先です。

**ここで失敗したとき:** 検索しても拡張子が出ないときは、ドット付き（`.jpg`）と無し（`jpg`）の両方を試します。選んだあとすぐ別のアプリ名に戻るなら、裏で常駐が既定を奪っています。最近入れた PDF ツール、コーデック、ブラウザを終了してから、もう一度選んでください。選ぶ画面に使いたいアプリが無く「ストアで探す」だけなら、そのアプリは未インストールか、その種類に対応していません。

### 3. 拡張子の取り違えを見る

1. ファイル名の末尾が `.pdf.txt`、`.jpg.jpg`、`.docx.bak` になっていないか見る。
2. ダウンロードしたファイルなら、ブラウザのダウンロード一覧から、もう一度正規のリンクで取り直す。失敗したままのファイルは [ダウンロードが失敗したとき](/articles/chrome-download-failed/) で、サイズが最後まで落ちているかを見ます。
3. メール添付で拡張子が消えているときは、差出人に形式を確認する。自分で `.exe` を付け足さない。

名前の変更で拡張子だけ直すのは、中身がその形式のときだけです。中身がわからないファイルの拡張子を、推測で付け替えないでください。

**ここで失敗したとき:** 拡張子を表示しても末尾が `.pdf` のまま、アイコンだけ白い用紙、なら名前は正しく、関連付けだけが違います。名前は変えず、手順1へ戻ってください。名前を変えた瞬間に「拡張子を変更すると、ファイルが使えなくなる可能性があります」と出たら、中身がその形式だと確信できるときだけ **はい** です。確信が無いときは **いいえ** です。

### 4. アプリ側を一度修復する

1. **設定** → **アプリ** → **インストールされているアプリ**。
2. 使いたいアプリの **…** → **詳細オプション**（または **変更**）。
3. **修復** があれば実行する。無いときは公式サイトか Store から、同じアプリを入れ直す。
4. 修復後、手順1か2で既定をもう一度選ぶ。

修復や再インストールのあと、初回起動で「既定のアプリにしますか」と出たら、必要な種類だけ許可します。全部まとめて許可すると、また写真まで巻き込まれます。

**ここで失敗したとき:** **修復** が無く **アンインストール** しか無いデスクトップアプリは、公式のインストーラーを「修復」または「変更」で起動します。アンインストールしてから入れ直す前に、そのアプリで作ったファイルの保存場所を控えてください。修復後に既定がまた見知らぬアプリへ戻るなら、修復の最後の画面で「すべてを既定にする」を押しています。種類を1つずつ戻します。

## ブラウザと、職場PC

PDF をダブルクリックするとブラウザのタブで開く、写真がブラウザの窓になる、というときは Windows の既定がブラウザになっています。手順2で `.pdf` や `.jpg` を、使いたいアプリへ戻してください。ブラウザの中の「PDF をダウンロードする」設定とは別です。

ブラウザに見知らぬ拡張が入ったあとから、html や pdf の開き先が変わったときは [不要な拡張機能](/articles/browser-unwanted-extension/) を先に外します。拡張を残したまま既定だけ戻すと、翌日起動でまた奪われます。

職場・学校で **既定のアプリ** の選択が灰色、または選んでも翌朝戻るなら、ポリシーです。拡張子と、開きたいアプリの正式名を IT へ渡してください。家庭の「リセット」は、会社PCでは翌朝さらに上書きされます。

## まだ直らないとき

- 選んでも次回から戻る → 別の常駐アプリが、起動のたびに既定を奪っていることがあります。最近入れたコーデック、PDFツール、ブラウザを疑う。スタートアップにその名前が残っていないかは [起動時にアプリが開くとき](/articles/windows-startup-apps/) です
- Store アプリだけ既定にできない → そのアプリが、その拡張子に対応していないことがあります。デスクトップ版の公式があるならそちら
- ダブルクリックすると毎回「方法を選んでください」 → 手順2の検索で、その拡張子に既定が付いているか見る。空なら手順1の「常に使う」
- 職場・学校で既定が灰色 → 個人では終わりません。IT 担当へ、拡張子と開きたいアプリ名を渡す
- 写真の一部だけ別アプリ、フォルダーを変えると正しいアプリ → そのフォルダーだけ「プログラムから開く」が個別に付いていることがあります。おかしいファイルだけ手順1をやり直す
- 開いたアプリが文字化けする → 関連付けは直っています。中身の文字コードや、日本語入力の話は別です。テキストならアプリの「開き方」や文字コードを見て、拡張子はもう変えません

## まとめ

拡張子を表示してから、右クリックの「常に使う」か、設定の既定のアプリで1種類ずつ付け直す。レジストリと一括修復ツールは使いません。
