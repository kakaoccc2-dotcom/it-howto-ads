写真を開いたら見知らぬ画像ビューア。PDFがメモになる。`.docx` なのにワードパッド。アプリが起動エラーで落ちる場合は、開き方ではなく実行側です。

## 症状の見分け

- 同じ種類のファイルをどれも、意図しないアプリで開く
- アイコンが変わった（白い用紙、見知らぬロゴ）
- 右クリック → **プログラムから開く** に、使いたいアプリが無い
- Store や新規インストールのあとから、全部そのアプリ経由になる
- 「このファイルを開く方法を選んでください」が毎回出る
- メールの添付やダウンロードだけ失敗し、元フォルダーの同種ファイルは普通

同じ拡張子が全部おかしい → 既定のアプリ。1個だけ → そのファイルの破損か、名前の末尾。

## よくある原因

1. 新しいアプリの初回起動で、「既定にする」を押してしまった
2. **設定 → アプリ → 既定のアプリ** が、拡張子単位で入れ替わっている
3. 拡張子が実際と違う（`report.pdf.txt` のように二重）
4. 使いたいアプリが入っていない、または一度壊れている
5. 会社PCで、既定アプリがポリシー固定されている

アプリが「実行できません」で止まるときは、関連付けより先に [このアプリは実行できません](/articles/windows-app-cannot-run/) です。フォルダーを開いた瞬間に固まるなら [エクスプローラーが応答なし](/articles/windows-explorer-not-responding/) を見てください。

## 直す前に

- 直したい拡張子を1つに決める（例: `.jpg`、`.pdf`、`.xlsx`）。全部いっぺんに変えると、何が効いたかわかりません
- 使いたいアプリの正式名を、スタートメニューで一度開いて確認する
- 「関連付け修復」「拡張子一括復元」の実行ファイルは使わない

> **注意:** レジストリエディターで `HKEY_CLASSES_ROOT` を手で書き換えないでください。設定の既定のアプリと、右クリックの「常に使う」で足ります。出典不明の `.reg` は、別の種類まで巻き込みます。

## 手順

### 1. 右クリックから、その種類だけ付け直す

1. 問題のファイルを1つ選ぶ。拡張子が見えないときは、エクスプローラーの **表示** → **表示** → **ファイル名拡張子** をオン。
2. 右クリック → **プログラムから開く** → **別のアプリを選択**（Windows 10 は **別のプログラムを選択**）。
3. 使いたいアプリを選び、**常に使う**（または「常にこのアプリを使って .xxx ファイルを開く」）にチェックして **OK**。
4. 同じ種類の別ファイルをダブルクリックする。意図したアプリが前面に出ればOK。

一覧に無いときは **その他のアプリ** や **PCで別のアプリを探す** から、インストール先の `.exe` を指定します。アンインストール済みの名前が残っているだけなら、選ばないでください。

### 2. 設定の「既定のアプリ」で拡張子を固定する

1. **設定** → **アプリ** → **既定のアプリ**。
2. 上の検索に `pdf` や `jpg` など、拡張子を入れる（先頭のドットは無くてよい機種が多い）。
3. 今の既定をタップし、使いたいアプリを選ぶ。
4. アプリ名から探すなら、同じ画面でアプリを開き、種類ごとの既定を1つずつ変える。

「リセット」は全種類がメーカー初期値に戻ります。PDFだけ直したいときに押さないでください。全部が崩壊しているときだけ、画面下部の **リセット** を使い、そのあとよく使う種類を手順2で入れ直します。

### 3. 拡張子の取り違えを見る

1. ファイル名の末尾が `.pdf.txt`、`.jpg.jpg`、`.docx.bak` になっていないか見る。
2. ダウンロードしたファイルなら、ブラウザのダウンロード一覧から、もう一度正規のリンクで取り直す。
3. メール添付で拡張子が消えているときは、差出人に形式を確認する。自分で `.exe` を付け足さない。

名前の変更で拡張子だけ直すのは、中身がその形式のときだけです。中身がわからないファイルの拡張子を、推測で付け替えないでください。

### 4. アプリ側を一度修復する

1. **設定** → **アプリ** → **インストールされているアプリ**。
2. 使いたいアプリの **…** → **詳細オプション**（または **変更**）。
3. **修復** があれば実行する。無いときは公式サイトか Store から、同じアプリを入れ直す。
4. 修復後、手順1か2で既定をもう一度選ぶ。

修復や再インストールのあと、初回起動で「既定のアプリにしますか」と出たら、必要な種類だけ許可します。全部まとめて許可すると、また写真まで巻き込まれます。

## まだ直らないとき

- 選んでも次回から戻る → 別の常駐アプリが、起動のたびに既定を奪っていることがあります。最近入れたコーデック、PDFツール、ブラウザを疑う
- Store アプリだけ既定にできない → そのアプリが、その拡張子に対応していないことがあります。デスクトップ版の公式があるならそちら
- ダブルクリックすると毎回「方法を選んでください」 → 手順2の検索で、その拡張子に既定が付いているか見る。空なら手順1の「常に使う」
- 職場・学校で既定が灰色 → 個人では終わりません。IT 担当へ、拡張子と開きたいアプリ名を渡す

## まとめ

拡張子を表示してから、右クリックの「常に使う」か、設定の既定のアプリで1種類ずつ付け直す。レジストリと一括修復ツールは使いません。
