スタートボタンを押しても何も出ない、タスクバーが真っ黒や透明のまま、アイコンはあるのにクリックできない、外付けモニターをつないだら下のバーが消えた、といった状態は、Windows 全体が壊れたというより **エクスプローラー（シェル）の一時停止、表示設定、複数ディスプレイの取り違え** が多いです。デスクトップのフォルダーは開けるのに、スタートとタスクバーだけ死んでいることもよくあります。

この記事は Windows 11（一部は 10）の個人向け PC を対象にします。電源を入れてもデスクトップ自体が出ない、自動修復の画面で止まっているときは、先に [スタートアップ修復の手順](/articles/windows-startup-repair/) です。クリックはできるが全体が極端に遅いだけなら [動作が遅いときの手順](/articles/windows-pc-running-slow/) を先に見てください。

## 症状の見分け

- スタートボタン、検索、タスク ビューを押しても反応がない。または一度開いてすぐ閉じる
- タスクバー自体が見えない。マウスを画面下に寄せても出てこない
- タスクバーは見えるが、時計やアイコンが固まっていて、右クリックも効かない
- 外付けディスプレイをつないだ直後、またはノートを閉じたあとにだけ再現する
- サインイン直後は普通で、数分後やスリープ復帰後からスタートが死ぬ
- `Ctrl` + `Esc` や `Win` キーでもスタートが開かない

黒い画面にマウスだけ、またはフォルダーも開けないときはシェルより先に、画面と電源を疑います。明るさや真っ黒の切り分けは [画面が暗い・真っ黒なとき](/articles/windows-brightness-black-screen/) です。

## よくある原因

1. **Windows エクスプローラー** が応答停止している（スタートとタスクバーを描いている本体）
2. 「タスクバーを自動的に隠す」や、タブレット向けの表示でバーが画面外にある
3. 複数ディスプレイで、タスクバーが今見ていないモニター側に出ている
4. 全画面アプリ、ゲーム、リモートデスクトップのあと、シェルだけ戻っていない
5. 最近の Windows Update や、スタートの代わりに入れるサードパーティのランチャー
6. 今のユーザープロファイルだけ壊れていて、別アカウントでは普通に動く

## 直す前に

- 作業中の文書は、エクスプローラー経由で開けるなら先に保存する。タスクバー再起動で開いているウィンドウが閉じることがあります
- 出典不明の「スタート修復ツール」「タスクバー復活.reg」は入れない
- スタートが使えなくても、`Ctrl` + `Shift` + `Esc` でタスク マネージャーは出せることが多いです。ここから先の入口になります

> **注意:** この記事ではディスクの初期化や、レジストリファイルの配布は使いません。スタートが開かないからといって、すぐ「この PC をリセット」しないでください。先にエクスプローラーの再起動と、別ユーザーでの切り分けをします。

## 手順

### 1. タスク マネージャーからエクスプローラーを再起動する

いちばん効く、いちばん安全な一手です。

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー** を開く。出ないときは `Ctrl` + `Alt` + `Del` → **タスク マネージャー**。
2. **プロセス** の一覧から **Windows エクスプローラー** を探す。見当たらなければ、下の **詳細** で `explorer.exe` です。
3. 選んで **再起動** を押す。ボタンが「タスクの終了」しかないときは、終了したあと **新しいタスクを実行** に `explorer.exe` と入れて開く。
4. デスクトップのアイコンとタスクバーが一度消えて戻る。戻ったらスタートボタンを1回押す。

Windows 11 では、同じ一覧に **スタート**（`StartMenuExperienceHost.exe`）が出ることがあります。固まったままなら選んで **タスクの終了** し、スタートボタンをもう一度押します。自動で起き直ります。

ここで開くなら、一時的な応答停止です。すぐ再発するときは手順2へ進み、[スタートアップの整理](/articles/windows-startup-apps/) で見慣れないランチャーや「カスタムスタート」をオフにしてください。

### 2. タスクバーが隠れているだけではないか

1. マウスを画面の一番下（または左右）の端に寄せ、数秒待つ。自動的に隠す設定だと、ここにだけ出ます。
2. 出てきたバーを右クリックし、**タスクバーの設定** を開く。スタートが死んでいても、ここから設定に入れることがあります。
3. **タスクバーの動作** を開き、**タスクバーを自動的に隠す** をオフにする。
4. **タスクバーの配置** が **中央** か **左** か見て、いったん入れ替えて戻す（描画が戻ることがあります）。
5. 複数モニターを使っているときは、**すべてのディスプレイにタスクバーを表示する** をオンにして、今見ている画面にバーが出るか確認する。

ノートを閉じたまま外付けモニターだけ使っていると、タスクバーが「内蔵画面側」に残ったままになることがあります。`Win` + `P` で **セカンドスクリーンのみ** と **複製** を一度ずつ試し、戻します。

### 3. 設定アプリからスタートとタスクバーを戻す

タスク マネージャーの **新しいタスクを実行** に `ms-settings:` と入れて **設定** を開きます。

1. **個人用設定** → **タスクバー**。
2. **タスクバー項目** の **検索**、**タスク ビュー**、**ウィジェット** が意図どおりか見る。全部オフでもスタートボタン自体は残るはずです。消えているなら表示設定よりシェルです。
3. **個人用設定** → **スタート** で、最近使った項目やピン留めのスイッチを一度オフ→オンする。
4. スタートに変なタイルや広告カードだけが出て固まるときは、スタートを開いてピン留めを外し、シンプルな一覧にして試す。

設定アプリ自体が開かない、または「このアプリは実行できません」なら [アプリが実行できないとき](/articles/windows-app-cannot-run/) も並行して見てください。ストアアプリ全体が死んでいると、スタートの描画も巻き込まれます。

### 4. サインアウトと、全画面の取り違え

1. タスク マネージャー → **ユーザー** から、自分のアカウントを選んで **サインアウト**。保存していないアプリは閉じます。
2. もう一度サインインし、スタートとタスクバーを押す。
3. ゲームや動画の全画面、リモートデスクトップを使った直後だけ死ぬときは、`Alt` + `Tab` でそのウィンドウを選び、普通のウィンドウに戻してから閉じる。
4. タブレットや 2-in-1 の場合は、キーボードを着脱した直後に表示モードが変わることがあります。一度開いて閉じ、横向きに持ち直してから確認する。

サインアウトで直るなら、再発時は手順1のエクスプローラー再起動で足りることが多いです。すぐ再発するなら手順5です。

### 5. 別のローカルユーザーで、プロファイルかを切り分ける

今のアカウントだけ壊れているかを見ます。家族のアカウントがすでにあるなら、そちらでサインインしてスタートが開くか見てください。無いときだけ、新しいローカルユーザーを足します。

1. 設定が開けるなら **アカウント** → **他のユーザー** → **アカウントの追加**。Microsoft アカウントは後回しで、**Microsoft アカウントを持っていない** → **ローカル アカウントを作成**。
2. 設定が開けないときは、タスク マネージャーの新しいタスクに `control` と入れてコントロール パネルを開き、**ユーザー アカウント** から追加する。職場 PC で灰色なら、個人では追加できません。
3. 新しいユーザーでサインインし、スタートとタスクバーを試す。

こちらで普通に動くなら、Windows 全体ではなく今のプロファイル側です。ピン留めや設定を移すより、常用アカウントのスタートアップを整理し、どうしてもダメなら大事なファイルをコピーして新しいアカウントへ移す方が安全です。

> **注意:** 新しいアカウントへの引っ越しで、デスクトップやドキュメントを消す必要はありません。エクスプローラーで `C:\Users\<今のユーザー名>` から、必要なフォルダーだけコピーしてください。ディスクのフォーマットはしません。

### 6. システムのファイル点検（まだスタートが死んでいるとき）

別ユーザーでもダメ、再起動してもすぐ固まる、というときだけです。

1. タスク マネージャー → **新しいタスクを実行**。
2. `cmd` と入れ、**このタスクに管理者特権を付与する** にチェックして開く。
3. 次を実行し、終わるまで待つ。

```text
sfc /scannow
```

修復を見つけたら、表示どおり再起動してからスタートを試します。見つからなくても、スタートアップの整理と Windows Update は続けてください。更新が途中で止まっているとシェルが不安定なことがあります。[更新が進まないとき](/articles/windows-update-stuck/) も見てください。

`DISM` や回復環境のリセットは、この段階では必須ではありません。sfc のあとも真っ黒でフォルダーも開けないなら、[スタートアップ修復](/articles/windows-startup-repair/) の回復画面に進みます。

## まだ直らないとき

- スタートは開くが検索だけ真っ白 → タスクバー設定の検索をオフ→オン。インデックスの完全再構築は必須ではありません
- タスクバーのアイコンが重なる、時計だけ消える → 手順1のあと、表示スケール（**設定 → システム → ディスプレイ**）を 100% と推奨値で入れ替える
- セーフモードならスタートが使える → あとから入れたランチャー、テーマ、セキュリティソフトを疑う。通常起動に戻してスタートアップを削る
- 別ユーザーでもダメ、sfc でも変わらない → メーカーサポートか、回復画面の **システムの復元**（復元ポイントがあるとき）。ディスク消去のリセットは最終手段で、バックアップ後だけ
- 職場の PC でスタートがポリシーで制限されている → 家庭向けの設定では終わりません。IT 担当へこの画面を渡す

## まとめ

スタートとタスクバーが死んでも、多くの場合は **エクスプローラーの再起動** で戻ります。隠れている、別モニターに出ている、全画面のあと取りこぼしている、を先に消し、それでもダメなら別ユーザーでプロファイルかを分けます。修復ツールやレジストリ配布より、標準のタスク マネージャーと設定の方が安全です。
