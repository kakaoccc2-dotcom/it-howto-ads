本体のランプは点いているのに、Windows だけ「オフライン」と出るときの話です。会社の共有プリンターで権限エラーなら、いちばん下だけ先に見てください。

## 症状の見分け

- アイコンが「オフライン」または「一時停止」
- キューに文書が残り、消してもすぐ戻る
- 本体はコピーできる、スマホアプリからは刷れる。Windows だけダメ
- 紙なし・インクなしのランプ（これは補給してから再実行）

スマホからは刷れて Windows だけダメなら、本体より、Windows が覚えている接続先が古いことが多いです。

## よくある原因

1. USB の挿し直し不足、電源の省エネで本体が寝ている
2. キューに古い失敗ジョブが残り、以降を止めている
3. 「オフラインで使用する」がオンのまま
4. Wi-Fi プリンターの IP アドレスが、ルーター再起動後に変わった
5. 標準ドライバーとメーカー専用ドライバーが二重登録されている。同じ部屋でもゲストSSIDや 2.4GHz 専用だと見つからないこともあります

Wi-Fi そのものが不安定なときは、[Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) や [DNS エラー](/articles/windows-dns-server-problem/) で回線を落ち着かせてから戻ってきてください。

## 直す前に

- 本体の電源ランプ、Wi-Fi ランプ（点滅の意味は機種による）を見る
- USB なら、モニターのUSBポートではなく **PC本体のポート** に挿し直す
- インクと用紙を確認する。空なのにオフラインとだけ出る機種もあります
- 印刷中のジョブに、残したくない個人情報が紛れていないかキューを見る

> **注意:** 「プリンター修復」を名乗る実行ファイルや、レジストリ掃除は使わないでください。キューの削除と、デバイスの入れ直しで足りることがほとんどです。

## 手順

### 1. 本体とケーブルを起こす

1. プリンターの電源をオフ → コンセントを抜けるなら 20秒抜く → 入れる。
2. USB 接続なら、ケーブルを両端とも抜き、PC本体側の別ポートへ挿す。
3. 無線なら、プリンターのパネルで Wi-Fi が切れていないか見る。SSID がゲスト用になっていないかも見る。

Windows の表示が「アイドル」や「準備完了」に変わることがあります。変わらなければ下へ。

### 2. 印刷キューを空にする

1. **設定** → **Bluetooth とデバイス** → **プリンターとスキャナー**。
2. 対象プリンターを開き、**印刷キューを開く**。
3. **プリンター** メニューの **すべてのドキュメントの取り消し**（画面によってはジョブを右クリックして削除）。
4. キューが空になったことを確認する。

消してもすぐに同じ文書が戻るときは、元のアプリ（ブラウザや Word）側で再送していないか見て、いったんアプリを閉じます。

### 3. 「オフラインで使用する」を外す

キュー画面の **プリンター** メニューを開き、次がオフ（チェックなし）か確認します。

- オフラインで使用する
- 一時停止

チェックが付いていたら外します。家庭用では、誤ってオンにしたまま何ヶ月も、ということがあります。

### 4. Windows からプリンターをいったん外して入れ直す

二重登録のときに効きます。

1. **プリンターとスキャナー** で対象を選び、**削除** または **デバイスの削除**。
2. 同じ名前が複数行ある場合は、使っていないほうも削除する（「Fax」や「PDF」は残してよい）。
3. メーカー公式サイトから、今の Windows 向けドライバーを入れる。付属CDは、Windows 11 では古いことが多いです。
4. USB なら挿したまま待つ。無線なら、公式インストーラーの「同じネットワーク上の機器を探す」に従う。

IP を手打ちしている場合は、プリンターのパネルで現在の IP を表示し、それが設定のポートと一致するか見てください。ルーターを再起動するたびに IP が変わる回線では、DHCP 予約（固定）をルーター側で行うと再発しにくいです。

### 5. ネットワークの食い違いを見る

- PC が 5GHz、プリンターが 2.4GHz 専用、で SSID が分かれていると見つかりません。同じSSID（またはプリンターが載っているほう）に PC を合わせます。
- 「デバイスのセットアップ」通知を無視し続けると、OS標準ドライバーだけ半端に入ることがあります。通知から完了させるか、手順4で公式ドライバーに統一します。
- Bluetooth ヘッドセットやキーボードと同時に不安定なら、[iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) と同じく、古い登録の削除が効くことがあります（Windows 側は「デバイスの削除」）。

## まだ直らないとき

- テストページは出るが Word だけ出ない → アプリ側のプリンター選択が「Microsoft Print to PDF」や古い名前になっていないか見る
- テストページも出ない → 別のPCから同じプリンターへ出せるかで、本体故障か PC 側かを分ける
- 会社の複合機 → 「アクセスが拒否されました」はドライバーより権限です。共有名と部署の許可を担当へ確認する
- アプリが起動すらしなければ、[このアプリは実行できません](/articles/windows-app-cannot-run/) で実行ファイル側を先に見る

## まとめ

起こす、キューを空にする、オフライン指定を外す。それでダメなら入れ直してください。買い替えは急がなくて大丈夫なことが多いです。
