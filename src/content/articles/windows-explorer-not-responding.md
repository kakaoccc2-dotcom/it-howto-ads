フォルダーを開いた瞬間に「応答なし」、アドレスバーの緑だけが進まない、タスクバーのフォルダーアイコンを押しても窓が出ない、ならエクスプローラー（`explorer.exe`）側です。スタートやタスクバーだけ死んでいるときは、先に [スタートメニューとタスクバーの手順](/articles/windows-start-menu-taskbar-broken/) を見てください。

## 症状の見分け

- フォルダー窓のタイトルに **応答なし** と出る。数分待っても中身が描画されない
- アドレスバーの緑の進行が、特定のフォルダーや USB・ネットワーク場所だけで止まる
- デスクトップのアイコンをダブルクリックしても、何も開かない
- 右クリックメニューが出ない、または出たまま固まる
- サインイン直後は普通で、動画フォルダーやダウンロードを開いたあとから再発する

## よくある原因

1. エクスプローラー自身が一時停止している（フォルダーの窓だけ止まって、デスクトップのアイコンは動いていることもある）
2. プレビューや縮小表示が、壊れた動画・巨大な ZIP を読もうとして止まっている
3. クイック アクセスやピン留め先が、もう無いドライブ・切断された共有を見にいっている
4. C ドライブの空きが数GB以下、またはディスク使用率が張り付いている
5. OneDrive やセキュリティソフトが、そのフォルダーの読み取りを待たせている

## 直す前に

- 開いている文書は、メモ帳やブラウザ側で保存できるなら先に保存する。エクスプローラー再起動でフォルダー窓は閉じます
- 「エクスプローラー修復」「応答なし一発」系の実行ファイルは入れない
- スタートが使えないときも、`Ctrl` + `Shift` + `Esc` でタスク マネージャーは出せることが多いです

> **注意:** ディスクの初期化、レジストリ配布、BIOS の変更はこの記事では使いません。フォルダーが固まったからといって、すぐ「この PC をリセット」しないでください。

## 手順

### 1. タスク マネージャーからエクスプローラーを再起動する

いちばん先に試す一手です。

1. `Ctrl` + `Shift` + `Esc` で **タスク マネージャー** を開く。出ないときは `Ctrl` + `Alt` + `Del` → **タスク マネージャー**。
2. **プロセス** から **Windows エクスプローラー** を探す。無いときは **詳細** の `explorer.exe` です。
3. 選んで **再起動**。ボタンが **タスクの終了** しかないときは終了し、**新しいタスクを実行** に `explorer.exe` と入れて開く。
4. デスクトップのアイコンが一度消えて戻る。戻ったら、さっき固まったフォルダーではなく、まず **ドキュメント** や C ドライブ直下を開く。

ここですぐ開くなら、一時的な応答停止です。同じフォルダーだけまた固まるなら手順2へ。スタートや時計まで消えたままなら、スタートメニュー記事の手順に切り替えます。

### 2. 「どこを開いたときか」を分ける

1. **ドキュメント** や **ピクチャ** はすぐ開くか見る。開くなら、エクスプローラー本体より、さっきの場所側です。
2. 固まる場所が USB や外付けなら、いったん安全に取り外し、PC 内のフォルダーだけ試す。差し直してもドライブが出ないときは、別のケーブルと別の差し込みを先に見る。
3. `\\` で始まる共有フォルダーや、マップしたネットワークドライブだけダメなら、その先の PC・NAS が落ちているか、保存したパスワードの期限切れです。家庭の共有なら、相手の電源と、エクスプローラーのアドレス欄に打ったパスを紙に書いてから聞き直してください。
4. 左側の **クイック アクセス** やピン留めを開いた瞬間に固まるときは、そのショートカット先が死んでいます。アドレスバーに `C:\Users` と打ってユーザーフォルダーへ入り、ピン留めは右クリックで外す。

全部の場所で固まるなら手順3へ。一か所だけなら、そのフォルダーの中身（壊れた動画、巨大 ZIP、オフラインのクラウド）を疑います。

### 3. プレビューと縮小表示を切る

動画や RAW、壊れたサムネイルで止まりやすいです。

1. エクスプローラー上部の **表示** を開く（Windows 11 も **表示**）。
2. **プレビュー ウィンドウ** と **詳細ウィンドウ** をオフにする。
3. 縮小表示は別画面。`⋯` → **オプション**（または **フォルダー オプション**）を開き、**表示** タブで **常にアイコンを表示し、縮小表示はしない** にチェックする。
4. **適用** して、さっき固まったフォルダーをもう一度開く。

これで開くなら、そのフォルダーに問題のあるファイルがあります。全部まとめて消さず、名前や日付で最近足したものから退避してください。プレビューを戻すのは、問題のファイルを移したあとで構いません。

### 4. 空き容量と、ディスクの張り付きを見る

1. エクスプローラーで C ドライブを開き、空きが **10GB 以上**あるか見る。赤い、または数GBなら、この先より [ストレージ不足の片付け](/articles/windows-storage-full/) を先に進める。
2. `Ctrl` + `Shift` + `Esc` の **パフォーマンス** または **プロセス** で、**ディスク** が数分 90〜100% のままではないか見る。張り付いているときは、名前のわかる不要アプリを終了してから、同じフォルダーを開き直す。
3. OneDrive のアイコンが「同期中」なら、終わるまで待つか、トレイから同期を一時停止して、同じフォルダーを開き直す。

空きが無いのにフォルダーを開き続けると、また「応答なし」に戻りやすいです。クリーナーアプリは使いません。

### 5. 再起動と、スタートアップの整理

1. 保存できる窓を閉じて、PC を再起動する。再起動後に同じフォルダーを開いて、緑のバーが進むか見る。
2. 再発するときは、タスク マネージャーの **スタートアップ アプリ** から、見慣れないランチャーや「エクスプローラー拡張」をオフにする。名前がわからない項目は消さない。
3. クラウド同期、コーデックパック、右クリックメニューを増やすツールを最近入れたなら、いったん終了して再現するか見る。

> **注意:** 出典不明のコーデックや「フォルダー高速化」は、応答なしの原因側になりがちです。アンインストールは **設定 → アプリ → インストールされているアプリ** から、名前がわかるものだけにしてください。

## まだ直らないとき

- セーフモードだとフォルダーが開く → あとから入れた常駐や拡張を疑う。通常起動に戻してスタートアップを削る
- 別のローカルユーザーでは開く → 今のプロファイルのピン留めや Quick Access 側です。新しいアカウントへいきなり引っ越さず、ピン留めを外してから様子を見る
- 異音（カチカチ）や、どのフォルダーも数分かかる → 軽量化より、残したいファイルを別媒体へコピーしてメーカー診断。ディスクのフォーマットはしない
- 自動修復や真っ黒でデスクトップ自体が出ない → フォルダーの応答なしではなく、起動修復の話に切り替える
- 職場 PC で共有だけ固まる → 個人のフォルダーオプションでは終わらないことがあります。IT 担当へ、固まるパスと「応答なし」のスクリーンショットを渡す

## まとめ

応答なしのフォルダーは、いったん閉じてエクスプローラーを再起動するのが先です。同じ場所だけ固まるなら、そのフォルダーかプレビュー、空き容量を疑ってください。
