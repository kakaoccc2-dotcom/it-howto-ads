`Win` + `Shift` + `S` を押しても画面が暗くならない。切り取りツールが開いてすぐ閉じる。撮ったはずなのに貼れない。ゲームバーや、メーカーキーボードの撮影キーが別動作になっている機種もあります。

## 症状の見分け

- `Win` + `Shift` + `S` で、画面上部のツールバー（四角形・フリーフォームなど）が出ない
- ツールバーは出るが、ドラッグしても画像にならない
- 切り取りのあと通知が来ず、`Ctrl` + `V` しても貼れない
- `PrtScn` を押すと設定が開く、または何も起きない
- スタートから **切り取りツール**（古い表記は **切り取り & スケッチ**）を開くと落ちる
- `Win` + `PrtScn` で画面は一瞬暗くなるが、ピクチャにファイルが増えない

キーを押してもスタートメニューまで死んでいるなら、撮影よりシェルです。[スタートとタスクバー](/articles/windows-start-menu-taskbar-broken/) を先に見てください。コピー全般が死んでいるなら [クリップボード履歴](/articles/windows-clipboard-history/) です。

## よくある原因

1. 切り取りツールが壊れている、またはスタートアップで落ちている
2. `Win` + `Shift` + `S` が、別アプリ（ゲームバー、動画キャプチャ）に取られている
3. 通知がオフで、保存先に気づけない。実はクリップボードには載っている
4. クリップボード履歴がオフ、または管理者画面との行き来で貼れない
5. グラフィックドライバーの一時不良で、画面の取り込みだけ失敗する
6. OneDrive の「スクリーンショットを自動保存」と、ピクチャフォルダーの取り違え

## 直す前に

- 撮ろうとしている画面に、パスワードや個人情報が大きく写っていないか見る
- 使いたい方法を一つに決める（ショートカットか、切り取りツールか、`Win` + `PrtScn` か）
- 「スクショ修復」「キャプチャ強化」系の実行ファイルは入れない

> **注意:** グラフィックドライバーのクリーンインストールや、レジストリでショートカットを書き換える手順は使いません。標準の切り取りツールと、設定のキーボード、ドライバーの「修復」までです。作業中のファイルは先に保存してください。

## 手順

### 1. 切り取りツールを、スタートから一度開く

1. スタートで `切り取り` と入力し、**切り取りツール** を開く。
2. **新規** を押し、画面が薄暗くなり、上に四角形などのアイコンが出るか見る。
3. 四角形で適当な範囲をドラッグする。切り取りツールの窓に画像が出れば、アプリ側は生きている。
4. 開いた瞬間に閉じる、真っ白、エラー、なら **設定** → **アプリ** → **インストールされているアプリ** で切り取りツールを探し、**…** → **詳細オプション** → **修復**。無ければ **リセット**。

> **注意:** **リセット** は、切り取りツール内の設定が初期化されます。撮った画像のファイルそのものは、ピクチャフォルダーに残っている分は消えません。

修復後にもう一度 **新規**。画像が出れば、ショートカット側を手順2で見ます。

### 2. `Win` + `Shift` + `S` と PrtScn の割り当て

1. **設定** → **アクセシビリティ** → **キーボード**。
2. **Print Screen キーを使って画面キャプチャを開く** がオンなら、`PrtScn` 単独で切り取りが始まります。オフのままでも、`Win` + `Shift` + `S` は別動作です。
3. ゲームを入れている PC では、`Win` + `G` のゲームバーが同じキーを奪っていることがあります。**設定** → **ゲーム** → **ゲームバー**（表記が Xbox Game Bar のこともある）を開き、使っていないならオフ。
4. もう一度 `Win` + `Shift` + `S`。上のツールバーが出て、ドラッグ後に切り取りツールか通知が出ればOK。

メーカーキーボードの `Fn` + `PrtScn` が別機能の機種があります。`Fn` を押しながら、もう一度試してください。

### 3. 撮ったあとの行き先（通知とクリップボード）

1. 切り取り直後、画面右下に「切り取りツール」の通知が出るか見る。出たらタップして窓を開く。
2. 通知が無いときは、メモ帳を開いて `Ctrl` + `V`。画像が貼れれば、撮影は成功しています。履歴を残したいときは [クリップボード履歴](/articles/windows-clipboard-history/) で `Win` + `V` をオン。
3. `Win` + `PrtScn` を使った場合は、エクスプローラーで **ピクチャ** → **スクリーンショット** を開く。日付の新しい PNG があればOK。
4. OneDrive を使っていると、同じ名前のフォルダーがクラウド側にもできます。エクスプローラー左の OneDrive と、PC本体のピクチャを取り違えない。

管理者として開いたアプリへは、通常権限で撮った画像が貼れないことがあります。貼る先を、普通のメモ帳に変えて確認してください。

### 4. 画面が取り込めないとき（グラフィックの範囲）

ツールバーは出るのに、ドラッグ結果が真っ黒、または古い画面のまま、のときです。

1. 作業を保存し、サインアウトしてサインインし直す。変わらなければ再起動。
2. 外付けモニターだけ使っているときは `Win` + `P` で **複製** を一度試す。内蔵画面でも切り取りできるか見る。
3. **設定** → **Windows Update** → **詳細オプション** → **オプションの更新プログラム** に、メーカーのディスプレイドライバーがあるか見る。あるなら入れる。無いなら、この段階ではドライバーを外さない。
4. 全画面の動画やゲームのときだけ失敗するなら、いったんウィンドウ表示にしてから `Win` + `Shift` + `S`。

ドライバーを「デバイスのアンインストール」で消す手順は、画面が戻らなくなることがあるので使いません。

## まだ直らないとき

- 切り取りツールの修復もリセットも失敗する → Store から「切り取りツール」を検索し、公式の同じアプリを更新する。出典不明の代替キャプチャは入れない
- 特定のアプリ（銀行、動画会議、一部のゲーム）だけ黒い → そのアプリが画面取り込みを禁止しています。OS側では解除できません
- ショートカットだけ死んで、切り取りツールの新規は使える → キーボード配列、またはゲームバー。手順2を繰り返す
- 職場PCでショートカットが無反応 → ポリシーで無効のことがあります。IT 担当へ、`Win` + `Shift` + `S` が無反応であることと、切り取りツールの有無を伝える

## まとめ

スタートから切り取りツールを開き、修復してから `Win` + `Shift` + `S`。ツールバーが出るのに貼れないときは、通知とクリップボードを見る。ドライバーの削除はしません。
