USB メモリを挿してもエクスプローラーに出ない、キーボードのランプが点かない、なら本体の別ポートと別ケーブルで切り分けてください。プリンターだけオフラインなら [プリンターがオフライン](/articles/printer-offline/) です。

## 症状の見分け

- 挿しても音がせず、デバイス マネージャーにも増えない
- 「認識されませんでした」、コード 43 / 10
- 別のマウスは同じポートで使える。その機器は別 PC では使える
- 外付けHDD のランプは点くが、ドライブ文字が付かない
- ハブやモニター背面のポートに挿したときだけ失敗

別PCでは使える・このPCの別ポートではダメ、ならこの PC のポート / 電源 / ドライバー側です。どの PC でもダメなら機器かケーブルを先に疑います。

## よくある原因

1. モニターや未給電ハブ経由で、電力が足りない
2. USB ケーブルが充電専用で、データ線が無い（薄いケーブルに多い）
3. USB 選択的サスペンドや、ルートハブの省電力でポートが寝ている
4. チップセット / USB ドライバーの破損、またはメーカー不明の「USB修復」で上書きされている
5. 新品のHDDが未初期化で、エクスプローラーに出ないだけ（認識自体はできている）

マイク付きヘッドセットが USB なのに「音声デバイスだけ無い」ときは、認識のあと [マイクが使えない手順](/articles/windows-microphone-not-working/) に進みます。

## 直す前に

- 可能なら、問題の機器と、動いている別の USB 機器（マウスなど）を用意する
- 外付けHDD なら、中のデータを消す操作（フォーマット、ディスクの初期化）の前に、別 PC で中身が見えるか試す
- USB-C ハブで映像も同時に出ないときは、[外付けディスプレイが映らない](/articles/external-display-no-signal/) と切り分ける

> **注意:** 検索上位の「USBドライバーパック」「一発認識ツール」は入れないでください。チップセット用は PC メーカーか、Intel / AMD の公式から取ります。

## 手順

### 1. ポートとケーブルを切り替える

1. 機器を抜き、**PC 本体背面** の別ポートへ挿す。モニターやキーボード付属ハブ、机の延長は使わない。
2. USB 3（青や USB-C）で失敗する機器は、USB 2（黒や白）へ挿してみる。古いメモリや一部の計測器は 3.0 と相性が悪いことがあります。
3. ケーブルを差し替え、可能なら短いケーブルにする。充電専用ケーブルは、スマホは充電できても PC には出ません。スマホ側の充電そのものが不安定なら [充電が遅い・できない手順](/articles/smartphone-charging-slow/) で線とポートを分けてください。
4. バスパワーのHDD / SSD は、可能なら付属の Y ケーブルや AC アダプターをつなぐ。ランプが弱い・点滅しないときは電力不足です。

同じポートで別のマウスが動けば、ポート自体は生きています。どのポートでもマウスごと死ぬときは、手順3のコントローラーを見ます。

### 2. デバイス マネージャーでエラーを見る

1. スタートボタンを右クリック → **デバイス マネージャー**。
2. **ユニバーサル シリアル バス コントローラー** と **ディスク ドライブ**、**その他のデバイス** を開く。
3. 黄色い「！」や「不明なデバイス」「USB 大容量記憶装置」を探す。
4. 問題の項目を右クリック → **デバイスのアンインストール**。アンインストール後に機器を抜き、10秒待って挿し直す。Windows が標準ドライバーを入れ直します。
5. 何も増えないときは、**操作 → ハードウェア変更のスキャン**。

コード 43 / 10 が付いている項目は、プロパティの **イベント** タブに直前の失敗理由が出ます。スクリーンショットを残しておくと、サポートへ渡しやすいです。

外付けHDD のランプが点き、ディスク ドライブには出ているのにエクスプローラーに無い場合は、右クリック スタート → **ディスクの管理** を開きます。未割り当てなら、データが不要な新品に限り初期化します。中身があるディスクを「新規シンプル ボリューム」で潰さないでください。別 PC で見えるなら、この PC のドライブ文字だけ足りないことがあります（ボリュームを右クリック → **ドライブ文字とパスの変更**）。

### 3. USB の省電力を切る

挿しているあいだだけ消え、抜いて入れ直すと一時的に直るときに効きます。

1. デバイス マネージャーの **ユニバーサル シリアル バス コントローラー** で、**USB Root Hub**（や USB ハブ）を開く。
2. **電源の管理** タブがある場合、**電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする** のチェックを外す。ハブが複数あるときは、使っている側から順に外す。
3. **コントロール パネル** → **電源オプション** → 現在のプランの **プラン設定の変更** → **詳細な電源設定の変更**。
4. **USB 設定 → USB の選択的一時停止の設定** を **無効** にする（バッテリーと電源接続の両方）。
5. PC を再起動し、機器を挿し直す。

ノートでバッテリー駆動のときだけ失敗するなら、この省電力が原因のことが多いです。直ったあと、常時無効のままでも構いません。

### 4. 高速スタートアップを切ってみる

シャットダウンのあとにだけ USB が死に、再起動（リスタート）だと直るパターンです。

1. コントロール パネルの **電源オプション** → **電源ボタンの動作を選択する**。
2. **現在利用可能ではない設定を変更します**。
3. **高速スタートアップを有効にする** をオフにして保存。
4. **シャットダウン**（再起動ではない）してから電源を入れ、USB を確認する。

### 5. 公式のチップセット / USB ドライバーに戻す

1. PC の型番でメーカー サポートページを開き、Windows 11 / 10 向けの **チップセット** または **USB** を入れる。ノートパソコンは、Intel / AMD の汎用よりメーカー版が先です。
2. 付属CDや、何年も前の「USB3.0メーカーツール」は使わない。
3. 入れたあと再起動し、デバイス マネージャーに「！」が残っていないか見る。

アプリのインストーラー自体が「実行できません」になる場合は、USB より先に [アプリが実行できません](/articles/windows-app-cannot-run/) です。セキュリティソフトのデバイス制御が社内PCでオンのこともあり、そのときは個人でドライバーを入れ直しても戻りません。

## まだ直らないとき

- キーボードやマウスだけ、BIOS / メーカーロゴの画面では動くが Windows に入ると死ぬ → OS 側のドライバーか省電力です。セーフモードで使えるなら、あとから入れたUSBユーティリティを外す
- USB メモリだけ特定のファイル操作で切れる → 機器の寿命やケーブル。別のメモリで同じポートを試して切り分ける
- Thunderbolt / USB4 の箱だけ認識しない → Windows の承認ダイアログや、BIOS の Thunderbolt セキュリティを確認する。通常の USB メモリとは別系統です
- どの機器を挿しても「電力不足」→ 本体側 USB コントローラーや電源の故障があり得ます。保証期間内なら、手順を試した記録（別ポート、別ケーブル、デバイス マネージャーのコード）を添えてメーカーへ

## まとめ

認識されない USB は、本体直挿しと別ケーブルで切り分けてください。HDD が見えないだけのときは、フォーマットより先にディスクの管理でドライブ文字を見てください。ドライバーは、まとめサイトではなく PC メーカーのチップセットに戻します。
