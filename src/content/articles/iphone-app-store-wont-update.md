ホーム画面のアイコンの下で、円が止まったまま朝を越える。App Store の **アップデート** を押しても「読み込み中」から戻らない。小さい道具は入るのに、ゲームだけ残る。iOS そのものの **ソフトウェアアップデート** が止まる話とは別です。こちらは App Store のアプリです。

Android の Play ストアは [ダウンロードできないとき](/articles/android-play-store-wont-download/) です。

## 症状の見分け

- アイコンに「待機中」「読み込み中」が残る
- 右上のアカウント画面に更新が並ぶ。ボタンを押しても進まない
- 小さいアプリは入る。容量の大きいものだけ失敗する
- ページのボタンが **アップデート** ではなく **開く**。開くと、自分では古いと感じる
- 「この App を使用するには iOS ○ が必要です」
- 「前回の購入で、お支払いに問題がありました」「確認が必要です」
- アイコンが雲の形で、タップしても落ちてこない

Wi-Fi の選択画面から先に進めないときは [iPhone の Wi-Fi](/articles/iphone-wifi-cannot-connect/) です。モバイルデータだけ死んでいるときは [モバイルデータ](/articles/iphone-mobile-data-not-working/) です。

## よくある原因

1. 空きが足りない
2. Wi-Fi を離れると止まる。App Store のモバイルデータ通信がオフ
3. 自動の **アプリのアップデート** がオフで、一覧も古いまま
4. 支払い方法。無料の更新でも、Apple が確認で止めることがある
5. スクリーンタイムで、インストールが許可されていない
6. その更新が要求する iOS より、端末の iOS が古い
7. Apple ID がサインアウトしている。別の人の ID で入っている

## 直す前に

- 今つながっている Wi-Fi の名前を見る。不安定なら Wi-Fi の記事が先です
- **設定 → 一般 → iPhoneストレージ** のグラフが赤なら、先に [ストレージ](/articles/iphone-storage-full/) です
- 構成プロファイルや、「更新を強制する」アプリは入れない

> **注意:** **メディアと購入** からのサインアウトでは、入っているアプリは消えません。**iPhone を消去** は使いません。アプリを削除すると、そのアプリの中にしか無いデータは消えます。削除の前に、**App を取り除く** を先にします。

## 手順

### 1. アカウント画面から、一本だけ押す

自動が止まっていても、右上の一覧から入れ直せます。

1. App Store を開く。右上の自分の写真をタップする。写真を設定していなければ、人型のアイコンです。
2. 画面を下へ引っ張って、一覧を読み直す。
3. **アプリのアップデート** に並んでいるうち、一本の **アップデート** だけ押す。**すべてをアップデート** は、どのアプリが止めたのか見えてからにします。
4. ホーム画面に戻り、そのアイコンの円が進むか見る。止まったアイコンを長押しして **ダウンロードを優先** が出たら、それを押す。待ち行列の先頭に上げる操作で、Apple が更新できないときの手順に入れています。
5. ほかのアプリが「待機中」で列を塞いでいるなら、塞いでいる側を長押しして一時停止し、欲しい側の **ダウンロードを優先** を押す。

一本だけ進むなら、回線は生きています。止まった側は、容量か、そのアプリの条件です。

### 2. 自動更新と、モバイルデータ

1. **設定 → アプリ → App Store** を開く。iOS 18 以降は、設定の下のほうにある **アプリ** の中です。一覧に **アプリ** が無い端末は、設定の検索に「App Store」と入れます。
2. **アプリのアップデート** がオフならオン。オンにしても、溜まっている分がその場で全部は入りません。手順1の手動が先に終わります。
3. 同じ画面の **モバイルデータ通信** を見る。オフだと、Wi-Fi を離れた瞬間に更新が待ちになります。家の Wi-Fi の下にいるなら、オフのままでも更新は始まります。外出先だけで止まるなら、ここです。
4. モバイルデータで、大きいアプリだけ確認を求められる機種があります。その確認を毎回拒否していると、ゲームだけ残ります。Wi-Fi に戻すと、サイズの確認を通ります。

### 3. 空き、日付、再起動

1. **設定 → 一般 → iPhoneストレージ** を開く。空きがほとんど無いと、円の途中で止まります。グラフが赤ならストレージの記事です。
2. 更新したいアプリの行を開き、**App を取り除く** があるなら、それを押してからホーム画面のアイコンをタップする。書類とデータは残り、App Store から入れ直します。雲のアイコンのまま落ちてこないアプリも、同じ操作で取り直せることがあります。
3. **設定 → 一般 → 日付と時刻** の **自動設定** がオフで、日付が何年もずれていると、Store の通信が拒否されます。オンに戻します。
4. 音量ボタンのどちらかとサイドボタンを、電源オフのスライダが出るまで押す。一度切ってから、サイドボタンで起動する。Apple も、更新できないときの手順に再起動を入れています。起動したら、手順1の一覧をもう一度下へ引っ張ります。

### 4. 支払い、Apple ID、スクリーンタイム

1. 「お支払いに問題がありました」「確認が必要です」と出るなら、無料の更新でも止まります。**設定** の一番上の自分の名前 → **お支払いと配送先** で、期限の切れたカードが残っていないか見る。直すのは、そのカードの情報です。
2. 設定の一番上に「iPhone にサインイン」と出ているなら、Store は更新を落とせません。自分の Apple ID でサインインします。
3. サインイン済みでも、Store の右上だけ別の人の写真、というときは、**設定 → 一番上の名前 → メディアと購入 → サインアウト**。アプリのアイコンは残ります。自分の ID で入り直し、手順1の一覧を引っ張ります。
4. インストールのボタンが最初から無い、子どもに渡した iPhone、なら **設定 → スクリーンタイム → コンテンツとプライバシーの制限** を見る。制限がオンのとき、中の **App のインストール**、または **iTunes および App Store での購入** が「許可しない」だと、更新も止まります。スクリーンタイムのパスコードが分からない端末では、ここで終わりです。パスコードを破る手順は書きません。

### 5. 「開く」しか無い、iOS が古い

1. アカウント画面を下へ引っ張っても、そのアプリが更新一覧に無い。アプリのページは **開く** だけ。開発元は新しい版があると言う。一覧の読み直しで出ることがあります。それでも **開く** なら、今の Apple ID にはその更新が来ていません。別の国の ID で入れたアプリは、今の Store に同じアプリが無いと更新できません。
2. ページに「iOS ○ 以降が必要」と出ているなら、アプリの不具合ではありません。**設定 → 一般 → ソフトウェアアップデート** に、新しい iOS が出るか見ます。出ない端末は、その iOS が上限です。条件を満たす端末でなければ、その更新は入りません。
3. 「この App は現在利用できません」なら、Store の公開が止まっています。削除して入れ直しても、同じ文で戻ることがあります。開発元の案内を見ます。

## まだ直らないとき

- 同じ Wi-Fi の別の iPhone では、そのアプリが更新できる。この端末は空きも支払いも足りている → Apple のサポート。消去は、案内されるまでしません
- 円が何時間も 0 のまま。**ダウンロードを優先** も再起動も同じ → 機内モードを十秒オンにしてオフにし、Wi-Fi に戻して、もう一度優先を押す。それでも 0 なら、**App を取り除く** のあとアイコンをタップする。中のデータまで消す削除は、そのアプリにバックアップの案内があるときだけにします
- **設定 → 一般 → ソフトウェアアップデート** の iOS 自体がダウンロードの途中で止まる → App Store のアプリの話ではありません。ストレージに「iOS アップデート」が残っていたら、それを削除してから、ソフトウェアアップデートをやり直します

## まとめ

右上の写真を開き、一覧を下へ引っ張って、一本だけ **アップデート** を押します。円が止まったアイコンは長押しの **ダウンロードを優先**。家を出たときだけ止まるなら、**設定 → アプリ → App Store** の **モバイルデータ通信** です。支払いの赤文字と、「iOS ○ 以降が必要」は、ボタンを重ねても進みません。
