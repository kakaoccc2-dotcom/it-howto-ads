Windows でワイヤレスイヤホン、マウス、キーボード、ゲームパッドが「ペアリング中」のまま終わらない、接続済みなのに数秒で切れる、音は出るがポインターが飛ぶ、といった状態は、機器そのものの故障より **古い登録が残っている、クイック設定だけではオフのまま、省電力で電波が落ちる** ことが多いです。USB の Bluetooth アダプターを挿しているデスクトップでは、挿し直しとドライバーの無効化もよくあります。

この記事は Windows 10 / 11 の標準 Bluetooth を対象にします。つながったあとに無音だけなら、接続より出力先です。[音が出ないときの手順](/articles/windows-no-sound/) を先に見てください。USB ドングル自体が一覧に出ないときは [USB機器が認識されない](/articles/usb-device-not-recognized/) です。

## 症状の見分け

- **設定 → Bluetooth とデバイス** に機器名が出ない。近くにあるはずなのに検出されない
- 出ているが、タップしても「接続されていません」のまま。または「ドライバー エラー」
- 一度つながって、スリープやカバンにしまったあとから二度と戻らない
- 音楽用ではつながるが、マイク付き通話だけ切れる（またはその逆）
- マウスだけ途切れる。イヤホンは安定している（またはその逆）
- 昨日まで使えていたのに、Windows Update や新しい機器を足したあとから不安定
- 同じイヤホンをスマホでは普通に使える

スマホでもダメなら、先にイヤホン側の充電とペアリングモードです。Windows だけダメなら、以下の PC 側が中心です。iPhone 側の切り分けは [iPhone の Bluetooth 手順](/articles/iphone-bluetooth-pairing/) が近いです。

## よくある原因

1. タスクバーのクイック設定では Bluetooth がオンに見えて、実際の無線は切れている
2. 以前のペアリング情報が PC と機器の双方に残り、再認証に失敗している
3. 別の端末（スマホや古い PC）に接続したままになっている
4. 電源管理で、使っていないあいだに Bluetooth アダプターの電源が落ちる
5. 飛行機モードの名残、または Wi-Fi と Bluetooth をまとめて切るメーカーユーティリティ
6. USB 3.0 ハブや金属製の机、電子レンジ近くで 2.4GHz が干渉している

## 直す前に

- イヤホン・マウスの充電残量を確認する。ケースのランプが赤いときは充電してから試す
- 機器側の「ペアリングモード」（数秒長押し、ランプが点滅）の入れ方を取説で見ておく
- 出典不明の「Bluetooth 修復ツール」や、ドライバーパックの一括インストールは使わない。標準の設定とデバイス マネージャーで足りることがほとんどです

> **注意:** デバイスの削除は、その機器の登録だけ消します。Windows 全体の初期化ではありません。ただし削除したあとは、機器側もペアリングモードに入れ直す必要があります。片方だけ消すと、また失敗しやすいです。

## 手順

### 1. クイック設定ではなく、設定アプリでオンにする

1. `Win` + `A` でクイック設定を開き、**Bluetooth** がオンか見る。オフならオン。飛行機モードのアイコンが残っていたらオフにする。
2. **設定** → **Bluetooth とデバイス** を開き、画面上部の **Bluetooth** スイッチがオンか確認する。クイック設定とここが食い違うことがあります。ここが正です。
3. ノートなら、キーボードの無線キー（アンテナや飛行機のマーク、`Fn` との組み合わせ）も一度オン側にする。メーカーによって、Windows のスイッチよりこちらが優先されます。
4. オンにしたあと 10 秒待ち、近くの機器名が一覧や「新しいデバイス」に出るか見る。

スイッチが灰色で触れない、または「このデバイスでは Bluetooth が使用できません」と出る PC は、内蔵アダプターが無い、BIOS で無効、ドライバーが落ちている、のいずれかです。手順5へ進みます。デスクトップでドングルを挿していないなら、先に挿してください。

### 2. 古い登録を消して、入れ直す

いちばん効く手順です。PC と機器の両方から消します。

1. **設定** → **Bluetooth とデバイス**。
2. 問題の機器の **その他のオプション**（…）→ **デバイスの削除** → **削除**。
3. 同じ名前が二つ出ているときは、古い方から順に両方消す。
4. イヤホンやキーボード側も、取説どおりペアリング情報を消す（リセット長押し、または機器の「スマホを忘れる」）。
5. 機器をペアリングモード（ランプ点滅）にしてから、Windows 側で **デバイスを追加する** → **Bluetooth**。
6. 名前が出たら選び、接続済みになるまで待つ。コードを求められたら、機器の画面または取説の番号を入れる。

成功の目安は、一覧が **接続済み** になり、マウスならポインターが動く、イヤホンならタスクバーのスピーカーからその機器名が選べることです。音が出ないだけのときは、このあと [音が出ない手順](/articles/windows-no-sound/) で既定の出力を見てください。通話の声だけ届かないときは [マイクが使えない手順](/articles/windows-microphone-not-working/) です。

### 3. ほかの端末が掴んでいないか

Bluetooth の多くの機器は、同時に1台（またはごく少数）にしかつながりません。

1. スマホ、タブレット、別の PC の Bluetooth 一覧から、同じ機器を切断または削除する。
2. 車載オーディオやテレビに自動接続している場合は、先にそちらの電源を切るか、機器側で「接続先」を PC にする。
3. もう一度、Windows 側で手順2の追加を行う。

「接続済み」と出てもすぐ切れるときは、スマホ側の自動再接続が奪っていることがあります。切り分けのあいだは、スマホの Bluetooth をオフにしてください。

### 4. 電源管理で、アダプターが寝ないようにする

スリープから戻ったあとだけ切れる、数分放置するとマウスが死ぬ、ときに有効です。

1. `Win` キーを押し、`デバイス マネージャー` と入れて開く。
2. **Bluetooth** を展開し、使っているアダプター（Intel、Realtek、USB Bluetooth など）を右クリック → **プロパティ**。
3. **電源の管理** タブがあれば、**電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする** のチェックを外して OK。
4. 同じ画面の **ドライバー** で、最近の日付のあとに不調が始まったなら **ドライバーを元に戻す** を試す。ボタンが灰色なら、無理に「更新」の自動検索を繰り返さない。
5. ノートの **設定 → システム → 電源とバッテリー** で、電源モードが極端な省電力になっていないか見る。試しに **バランス** か **最適なパフォーマンス** にして再接続する。

スリープから戻れない、勝手に寝る、が同時に起きているときは [スリープと復帰の手順](/articles/windows-sleep-wake-problems/) も見てください。Bluetooth アダプターの省電力は、そちらの原因にもなります。

### 5. アダプターの切り直しと、干渉

1. デバイス マネージャーの Bluetooth アダプターを右クリックし、**デバイスを無効にする** → 10秒 → **デバイスを有効にする**。
2. USB ドングルなら、いったん抜き、PC 背面の USB ポート（前面ハブや延長ケーブルではない）へ挿し直す。USB 3.0 端子のすぐ隣だと切れやすいことがあるので、離れたポートも試す。
3. 金属製の机、モニター裏、電子レンジ、コードレス電話の近くから、受信側（ノート本体やドングル）を少し離す。
4. 外付けの USB ハブにドングルを挿しているときは、本体直挿しにする。

無効のまま戻し忘れると「Bluetooth がありません」になります。有効化したあと、設定アプリのスイッチがオンに戻るか確認してください。

### 6. Bluetooth サポート サービスの確認

家庭向け PC でサービスをいじる必要はほとんどありません。スイッチがすぐオフに戻る、追加画面が真っ白、のときだけ見ます。

1. `Win` キーを押し、`services.msc` と入れて **サービス** を開く。
2. **Bluetooth サポート サービス**（英語表示なら Bluetooth Support Service）を探してダブルクリック。
3. **スタートアップの種類** が **手動** または **自動** であること。**無効** なら **手動** に変えて **開始**。
4. 状態が **実行中** になってから、設定アプリで Bluetooth を入れ直す。

職場 PC でこの項目が灰色なら、個人では変更できません。IT 担当へ渡します。スタートアップ全体が重いせいでサービス起動に失敗しているように見えるときは、[スタートアップの整理](/articles/windows-startup-apps/) も有効です。

## まだ直らないとき

- 一覧には出るが、ドライバー エラー → デバイス マネージャーで黄色い印のアダプターを開き、いったん無効→有効。メーカーサイトの Bluetooth / チップセットだけを入れる。パック型の一括ドライバーは使わない
- イヤホンはつながるが、マイク付き通話だけおかしい → ステレオと Hands-Free が別デバイスとして出ます。通話アプリ側のマイクとスピーカーを、同じ機器の正しい項目にする
- マウスだけ途切れる → 受信機（2.4GHz ドングル）と Bluetooth を取り違えていないか見る。付属レシーバー型は Bluetooth 設定ではなく、USB の挿し直しです
- ほかの Bluetooth 機器は使える → 問題の機器側のリセットと充電。PC 全体の設定を深追いしない
- どの機器も検出されない、アダプターが一覧に無い → デスクトップはドングルの有無、ノートはメーカーの無線スイッチ。BIOS の書き換えやファームウェア更新はこの記事ではしません。メーカーサポートへ型番を渡す

## まとめ

Windows の Bluetooth は、クイック設定のアイコンより **設定アプリのスイッチと、古い登録の削除** が本体です。機器と PC の両方から消して入れ直し、ほかの端末が掴んでいないかを見て、それでも途切れるなら電源管理です。新しい修復ツールを入れる前に、標準の削除と再ペアリングで足りることがほとんどです。
