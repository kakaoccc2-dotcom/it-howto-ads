iPhone 側はアンテナがあるのに、ノート PC の Wi-Fi 一覧にホットスポットが出ない。つながっても「インターネットなし」。Android や Windows からは見えるが、すぐ切れる。Wi-Fi そのものが家のルーターに繋がらない話は扱いません。iPhone 単体の回線は [モバイルデータ](/articles/iphone-mobile-data-not-working/) 、家の Wi-Fi は [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) です。

この記事は、iPhone を親機にして別の機器を乗せる **インターネット共有** です。Android を親機にする手順は機種差が大きいので、ここでは書きません。家族の iPhone では共有できるのに自分だけダメ、なら設定か契約です。どの iPhone から出してもダメなら、その場所の電波か、キャリアの障害です。

## 症状の見分け

- **設定 → インターネット共有** の項目自体が無い、または灰色
- スイッチはオンなのに、PC や Android の Wi-Fi 一覧に iPhone の名前が出ない
- 名前は出るが、パスワードを入れても「接続できません」
- つながった表示なのに、ブラウザが白い。Windows なら「インターネットなし」
- USB ケーブルで PC につないでも、ネットワークアダプターに出ない
- 同じ Apple ID の Mac なら Instant Hotspot で出るが、Windows だけ出ない

コントロールセンターのインターネット共有アイコンは、設定のスイッチと連動します。アイコンが無い機種・iOS では、設定アプリ側で見てください。

## よくある原因

1. モバイルデータがオフ、または親機の iPhone 自身が家の Wi-Fi に繋がったまま共有しようとしている
2. **ほかのユーザの参加を許可** がオフで、見知らぬ機器からは見えない
3. 契約にテザリングが含まれていない、または容量超過で止められている
4. パスワードの取り違え、SSID（名前）の変更が相手に残っている
5. Windows / Android が 5GHz 側を探し、iPhone が 2.4GHz だけ出している（またはその逆）
6. VPN、プライベートリレー、低データモードが、共有先の通信だけ失敗する

## 直す前に

- 親機 iPhone のパスコードを、すぐ開ける状態にしておく。共有の初回はロック解除が要ることがあります
- 相手機器（ノート PC など）の Wi-Fi パスワード入力画面を出しておく
- キャリアの「テザリング無料」「オプション未加入」を、マイページで一度見る。設定だけでは契約は増えません

> **注意:** インターネット共有は、親機のモバイルデータ容量を食います。動画のバックアップや Windows Update を流すと、すぐ上限です。会社の MDM で共有が禁止されている iPhone は、スイッチが灰色のままです。非公式の「テザリング解除」構成は入れないでください。

## 手順

### 1. 親機 iPhone の回線を先に通す

1. 親機で **機内モードをオフ**。**設定 → モバイル通信** でモバイルデータ通信をオン。5G / LTE が出るか見る。出ないなら、共有の前にモバイルデータの記事です。
2. 親機の **Wi-Fi をオフ** にする。家のルーターに繋がったまま共有すると、相手に「インターネットなし」が出ることがあります。テザリングはモバイル回線を配る機能です。
3. Bluetooth はオンのままでよいです。Instant Hotspot（同じ iCloud の Mac / iPad）は Bluetooth を使います。
4. 親機で Safari を開き、モバイルだけで適当なページが開くか確認する。親機が圏外なら、共有先も圏外です。

低データモードがオンだと、共有先のアプリが「繋がっていない」ように見えることがあります。切り分けのあいだオフ。

### 2. インターネット共有をオンにする

1. **設定 → インターネット共有**。項目が無いときは **設定 → モバイル通信 → インターネット共有**。
2. **ほかのユーザの参加を許可** をオン。パスワードが表示されます。紙に控える。大文字小文字、スペースをそのまま。
3. **Wi-Fi のパスワード** を、覚えやすいものに変えてもよいです。変えたあとは、以前つないだ機器側の保存ネットワークを忘れてから入れ直す。
4. コントロールセンターにインターネット共有が出る機種は、そこが緑か見る。灰色なら設定側がオフです。

スイッチが灰色、または画面に「通信事業者がインターネット共有を許可していません」と出るなら、端末設定ではなく契約か SIM。キャリアに「テザリングオプション」を確認してください。MVNO はプランによって最初から無し、があります。

### 3. 相手の機器から、名前とパスワードでつなぐ

1. Windows ならタスクバーの Wi-Fi → 一覧に iPhone の名前（**設定 → 一般 → 情報 → 名前**）があるか見る。
2. Android なら **設定 → ネットワークとインターネット → インターネット** の Wi-Fi 一覧。
3. 同じ名前が無ければ、iPhone 側で共有をいったんオフ→オン。親機の画面を点灯したまま、ロックも解除したままでもう一度探す。
4. パスワードを入れても失敗するときは、相手側でその SSID を「忘れて」、iPhone に表示されているいまのパスワードを打ち直す。以前変えたパスが残っていることが多いです。

iPhone 同士、または Mac なら、同じ Apple ID で **Instant Hotspot** が出ます。設定のインターネット共有をオンにしなくても、相手の Wi-Fi 一覧に親機名が出ることがあります。Windows や Android にはこの仕組みは無いので、手順2のスイッチが必須です。

### 4. 「互換性を最大化」と、USB 共有

1. インターネット共有の画面に **互換性を最大化** があればオンにする。2.4GHz 側で出す設定です。古い Windows、安い子機、IoT 機器は 5GHz の iPhone 名を拾いません。
2. まだ一覧に出ないときは、USB ケーブルで PC と iPhone をつなぐ。iPhone に「このコンピュータを信頼」と出たら信頼する。
3. Windows は **設定 → ネットワークとインターネット** に、iPhone 由来の Ethernet やリモート NDIS が出るか見る。出れば USB 経由の共有です。出ないときは Microsoft Store の **Apple Devices**（古い PC なら iTunes）が入っているか見る。ドライバーが無いと充電だけして、ネットワークには出ません。
4. ケーブルが充電専用だと、ランプは点いてもネットワークには出ません。写真を取り込めるケーブルか、[USB が認識されないとき](/articles/usb-device-not-recognized/) と同じ切り分けです。

Lightning / USB-C の変換を何段も重ねると失敗しやすいです。端子が一致する一本にします。

### 5. VPN・リレーを切って、ネットワーク設定をリセット（最終手前）

1. 親機の VPN を切る。共有先にも別の VPN を入れない。二重になると名前解決だけ死にます。
2. 親機の **iCloud プライベートリレー** を、切り分けのあいだオフ。
3. 相手が Windows で「インターネットなし」だけなら、家の Wi-Fi ではなく DNS 側のこともあります。[DNS サーバーに問題があります](/articles/windows-dns-server-problem/) と、[Wi-Fi は繋がるのに出られない](/articles/wifi-connected-no-internet/) を、テザリング中の表示と取り違えないでください。今は iPhone 経由です。
4. 親機で **設定 → 一般 → 転送または iPhone をリセット → リセット → ネットワーク設定をリセット**。Wi-Fi パスも消えます。家のパスを控えてから。

> **注意:** リセットしても契約は変わりません。オプション未加入のままスイッチだけ復活することはありません。リセット後はモバイルデータが通ることを確認してから、もう一度インターネット共有をオンにします。

## まだ直らないとき

- 項目が無い → iOS の検索バーで「インターネット共有」。スクリーンタイムの **コンテンツとプライバシー制限 → モバイルデータ通信の変更** がオフだと灰色
- つながるがすぐ切れる → 親機のロック、省電力、電波。親機を充電器につなぎ、画面を点灯したまま試す。Wi-Fi が頻繁に切れる一般論は [Wi-Fi が頻繁に切れるとき](/articles/wifi-keeps-disconnecting/) ですが、テザリング中の親機スリープが先です
- PC だけダメ、別のスマホは乗れる → PC の Wi-Fi 子機。互換性を最大化、USB 共有
- 誰の機器も乗ると親機が熱い → 仕様に近いです。動画の大容量は避ける。熱で通信が落ちるなら、ケースを外して冷ます
- 職場の iPhone → MDM。個人の設定では終わりません

Apple Watch だけの通信、Mac の Instant Hotspot は、Windows 向けのこの手順とは別物です。相手が Windows なら **ほかのユーザの参加を許可** がオンかを先に見る。

## まとめ

テザリングできないときは、相手の Wi-Fi より先に親機です。モバイルデータが通っているか、インターネット共有がオンか、**ほかのユーザの参加を許可** がオンか。家の Wi-Fi に親機が乗ったまま配ると、接続済みなのにネットなし、になりやすいです。契約にテザリングが無いときは、設定を繰り返しても項目は灰色のままです。
