自動修復やスタートアップ修復から先に進めないときは、ディスクを消す前にここを見てください。普段どおり起動できる容量不足は [ストレージ不足の片付け](/articles/windows-storage-full/)、更新のパーセントだけなら [Windows Update が進まないとき](/articles/windows-update-stuck/) です。

## 症状の見分け

- ロゴのあと、自動修復から進まない、同じ画面を繰り返す
- スタートアップ修復が失敗し、「PCが正しく起動しませんでした」
- 通常起動はできないが、セーフモードならデスクトップが出る
- 昨日の更新や、電源コードが抜けたあとにだけ再現する
- BitLocker の回復キー入力を求められる

黒い画面にマウスだけ、または BIOS（メーカーロゴで F2 / Del）にも入れない場合は、OS の修復よりハードウェアか電源です。修復コマンドを重ねないでください。

## よくある原因

1. Windows Update のインストール中に電源が落ちた、または再起動ループになった
2. ディスプレイ／チップセット／セキュリティソフトのドライバーが、通常起動だけ失敗する
3. ディスクの一時的なエラー（ファイルシステムの不整合）
4. 高速スタートアップのあと、中途半端な状態で落ちた
5. BitLocker が有効で、マザーボードや起動順の変化を不正と見なしている

起動はするが極端に遅いだけのときは [動作が遅いときの手順](/articles/windows-pc-running-slow/) です。

## 直す前に

- ノートなら充電器をつなぐ。作業中にバッテリー切れで再ループしないようにする
- 可能なら、スマホでこのページを開きながら作業する（PCが使えないため）
- Microsoft アカウントを使っているなら、別の端末で [BitLocker の回復キー](https://account.microsoft.com/devices/recoverykey) を確認できるか見る。聞かれたときに入力する。推測や空欄で何度も試さない
- 外付けHDD や大事なUSBメモリはいったん外す（起動順が変わることがある）

> **注意:** ディスクの初期化、`diskpart` でのクリーン、レジストリファイルの配布、出所不明の「修復ISO」「一発復活ツール」は使わないでください。BIOS / UEFI のファームウェア更新もしません。この記事は、Windows の回復画面にある標準項目だけを使います。データの入ったドライブをフォーマットしないでください。

## 手順

### 1. 回復環境（Windows 回復環境）を出す

すでに「オプションの選択」や「トラブルシューティング」が出ているなら、手順2へ進みます。

まだロゴと自動修復を繰り返すだけのときは、次のどちらかです。

1. 電源ボタンを長押しして強制終了 → 入れる、を自動修復に入るまで最大2〜3回だけ試す。入ったら繰り返さない。
2. 別の Windows PC がある場合でも、インストール用メディアの作成は必須ではありません。本体の回復画面を先に使います。

「オプションの選択」が出たら、**トラブルシューティング** → **詳細オプション** を開きます。

### 2. スタートアップ修復を1回だけ実行する

1. 詳細オプションで **スタートアップ修復**（機種によっては「修復」）を選ぶ。
2. アカウントとパスワードを求められたら入力する。
3. 完了まで待つ。成功したら通常起動できるか確認する。

失敗しても、同じ修復を連続で何回も回す必要はありません。1回失敗したら手順3へ。

### 3. セーフモードで起動できるか見る

ドライバーや常駐が原因のときに効きます。

1. 詳細オプション → **スタートアップ設定** → 再起動。
2. 数字キーの 4 または F4（セーフモード）、ネットも必要なら 5 / F5（セーフモードとネットワーク）。
3. デスクトップが出たら、最近入れたアプリや、メーカー以外のセキュリティソフトを **設定 → アプリ** から外す。
4. [スタートアップの整理](/articles/windows-startup-apps/) で、原因になりそうな常駐をオフにする。
5. 再起動し、通常起動できるか見る。

セーフモードでも真っ黒、またはすぐ落ちるなら、ドライバーよりディスクかシステムの復元です。外付けモニターだけが関係しているように見えるときは、ケーブルを外して内蔵画面だけで試してください。映り方の切り分けは [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) です。

### 4. 最近の更新を取り消す

更新の直後からループしているときに効きます。

1. 詳細オプション → **更新プログラムのアンインストール**。
2. 案内に従い、最新の品質更新プログラム、だめなら最新の機能更新プログラムをアンインストールする。
3. 再起動し、通常起動できるか見る。

どちらが原因かわからないときは、品質（毎月の小さいほう）から試します。会社PCで項目が灰色のときは、個人では取り消せません。

### 5. システムの復元（個人の復元ポイントがあるとき）

アプリを入れた日やドライバー更新の直前に戻します。

1. 詳細オプション → **システムの復元**。
2. 復元ポイントが一覧にあれば、不調が始まる前の日付を選ぶ。無いときはこの手順は使えません。
3. 影響を受けるプログラムの案内を読み、問題なければ実行する。

> **注意:** 復元すると、その日付以降に入れたアプリやドライバーは消えることがあります。ドキュメントや写真などの個人ファイルは、通常は残りますが、復元中に電源を切らないでください。

### 6. コマンド プロンプトでの点検（任意・上級）

スタートアップ修復も復元も使えないときに限ります。詳細オプションの **コマンド プロンプト** を開きます。

```text
chkdsk C: /f
```

完了後、`exit` して再起動します。エラーを直したと出たら、もう一度通常起動を試します。

続けてシステムのファイル点検をする場合は、ネットにつながるセーフモードか、通常起動できたあとで次を使います（回復環境ではドライブ文字が C ではないことがあります）。

```text
sfc /scannow
```

`C:` が見当たらない、または別文字になっているときは、無理に別ドライブへ `chkdsk` しないでください。わからない時点でメーカーサポートへ写真を渡します。

## まだ直らないとき

- BitLocker のキーを求められた → Microsoft アカウントの回復キー一覧か、組織の IT 担当が持つキーです。キーが無い状態でディスクを初期化すると、中身は戻りません
- 回復画面自体が出ない、メーカーロゴのあと即電源が落ちる、カチカチ異音 → ストレージか電源の故障があり得ます。重要データの救出を優先し、保証内なら分解せずメーカーへ
- 「この PC を初期状態に戻す」は、ファイルを残すオプションがあってもアプリは消えます。上記1〜5で戻らないときの最終手段です。実行前に、別 PC へ出せるデータの有無を確認する
- 職場・学校 PC → 個人の復元や初期化がポリシーで禁止されていることがあります。資産管理の担当へ、画面の全文写真を渡す
- 起動できたあとに更新がまた失敗する → [Windows Update が進まないとき](/articles/windows-update-stuck/) で配布フォルダーを入れ直す。空きが無ければストレージ記事へ

## まとめ

修復画面が出ても、フォーマットの話ではありません。スタートアップ修復を1回、だめならセーフモードと更新の取り消し、と進めてください。異音、ロゴ前の停止、BitLocker のキーが無いときは、ここで止めてサポートへ。
