「バックアップを作成できませんでした」。**最後に成功したバックアップ** が何週間も前の日付のまま。**今すぐバックアップを作成** を押しても、パーセントが途中で止まる。写真が撮れない本体容量の話は [iPhoneのストレージ不足](/articles/iphone-storage-full/) です。こちらは **iCloud 上のバックアップ** が失敗する、終わらないときだけです。

## 症状の見分け

- **設定** を開くと、「iPhoneのバックアップを作成できませんでした」と出る
- 文面に **iCloudストレージに十分な空き領域がありません** とある
- **最後に成功したバックアップ** の日付が、昨日や今朝ではなく何日も前
- 「バックアップを作成中」のまま、パーセントが何時間も動かない
- 充電してロックしているのに、朝になっても日付が更新されない
- Wi-Fi を切ったモバイル通信だけでは、バックアップが始まらない

本体の空きは十分あるのにこの文面なら、ここから先です。iPhone のストレージ画面が赤いなら、先に本体側の片付けです。バックアップは本体のコピーを iCloud に置くので、クラウド側の空きが別に要ります。

## よくある原因

1. iCloud の 5GB 無料枠が、写真や前の iPhone のバックアップで埋まっている
2. Wi-Fi ではなくモバイル通信のまま。iCloud バックアップは Wi-Fi が要る
3. 充電していない、ロックしていない、低電力モードで、自動バックアップが後回しになっている
4. 大きいアプリのデータがバックアップに入り、途中で失敗している
5. 日付と時刻がずれていて、アップロードが拒否されている
6. VPN や不安定な Wi-Fi で、作成中のまま切れる

## 直す前に

- 残したい写真と LINE などのトークは、バックアップが失敗しているあいだ、この iPhone の中にしか無いものがあります。失敗中に初期化しない
- 古い端末のバックアップを消すと、その端末の時点には戻せません。消す対象の名前と日付を読む
- 会社支給の iPhone で iCloud の項目が灰色なら、個人の Apple ID では枠を増やせないことがあります

> **注意:** **このiPhoneをバックアップ** をオフにすると、iCloud に置いてあるこの端末のバックアップが、あとから削除されます。失敗の切り分けで、このスイッチを不用意に切らないでください。「すべてのコンテンツと設定を消去」も、この記事では使いません。

## 手順

### 1. 失敗の文面と、最後に成功した日付を読む

1. **設定** の一番上、自分の名前を押す。
2. **iCloud** → **iCloudバックアップ**。
3. **最後に成功したバックアップ** の日付と時刻を見る。今日なら、いまのエラーは別の一時的な失敗です。何日も前なら、自動では終わっていません。
4. 同じ画面に赤い説明が出ていれば、その文をメモする。空き領域、とネットワーク、では次の手順が違います。
5. **このiPhoneをバックアップ** がオフなら、オンにする。オフの理由が分からないままオンに戻すだけなら、中身は消えません。オンにした瞬間にバックアップが走るので、このあと手順2と3を先に済ませてからでもかまいません。

日付が今日で、エラー文も無いなら、失敗はもう残っていません。次に失敗したときの文面を見てから戻ってください。

### 2. iCloud の空きと、古いバックアップ

「十分な空き領域がありません」のときの手順です。本体の写真を消しても、iCloud の枠は空きません。

1. **設定 → 自分の名前 → iCloud** を開き、容量のバーを見る。満杯、または残りが数百MBならバックアップは落ちます。
2. **ストレージを管理**（**アカウントのストレージ** と出る版もあります）を開く。
3. 一覧の **バックアップ** を開く。前に使っていた iPhone や、家族と共有していない古い名前が残っていないか見る。
4. 消してよい古い端末の名前を開き、**バックアップを削除**。確認の文を読んでから進める。今つかんでいる iPhone の行は、成功したバックアップが一つも無いあいだは消さない。
5. バーに戻って空きが増えたら、**iCloudバックアップ** に戻り **今すぐバックアップを作成** を押す。

写真やメールがバーの大半なら、バックアップの行を消しても数GBしか戻りません。iCloud 写真の整理は本体のストレージ記事とは別で、**設定 → 自分の名前 → iCloud → 写真** 側の容量です。有料プランを足す前に、古い端末のバックアップと、使っていない大容量のバックアップ対象を先に見てください。

> **注意:** バックアップの削除は、そのコピーを捨てる操作です。写真アプリの「最近削除した項目」とは違い、30日では戻りません。名前を読み間違えないでください。

### 3. Wi-Fi、充電、ロックのまま待つ

空きはあるのに終わらない、日付だけ古い、というときに多いです。

1. 自宅の Wi-Fi に接続する。モバイル通信のマークだけ、コントロールセンターが機内モード、という状態ではバックアップは始まりません。Wi-Fi 自体が不安定なら [iPhoneがWi-Fiに繋がらないとき](/articles/iphone-wifi-cannot-connect/) を先に見てください。
2. 電源につなぐ。残量が多くても、ケーブルが抜けていると自動バックアップは後回しになります。
3. **設定 → バッテリー** で **低電力モード** がオンならオフにする。黄色の電池アイコンが出ているあいだは、裏のアップロードが止まりやすいです。
4. **iCloudバックアップ** に戻り、**今すぐバックアップを作成** を押す。画面に「バックアップを作成中」と、残り時間かパーセントが出ることを見る。
5. 作成中は iPhone をロックして、そのまま置く。画面を付けたままアプリを触っていると、進みが遅く、途中で切れたように見えます。
6. ロックしたあと 15分ほどしてから開き、**最後に成功したバックアップ** が今の時刻に近い日付になっているか見る。

「残り時間を計算中」のまま長いときは、バックアップのサイズが大きいだけ、ということもあります。写真やアプリのデータが数十GBあると、初回は一晩かかります。そのあいだに Wi-Fi が切れると、また計算からになります。

### 4. 日付、VPN、大きすぎるアプリ

計算が終わったあとにすぐ失敗するときの切り分けです。

1. **設定 → 一般 → 日付と時刻** で **自動設定** がオンか見る。オフで日付が飛んでいると、iCloud が受け付けません。
2. **設定 → 一般 → VPNとデバイス管理** に VPN がオンなら、バックアップのあいだだけオフにする。会社のプロファイルを削除はしない。接続の解除だけです。
3. 失敗の直前までパーセントが進むなら、**設定 → 自分の名前 → iCloud → ストレージを管理 → バックアップ → このiPhone** を開く。アプリごとのオン／オフと、サイズが並びます。
4. ゲームなど、セーブを iCloud に載せなくてよいアプリだけオフにする。メッセージ、ヘルスケア、パスワードが入った行は、理由が読めるまでオフにしない。
5. オフにしたら、もう一度 **今すぐバックアップを作成**。成功の日付が更新されれば、そのアプリの大きさが途中失敗の原因でした。

オフにしたアプリのデータは、次のバックアップには入りません。iPhone を壊したときに、そのゲームの続きは戻りません。写真は iCloud 写真を別に使っているなら、バックアップの対象から外れていてもクラウド側に残っていることがあります。両方オフ、という状態にしないでください。

### 5. コンピュータへのバックアップに切り替える

iCloud の枠を増やせず、消してよい古いバックアップも無いときは、Mac の Finder、または Windows の「Apple デバイス」アプリ（古い環境では iTunes）へケーブルでコピーします。

1. iPhone の端子を見る。iPhone 15 以降は USB-C、それより前は Lightning です。充電しかできない細い互換ケーブルだと、コンピュータに「このiPhone」が出ません。
2. コンピュータに繋ぎ、iPhone 側に「このコンピュータを信頼しますか」と出たら **信頼**。パスコードを入れる。
3. Mac なら Finder のサイドバーに iPhone が出る。Windows なら Apple デバイスアプリ（または iTunes）にデバイスが表示される。
4. **すべてのバックアップを暗号化** にチェックを入れる場合は、パスワードを紙に書く。忘れたバックアップは復元できません。暗号化しない選択もあります。ヘルスケアなどの一部は、暗号化したバックアップにしか入りません。
5. **今すぐバックアップ** を押す。終わるまでケーブルを抜かない。完了と出たら、バックアップの日付が今日になっていることを見る。

iCloud 側の失敗は、このコピーとは別です。コンピュータに取れたからといって、iCloud の赤いエラーが自動では消えません。クラウドにも残したいなら、手順2で空きを作ったあとにもう一度 iCloud を試してください。

## まだ直らないとき

- 空きを作っても同じ「十分な空き領域がありません」 → バーの数字が本当に増えたか、もう一度ストレージを見る。写真の iCloud が満杯のままなら、バックアップ行だけ消しても足りません
- 作成中が毎晩切れる → 充電器が接触不良で、夜中に給電が止まっていないか。朝の電池残量が減っていたら、ケーブル側です
- Wi-Fi では失敗、別の家の Wi-Fi では成功 → 自宅の回線かルーター。iPhone の初期化では見分けが付きません
- サインインを求められてバックアップが進まない → Apple ID のパスワード。直ったあとに **今すぐバックアップ** を押し直す
- コンピュータにも iPhone の名前が出ない → ケーブルを替え、別の USB ポートに挿す。信頼のボタンが出ないままなら、iCloud の手順を繰り返してもコンピュータ側は始まりません

## まとめ

失敗の文面が空き領域なら、本体の写真ではなく **iCloud のバーと、古い端末のバックアップ** です。日付だけ古いなら、Wi-Fi と充電とロックのまま **今すぐバックアップを作成** を最後まで待ちます。スイッチをオフにして切り分けないでください。クラウドの枠がどうしても足りないときは、ケーブルでコンピュータへ別のコピーを取ります。
