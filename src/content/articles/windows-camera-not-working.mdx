Zoom や Teams、ブラウザ会議で自分だけ黒い、カメラアプリを開くと「使用中」や「起動できません」、設定のプレビューが動かない、といった状態はカメラ故障より **プライバシー許可がオフ、物理シャッター、別アプリの占有、外付けと内蔵の取り違え** が多いです。Windows はマイクとカメラの許可が別画面なので、声は届くのに映像だけ無い、がよく起きます。

この記事は Windows 10 / 11 の内蔵カメラと USB Webカメラを対象にします。声が届かないときは [マイクが使えない手順](/articles/windows-microphone-not-working/) です。USB カメラ自体がデバイス一覧に出ないときは、先に [USB機器が認識されない](/articles/usb-device-not-recognized/) です。

## 症状の見分け

- 会議はつながるが、自分の映像だけ黒い、または「カメラを起動できません」
- **設定 → プライバシーとセキュリティ → カメラ** のプレビューが動かない
- カメラアプリでは映るが、ブラウザだけ映らない（またはその逆）
- 昨日まで使えていたのに、Windows の更新後や、新しい会議アプリを入れたあとから真っ黒
- 外付けカメラを挿すと内蔵が選べなくなる、またはその逆
- ランプは点くが映像が来ない、またはランプ自体が点かない

プレビューが動けばハードウェアは生きています。動かないなら許可・シャッター・ドライバーを先に見ます。ランプが点くのに真っ黒なら、アプリのデバイス選択か占有です。

## よくある原因

1. **設定 → プライバシーとセキュリティ → カメラ** で、OS またはそのアプリがオフ
2. ノートの物理シャッター、Fn キーのカメラオフ、シールやカバーの閉じ忘れ
3. 先に開いたアプリがカメラを独占している（カメラアプリ、ブラウザの別タブ、メーカーの顔認証）
4. 会議アプリ内のカメラ選択が、使っていない機器名になっている
5. ブラウザのサイト許可（鍵アイコン）だけオフ
6. iVCam などの仮想カメラ、または古いドライバーが「通常のカメラ」より優先されている

外付けディスプレイをつないだ直後から内蔵カメラが消えたように見えるときは、モニター内蔵カメラが既定になっていることがあります。映りそのものの切り分けは [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) も参照してください。

## 直す前に

- レンズのスライドカバーが閉じている、シールが貼ったまま、を先に見る
- キーボードのカメラキー（Fn + カメラアイコン）を一度押し、インジケーターが変わらないか見る
- 会議アプリと、Windows 付属の **カメラ** アプリをいったん終了する（占有の切り分け）

> **注意:** 「Webカメラ修復」「ドライバーパック」を名乗る実行ファイルは入れないでください。許可と既定デバイス、公式のカメラドライバーで足りることがほとんどです。レジストリでプライバシーを書き換える必要はありません。

## 手順

### 1. Windows のカメラ許可を確認する

1. **設定** → **プライバシーとセキュリティ** → **カメラ**。
2. **カメラへのアクセス** がオンか見る。オフならオンにする。
3. **カメラにアクセスできるアプリを選択** で、使っている会議アプリや **カメラ** アプリがオンか見る。
4. 下のほうの **デスクトップ アプリがカメラにアクセスすることを許可する** もオンにする（Store アプリではない Zoom / Discord / ブラウザで必要です）。
5. 同じグループに **マイク** の許可が別にあるので、声だけ無いときはマイク記事へ。取り違えないでください。

組織の PC では、このスイッチ自体が灰色で触れないことがあります。その場合は IT 担当へ、カメラ画面のスクリーンショットを渡します。顔認証（Windows Hello）を使う機種でも、会議中のカメラ許可は別です。

### 2. Windows のカメラアプリでプレビューを見る

1. スタートメニューから **カメラ** を開く。
2. 映像が出るか、切り替えアイコンで内蔵と外付けが入れ替わるか見る。
3. 「使用中です」と出るときは、タスク マネージャーで他の会議アプリやブラウザを終了してから開き直す。

ここで映るならハードウェアと OS の許可は生きています。映らない会議アプリ側の選択と、ブラウザ許可へ進みます。ここで真っ黒なら、手順4のデバイスとドライバーです。

カメラアプリが「実行できません」と出る場合は、カメラ以前の互換性エラーです。[このアプリは実行できません](/articles/windows-app-cannot-run/) を先に見てください。

### 3. 会議アプリとブラウザの選択を揃える

1. Teams / Zoom / Meet を完全に終了してから起動し、設定の **カメラ** で機器名を選ぶ。Windows の許可がオンでも、アプリが「なし」や古い仮想カメラを掴んでいることはよくあります。
2. ブラウザ会議なら、アドレス欄の **鍵（またはカメラ）アイコン** → カメラを **許可**。サイトごとに拒否が残ります。
3. 同じサイトを別ブラウザで開き、片方が映れば拡張機能かサイト許可です。
4. 仮想カメラ（スマホ連携、背景合成）を使っていないときは、一覧から外すかアプリを終了する。名前が `OBS`、`ManyCam`、`iVCam` になっていると、実カメラが選ばれません。

起動時にカメラユーティリティが常駐していると、既定が毎回書き換わります。不要なら [スタートアップの整理](/articles/windows-startup-apps/) で、カメラに関係する常駐だけ残します。

### 4. デバイス マネージャーと、USB の切り分け

1. スタートボタンを右クリック → **デバイス マネージャー**。
2. **カメラ** または **イメージング デバイス** を開く。黄色い「！」や「不明なデバイス」を探す。
3. 問題の項目を右クリック → **デバイスのアンインストール**。アンインストール後に再起動し、内蔵なら待ち、USB なら挿し直す。Windows が標準ドライバーを入れ直します。
4. USB カメラは **PC 本体のポートへ直挿し** する。モニター背面や未給電ハブは電力不足でランプだけ点くことがあります。
5. 内蔵だけダメで USB カメラは映るなら、内蔵のシャッターか基板側です。保証内なら、手順1の画面写真と「USB なら映る」を添えてメーカーへ。

ドライバーは PC メーカーのカメラ／イメージング用を使う。汎用の「USBカメラ最新版」をまとめサイトから入れる必要はありません。

### 5. プライバシーの物理スイッチと、Windows Hello

1. ThinkPad など、画面枠のスライドカバーや、キーボードのカメラ無効キーがある機種は、LED の状態をマニュアルどおり確認する。カバーが閉まっていると、許可をオンにしても真っ黒です。
2. **設定 → アカウント → サインイン オプション** の顔認証が「カメラを使用できません」と出るときは、会議より先に Hello 用カメラが落ちています。メーカーの顔認証ユーティリティを入れ直すか、PIN でサインインして会議用カメラだけ切り分ける。
3. グループポリシーやセキュリティソフトの「Webカメラ制御」がオンの社内 PC では、個人のプライバシー画面をいじっても戻りません。

## まだ直らないとき

- カメラアプリは映るが会議だけ真っ黒 → アプリ内のデバイス名、ブラウザのサイト許可、仮想カメラの残留。再インストールより先に選択を揃える
- どのアプリでも真っ黒、デバイス マネージャーにカメラが無い → ドライバーまたはハードウェア。USB カメラを1台借りて、同じ PC で映るかで本体側かを分ける
- 映像は出るが極端に暗い・逆光 → 許可の問題ではなく、アプリ内の照明・背景ぼかし。Windows のプライバシー画面では直りません
- 更新直後から内蔵が消えた → [Windows Update が進まないとき](/articles/windows-update-stuck/) とは別に、更新履歴からカメラ関連ドライバーだけ失敗していないか見る。失敗していればメーカー公式ドライバーを先に入れる
- 職場PCでプライバシー画面が操作できない → 会議ツール名と、「カメラアプリでは映る / 映らない」を担当へ伝える
