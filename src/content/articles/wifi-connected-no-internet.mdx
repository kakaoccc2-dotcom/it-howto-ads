タスクバーの扇形アイコンはつながっているのに、ブラウザだけ読み込めない、「接続済み、インターネットなし」と出る、という状態は、電波が切れたときとは別の切り分けになります。Wi-Fi 認証までは成功していて、**その先のルーター、DNS、VPN、ホテルなどのログインページ** で止まっていることが多いです。

この記事は Windows 10 / 11 と、自宅または公衆無線LANを対象にします。Android だけが「インターネットなし」のときは [Android の Wi-Fi 手順](/articles/android-wifi-cannot-connect/) が近いです。Chrome に「DNSサーバーに問題があります」と出る場合は、この記事で番号通信を確認したあと [DNS の手順](/articles/windows-dns-server-problem/) へ進みます。

## 症状の見分け

- Wi-Fi 名の横に「接続済み」と出るが、ブラウザがタイムアウトする
- 「接続済み、インターネットなし」「セキュリティで保護されていない」だけが続く
- スマホのモバイルデータでは同じサイトが開ける
- 同じ Wi-Fi のテレビや家族のスマホは普通に使える（この PC だけ）
- 家族の端末も全員ダメ（ルーターか回線側）
- 会社VPNを切ると直る / つなぐと再現する
- ホテルやカフェで、ブラウザを開いても利用規約ページが出ない

特定のサイトだけダメで、検索や他サイトは使えるなら、サイト側の障害か DNS の部分障害です。全部ダメなら、この先の順で見ます。

## よくある原因

1. ルーターは生きているが、ONU（光回線の終端）や ISP 側が落ちている
2. DHCP で受け取った DNS が応答しない、または古い手動 DNS / プロキシが残っている
3. VPN、セキュリティソフトのウェブ保護、ファイアウォールのプロファイル違い
4. 公衆無線LANのキャプティブポータル（ログインページ）に出ていない
5. アダプターが「識別されていないネットワーク」、または仮想アダプターが優先されている
6. スマホのテザリング側でデータ通信がオフ、または端末側のプライベートDNS

プリンターだけ不通なら、インターネット全体ではなく機器側です。[プリンターがオフライン](/articles/printer-offline/) を見てください。

## 直す前に

- スマホのモバイルデータで、今このページや回線ステータスを見られるようにする
- 使っているSSIDのパスワードを、あとで入れ直せるよう控える（ネットワークリセットに進む場合）
- 作業中のVPNは一度切る

> **注意:** 「ネット修復ワンクリック」系の実行ファイルは使わないでください。**ネットワークのリセット**は Wi-Fi パスワードとVPN設定も消します。最後の手段として警告つきで書きます。レジストリ掃除は不要です。

## 手順

### 1. 自分のPCだけか、家全体かを分ける

1. 同じ Wi-Fi に載っているスマホやタブレットで、ブラウザが開くか見る。
2. スマホを **モバイルデータ** にして、同じサイトが開くか見る（サイト側の障害切り分け）。
3. 可能なら、LANケーブルでルーターに直結してみる。有線だけ直るなら Wi-Fi 側、有線でもダメならルーターか回線です。

家中ダメなら、手順6のルーター再起動を先にしても構いません。自分の PC だけなら手順2へ進みます。

### 2. Windows の表示と、機内モードの入れ直し

1. **設定** → **ネットワークとインターネット** → **Wi-Fi** で、今のSSIDに接続済みと出ているか見る。
2. 機内モードをオン → 10秒 → オフ。Wi-Fi を入れ直す。
3. 同じ画面の **ハードウェア プロパティ** で、IPv4 アドレスが `169.254.` で始まっていないか見る。これだと DHCP に失敗していて、インターネットには出られません。
4. ゲートウェイ（例: `192.168.0.1` や `192.168.1.1`）が表示されているか見る。空なら手順4のIP設定です。

`169.254.` のときは、Wi-Fi を「忘れる」→ パスワードを手入力で入れ直す、を先にします。

### 3. 番号では通るか、名前だけダメかを見る

1. `Windows` キーを押し、`cmd` と入れて **コマンド プロンプト** を開く。
2. 次を順に実行する。

```text
ping 192.168.1.1
ping 8.8.8.8
ping example.com
```

ゲートウェイの番号は、設定に出ていた値に置き換えてください。`192.168.1.1` が違う家も多いです。

読み方です。

- ゲートウェイへ `ping` が失敗 → PC とルーターの間（Wi-Fi、アダプター、DHCP）
- ゲートウェイは成功、`8.8.8.8` が失敗 → ルーターより外側（回線、ONU、ISP）
- `8.8.8.8` は成功、`example.com` が名前解決失敗 → **DNS**。[DNS の手順](/articles/windows-dns-server-problem/) のキャッシュ削除と公開DNS指定へ進む
- どれも成功なのにブラウザだけダメ → プロキシ、セキュアDNS、拡張機能、セキュリティソフト

ブラウザのアドレス欄に `https://1.1.1.1` のように番号で開けるかも、同じ切り分けになります。

### 4. IP を自動に戻し、アダプターを切り直す

1. **設定** → **ネットワークとインターネット** → 使っている Wi-Fi → **ハードウェア プロパティ**。
2. IP の割り当てが **手動** なら **自動 (DHCP)** に戻す。引っ越し前の固定IPが残っていることがあります。
3. **設定** → **ネットワークとインターネット** → **詳細ネットワーク設定** → **ネットワーク アダプター オプション**。
4. 使っている Wi-Fi アダプターを右クリック → **無効にする** → 10秒 → **有効にする**。
5. 使っていない VPN 用仮想アダプターが何本もあるときは、今使わないものを無効にして試す。

**設定 → ネットワークとインターネット → プロキシ** で、手動プロキシとセットアップ スクリプトがオフかも確認します。会社PCで必須のプロキシなら、オフにせず担当へ渡します。

### 5. キャプティブポータルと VPN

ホテル・カフェ・学校の Wi-Fi でよくあります。

1. ブラウザで `http://neverssl.com` や、ゲートウェイ番号を開いてみる。ログインや利用規約が出たら同意する。
2. 通知領域の「Wi-Fi にログインが必要」を開く。
3. VPN アプリを切断し、**設定 → ネットワークとインターネット → VPN** の常時接続もオフ。
4. セキュリティソフトの「ウェブ保護」「HTTPSスキャン」を一時停止して再現するか見る。直るなら、公式の除外手順を使う。止めっぱなしにはしない。

Android 側でプライベートDNSをいじっているテザリングは、PC だけ名前解決に失敗することがあります。テザリング元のスマホでプライベートDNSを自動に戻して試してください。

### 6. ルーターと、最後のネットワーク リセット

家中の端末がダメなとき、または PC だけでも 1〜5 で変わらないときです。

1. ルーターの電源を抜き、30秒待つ。ONU がある場合は、回線事業者の案内どおり **ONU → ルーター** の順で入れる。ランプが安定してから Windows 側で再接続する。
2. それでもこの PC だけダメなら、**設定 → ネットワークとインターネット → 詳細ネットワーク設定 → ネットワークのリセット**。

> **注意:** ネットワークのリセットは、保存済み Wi-Fi、VPN、一部のアダプター設定を消します。実行前にSSIDとパスワードを控え、プリンターの再セットアップが必要になることがあります。リセット後は再起動し、Wi-Fi を入れ直します。

## まだ直らないとき

- 有線は使えるが Wi-Fi だけダメ → チャンネル混雑や、バンド（2.4 / 5GHz）の取り違え。SSID が分かれているときは、スマホがつながっているほうへ PC も合わせる
- 番号も名前も失敗し、他端末は問題なし → アダプターのドライバー。PC メーカーの Wi-Fi / チップセットを公式から入れ直す。まとめサイトの「無線LANパック」は使わない
- ブラウザだけダメ、`ping` は成功 → 拡張機能を切る、別ブラウザで試す。Edge と Chrome の両方でダメなら OS のプロキシかフィルタ
- 職場や学校のネットワーク → 個人の DNS 変更が禁止されていることがあります。IT 担当へ、`ping` の結果と「インターネットなし」のスクリーンショットを渡す
- USB ドングルだけ認識されない → ネット設定より先に [USB機器が認識されない](/articles/usb-device-not-recognized/)

## まとめ

「Wi-Fi につながっている」と「インターネットに出られる」は別です。まず **他端末と比べ、ゲートウェイ・番号・名前の ping で層を分ける**。自分の PC だけなら DHCP とプロキシと VPN、家中ダメならルーター、名前だけ失敗なら DNS 記事へ、が遠回りしにくい順です。ネットワークのリセットはパスワードが消えるので、最後にします。
