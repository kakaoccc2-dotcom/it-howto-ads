デスクトップごと白く点滅する。ブラウザの中だけ明滅する。右下に「ディスプレイ ドライバーが応答を停止しましたが、正常に回復しました」と出て、一度黒くなって戻る。このあたりは、夜間モードの黄ばみとは別です。真っ黒のまま明るさキーも効かないときは [画面が真っ暗・明るさが変わらないとき](/articles/windows-brightness-black-screen/) です。外付けだけ「信号なし」で内蔵は普通なら [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) を先に見てください。

## 症状の見分け

- タスクバーもアイコンも、1秒に何回も明滅する。マウスは動いている
- Microsoft Edge や Chrome、動画の窓だけちらつき、デスクトップに戻すと止まる
- 右下の通知に、ディスプレイ ドライバーの応答停止と回復、と出る。そのたびに画面が一度黒くなる
- ゲームや動画を始めたあと、本体が熱くなってから点滅が増える
- 外付けモニターをつないだあと、または抜いたあとに内蔵がちらつき始めた
- 横線、色の抜け、画面を押すと模様が変わる。角度を変えると濃くなる

ゆっくり暗くなったり黄ばんだりするだけなら、明るさや夜間モード側です。線が入って角度で変わるのは、設定よりパネルかケーブルです。

## よくある原因

1. ブラウザや動画アプリのハードウェア アクセラレーションが、今のドライバーとぶつかっている
2. グラフィックドライバーが一時停止して、Windows が描画をやり直している（応答停止の通知）
3. モニターが対応していないリフレッシュ レート、または可変リフレッシュの食い違い
4. HDMI ケーブル、変換アダプター、緩んだ USB-C。外付けだけがちらつく
5. HDR をオンにしたあと、その画面だけ明滅する
6. ノートの排気口が塞がれ、熱いときだけ描画が落ちる
7. 更新の直後に入ったディスプレイドライバーが、その PC の型と合っていない

## 直す前に

- 文書は、ちらつきが弱いあいだに保存する。手順5の再起動で、保存していない文書は消えます
- 「ディスプレイ修復」、ドライバーのまとめサイト、BIOS の更新ファイルは使わない
- 点滅が激しくて目が痛むときは、作業を続けない。ノートなら蓋を閉じ、外付けの電源を切ってから次の手順に入る

> **注意:** グラフィックボードの抜き差し、液晶パネルの分解、レジストリで応答停止の秒数を延ばす操作はしません。応答停止の通知は、ドライバーが一度落ちて戻った記録です。通知を消すだけでは原因は残りません。

## 手順

### 1. どこがちらつくかを分ける

1. ブラウザをすべて閉じ、デスクトップとタスクバーだけを10秒見る。ここも点滅するなら、PC 全体の描画です。手順2へ。
2. デスクトップは静かで、Edge や Chrome、Zoom の共有画面だけ明滅するなら、手順3のアクセラレーションです。
3. 内蔵は普通で、HDMI や USB-C の外付けだけちらつくなら、ケーブルを一度抜き、本体の端子へ直接挿し直す。変換アダプターを挟んでいるときは、アダプターを外して別ケーブルで試す。信号なしで何も出ない症状は外付けの記事です。
4. ゲーム中だけ、ファンがうるさい、底が熱い、なら描画設定より先に熱です。[ファンがうるさい・本体が熱いとき](/articles/windows-pc-hot-fan-loud/) の通気の手順を見て、布団やクッションの上から下ろす。

全体が点滅しているあいだは、レートの一覧を目で追うより先に、次のショートカットを押します。

### 2. グラフィックドライバーをその場でリセットする

Windows 標準の操作です。データは消えません。

1. `Win` + `Ctrl` + `Shift` + `B` を一度押す。
2. 画面が一瞬黒くなり、ビープが鳴って戻る。戻ったあと、同じ操作（ブラウザを開く、動画を再生する）で再発するか見る。
3. 黒いまま戻らないときは、10秒ほど待つ。それでも無ければ、明るさが落ちているか、投影先が外付けのままかを疑う。`Win` + `P` で **PC 画面のみ** を選ぶ。真っ黒の切り分けは明るさの記事です。

一度で収まり、その日のうちに再発しないなら、一時的な応答停止です。同じ通知が何度も出るなら、手順4と5へ進みます。ショートカットを連打しないでください。

### 3. ブラウザだけなら、ハードウェア アクセラレーションを切る

窓の中だけちらつくときに有効です。全体が点滅しているときは、ここをいじるより手順2と5が先です。

1. Microsoft Edge なら **設定 → システムとパフォーマンス**。**使用可能な場合はハードウェア アクセラレータを使用する** をオフにし、Edge を閉じてもう一度開く。
2. Chrome なら **設定 → システム**。**ハードウェア アクセラレータが使用可能な場合は使用する** をオフにして、Chrome を起動し直す。
3. オフのまま、さっきちらついたページや動画を開く。止まったなら、そのブラウザと今のドライバーの組み合わせです。点滅が残るならオンに戻して、手順4へ進みます。

配信ソフトや、画面の上に重なるゲームバーだけが明滅するときも、そのアプリを終了してデスクトップが静かかを見ます。常駐の配信ツールを入れた直後からなら、そのアプリの終了が先です。

### 4. リフレッシュ レートと HDR、投影を戻す

1. スタートボタンを右クリック → **設定** → **システム** → **ディスプレイ**。
2. **詳細ディスプレイ** を開き、**リフレッシュ レートの選択** を **60 Hz** にする。60 が無いときは、一覧のいちばん低い値にする。変えた直後に点滅が収まるか見る。
3. 同じ詳細画面に **動的リフレッシュ レート** があればオフにする。
4. ディスプレイの画面に戻り、**HDR** がオンならオフにして、同じ映像をもう一度出す。
5. 外付けがつながっているときは `Win` + `P` で **PC 画面のみ** と **拡張** を切り替え、内蔵だけにしてもちらつくかを見る。内蔵だけで止まるなら、外付けのレートかケーブルです。

60 Hz に戻したあとも全体が点滅するなら、ケーブルでもレートでもなく、ドライバー側です。

### 5. ドライバーは、元に戻すところまで

まとめサイトから「最新のグラフィックドライバー」を取ってきません。

1. スタートボタンを右クリック → **デバイス マネージャー** → **ディスプレイ アダプター**。
2. 表示されている名前（Intel、AMD、NVIDIA など）を右クリック → **プロパティ** → **ドライバー**。
3. **ドライバーを元に戻す** が押せるなら、それを選んで再起動する。更新のあとからちらつき始めた PC は、ここで収まることが多いです。ボタンが灰色なら、戻すコピーが残っていません。
4. 灰色で、通知の応答停止が続くときは、そのアダプターを右クリック → **デバイスのアンインストール**。ドライバーの削除にチェックが出たら外す。再起動すると、Windows が標準のドライバーを入れ直します。入れ直し後、解像度が一時的に荒くても、点滅が止まったかを先に見る。
5. メーカーのドライバーを入れるなら、PC 本体の型番のサポートページから、グラフィックまたはディスプレイと書かれたものだけにする。ノートに、デスクトップ向けの大きなパッケージを入れない。

アダプターが2行あるノートは、昨日更新した方だけ戻します。どちらを触ったか分からないときは、両方を続けて消さず、1行戻して再起動し、結果を見てから次です。Windows Update が同じドライバーを何度も途中で止めるときは [更新が進まないとき](/articles/windows-update-stuck/) です。

同じ **ディスプレイ** の画面から **グラフィック** を開き、**ハードウェア アクセラレータによる GPU スケジューリング** というスイッチがある機種は、オンならオフにして再起動する。スイッチ自体が無い PC は、この項目は飛ばします。

## まだ直らないとき

- ブラウザの中だけ直り、デスクトップの点滅は残る → 手順4の 60 Hz と、手順5のロールバック。アクセラレーションだけでは全体は止まりません
- 熱いとき、ゲームのときだけ通知が出る → 通気。ファンが止まった異音がするなら、描画設定を増やすよりメーカー診断
- 横一線、にじみ、角度で色が変わる、押すと模様が出る → パネルか内部のケーブル。Hz を変えても戻りません。保証内なら、点滅の様子が分かる短い動画を添えて修理
- セーフモードだと点滅が止む → あとから入れた常駐を疑う。画面に重なる配信ツール、光るキーボードやロゴを動かすメーカーのアプリを、通常起動に戻してから終了する
- 設定画面を追えないほど点滅が強い → `Win` + `Ctrl` + `Shift` + `B` のあと外付けを外し、再起動を1回。それでもメニューが読めないときは、作業を止めてメーカーか購入店へ。BIOS の書き込みはしない

## まとめ

全体が点滅するときは `Win` + `Ctrl` + `Shift` + `B`、その次に 60 Hz とドライバーのロールバックです。ブラウザの窓だけなら、ハードウェア アクセラレーションを切って切り分けてください。線が入る、熱いときだけ落ちる、は設定の先に修理と通気があります。
