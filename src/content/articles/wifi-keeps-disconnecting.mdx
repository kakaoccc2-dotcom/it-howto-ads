つながったあとに、数分〜数十分で切れる話です。最初から認証エラーなら [Android の Wi-Fi](/articles/android-wifi-cannot-connect/) か [iPhone の Wi-Fi](/articles/iphone-wifi-cannot-connect/)。つながった表示なのにサイトが開けないなら [インターネットなし](/articles/wifi-connected-no-internet/) が先です。

ルーターの電源を抜き差しする前に、自分の端末だけか、家中か、を分けます。抜き差しは最後で足ります。

## 症状の見分け

- 扇形アイコンが、しばらくすると切れたマークになる。入れ直すとまた数分持つ
- 動画が途中で止まり、Wi-Fi をオフ→オンすると戻る
- 同じ部屋のスマホは安定、この PC（またはこのスマホ）だけ切れる
- 家の端の部屋、電子レンジの使用中、だけ切れる
- 夜だけ切れる。昼間は持つか、その逆
- 5GHz だと切れるが 2.4GHz だと持つ（またはその逆）

家族のテレビもゲーム機も同時に落ちるなら、端末設定よりルーターか回線です。自分だけなら、この先の端末側が中心です。

## よくある原因

1. Windows の Wi-Fi アダプター省電力、Android のスリープ時切断、iPhone のプライベートアドレス
2. 5GHz の DFS（気象レーダー回避）で、突然チャンネルが飛ぶ
3. 2.4GHz の混雑、電子レンジ、コードレス電話、USB 3
4. 端末が遠い。壁が厚い。バンドステアリングが 5GHz に貼り付けて、途中で落とす
5. 古いSSIDの設定が残っている。ルーター交換後の同名ネットワーク
6. ONU / 回線側の瞬断。このときは家中が同時に落ちる

## 直す前に

- 自分の端末だけか、家族も同じか、紙に書く。以降の操作が変わります
- ルーターの機種名と、2.4GHz / 5GHz のSSIDが分かれているかを、本体シールか管理画面で確認する
- 「Wi-Fiブースター」アプリや、出所不明のファームウェアは入れない

> **注意:** ルーターの初期化（RESET ピン）は、回線の ID と Wi-Fi パスワードが消えます。この記事では使いません。ファームウェア更新も、メーカーが画面で案内しているとき以外は後回しです。

## 手順

### 1. 自分だけ切れるなら、端末の省電力を外す

**Windows 11**

1. **設定** → **ネットワークとインターネット** → **Wi-Fi** → つながっているSSID。切れた直後に「制限付き」や「インターネットなし」と出るなら、切断というより [インターネットなしの切り分け](/articles/wifi-connected-no-internet/) です。アイコン自体が切れるなら、このまま下へ。
2. **設定** → **ネットワークとインターネット** → **詳細ネットワーク設定** → **アダプターのオプションを変更する**。 Wi-Fi アダプターを右クリック → **プロパティ** → **構成** → **電源の管理**。 **電力を節約するために、コンピューターでこのデバイスの電源をオフにできるようにする** のチェックを外す。
3. ノートなら **設定 → システム → 電源とバッテリー** の電源モードを、切り分けのあいだ **バランス** 以上にする。超省エネだと無線が先に落ちます。
4. 同じアダプターの **詳細設定** に **ローミングの積極性** があれば、**中** にする。最高だと、隣の弱いSSIDへ飛びやすいです。項目が無い機種はそのまま。

**Android**

1. **設定** → **ネットワークとインターネット** → **インターネット**（機種により **Wi-Fi**）→ 歯車。 **ネットワーク使用量を減らすためにWi-Fiをオフにする** や、類似の自動オフをオフ。
2. **設定 → バッテリー** の省電力をオフ。Wi-Fi を「スリープ時も維持」にできる機種は、そこをオン。
3. 保存済みSSIDを一度削除し、パスワードを打ち直す。古いセキュリティ方式の名残が、数分後に切る機種があります。

**iPhone**

1. **設定 → Wi-Fi** でSSIDの i を開き、**プライベートWi-Fiアドレス** を切り分けでオフにする。マンションや古いルーターで、切断を繰り返すことがあります。常用するかどうかは、安定してから決める。
2. **設定 → モバイル通信 → Wi-Fiアシスト** は、切れたあとにモバイルへ逃げる設定です。切断そのものは止めません。切り分けのあいだオフにすると、「切れたのか、モバイルへ逃げたのか」が分かります。
3. 保存済みを **このネットワーク設定を削除** して入れ直す。

### 2. 2.4GHz と 5GHz を分けてつなぐ

SSID が「例: example」と「example-5G」のように分かれていれば、切り分けが早いです。

1. 端末を **5GHz 側だけ** につなぎ、同じ場所で15分使う。切れたら **2.4GHz 側だけ** で同じ時間使う。
2. 5GHz だけ切れる、部屋を移動すると切れる → 距離か DFS。2.4GHz に固定して、動画が持つか見る。
3. 2.4GHz だけ切れる、電子レンジ中だけ切れる → 干渉。5GHz に固定する。届かない部屋は、無理に 5GHz へ貼らず、2.4GHz のまま距離を詰める。
4. ルーターの「スマート接続」「バンドステアリング」（SSID が1つで自動切替）が、遠い部屋で 5GHz に貼って落とすことがあります。管理画面でバンドステアリングをオフにし、SSID を帯域ごとに分ける。メーカー画面の名前は「バンドステアリング」「スマートコネクト」が多いです。分からなければ、この項目は触らず手順3の置き場所へ。

ゲストSSIDや、IoT 用の 2.4GHz 専用に PC が入り続けていると、切れやすく見えることがあります。普段使うSSIDへ戻してください。

### 3. 置き場所と、家電の干渉

1. ルーターを、床置きの箱の中、テレビの裏、電子レンジの横、から出す。目安は、目線の高さ、家の中央に近い棚です。
2. 電子レンジ、コードレス子機、Bluetooth 多数、USB 3 ハブの隣、で Windows だけ切れるなら、1メートル以上離す。Bluetooth イヤホンの途切れと同じ 2.4GHz 帯です。Android のイヤホンが同時に途切れるなら [Bluetooth イヤホンの途切れ](/articles/android-bluetooth-earbuds-cutting-out/) も疑う。
3. 端末とルーターのあいだの壁がコンクリート、鏡、水槽、なら 5GHz は落ちやすいです。その部屋だけ 2.4GHz に固定する。
4. 窓際のルーターが、隣のマンションの電波を拾ってローミングすることがあります。SSID を家の中だけ覚えて、近所の同名フリー Wi-Fi は保存しない。

有線端子がある PC なら、短い LAN ケーブルでルーターへ直結して同じ時間使う。有線が全く切れないなら無線側、有線も切れるなら回線かルーターです。

### 4. ルーター側は、再起動より先にチャンネルを見る

家中が同時に落ちる、または手順1〜3で自分だけ直らないときに触ります。管理画面はブラウザで `192.168.0.1` や `192.168.1.1`（本体シールの URL）です。

1. 電源の抜き差しをするなら、ONU（回線終端）とルーターを **5分以上** 切る。すぐ入れると、同じ状態に戻ることがあります。入れる順番は、ONU のランプが安定してからルーター、です。家族の作業中は避けてください。
2. 2.4GHz のチャンネルが **自動** で、夜だけ切れるなら、いったん **1 / 6 / 11** のどれか固定を試す。隣と重なりにくい番号です。幅は 20MHz を先に試す。40MHz は混雑で負けやすいです。
3. 5GHz で突然切れるなら、日本の W53 / W56（DFS）チャンネルを避け、W52（36, 40, 44, 48）へ固定できる機種はそこにします。レーダーを検知すると、1分間クラスで落ちます。
4. 「ECO」「LED消灯に合わせて無線も弱める」がオンの機種はオフ。夜間だけ落ちることがあります。
5. ファームウェア更新は、管理画面に公式の更新ボタンがあるときだけ。ファイルを自分で探す必要はありません。失敗すると起動しなくなるので、作業中は電源を抜かない。

プリンターやゲーム機だけ切れるのは、PC の省電力ではありません。[プリンターがオフライン](/articles/printer-offline/) のネットワーク項も見てください。

### 5. 古い接続情報と、回線側

1. Windows なら **設定 → Wi-Fi → 既知のネットワークの管理** で、使っていないSSIDを **忘却** する。同名の古いセキュリティー（WEP や弱いままの WPA）が残っていると、つなぎ直すたびに落ちることがあります。
2. ルーターを交換したあとは、端末側の保存を消して、新しいパスワードで入れ直す。SSID が同じだと、古い鍵のまま数分後に切れることがあります。
3. 家中が同時に、時計どおり数時間おきに落ちるなら、ISP のセッション切れや ONU の故障があります。個人の Wi-Fi 設定では終わりません。ONU のランプ（認証、光）が落ちる瞬間があるか見て、プロバイダへランプ色を伝える。
4. IPv6 をオンにした直後から再接続を繰り返す回線があります。ルーターの IPv6 を切り分けでオフにして、半日見る。オフで安定し、オンで再現するなら、プロバイダの案内を見てください。自分でトンネルアプリは入れない。

VPN 常時接続の PC だけ切れて見えるときは、VPN を切った状態で同じ時間 Wi-Fi が持つかを見ます。切ると持つなら、Wi-Fi ではなく VPN 側です。

## まだ直らないとき

- 自分の端末だけ、どのSSIDでも切れる → 端末の無線。別端末が同じ場所で持つなら、保証内はメーカーへ。Windows ならチップセット / WLAN ドライバーを PC メーカーサイトから入れ直す（まとめサイトは使わない）
- 有線は安定、Wi-Fi だけダメ → 手順3と4。置き場所とチャンネル
- 特定の部屋だけ → 5GHz の距離。その部屋は 2.4GHz 固定
- 家中が同時、ONU のランプも落ちる → 回線。プロバイダ
- 証明書エラーや日付の話が混ざる → 切断ではなく [時計のずれ](/articles/windows-time-out-of-sync/) や [プライベートではありません](/articles/browser-connection-not-private/)

## まとめ

自分だけ切れるなら省電力とSSIDの入れ直し、家中なら置き場所とチャンネルです。電源の抜き差しは、切り分けの最後で足ります。
