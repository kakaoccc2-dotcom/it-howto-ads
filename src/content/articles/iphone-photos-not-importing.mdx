ケーブルを挿すと充電の稲妻は付く。エクスプローラーの **このPC** には iPhone の名前が無い。フォトの取り込み一覧も空。あるいはコピーはできたのに、開くと真っ白。USBメモリ全般がどの機器も出ないときは [USB機器が認識されない手順](/articles/usb-device-not-recognized/) 、充電自体が不安定なら [充電が遅い手順](/articles/smartphone-charging-slow/) です。

## 症状の見分け

- **このPC** に Apple iPhone も、自分の iPhone の名前も増えない
- 名前は出るが、開くと「このデバイスに到達できません」、中身が空
- **DCIM** まで開けるのに、さっき撮った写真が無い
- コピーしたファイルの末尾が `.HEIC` で、フォトや別の PC で開けない
- iPhone に「このコンピュータを信頼しますか？」が出たまま、または以前 **信頼しない** を押した
- 充電はできている

## よくある原因

1. iPhone がロック画面のまま、または **信頼** を押していない
2. ケーブルが充電専用で、データ線が無い
3. iCloud 写真の最適化で、本体にフルサイズのファイルが無い
4. HEIC のまま渡して、Windows 側に開くための拡張が無い
5. iPhone 用の接続ソフト（Apple デバイス）が入っておらず、ポータブルデバイスとして見えない

## 直す前に

- パスコードをすぐ入れられるようにしておく。ロック中は中身を読めません
- コピーの途中でケーブルを抜かない。途中のファイルは壊れます
- 「写真復元」「一発転送」系のソフトは入れない
- この記事に、iPhone 側の写真を消す操作はありません。PC で開いてから消すか決めてください

> **注意:** うしろの手順で使う「位置情報とプライバシーをリセット」は、写真もアプリも消しません。位置情報の許可だけ、アプリを開いたときに聞き直されます。工場出荷時の初期化ではありません。

## 手順

### 1. ロックを解除して「信頼」を押す

1. iPhone の画面を付け、パスコードまで入れる。顔や指紋だけでロック画面に止まっている状態では、PC からフォルダを読めません。
2. ケーブルは PC 本体の USB へ直接挿す。モニターの裏や、電源の無いハブは挟まない。
3. 「このコンピュータを信頼しますか？」と出たら **信頼**。パスコードを聞かれたら入れる。
4. エクスプローラーの **このPC** を開く。Apple iPhone、または iPhone に付けた名前が出るか見る。
5. 出たら開く。中は **Internal Storage**（内部ストレージと出る版もある）→ **DCIM**。`100APPLE` のようなフォルダの中に、`.JPG` や `.HEIC` がある。

ここに写真が見えれば、取り込みはできています。必要なものだけ、PC のピクチャなどへコピーする。フォトを使わなくても、このコピーで移せます。

**信頼しない** を押したあとは、抜き挿しだけでは信頼の画面が出ないことがあります。そのときは手順5です。

### 2. 充電はできるのに、このPCへ何も増えない

1. ケーブルを変える。iPhone 15 以降の端子は USB-C、それより前は Lightning。箱に入っていた線か、データ通信と書いてある線にする。
2. 同じ線のまま、本体の別ポート（できれば背面）へ挿す。
3. 稲妻だけ付いて PC が無反応なら、その線は充電専用のことが多いです。充電そのものが途切れるときは [充電の切り分け](/articles/smartphone-charging-slow/) 。マウスもどのポートでも死ぬなら [USBが認識されない手順](/articles/usb-device-not-recognized/) です。

### 3. 端末は出るが、DCIMが空、フォトの一覧も空

iPhone の写真アプリには写っている。PC のフォルダだけ空、のときです。

1. スタートから **フォト** を開き、**インポート** があれば接続中の iPhone を選ぶ。一覧に枚数が出るか見る。
2. 出ないときは、本体に実ファイルが無いことがあります。**設定** の一番上の検索に「iCloud」か「写真」と入れる。
3. **iPhoneのストレージを最適化** になっていると、最適化中でもファイル名は出ることがあります。雲のマークが消えるまで、フルサイズはありません。取り込みたい写真を iPhone の写真アプリで開き、雲のマークが消えて絵が表示されるまで、Wi-Fi のある場所で待つ。
4. まとめて本体へ戻すには空きが要ります。空きが足りないときは [iPhoneのストレージ](/articles/iphone-storage-full/) を先に空ける。
5. 最適化をやめると、クラウドのオリジナルが本体へ降りてきます。ライブラリのほうが空きより大きいと、そこで止まります。
6. **非表示** に入れた写真は、PC の一覧に出ないことがあります。出したいものは、写真アプリの非表示から戻す。

### 4. コピーはできたが、開くと真っ白（HEIC）

1. コピーしたファイルの末尾を見る。`.HEIC` や `.HEIF` なら、iPhone の高効率の形式です。`.JPG` なら、この手順ではありません。
2. iPhone の **設定** の検索に「転送」と入れる。**MacまたはPCに転送** を開く。場所は **写真** の中か、**アプリ → 写真** の下です。版で違います。
3. 項目は二つです。パソコン向けに変換するほう（**自動**）と、撮った形式のまま渡すほう。いま JPEG で受け取りたいなら **自動** にして、ケーブルを挿し直し、同じ写真をコピーし直す。まま渡す側の表記は「元のフォーマットのまま」「保持」など、版で少し違います。
4. これから撮る分を JPEG にしたいときだけ、**設定 → カメラ → フォーマット → 互換性優先**。すでに撮った HEIC は、ここを変えても JPEG になりません。
5. HEIC のまま Windows 11 で開きたいときは、Microsoft Store で **HEIF 画像拡張機能** を探す。提供元が Microsoft のものだけ入れる。動画の `.MOV` が再生できないときは、同じ店の HEVC の拡張を見る。
6. 無料と有料が並ぶので、入れる前に提供元と値段を確認する。

### 5. 名前すら出ないとき

データ用のケーブルに替え、ロックも解除した。それでも **このPC** に何も増えないときです。

1. iPhone を再起動し、パスコードを入れた状態で挿し直す。
2. 「信頼」の画面が出ないときは、**設定 → 一般 → 転送またはiPhoneをリセット → リセット → 位置情報とプライバシーをリセット**。終わったら挿し直し、**信頼** を押す。
3. Windows には、Microsoft Store の **Apple デバイス** を入れる。すでに Microsoft Store 版の iTunes が入っている PC は、両方を重ねず、入っているほうに iPhone が出るか先に見る。入れたあと PC を再起動し、もう一度 **このPC** を開く。
4. スタートボタンを右クリック → **デバイス マネージャー** → **ポータブル デバイス**。Apple iPhone に黄色い「！」があるなら、その項目を右クリック → **デバイスのアンインストール**。ケーブルを抜き、10秒待って挿す。Windows が付け直します。
5. まとめサイトのドライバパックは入れない。

ロックしたまま長く置くと、USB のデータ通信だけ拒否する機種があります。画面のロックを解除してから挿す。**Face IDとパスコード**（ホームボタンのある機種は **Touch IDとパスコード**）の中に、USB アクセサリの項目がある版もあります。名前が違っても、ロックを解除してから挿せば通ることが多いです。

> **注意:** エクスプローラー自体が「応答なし」で固まるときは、写真の前に [エクスプローラーの手順](/articles/windows-explorer-not-responding/) です。

## まだ直らないとき

- 別の PC では DCIM が見える → いまの Windows の接続かポートです。Apple デバイスを入れたか、デバイス マネージャーに「！」が残っているかを残しておく
- どの PC でもフォルダが空 → iPhone 側です。非表示、または共有アルバムだけで本体に保存されていない。最適化中でもファイル名は出ることがあり、雲のマークが消えるまでフルサイズがありません
- コピーの途中で切れる → ハブを外し、短いデータケーブルで、10枚だけコピーする
- ここまでで **このPC** に名前が出ない → Apple か PC メーカーへ。初期化は写真が消えるので、この確認の途中ではやりません
