LINE を開くと未読のトークはある。ロック画面にもバナーにも音にも残っていない。メールやほかのアプリは来るのに、LINE だけ静か。この組み合わせは、端末全体の通知より **LINE の中のミュート、パソコン版を開いたまま、トーク単位の通知オフ** が多いです。

iPhone の通知全体は [iPhoneで通知が来ないとき](/articles/iphone-notifications-not-working/)、Android 全体は [Androidで通知が来ない・遅れるとき](/articles/android-notifications-delayed/) です。こちらは LINE の画面に限って書きます。

## 症状の見分け

- LINE を開いたときだけ未読がある。来た瞬間のバナーは無かった
- 特定のトーク、またはグループだけ音がしない。ほかの友だちは来る
- 家のパソコンで LINE を開いているあいだだけ、スマホが鳴らない
- メッセージは来るのに、音声通話・ビデオ通話だけ鳴らない
- ステータスバーや LINE のベルに、斜線や「一時停止」が出ている
- アプリを開いても新着が古い。通知以前に、トークが更新されていない

最後の一つは通知設定では直りません。Wi-Fi やモバイルデータ、LINE へのログインが先です。開いたら内容はある、という状態だけ、この先に進んでください。

## よくある原因

1. LINE の **通知の一時停止** が、1時間や翌朝まで残っている
2. そのトークだけ **通知オフ**。グループのベルに斜線が付いている
3. パソコン版 LINE にログインしたままで、スマホ側の通知が止まっている
4. iPhone の集中モードや、Android のバッテリー制限が LINE だけを止めている
5. サブ端末（QR で入ったもう一台）で、メイン端末にしか通知が行かない
6. 通話の通知種類だけオフ。メッセージの種類はオン

## 直す前に

- どのトークが来ないのか、一人に決める。全員いっぺんに触ると、何が戻ったかわかりません
- 「通知強化」「LINEが確実に鳴る」系のアプリは入れない
- 作業中に急ぎの連絡が必要な人には、別の手段を先に伝えておく

> **注意:** LINE を削除して入れ直すと、引き継ぎを間違えたときにトーク履歴が残らないことがあります。この記事の手順ではアンインストールしません。通知オフを戻すだけなら、トークの中身は消えません。

## 手順

### 1. LINE の「通知の一時停止」を外す

バナーが全部止まり、アプリを開くと未読だけある、というときに先に見ます。

1. LINE の **ホーム** を開く。右上の歯車を押して **設定**。
2. **通知** を開く。
3. **通知の一時停止** がオン、または「8時まで」「1時間」のような残り時間が出ていたらオフにする。
4. 同じ画面で **メッセージの通知** がオンか見る。オフならオン。
5. **通知の内容を表示**（プレビュー）がオフだと、ロック画面に「LINE」とだけ出て中身が見えません。音も欲しいなら、下の通知音が **デフォルト** や選んだ音になっていて、**なし** ではないことを見る。

オフにしたあとに、別のスマホかパソコンからそのアカウントへ短いメッセージを送る。バナーが出れば、一時停止だけでした。

### 2. トーク単位の通知オフを戻す

一人だけ、またはグループだけ静か、というときは設定の全体スイッチを何度押しても直りません。

1. トーク一覧で、来ない相手の行を見る。ベルに斜線、または「通知オフ」と出ていないか。
2. Android は、その行を左へスワイプして **通知オフ** がオンなら解除する。機種によってスワイプの向きが逆です。
3. iPhone は、そのトークを開いて右上のメニュー（横線）を押す。**通知オフ** がオンならオフに戻す。
4. グループなら、同じメニューに **トークの通知** や **通知オフ** が分かれています。メンションだけ欲しいのか、全部欲しいのかを選ぶ。全部オフのままでは、メッセージが付いても鳴りません。
5. 一覧に戻ったとき、その行のベル斜線が消えていることを見る。

一覧から消したトークは、トーク一覧の下のほうにある **非表示** から開きます。行が無い版は、設定の検索に「非表示」と入れます。非表示でもメッセージ自体は届きます。一覧に出ないので、来ていないように見えます。

### 3. パソコン版 LINE を開いたままになっていないか

昼だけスマホが静かで、夜パソコンを切るとまとめて来る、という動きです。パソコン版にログインしているあいだ、スマホへ通知を出さない設定が残っていることがあります。

1. パソコンの LINE を終了する。ウィンドウを閉じたあと、タスクバーにアイコンが残っていたら右クリックして終了する。
2. スマホの LINE → **設定 → 通知** を下まで見る。パソコン版の利用中は通知しない、という項目があればオフにする。名前は版で少し違います。項目自体が無い版は、パソコン版を終了しただけで届くかを試します。
3. 別の人から短いメッセージを送ってもらう。パソコンを終了したあとだけスマホに出るなら、ここです。

パソコンを開いたままスマホにも出したいときは、その項目をオフにして、使い終わったあとはパソコン版を終了します。ログアウトしたままにしなくて大丈夫です。

### 4. iPhone 側で、LINE だけが止まっていないか

手順1〜3のあとも iPhone だけ静かなら、iOS が LINE を止めています。集中モードの時間帯は、上でリンクした iPhone の通知記事です。ここでは LINE の行だけ触ります。

1. **設定 → 通知 → LINE**。**通知を許可** がオフならオン。
2. **ロック画面**、**通知センター**、**バナー** のうち、欲しい場所にチェックがあるか見る。バナーだけ外れていると、開くまで気づけません。
3. **サウンド** がオンか見る。着信音のスライダがゼロだと、許可していても鳴りません。
4. 音声通話だけ欲しいのに集中モードで消えるときは、同じ LINE の通知画面で **タイムセンシティブ通知** をオンにする。おやすみ時間中も通話を通したいとき用です。メッセージまで全部通すと、夜中も鳴ります。
5. **設定 → 一般 → バックグラウンド App更新** で、LINE がオンか見る。オフだと、アプリを開くまで届きが遅れます。

画面右上からコントロールセンターを下げ、三日月や集中モードが点灯していたら、切り分けのあいだオフにします。点灯中は、LINE を許可した集中モードでない限りバナーは出ません。

### 5. Android 側で、LINE の種類と電池制限を見る

Android は「LINE の通知」がオンでも、その下の種類が個別にオフ、という状態があります。メーカーで項目の場所が一段ずれます。

1. **設定 → アプリ → LINE → 通知**。上のスイッチがオフならオン。
2. 下に **メッセージ**、**通話**（着信）、**お知らせ** のように種類が並んでいたら、来てほしい種類を開く。オフ、または音が **なし** なら戻す。メッセージは来るのに通話だけ鳴らない、はここの分割です。
3. **設定 → アプリ → LINE → アプリのバッテリー**（**バッテリー**）を開く。**制限なし**、または **最適化しない** にする。**制限** のままだと、画面を消してから数十分で通知が遅れます。
4. Samsung なら **バッテリー → バックグラウンド使用量の制限 → スリープ中のアプリ** に LINE が入っていたら外す。Xiaomi や OPPO 系は、設定内検索で「自動起動」と入れ、LINE を許可する。

**制限なし** にするのは LINE だけにします。おやすみ時間やほかのアプリの省電力は、Android の通知記事に戻ってください。

### 6. メイン端末と、サブ端末の取り違え

もう一台のスマホやタブレットに、QR コードで LINE に入っている場合です。

1. 通知が欲しいスマホで LINE の **設定 → アカウント** を開く。
2. サブ端末と出ているなら、メッセージの通知はメインのスマホに行きます。サブのロック画面は静かです。
3. 普段持つスマホがサブなら、メイン側の通知を直しても手元は鳴りません。タブレットや家族の一台がメインになっていないか見る。
4. メインをこちらへ移す（電話番号の確認）は、LINE のアプリ内の案内だけ使います。検索で出てきた引き継ぎサイトは開きません。

テストは、鳴ってほしいその一台で受けます。隣のタブレットがメインだと、そちらだけ鳴ります。

## まだ直らないとき

- バナーは出るが音だけ無い → LINE の通知音が **なし**、または端末のサイレント。iPhone は側面のオレンジ、Android はクイック設定のベル
- ロック画面だけ出ない → 手順4または5の、ロック画面のチェック。LINE のプレビューをオフにしていると、中身が隠れて「来ていない」に見えることもあります
- どの友だちも、開いても新着が増えない → 通知ではなく通信かログイン。機内モードの名残、パスワードの再入力、相手が送っていない、を先に分ける
- 再インストールを案内された → 削除の前に、LINE の **設定 → トーク → トークのバックアップ**（項目名は版で違います）と、公式の引き継ぎ手順を読む。この記事では削除手順を書きません
- 職場の管理端末で LINE の通知項目が灰色 → 個人のスイッチでは戻りません。管理者へ

## まとめ

LINE を開くと未読があるなら、通信より **通知の一時停止、そのトークの通知オフ、パソコン版を開いたまま** が先です。一人だけ静かなら全体設定を触らず、そのトークのベルを戻してください。iPhone と Android の残りのスイッチは、LINE の行だけ直して、端末全体の手順はそれぞれの通知記事へ戻ります。
