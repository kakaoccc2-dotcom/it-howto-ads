Wi-Fi を切ると Safari が白い。アンテナは立っているのに「通信環境の良い場所で再度お試しください」。4G / 5G の表示自体が出ない。Wi-Fi のパスワードやSSIDの話は扱いません。そっちは [iPhone の Wi-Fi 手順](/articles/iphone-wifi-cannot-connect/) です。Android は [モバイルデータの手順](/articles/android-mobile-data-not-working/) です。

家族のスマホが同じ場所で使えるなら、この iPhone か SIM です。誰の端末もダメなら、その場所の電波か、契約の障害です。

## 症状の見分け

- 画面上のアンテナは見えるが、すぐ横に **通信環境の良い場所**、または何も読み込めない
- Wi-Fi オフだとアプリが更新されず、オンに戻すと動く
- **設定 → モバイル通信** のスイッチを入れても、すぐオフに戻る
- 通話はできるが、Safari とメールだけ死んでいる
- 自宅ではダメ、外出先では使える（またはその逆）
- eSIM と物理 SIM の両方があり、使いたいほうだけ死んでいる

コントロールセンターの扇アイコンは Wi-Fi です。モバイルデータのオンオフは、**設定 → モバイル通信** で見ます。クイック設定だけで切り分けを終わらせないでください。

## よくある原因

1. 機内モードの残り、または **モバイルデータ通信** がオフ
2. そのアプリだけモバイルデータの使用がオフ
3. 低データモード、通信の制限、または容量超過の速度制限
4. SIM / eSIM の回線が「オフ」、または間違った回線がデフォルト
5. ネットワーク選択が手動のまま、古い事業者名で止まっている
6. VPN、iCloud プライベートリレー、日付のずれで、名前解決だけ失敗している

## 直す前に

- 今つながっている Wi-Fi の名前を控える。あとで戻す用です
- キャリアの障害情報を、別の端末か PC で一度見る
- 「APN自動設定」「通信制限解除」を名乗るアプリは入れない。iPhone の APN はキャリアの構成プロファイルか、公式の案内だけです

> **注意:** 構成プロファイルの削除は、会社や学校のメールも消えることがあります。自分で入れた覚えのないプロファイルは、削除する前に管理者へ。SIM の強制リセットや、非公式の APN 上書きはしないでください。

## 手順

### 1. 機内モードと、モバイルデータ通信を入れ直す

1. **設定** を開き、一番上の **機内モード** が緑ならオフ。コントロールセンターの飛行機アイコンも見る。
2. **設定 → モバイル通信**（機種・iOS によっては **モバイルデータ通信**）で、一番上のスイッチをオンにする。
3. 同じ画面の **モバイルデータ通信** がオンのまま、ステータスバーに **5G** / **4G** / **LTE** が出るか10秒待つ。
4. 機内モードをオン → 15秒待つ → オフ。そのあとモバイルデータをもう一度オン。

ここで 5G / LTE が出て Safari が開くなら、一時的な電波の張りつきです。すぐまた切れるなら手順4です。スイッチが灰色で動かないときは、スクリーンタイムの制限か、構成プロファイルです。

### 2. アプリごとのモバイルデータを確認する

1. **設定 → モバイル通信** を下へスクロールする。アプリの一覧があります。
2. 使いたいアプリ（Safari、LINE、メール）がオフならオンにする。オフのアプリは Wi-Fi のときだけ通信します。
3. 一覧の下の **モバイルデータ通信を使用** がオフのシステムサービスは、触らなくてよいことが多いです。むやみに全部オンにしない。
4. **低データモード** がオンなら、いったんオフにする。写真の自動更新や、バックグラウンドが遅くなる設定です。回線そのものは生きていても、アプリが「ネットなし」に見えることがあります。

Safari だけダメで、別のブラウザや YouTube は動くなら、Safari のモバイルデータか、プライベートリレーです。手順5へ。

### 3. 回線（SIM / eSIM）を正しいほうにする

1. **設定 → モバイル通信** の **SIM** または回線の名前を開く。
2. 使いたい回線が **オン** か見る。デュアル SIM なら **モバイルデータ通信** に使う回線が、契約のあるほうか確認する。音声回線とデータ回線が別々、がよくある取り違えです。
3. eSIM を入れたあと、古い物理 SIM がデータ側のまま残っていることがあります。データに使う回線を、今の契約のほうへ切り替える。
4. 物理 SIM の iPhone なら、電源を切ってトレイを開け、チップの向きと汚れを見る。乾いた布で接点を拭き、カチッと閉めてから電源オン。

SIM なし、無効な SIM、と出るなら、契約と端末の対応です。設定のトグルでは戻りません。キャリアのマイページか店頭です。eSIM の再発行は、公式アプリの案内どおり。ここで変なQRを読み込まないでください。

### 4. ネットワーク選択と、キャリア設定

1. **設定 → モバイル通信 → 通信のオプション → 音声通話とデータ** で、**5G オート** または **4G** を選ぶ。5G のみで圏外になる場所では、4G に落とすと戻ることがあります。
2. 同じ系統の **ネットワーク選択** で **自動** がオフなら、オンに戻す。海外ローミングのあと、古い事業者名で止まっていることがあります。
3. **設定** の一番上、名前の下に **キャリア設定のアップデート** が出ていれば更新する。Wi-Fi につないだ状態で出ることが多いです。
4. まだダメなら **設定 → 一般 → 転送または iPhone をリセット → リセット → ネットワーク設定をリセット**。

> **注意:** ネットワーク設定のリセットは、保存した Wi-Fi パスワード、VPN、APN 相当の構成が消えます。モバイルデータだけ触る操作ではありません。リセットの前に、家の Wi-Fi パスワードを紙で確認してください。

リセット後は再起動し、モバイルデータをオンにしてから、Wi-Fi は後で入れ直します。

### 5. VPN・リレー・日付の取りこぼし

1. **設定 → VPN**（または **一般 → VPNとデバイス管理**）で、接続中の VPN を切る。
2. **設定 → Apple ID → iCloud → プライベートリレー**（場所は iOS の版で少し違う）を、切り分けのあいだオフにする。
3. **設定 → 一般 → 日付と時刻** で **自動的に設定** をオン。日付が未来だと、キャリアの認証に失敗します。
4. 構成プロファイル（**VPNとデバイス管理**）に、自分で入れた覚えのないモバイル用プロファイルがあれば、名前を控えてから削除するかどうかを決める。会社配布なら触らない。

これでも Safari が白いときは、一度 Wi-Fi を完全オフにして、モバイルだけで [接続がプライベートではありません](/articles/browser-connection-not-private/) が出るかも見ます。証明書の警告は、モバイルデータのオンオフとは別件です。

## まだ直らないとき

- 通話もSMSもダメ、アンテナが無い → 電波か SIM。別の場所へ移す。物理SIMなら、対応している別の iPhone に挿して切り分ける。トレイの大きさは機種で違う。eSIM は店頭か公式アプリの再発行で、変なQRは使わない
- スイッチがすぐオフに戻る → 通信プランの容量超過、未払い、回線の一時停止。キャリアのマイページ
- 海外だけダメ → データローミングがオフ。オンにすると料金が跳ねるので、契約の案内を先に読む
- リセットしてもダメ、他の iPhone では同じ SIM が使える → 本体側。正規サービスへ。非公式の「電波改善」は不要です
- スクリーンタイムでモバイルデータが灰色 → **設定 → スクリーンタイム → コンテンツとプライバシー制限 → モバイルデータ通信の変更**

充電が遅くて機内モードに落としているつもりが、機内のまま、という取り違えもあります。電池残量と機内アイコンを同時に見てください。

## まとめ

新しいプロファイルを入れる前に、機内モード、**設定 → モバイル通信** のスイッチ、データに使う回線の3つを見る。Safari だけオフ、もよくあります。ネットワーク設定のリセットは Wi-Fi パスも消えるので、紙に控えてから。
