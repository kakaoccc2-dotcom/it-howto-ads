ノート PC の画面が真っ黒、明るさキーを押しても変化がない、スライダーは動くのに見た目が変わらない、電源は入っているのに内蔵画面だけ何も出ない、という状態は、ブルーライト削減や **夜間モード** の話ではありません。夜間モードは色が少し黄ばむだけで、画面を消したり輝度スライダーを無効にしたりはしません。多いのは **Fn の明るさキー、バッテリー節約、HDR、外部モニターへの投影、グラフィックドライバー** です。

この記事は Windows 10 / 11 のノート内蔵画面を対象にします。外付けモニターが「信号なし」のときは [外付けディスプレイが映らない手順](/articles/external-display-no-signal/) です。メーカーロゴも出ず起動しないときは [スタートアップ修復](/articles/windows-startup-repair/) を先に見てください。

## 症状の見分け

- 電源ランプとファンは動くが、内蔵画面が真っ黒。マウスを動かしても戻らない
- `Win` + `P` や外部モニターでは映るが、本体パネルだけ黒い
- **設定 → システム → ディスプレイ** の明るさスライダーが灰色、または動かしても変化なし
- 画面は点いているが極端に暗く、夜間モードをオフにしても戻らない
- 明るさキー（太陽アイコン）を押すと OSD は出るが、実際の輝度が変わらない
- 動画や白い画面のときだけ急に暗くなる（適応型の明るさ）
- 蓋を閉じて外部だけ使ったあと、蓋を開けても内蔵が戻らない

CapsLock ランプが切り替わる、キーボードは打てる、なら OS は生きていることが多いです。電源ボタンを押してもランプ自体が消えるなら、輝度ではなく電源です。

## よくある原因

1. 明るさキーが **Fn ロック** で別機能になっている、またはメーカーユーティリティが止まっている
2. バッテリーセーバーや「画面の明るさを自動調整」が輝度を下げたまま
3. 投影が **セカンド スクリーンのみ** で、外付けが切れたあとも内蔵がオフ
4. HDR をオンにした結果、SDR のデスクトップが極端に暗く見える
5. コンテンツに応じた明るさ調整（CABC）が、白い画面以外を沈める
6. グラフィックドライバーの失敗。更新直後や、外部出力の抜き差しのあと

## 直す前に

- 夜間モード（**設定 → システム → ディスプレイ** の色温度）はオフでも、真っ暗の原因にはなりません。色が黄色いだけなら夜間モードをオフにする。黒い・輝度が変わらないなら、この先の手順です
- 可能なら HDMI や USB-C で別モニターを一時接続し、内蔵だけが黒いかを切り分ける
- 画面の最大輝度確認は短時間にする。暗い部屋で突然 100% にしない

> **注意:** 「輝度修復」「モニターキャリブレーション一発」を名乗る実行ファイルは不要です。Fn キー、電源、投影、公式ドライバーで足りることがほとんどです。レジストリで輝度を書き換える手順も、家庭向けではありません。

## 手順

### 1. 投影モードとグラフィックの再起動（真っ黒なとき）

内蔵が真っ黒でも、キーボードは反応するときに先に試します。

1. `Windows` キー + `P` を押し、矢印キーで **PC 画面のみ** または **複製** を選び、Enter。外付けを外したあとに **セカンド スクリーンのみ** のままだと、本体は黒いままです。
2. `Windows` キー + `Ctrl` + `Shift` + `B` を押す。画面がごく短く点滅すれば、グラフィックドライバーの再起動が通っています。
3. ノートの蓋を一度閉じ、数秒後に開く。ドックや HDMI を抜いているなら、抜いた状態でやり直す。
4. まだ黒く、外部モニターには出るなら、以降は内蔵パネル側か、ディスプレイ設定です。外部側の入力切替はディスプレイの記事へ。

サインイン画面すらいまの内蔵に出ないが、外部には出る、という組み合わせは、投影モードかパネル接続の切り分けになります。

### 2. 明るさキーとクイック設定を使う

1. キーボードの太陽アイコン（多くは F5 / F6 やファンクション列）を、必要なら **Fn と同時** に押す。Fn ロックが逆だと、明るさのつもりが音量やAirplane になります。
2. `Windows` キー + `A` でクイック設定を開き、明るさスライダーを中央より少し上へ動かす。
3. **設定** → **システム** → **ディスプレイ** で、**明るさ** が動かせるか見る。デスクトップ PC や一部の外部モニター接続中は、スライダー自体が無い／灰色です。その場合はモニター本体のボタンで輝度を変えます。
4. Lenovo Vantage、Dell のクイック設定、HP のサポートアプリなど、メーカーのOSDが別にある機種は、そちらの輝度も 0 になっていないか見る。

スライダーは動くのに見た目が変わらないときは、手順3の自動調整と HDR です。

### 3. バッテリー節約・自動明るさ・HDR を切る

1. **設定** → **システム** → **電源とバッテリー**。**バッテリーセーバー** がオンならオフにする。同じ画面に「バッテリーセーバーでは画面の明るさを下げる」があればオフ。
2. **設定** → **システム** → **ディスプレイ**。**周囲の明るさに合わせて明るさを変更する**（機種により文言が少し違います）をオフにする。
3. 同じディスプレイ画面で、**表示されるコンテンツと明るさを最適化してバッテリーを改善する**（コンテンツ適応型）があればオフ。白いウィンドウのときだけ明るく、ほかが沈む症状に効きます。
4. **HDR** をオンにしている場合はいったんオフにする。対応しきれていないパネルや HDMI 機器で、デスクトップだけ真っ黒に近いことがあります。ゲームの HDR だけ残したい場合は、Windows の HDR をオフにしてから、アプリ側を見ます。

電源ケーブルを挿しても暗いときは、バッテリーセーバーが「常にオン」になっていないか確認します。

### 4. ディスプレイドライバーを入れ直す

1. スタートを右クリック → **デバイス マネージャー** → **ディスプレイ アダプター** と **モニター**。
2. モニターの「汎用モニター」やメーカー名を右クリック → **デバイスを無効にする** → 10秒 → **有効にする**。
3. アダプター（Intel / AMD / NVIDIA）を右クリック → **プロパティ** → **ドライバー**。更新の直後から暗い・真っ黒なら **ロールバック** が使えることがあります。
4. 改善しなければアダプターの **デバイスのアンインストール**（ドライバー ソフトウェアも削除できるときはチェック）。再起動後、Windows が基本ドライバーを入れ直します。そのあと PC メーカーまたは GPU メーカーの公式ドライバーを入れます。

更新そのものが途中で止まってドライバーだけ中途半端なときは、[Windows Update が進まないとき](/articles/windows-update-stuck/) もあわせて見てください。

### 5. 画面のタイムアウトと、暗いだけに見える設定

真っ黒ではなく「すぐ消える」「常に暗い」ときです。

1. **設定** → **システム** → **電源とバッテリー** → **画面とスリープ**。画面をオフにするまでの時間を、確認中だけ長めにする。
2. ディスプレイの **夜間モード** は色温度だけです。オフにして色が戻っても明るさは別問題、と切り分けてください。
3. テーマやダークモードは背景が黒いだけで、バックライトは生きています。スライダーが無反応なときとは別です。
4. 外部モニターを常用しているなら、内蔵の明るさキーが外部側を触っていることがあります。内蔵を触りたいときは `Win` + `P` で **複製** にし、設定のディスプレイで内蔵パネルを選んでからスライダーを動かします。

## まだ直らないとき

- 外部には映るが内蔵が常に黒、バックライトの光も全く無い → ケーブルやパネル側の可能性があります。保証内なら、投影を **PC 画面のみ** にした結果と、`Win` + `Ctrl` + `Shift` + `B` の可否を添えてメーカーへ。分解はしない
- スライダーが灰色のまま（ノートなのに） → メーカーのホットキードライバー不足が多いです。サポートページのチップセット／ホットキー／ME を入れる。汎用の「輝度ツール」は不要です
- 動画再生中だけ暗くなる → 手順3のコンテンツ適応型。GPU の省電力も疑うので、公式グラフィック設定の省電力を標準に戻す
- 起動ロゴは見えるが、Windows のサインイン以降だけ黒い → OS 側。セーフモードで内蔵が出るか見る。修復画面になるならスタートアップ修復の記事へ
- 画面は点くがタッチやペンだけおかしい → 輝度ではなくデジタイザです。この記事の対象外です

カメラのプレビューが黒いだけのときは、画面ではなく [カメラが使えない手順](/articles/windows-camera-not-working/) です。

## まとめ

真っ暗や輝度が変わらないときは、夜間モードをいじる前に **投影（Win+P）、明るさキー、バッテリーセーバー、HDR、公式ドライバー** を順に見ます。外部だけ映るなら内蔵パネルか投影の取り残し、スライダーが灰色ならホットキー用ドライバーです。出自不明の修復ツールより、標準設定のほうが切り分けしやすいです。
