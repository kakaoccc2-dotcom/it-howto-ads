アイコンを押した瞬間にホームへ戻る。「○○は繰り返し停止しています」と出て、閉じるしかない。更新した翌日だけそのアプリが起動しない。こういった強制終了は、端末の故障より **キャッシュ、空き容量、そのアプリか WebView の古さ、開発者向けオプションの設定** が多いです。Play ストアのボタンが保留のまま進まないときは [ダウンロードできない手順](/articles/android-play-store-wont-download/) です。

## 症状の見分け

- 起動して一秒以内に「停止しました」「繰り返し停止しています」と出る
- 操作の途中、特定の画面（ログインの次、カメラ、支払い）だけ落ちる
- そのアプリだけ落ちて、電話も設定も普通に開く
- 画面を切り替えるたびに最初から開き直す。ダイアログは出ない
- 本体が熱い、充電しながらゲームや動画のときだけ落ちる
- 空き容量の警告が出たあとから、いくつものアプリが起動に失敗する
- ブラウザから入れたアプリだけ落ち、ストアのアプリは無事

ダイアログも出ずに、しばらく置くと裏で消えているだけなら、落ちたのではなく省電力で止まっています。通知が遅れるときと同じ電池側です。[通知が来ない・遅れる手順](/articles/android-notifications-delayed/) のバッテリーの項を見てください。

## よくある原因

1. そのアプリのキャッシュが壊れて、起動のたびに同じ場所で落ちる
2. 本体の空きが少なく、更新の展開や起動に失敗する
3. アプリ本体、または中でページを描く **Android システム WebView** と Chrome が古い
4. **開発者向けオプション** の「アクティビティを保持しない」がオン。画面を離れるたびに終了する
5. ストア以外から入れた版と、公式の更新が食い違っている
6. 熱。ケースをしたまま充電しながら重いアプリを開いている
7. そのアプリの更新そのものの不具合。他の端末でも同じ版で落ちている

## 直す前に

- 落ちるアプリを一つに決める。設定も電話も全部落ちるときと、地図だけ落ちるときでは、次が違います
- **キャッシュを削除** と **データを削除**（ストレージを消去）は別です。データ削除はログインやダウンロードが消えます。先に押さない
- ブラウザの宣伝から「落ちないようにする」アプリや、拡張子が apk のファイルは入れない

> **注意:** ルート化、提供元不明の apk の入れ直し、リカバリからの初期化はしません。初期化は写真と認証アプリが消えます。設定や電話まで落ちるときは、消す前に写真を移してから販売店へ持っていきます。

## 手順

### 1. 名前を見て、再起動する

1. ダイアログに出たアプリ名を読む。見ているアプリと違う名前（システム UI、Android システム）なら、その一つのキャッシュでは終わりません。手順2の空きと、再起動を先にします。
2. 電源を切り、数十秒置いてから入れる。起動後、落ちていたアプリを一度だけ開く。
3. 一回の再起動でダイアログが消えたなら、その日は入れ直しまで進まない。同じ日に三度出るなら、次へ進みます。

再起動の直後だけ動いて、半日でまた落ちるときは、熱か空き容量が残っています。

### 2. 空き容量を空ける

1. **設定 → ストレージ**（機種によっては **デバイスのケア** や **バッテリーとデバイスケア** の中）を開く。
2. 空きが **1GB を切っている**、またはバーが赤いときは、起動に失敗しやすいです。カメラの大きな動画、ダウンロードフォルダ、使っていない動画アプリのオフライン保存から移すか削除する。
3. 「クリーナー」「メモリ解放」を名乗るアプリは入れない。表示されている不要ファイルのうち、自分で撮った写真の一覧は、消す前に中身を見る。
4. 空きが数GBあるのにそのアプリだけ落ちるなら、容量が原因ではありません。手順3へ。

ストアの更新が空き不足で失敗しているときは、Play ストアの記事と重なります。先に空きを作ってから更新です。

### 3. キャッシュだけ消して、開き直す

1. **設定 → アプリ**（**アプリと通知 → アプリ情報** の機種もある）→ 落ちるアプリ。
2. **ストレージとキャッシュ**（または **ストレージ**）を開く。
3. **キャッシュを削除** を押す。隣の **データを削除** や **ストレージを消去** は押さない。
4. ホームに戻り、そのアプリを開く。同じダイアログがすぐ出るか見る。

キャッシュ削除では、ログインや履歴は残る機種がほとんどです。パスワードを聞かれず、ダイアログも出ないなら、壊れていたのはキャッシュです。同じダイアログがすぐ出るなら手順4です。

### 4. アプリと WebView を、ストアから更新する

ショッピングや銀行、一部のゲームは、中身の表示に WebView を使います。本体が古いままだと、その系統だけまとめて落ちます。

1. Play ストアで、落ちるアプリのページを開き、**更新** があれば入れる。ボタンが **開く** なら、そのアプリは最新です。
2. ストアの検索で **Android システム WebView** を開き、更新があれば入れる。**無効** とだけ出て更新ボタンが無い端末は、そのままにします。無理に有効へ戻さない。
3. 同じように **Google Chrome** の更新も入れる。WebView が無効の端末は、Chrome 側がページ表示を担っていることがあります。
4. 更新後、端末をもう一度起動し、落ちていたアプリを開く。

ストアが保留のまま、エラーで何も入らないときは、この先の入れ直しより [Play ストアの手順](/articles/android-play-store-wont-download/) が先です。

### 5. 開発者向けオプションが入っているときだけ見る

普通に使っていて **開発者向けオプション** という項目が設定に無い人は、この手順は飛ばします。ビルド番号を連打して、新しく出さないでください。

1. **設定** の検索に「開発者」と入れる。または **設定 → システム → 開発者向けオプション**。
2. **アクティビティを保持しない** がオンならオフ。オンだと、他のアプリへ移るたびに今のアプリが終了し、強制終了したように見えます。ダイアログは出ません。
3. **バックグラウンド プロセスの制限** が「プロセスを使用しない」など極端な値なら、**標準の制限** に戻す。
4. 使い道が自分で分からないときは、開発者向けオプションの一番上のスイッチをオフに戻して、アプリを開き直す。

オフにしたあと、画面を切り替えてもそのアプリが残るなら、落ちたのではなくこの設定でした。

### 6. 公式の版だけ入れ直す

キャッシュと更新でも同じダイアログが出るときです。中のデータは消えます。

1. チャットやゲームは、引き継ぎやバックアップの方法が公式のヘルプにあるか先に読む。認証アプリは、消し方を間違えるとログインできなくなります。
2. **設定 → アプリ → 対象アプリ**。**アップデートをアンインストール** と出るプリインストールアプリは、それを押すと工場出荷の版に戻る。戻ったあとストアで通常の更新をかけ、起動するか見る。
3. 普通のアプリは **アンインストール** してから、Play ストアの同じページから入れ直す。ブラウザのダウンロードから入れない。
4. アイコンが二つある、ストアに無い版を前に入れている、ならその方を削除する。提供元不明のアプリを残したまま公式を重ねない。

> **注意:** 「データを削除」はキャッシュ削除の隣にあります。ログイン、オフラインのファイル、アプリ内の設定が消えます。手順3と押し間違えないでください。

熱いときにだけ落ちるなら、ケースを外し、充電ケーブルを抜いて数分置く。充電口が熱い、すぐ電池が減る、は [充電が遅いときの切り分け](/articles/smartphone-charging-slow/) です。熱いまま更新と入れ直しを繰り返さないでください。

## まだ直らないとき

- セーフモードだと落ちない → あとから入れたクリーナー、重複したセキュリティ、画面に重なるツールを疑う。セーフモードのボタン操作は機種で違うので、メーカーの案内に従う。通常起動に戻して、そのアプリをアンインストールする
- 設定アプリや電話まで「繰り返し停止」 → 個別のキャッシュでは足りません。空きと再起動のあと、まだ全部落ちるなら初期化の前に写真を退避し、購入店かメーカーへ
- カメラを開く画面だけ落ちる → そのアプリの権限。**設定 → アプリ → 対象 → 権限** でカメラが拒否になっていないか見る。レンズが真っ黒なだけで落ちないなら、権限とは別です
- 家族の同じアプリ、同じ版でも落ちる → アプリ側の不具合です。非公式の古い apk へ戻さない。ストアの更新を待つか、公式の問い合わせへ
- 職場の仕事用プロファイルの中だけ落ちる → 個人側のキャッシュでは終わりません。管理者に、落ちるアプリ名とダイアログの文面を渡す

## まとめ

ダイアログに出た名前のアプリを、再起動、空き、キャッシュ削除、ストアの更新の順で見ます。データ削除と、ストア以外からの入れ直しは先に使いません。画面を離れるたびに消えるだけでダイアログが無いなら、「アクティビティを保持しない」がオンのままです。
