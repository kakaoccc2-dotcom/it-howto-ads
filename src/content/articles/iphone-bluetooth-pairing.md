片方の耳だけ鳴る、数秒で切れる、なら古い登録が残っていないかを先に見てください。アイコンが青くても、状態は設定アプリの Bluetooth 一覧で確認します。

## 症状の見分け

- 設定の Bluetooth に機器名が出ない、または「接続していません」のまま
- 音楽だけ / 通話だけ切れる
- iOS 更新のあとから不安定
- 他のスマホではそのイヤホンが普通に使える
- 「その他のデバイス」に名前は出るが、タップするとくるくるして失敗
- つながった表示のまま、音は iPhone のスピーカーから出る

他のスマホでもダメなら、イヤホン本体の充電とリセットを先に見てください。Android 側で途切れるだけの話は [Android のイヤホンが途切れるとき](/articles/android-bluetooth-earbuds-cutting-out/) です。

## よくある原因

1. コントロールセンターでは Bluetooth がオンに見えて、実際の機器接続は切れている
2. 以前のペアリング情報が iPhone と機器の双方に残り、再認証に失敗している
3. 別の端末（Android や古い iPad）に接続したままになっている
4. 低電力モード、機内モードの名残、ケースにしまっていない AirPods の検出ミス
5. 車載器やテレビ側が「1台だけ記憶」で、新しい iPhone に切り替わっていない

Wi-Fi と Bluetooth は帯域が近いので、電子レンジの近くや、USB 3.0 ハブだらけの机では切れやすくなることもあります。ソフト側を片付けてから、置き場所を疑います。

## 直す前に

- イヤホンやキーボードの充電残量を確認する（ケースのランプが赤いときは充電）
- 取扱説明の「ペアリングモード」の入れ方（数秒長押し、ランプが点滅）を見ておく
- 車の場合は、エンジンをかけた状態で操作する（アクセサリ電源だけだと失敗する車種があります）

> **注意:** すぐ「ネットワーク設定をリセット」すると、Wi-Fi パスワードも消えます。この記事では最後の手段に置いてあります。

## 手順

### 1. コントロールセンターではなく、設定アプリで見る

1. **設定** → **Bluetooth** を開く。
2. トグルが緑（オン）か確認する。オフならオンにする。
3. 画面を閉じず、この一覧を出したまま次へ進む。

コントロールセンターの Bluetooth アイコンは、接続を一時的に切る操作にも使われます。アイコンが青いからつながっている、とは限りません。機器との状態は、この設定画面の名前の下（接続済み / 接続していません）を正とします。

**ここで失敗したとき:** トグルをオンにしてもすぐオフに戻るときは、機内モードが残っています。コントロールセンターで飛行機アイコンをオフにしてから、もう一度 **設定 → Bluetooth** を開いてください。オンなのに一覧が「検索中」のまま名前が出ないなら、相手がペアリングモードに入っていません。ランプが点滅するまで、機器側のボタンを押し直してください。

### 2. 相手機器をペアリングモードにする

1. イヤホンならケースを開け、説明どおりにボタンを長押ししてランプを点滅させる。
2. キーボードなら電源オンのあと、Bluetooth ボタンを長押し。
3. 車なら、車側の「電話」や「Bluetooth」メニューから **機器の登録** を開始する。

iPhone の「自分のデバイス」に古い名前がある状態で、機器側だけ新しいペアリングに入ると失敗しやすいです。下で古い登録を消してから、このモードに入れてください。

**ここで失敗したとき:** ランプが点滅せず点灯のままなら、すでに別のスマホへつながっています。そのスマホの Bluetooth をオフにしてから、もう一度長押しします。車の画面が「接続中」で止まったまま進まないときは、車側の登録を一度キャンセルし、iPhone の登録解除が終わってからやり直してください。エンジンを切った状態だと、ここで失敗しやすいです。

### 3. iPhone 側の登録を解除する

1. **設定** → **Bluetooth**。
2. 問題の機器名の右の **i** をタップ。
3. **このデバイスの登録を解除**。
4. 相手機器側でも、記憶している iPhone を削除する（車載器は「削除」「初期化」などの名称）。
5. 両方消えたことを確認してから、機器をペアリングモードにし、iPhone の「その他のデバイス」に出たら名前をタップする。

AirPods の場合、近くに別の Apple ID の iPhone / Mac があると、意図しないほうに吸い寄せられることがあります。作業中は他の Apple 機器の Bluetooth をオフにすると楽です。

**ここで失敗したとき:** **i** を押しても「このデバイスの登録を解除」が無い、名前が灰色、ならその行は今つながっていない古い表示です。一度画面を戻り、Bluetooth をオフ→オンしてから同じ名前を開き直してください。解除したのに「自分のデバイス」へすぐ戻るときは、相手側がまだ iPhone を覚えています。機器側の削除が先です。タップしたあと「接続できませんでした」なら、両方の登録が残ったままです。手順3の 3 と 4 を、名前が両方の一覧から消えるまでやり直します。

### 4. iPhone と機器を再起動する

1. 機器の充電ケースを閉じる、または電源オフ。
2. iPhone を再起動する。
3. 起動後、先に **設定 → Bluetooth** を開き、そのあと機器の電源 / ケースを開ける。

「先に iPhone の Bluetooth 画面を開く」だけで安定することがあります。

**ここで失敗したとき:** 再起動後にステータスバーへ機内モードが戻っているなら、再起動の途中でスイッチが戻っただけです。オフにしてから手順3をやり直してください。ケースを開けても「その他のデバイス」に出ない AirPods は、フタのセンサーがケースのゴミやフィルムで反応していないことがあります。フィルムを剥がし、両方のイヤホンが充電ランプを出すか見てください。

### 5. まだ不安定なら、iPhone のネットワーク設定リセット（最終）

Wi-Fi も同時に不調、または iOS 更新のあとに無線全般がおかしいときに限ります。

1. **設定** → **一般** → **転送または iPhone をリセット** → **リセット**。
2. **ネットワーク設定をリセット**（すべての設定をリセット、ではない）。
3. 再起動後、Wi-Fi を入れ直し、Bluetooth 機器を手順3から登録し直す。

Android の無線切り分けは [Wi-Fi に繋がらないとき](/articles/android-wifi-cannot-connect/) を見てください。同じイヤホンやマウスが Windows でも切れるなら、[Windows の Bluetooth 手順](/articles/windows-bluetooth-cannot-connect/) です。iPhone のテザリングと同時に切れるときは [インターネット共有が使えないとき](/articles/iphone-personal-hotspot-not-working/) も見てください。

**ここで失敗したとき:** 「すべての設定をリセット」や「iPhone を消去」を押さないでください。ネットワーク設定のリセットのあと、Wi-Fi パスワードは消えます。Bluetooth だけ直れば成功です。リセット後も同じ名前が「自分のデバイス」に残っているなら、リセット前の解除が終わっていません。手順3からやり直します。

## イヤホン・車・キーボードで見る場所が違う

- イヤホン: ケースのランプと、iPhone の「接続済み」。音だけ iPhone のスピーカーから出るなら、コントロールセンターの再生先（三角のマーク）が iPhone のままです。AirPlay の行き先をイヤホン名に変えてください
- 車: 電話帳は出るが音楽が車のスピーカーに行かない、またはその逆、ならプロファイルの片方だけです。車側で「オーディオ」と「ハンズフリー」の両方がオンか見てください。iPhone を買い替えたあとは、古い iPhone の名前が車に残っていることが多いです
- キーボード: 文字は出るが、日本語が英数のままなら Bluetooth はつながっています。入力は [Windows 側の日本語入力](/articles/windows-ime-japanese-input/) とは別で、iPhone は地球儀キーか **設定 → 一般 → キーボード** です。ペアリングをやり直しても配列は変わりません

## まだ直らないとき

- 片方の AirPods だけ鳴らない → ケースに両方入れてフタを閉じ、30秒待ってから開き、接続先を選び直す。片側だけ充電ランプが点かないなら、接点の汚れか本体側です。設定では戻りません
- 通話だけ切れる → **設定 → Bluetooth → 機器の i** で「iPhone を使用」がオンか見る（機種により表示がありません）。コントロールセンターのマイクが別アプリに取られていないかも見ます
- 車だけダメ → 車側の対応プロファイル（Hands-Free / Audio）と、iPhone の機内モードの名残を確認する。自宅のイヤホンは安定、車だけ失敗、なら iPhone のリセットより車の登録削除が先です
- 低電力モードのあいだだけ切れる → **設定 → バッテリー** の低電力をオフにして、同じ機器でもう一度つなぐ。直るなら電池設定であって、ペアリング情報ではありません
- 修理・保証期間内の純正品なら、機器側の故障（充電接点、片耳の基盤）も疑う。ソフトウェア手順を一通り試した記録があるとサポートが早いです。iPhone の初期化は、この記事では使いません

## まとめ

設定アプリで登録を解除し、相手側の記憶も消してからつなぎ直してください。ネットワーク設定のリセットは、Wi-Fi 情報も消えるので最後です。
