iPhone でイヤホンやキーボード、車載オーディオの Bluetooth が「接続済み」にならない、接続しても数秒で切れる、片方の耳だけ鳴る、といった不調は、ケーブル不良より **古いペアリング情報が残っている**ことが多いです。iOS の Bluetooth は、コントロールセンターのアイコンと、設定アプリの一覧で意味が少し違います。

この記事では、AirPods 系とそれ以外の機器が混在していても使える順番にしています。

## 症状の見分け

- 設定の Bluetooth 画面に機器名が出ない
- 出ているが、タップしても「接続していません」のまま
- 接続できても、音楽だけ / 通話だけ切れる
- 昨日まで問題なかったのに、iOS の更新後から不安定
- 他のスマホではそのイヤホンが普通に使える

他のスマホでもダメなら、イヤホン本体の充電・リセットを先に見てください。iPhone だけダメなら、以下の iPhone 側が中心です。

## よくある原因

1. コントロールセンターでは Bluetooth がオンに見えて、実際の機器接続は切れている
2. 以前のペアリング情報が iPhone と機器の双方に残り、再認証に失敗している
3. 別の端末（Android や古い iPad）に接続したままになっている
4. 低電力モード、機内モードの名残、ケースにしまっていない AirPods の検出ミス
5. 車載器やテレビ側が「1台だけ記憶」で、新しい iPhone に切り替わっていない

Wi-Fi と Bluetooth は帯域が近いので、電子レンジの近くや、USB 3.0 ハブだらけの机では切れやすくなることもあります。まずはソフトウェア側を片付けます。

## 直す前に

- イヤホンやキーボードの充電残量を確認する（ケースのランプが赤いときは充電）
- 取扱説明の「ペアリングモード」の入れ方（数秒長押し、ランプが点滅）を見ておく
- 車の場合は、エンジンをかけた状態で操作する（アクセサリ電源だけだと失敗する車種があります）

> **注意:** すぐ「ネットワーク設定をリセット」すると、Wi-Fi パスワードも消えます。この記事では最後の手段に置いてあります。

## 手順

### 1. コントロールセンターではなく、設定アプリで見る

1. **設定** → **Bluetooth** を開く。
2. トグルが緑（オン）か確認する。オフならオンにする。
3. 画面を閉じず、この一覧を出したまま次へ進む。

コントロールセンターの Bluetooth アイコンは、接続を一時的に切る操作にも使われます。「アイコンが青だから繋がっている」とは限りません。機器との接続状態は、この設定画面の名前の下（接続済み / 接続していません）を正とします。

### 2. 相手機器をペアリングモードにする

1. イヤホンならケースを開け、説明どおりにボタンを長押ししてランプを点滅させる。
2. キーボードなら電源オンのあと、Bluetooth ボタンを長押し。
3. 車なら、車側の「電話」や「Bluetooth」メニューから **機器の登録** を開始する。

iPhone の「自分のデバイス」に古い名前がある状態で、機器側だけ新しいペアリングに入ると失敗しやすいです。次の手順で古い登録を消してから、このモードに入れてください。

### 3. iPhone 側の登録を解除する

1. **設定** → **Bluetooth**。
2. 問題の機器名の右の **i** をタップ。
3. **このデバイスの登録を解除**。
4. 相手機器側でも、記憶している iPhone を削除する（車載器は「削除」「初期化」などの名称）。
5. 両方消えたことを確認してから、機器をペアリングモードにし、iPhone の「その他のデバイス」に出たら名前をタップする。

AirPods の場合、近くに別の Apple ID の iPhone / Mac があると、意図しないほうに吸い寄せられることがあります。作業中は他の Apple 機器の Bluetooth をオフにすると楽です。

### 4. iPhone と機器を再起動する

1. 機器の充電ケースを閉じる、または電源オフ。
2. iPhone を再起動する。
3. 起動後、先に **設定 → Bluetooth** を開き、そのあと機器の電源 / ケースを開ける。

「先に iPhone の Bluetooth 画面を開く」だけで安定することがあります。

### 5. まだ不安定なら、iPhone のネットワーク設定リセット（最終）

Wi-Fi も同時に不調、または iOS 更新のあとに無線全般がおかしいときに限ります。

1. **設定** → **一般** → **転送または iPhone をリセット** → **リセット**。
2. **ネットワーク設定をリセット**（すべての設定をリセット、ではない）。
3. 再起動後、Wi-Fi を入れ直し、Bluetooth 機器を手順3から登録し直す。

Android の無線切り分けは [Wi-Fi に繋がらないとき](/articles/android-wifi-cannot-connect/) を見てください。キーボードやヘッドセットが PC 側でも切れるなら、[周辺機器カテゴリ](/categories/peripherals/) の接続記事もあわせてどうぞ。

## まだ直らないとき

- 片方の AirPods だけ鳴らない → ケースに両方入れてフタを閉じ、30秒待ってから開き、接続先を選び直す
- 通話だけ切れる → **設定 → Bluetooth → 機器の i** で「iPhone を使用」がオンか見る（機種により表示がありません）
- 車だけダメ → 車側の対応プロファイル（Hands-Free / Audio）と、iPhone の機内モードの名残を確認する
- 修理・保証期間内の純正品なら、機器側の故障（充電接点、片耳の基盤）も疑う。ソフトウェア手順を一通り試した記録があるとサポートが早いです

## まとめ

Bluetooth は「オンなのに繋がらない」より、**古い登録が双方に残っている**ことが多いです。設定アプリの一覧で登録解除し、機器側の記憶も消し、ペアリングモードに入れてからつなぐ。リセットは Wi-Fi 情報も消えるので最後、という順が安全です。
